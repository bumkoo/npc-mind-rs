## 2. 개선 기법 상세

### 2.1 샘플러 체인

```
  입력 토큰 (logits)
       │
       ▼
  ┌─────────────────────────────────┐
  │  DRY Sampler                    │  ← 시퀀스 수준 반복 억제
  │  multiplier=0.8, base=1.75     │     "같은 의미의 다른 표현" 패턴 감지
  │  allowed_length=2, last_n=-1   │     전체 컨텍스트 대상
  │  breakers: \n, :, ", *         │
  └──────────────┬──────────────────┘
                 │
                 ▼
  ┌─────────────────────────────────┐
  │  Penalties                      │  ← 토큰 수준 반복 억제
  │  last_n=64, penalty=1.10       │     최근 64토큰 내 반복 감시
  │  freq=0.05, presence=0.05      │
  └──────────────┬──────────────────┘
                 │
                 ▼
  ┌─────────────────────────────────┐
  │  Top-K (40) → Top-P (0.95)     │  ← 후보 필터링
  │  → Temperature (0.7) → Dist    │  ← 확률 조정 → 최종 선택
  └──────────────┬──────────────────┘
                 │
                 ▼
  ┌─────────────────────────────────┐
  │  한국어 필터 (후처리)            │  ← 비한국어 토큰 무음 차단
  │  허용: 한글, ASCII, 특수문자    │     filtered_count 기록
  └─────────────────────────────────┘
```

### 2.2 DRY vs Penalties 역할 분담

```
  DRY (시퀀스 수준)                  Penalties (토큰 수준)
  ─────────────────                  ────────────────────
  "정보가 필요하면 대가를 치러야 해"   "해" 토큰 빈출 억제
  "정보를 원하면 대가가 필요해"        "정보" 토큰 빈출 억제
       ↑                                  ↑
  같은 패턴, 다른 토큰 → DRY가 감지   같은 토큰 반복 → Penalties가 감지
```

### 2.3 슬라이딩 윈도우 구조

```
  96턴 대화 (day-size=24, window-days=2)

  ┌─────────────────────────────────────────────────┐
  │ 시스템 프롬프트 (고정, ~210 토큰)                │
  ├─────────────────────────────────────────────────┤
  │ Day 1 요약 (LLM 생성, ~60 토큰)                 │  ← 원본 24턴 → 2~3문장 요약
  │ Day 2 요약 (LLM 생성, ~60 토큰)                 │  ← 원본 24턴 → 2~3문장 요약
  ├─────────────────────────────────────────────────┤
  │ Day 3 원본 대화 (24턴, ~2400 토큰)               │  ← window-days 이내: 원본 유지
  │ Day 4 원본 대화 (현재 진행중)                     │  ← 현재 Day: 원본 유지
  └─────────────────────────────────────────────────┘

  요약 생성 프로세스:
  ┌──────────┐    ┌────────────────┐    ┌──────────┐
  │ Day N의   │───→│ 별도 컨텍스트에서│───→│ 2~3문장  │
  │ 24턴 원본 │    │ LLM 요약 생성   │    │ 요약 결과 │
  └──────────┘    └────────────────┘    └──────────┘
                   temp=0.5, max=100tok
                   ~2.5초/Day 소요
```

### 4.3 반복 표현 분석

Step 2 대비 **구조적 반복은 크게 감소**했으나, 접속 표현의 반복은 잔존:

| 표현 | 출현 횟수 | 평가 |
|------|:---------:|------|
| "그리고..." | ~60회 | 한국어 구어체에서 자연스러운 빈도이나, 96턴 기준 과다 |
| "네 안에 있는" | ~15회 | DRY가 억제했으나 변형 패턴 잔존 |
| "기억해" | ~12회 | 소연 캐릭터 특성으로 일부 허용 가능 |
| "눈을 가늘게 뜨며" | ~12회 | 행동 묘사 레퍼토리 부족 |
| "미소를 짓지 않고" | ~11회 | 동일 |

> **참고**: "그리고..."는 한국어 대화체에서 접속 표현으로 높은 사용 빈도를 보이므로,
> 단순 횟수만으로 문제라 단정하기 어렵다. 다만 96턴 중 60회(62.5%)는
> 과도한 수준이며, 프롬프트에서 "같은 접속사를 3턴 연속 사용하지 마" 등의
> 지시로 분산시키는 것이 자연스럽다.
