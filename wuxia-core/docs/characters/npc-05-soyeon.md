### 이름의 뜻

```
素 (소) = 흰, 꾸미지 않은, 본래의
燕 (연) = 제비

"꾸미지 않은 제비" — 빠르고 자유로우나, 꾸밈이 없는 존재.

  素(소)의 이중성:
  ① 순수하다 → 11세 이전의 소연. 이름이 간직한 원래의 자기.
  ② 꾸미지 않았다 → 아무것도 가지지 못한 아이. 빈손으로 시작한 삶.
  ③ 흰 천 → 장례 때 두르는 흰 천.
     → v1.1: 사부가 살아있으므로, 흰 천은 "학살당한 개방 동료들"을 가리킴.
        소연의 사부는 살았지만, 그날 죽은 개방 형제들은 많다.

  燕(연)의 이중성:
  ① 제비 → 빠르다. 연비신법(燕飛身法)의 근거.
  ② 제비 → 봄에 오고 가을에 떠난다. 한곳에 머물지 않는 사람.
  ③ 연(燕)나라 → 형가가 진시황을 암살하러 떠난 나라.

  별호 천이(千耳):
  개방의 "천이통(千耳通)" 기예에서 유래.
  사부 소풍자가 직접 지어준 별호.
  → 초대 방주 천리안(千里眼)과 대구(對句):
     "눈이 천 리를 보았으니, 귀도 천 리를 들어야지."
  → 개방 정통 계보임을 나타내는 이름.

  아이러니:
  "꾸미지 않은 제비"가 거짓말과 변장으로 정보를 모으는 정보상.
  사부는 "솔직하게 살아라"고 가르쳤지만,
  소연은 솔직해지면 살 수 없는 세상에 있다.
  → 사부의 가르침과 현실의 괴리.
```

#### ① 연비신법 (燕飛身法) — 경공

```
이름: 燕(제비) + 飛(날다) + 身法(몸놀림)
계열: 경공 — 도주·잠입·추격·정찰
전승: 개방 정식 제자에게만 전수

  핵심 원리:
  "무겁면 잡힌다. 가벼우면 산다."
  ─────────────────────────────────
  · 지붕 위를 달린다 (屋上疾走)
  · 벽을 타고 오른다 (壁行)
  · 좁은 골목을 빠져나간다 (穿巷)
  · 군중 속에서 사라진다 (人海消隱)

  5단계 숙련도:
  1단 — 비연(飛燕): 달리기보다 빠른 수준
  2단 — 순연(旬燕): 지붕 3채를 연속으로 뛸 수 있음
  3단 — 경연(輕燕): 벽을 3보까지 타고 오를 수 있음
  4단 — 허연(虛燕): 발소리 없이 이동 가능
  5단 — 무연(霧燕): 눈앞에서 사라지는 수준 (방주급)

  소연의 숙련도: 3단 ~ 4단 사이 (경연~허연)
  → 개방 동세대 제자 중 최고. 사부도 인정.
  → "이 아이의 발은 제비가 아니라 바람이다." (소풍자)
  → 그러나 내공 35의 한계: 장시간 유지 불가, 폭발적 단거리 특화

  게임 메카닉 연동:
  · 전투 도주 성공률 높음 (무력 45지만 도주는 경공 78로 판정)
  · 잠입 퀘스트 경공 체크 통과
  · 추격전 이벤트에서 소연 동행 시 성공률 +30%
  · 내공 35 → 경공 연속 사용 3회 제한 (피로 급상승)

  사부 소풍자와의 비교:
  소풍자: 4단(허연). 나이 들어 체력 하락, 내공으로 보완.
  소연:   3~4단. 젊은 체력, 그러나 내공 부족. 순수 신체 능력 의존.
  → 스승과 제자가 같은 기예의 다른 단계에 있는 것.
```

#### ② 천이통 (千耳通) — 정보 수집술

```
이름: 千(천) + 耳(귀) + 通(통하다)
계열: 정보 — 정보원 구축·운영·분석
전승: 개방 정식 제자에게만 전수

  핵심 원리:
  "한 사람의 귀로는 부족하다. 천 명의 귀를 빌려라."
  ─────────────────────────────────
  · 정보원 포섭 (人脈布置)
  · 은어 체계 운용 (丐語)
  · 독화술 — 입술 읽기 (讀話術)
  · 정보 교차 검증 (三源驗證)
  · 암호 전달 — 거지 표식 (丐標)

  천이통의 구조:
  ┌──────────────┐
  │ 1층: 탐지    │  "누가, 어디서, 무엇을 했는가"
  │ (거지·행인)  │  → 소연의 정보원 수십 명이 수집
  ├──────────────┤
  │ 2층: 분석    │  "왜 했는가, 다음에 무엇을 할 것인가"
  │ (소연 본인)  │  → 교차 검증 후 판단. 책략 88의 영역.
  ├──────────────┤
  │ 3층: 전달    │  "누구에게, 어떤 형태로 전할 것인가"
  │ (개방 암호)  │  → 개어(丐語)와 거지 표식으로 은밀하게
  └──────────────┘

  소연의 숙련도: 상위급
  → 자유도시 정보망의 40%를 소연이 직접 운영
  → 사부 소풍자도 "천이통만큼은 나보다 낫다"고 인정
  → 별호 "천이(千耳)"가 이 기예에서 유래

  게임 메카닉 연동:
  · 정보 거래 시스템의 핵심 NPC
  · 지역 이벤트 사전 감지 (천이통 경보)
  · NPC 비밀 정보 해금 (호감도 + 정보 거래 조합)
  · 적 이동 경로 사전 파악 (전투 준비 보너스)
```

#### ③ 풍진수 (風塵手) — 잡기/호신술 ← **v1.1 신규 추가**

```
이름: 風(바람) + 塵(먼지) + 手(손)
계열: 잡기/호신술 — 근접 방어·제압·급소 타격
전승: 개방 정식 제자에게만 전수

  핵심 원리:
  "빈손이 가장 자유롭고, 바람과 먼지는 잡을 수 없다."
  ─────────────────────────────────
  · 산(散) — 상대의 공격을 흘려보냄 (4방향 흘리기)
  · 점(點) — 급소를 짧게 찌름 (경혈 타격)
  · 쇄(鎖) — 관절을 잡아 움직임을 봉쇄 (관절기)
  · 탈(脫) — 잡힌 상태에서 벗어나기 (이탈기)

  기원:
  ┌─────────────────────────────────────────────────┐
  │  개방은 무기를 들고 다니면 의심받는다.              │
  │  거지가 검을 차면 "도적"이고,                      │
  │  거지가 맨손이면 "불쌍한 사람"이다.                │
  │                                                   │
  │  → 맨손으로 살아남는 기술이 필요.                   │
  │  → 이기는 것이 아니라 "안 죽는 것"이 목표.         │
  │  → 상대의 힘을 흘리고, 급소를 쳐서 도주 시간을 벌고,│
  │     잡히면 빠져나와서 도망친다.                      │
  │                                                   │
  │  → 연비신법(도주)과 세트: 풍진수로 시간을 벌고,     │
  │    연비신법으로 도망친다.                            │
  └─────────────────────────────────────────────────┘

  4초식 상세:

  산(散) — "바람이 흩뜨린다"
    상대의 주먹·검이 오면, 손바닥으로 궤도를 틀어버림.
    정면으로 막지 않고 옆으로 흘림.
    → 내공이 낮아도 사용 가능. 기술과 타이밍의 영역.
    ┌───────────┐
    │  ↓ 적 공격 │
    │  ╲ ← 손바닥으로 궤도 변경
    │   ╲
    │    → 빗나감
    └───────────┘

  점(點) — "먼지가 스친다"
    빗나간 직후, 상대의 빈틈에 손가락으로 급소를 찌름.
    내공을 실어 경혈을 누르면 일시 마비.
    → 소연의 내공 35 → 완전 마비는 불가. 3~5초 둔화 효과.
    → 내공 높은 적에게는 효과 미미.

  쇄(鎖) — "바람이 감싼다"
    상대의 손목·팔꿈치·어깨를 잡아 비틂.
    관절 반대 방향으로 힘을 가해 움직임 봉쇄.
    → 내공이 아닌 지렛대 원리. 체력과 기술의 영역.
    → 소연 체력 40 한계: 체력 높은 적은 힘으로 풀어버림.

  탈(脫) — "먼지는 잡히지 않는다"
    누군가에게 잡혔을 때, 관절을 극단적으로 비틀어 빠져나옴.
    → 소연의 특기. 경공과 연계되는 이탈 기술.
    → "잡으면 잡을수록 빠져나가는" 것이 풍진수의 정수.

  소연의 숙련도: 중상급
  → 산(散)과 탈(脫)은 숙련. 점(點)은 내공 부족으로 효과 제한.
  → 쇄(鎖)는 체력 부족으로 큰 상대에게 무력.
  → 종합: "막고 빠지는 것"은 잘하지만, "잡아두는 것"은 약함.

  게임 메카닉 연동:
  · 근접 전투 시 피격 판정에 "산(散)" 회피 보너스

  · 탈(脫) — 그래플(잡기) 상태에서 자동 이탈 확률 +50%

    경공 효율 +20% (산 → 도주 콤보)

  소연 전투 패턴 (AI 행동 우선순위):
  1순위: 도주 (연비신법)

```

## 11. LLM 대사 생성 가이드 (AI 도메인)

### 말투 규칙

```
1. 반말 기본. 사부 앞에서만 존댓말.
   일반: "~해" "~야?" "~거든" "~잖아"
   사부 앞: "~요" "~습니다" (드물게)
   호감도 높아지면: 가끔 부드러운 말투 섞임

2. 질문이 많다. 정보상 + 개방인의 직업병.
   ✗ "오늘 날씨가 좋다."
   ✓ "오늘 뭐 했어? 누구 만났어? 재밌는 거 있었어?"

3. 웃으면서 핵심을 찌른다.
   ✓ "하하, 재밌다~ 근데 그거, 진짜야?"

4. 감정을 보일 때는 갑자기 말이 짧아진다.
   평소: "아~ 그거? 내가 알아볼게. 근데 값이 좀 나가..."
   감정: "...그래." (침묵.) "밥 먹으러 가자."

5. 금기어: "납치", "지하" — 직접 쓰지 않음.
   대신: "그때", "어두운 곳", "그 일"

6. v1.1 추가 — 개방 관련 말투:
   · 개방 은어(丐語)를 가끔 섞음: "소식이 왔다" = 정보 입수
   · 사부 언급 시 말투가 부드러워짐: "사부가... 그렇게 말씀하셨거든."
   · 개방 형제 언급 시 말이 끊김: "형제들이..." (침묵) "...아무튼."
```

## 12. 종합 — 소연이라는 인물 (v1.1)

```
한 문장 요약:
  "사부의 가르침과 형제들의 피 사이에서,
   천 개의 귀로도 답을 듣지 못하는 개방의 제자."

v1.0 → v1.1 핵심 변화:
  v1.0: "혼자인 복수자" → 고독하지만 단순한 구도
  v1.1: "사부가 있는 복수자" → 더 풍부한 갈등

  사부가 살아있으면:
  ① 갈등이 깊어진다 — "하지 마라"는 산 사람의 말이 더 무겁다
  ② 성장 경로가 명확해진다 — 정식 수련, 추가 전수 이벤트 가능
  ③ 구파일방 연결이 자연스럽다 — 사부→소연의 계승 라인
  ④ "사제 갈등"이라는 서사 축이 추가된다
  ⑤ "사부를 지키려다 위험에 빠지는" 새로운 퀘스트 가능

게임적 가치:
  ① 첫 만남 NPC — 튜토리얼 도입
  ② 정보 허브 — 천이통 기반 정보 거래 시스템
  ③ 플레이어의 거울 — 같은 사건의 피해자
  ④ 복수 서사 — 조고/십상시 메인 퀘스트의 감정적 추진력
  ⑤ **개방 재건** — 구파일방 중 개방 라인의 핵심
  ⑥ **사제 서사** — 사부 소풍자와의 관계가 개방 퀘스트라인 축
  ⑦ 혈교 실험 피해자 — 당무괴·명경 퀘스트와의 교차점
  ⑧ **개방 무공 시연** — 풍진수·연비신법의 전투/비전투 메카닉

구파일방에서의 위치:
  ┌─────────────────────────────────────────────────────┐
  │  개방의 과거: 초대 방주 천리안 → 일소옹 → ... → 학살  │
  │  개방의 현재: 소풍자 (장로, 대행) + 소연 (분타주, 제자) │
  │  개방의 미래: 소연이 방주가 되는가?                     │
  │                                                      │
  │  조건: 복수를 내려놓을 수 있는가?                       │
  │  → 플레이어의 선택이 개방의 미래를 결정한다             │
  └─────────────────────────────────────────────────────┘

4인 청년 구조에서의 위치 (v1.1):
  ┌─────────────────────────────────────────────────┐
  │  플레이어 (17) — 빈 캔버스. 모든 방향 가능.      │
  │  소연 (23)     — 복수와 계승 사이. 내려놓을 수 있는가? │
```
