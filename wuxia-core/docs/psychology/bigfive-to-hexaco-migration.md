# BigFive → HEXACO 전환 기록

> **버전**: v1.1 | **최종 수정**: 2026-02-28T01:30:00Z
> **역할**: ①층 성격 모델 전환의 근거와 매핑 기록
> 📎 원본: [npc-psychology-architecture.md](npc-psychology-architecture.md) §2
> 📎 참고: Lee & Ashton (2012) "The H Factor of Personality", HEXACO-PI-R

---

## 1. 전환 배경

v1.x까지 NPC 심리 아키텍처의 ①층(성격)에 BigFive(O/C/E/A/N) 모델을 사용했다. v2.0에서 HEXACO(H/E/X/A/C/O) 모델로 전환했다.

이 문서는 **왜 전환했는지**, **무엇이 어떻게 이동했는지**를 기록한다.

---

## 2. 왜 BigFive에서 HEXACO로 변경했는가

세 가지 핵심 이유가 있다.

```
  ① H(정직-겸손) 요인이 무협 서사의 핵심을 직접 표현
     · 무협의 중심 갈등 = 의리 vs 배신, 겸손 vs 야망
     · BigFive에는 이것을 ①층에서 표현할 수단이 없었음
     · H 요인 = "이 사람이 본질적으로 남을 이용하는 사람인가"

  ② E(정서성)와 A(친화성)의 재편으로 감정 필터 정밀도 향상
     · BigFive-N(신경증)에 "불안"과 "분노"가 뒤섞여 있었음
     · HEXACO는 불안→E, 분노→A로 분리
     · 조고: "겁은 없는데(E↓) 화는 불같다(A↓)" 표현 가능

  ③ ①층(기질) ↔ ③층(5가치) 연결이 자연스러워짐
     · H = 충/의의 기질적 토대
     · "왜 이 사람은 의리를 중시하는가?" → 기질적으로 H가 높아서
```

참고: Lee & Ashton (2012) "The H Factor of Personality", HEXACO-PI-R

---

## 3. BigFive와의 차이 — 무엇이 어떻게 이동했나

HEXACO는 BigFive의 단순 확장이 아니다. E와 A의 내용이 재편되었다.

```
  BigFive                              HEXACO
  ──────────                            ──────────

  N (신경증)                            E (정서성)
  ┌─────────────────┐                   ┌─────────────────┐
  │ 불안             │ ─────────────→   │ 불안             │
  │ 걱정             │ ─────────────→   │ 걱정             │
  │ 두려움           │ ─────────────→   │ 두려움           │
  │ 우울/의존        │ ─────────────→   │ 감정적 의존      │
  │                  │                  │                  │
  │ 분노  ★         │ ──┐              │ 동정심 ★ (A에서) │
  │ 짜증  ★         │   │              └─────────────────┘
  │ 적대감 ★        │   │
  └─────────────────┘   │              A (친화성, 재편)
                        │              ┌─────────────────┐
  A (친화성)            │              │ 관용             │
  ┌─────────────────┐   └───────────→  │ 인내             │
  │ 관용             │ ─────────────→  │ 유연             │
  │ 인내             │ ─────────────→  │                  │
  │ 유연             │ ─────────────→  │ (+ 분노 조절) ★ │
  │                  │                  │ (+ 원한 조절) ★ │
  │ 동정심 ★        │ ──┐              └─────────────────┘
  │ 감정적 공감 ★   │   │
  └─────────────────┘   └───────────→  E (정서성)에 합류

  O (개방성)        ───── 거의 동일 ─────→  O (개방성)
  C (성실성)        ───── 거의 동일 ─────→  C (성실성)
  E (외향성)        ───── 거의 동일 ─────→  X (외향성, 글자만 변경)
                                            H (정직-겸손) ★ 신규
```

### 3.1 글자 혼동 주의

```
  BigFive-E = Extraversion (외향성)
  HEXACO-E = Emotionality (정서성) ← 완전히 다른 요인!
  HEXACO-X = eXtraversion (외향성) ← BigFive-E와 같은 것
```

### 3.2 재편의 핵심 이유 (Lee & Ashton)

BigFive-N(신경증) 안에 "불안"과 "분노"가 뒤섞여 있었다.
그러나 이 둘은 전혀 다른 성질이다.

```
  불안 = "나와 가족이 다칠까봐 걱정" → 자기/가족 보호 → E
  분노 = "상대방이 나를 도발했다"    → 대인 갈등 반응 → A의 반대극

  걱정이 많다고 화를 잘 내는 건 아니다.
  화를 잘 낸다고 걱정이 많은 건 아니다.
  → 같은 요인에 묶으면 안 된다.
```

## 4. 요인별 매핑 요약

```
  BigFive 요인   →  HEXACO 요인       변환 내용
  ──────────────────────────────────────────────────────────
  O (개방성)     →  O (개방성)         거의 동일
  C (성실성)     →  C (성실성)         거의 동일
  E (외향성)     →  X (외향성)         글자만 E→X
  A (친화성)     →  A (친화성, 재편)   동정심 빠짐, 분노조절 합류
  N (신경증)     →  E (정서성, 재편)   분노 빠짐, 동정심 합류
  (해당 없음)    →  H (정직-겸손)      ★ 신규 추가
```

## 5. 무협 RPG에서의 실질적 영향

### 5.1 BigFive로는 불가능했던 표현

```
  BigFive 시절의 한계:

  ① "본질적으로 남을 이용하는 사람" 표현 불가
     · BigFive-A(친화성)↓ = "까칠한 사람"이지 "착취하는 사람"이 아님
     · 조고의 핵심 특성인 "공정하지 않음"을 ①층에서 잡을 수 없었음
     · → HEXACO-H↓ = "착취적, 특권의식, 물욕" → 조고 H=10으로 직접 표현

  ② "겁은 없는데 화는 불같다" 표현 불가
     · BigFive-N(신경증)↑ = 불안도 높고 분노도 높음 (둘이 섞임)
     · BigFive-N↓ = 불안도 낮고 분노도 낮음 (둘이 섞임)
     · 조고처럼 "대담하지만(E↓) 화가 폭발적(A↓)"인 인물 불가능
     · → HEXACO는 E와 A가 분리되어 조합 자유로움

  ③ ①층↔③층 연결 부자연스러움
     · "이 NPC는 왜 의리를 중시하는가?"에 대한 기질적 토대 없음
     · → HEXACO-H가 충/의의 기질적 토대 역할
```

### 5.2 전환으로 얻은 것

```
  · H 요인 → 무협의 핵심 갈등(의리 vs 배신)을 ①층에서 직접 표현
  · E/A 재편 → 감정 필터 정밀도 향상 (두려움과 분노 분리 조절)
  · 인물 유형 조합 → Low-H 유형 가이드로 악역 설계 체계화
  · ①↔③ 연결 → "성격이 왜 이런 가치관을 낳았는가" 설명 가능
```

## 6. v1.x BigFive 프로필 → v2.0 HEXACO 프로필 전환표

참고용으로, 6인 NPC의 프로필이 어떻게 전환되었는지 기록한다.

```
  v1.x BigFive (더 이상 사용하지 않음):
           O개방  C성실  E외향  A친화  N신경
  명경      60    90    50    80    20
  조고      50    80    80    10    30
  소연      70    70    60    40    60
  야율설화  80    40    70    50    30
  진야림    50    30    30    60    40
  남궁현    60    70    70    30    50

  v2.0 HEXACO (현행):
           H정직  E정서  X외향  A친화  C성실  O개방
  명경      90    50    50    80    90    60
  조고      10    20    80    10    80    50
  소연      50    60    60    40    70    70
  야율설화  40    30    70    50    40    80
  진야림    60    40    30    60    30    50
  남궁현    40    50    70    30    70    60

  전환 주요 변경점:
  · H 요인 신규 추가 (각 인물의 서사적 핵심에 맞게 설정)
  · BigFive-N → HEXACO-E: 불안 요소만 추출 (분노 제외)
  · BigFive-A → HEXACO-A: 분노 조절 요소 추가 (동정심 제외)
  · O, C: 거의 동일 유지
  · BigFive-E → HEXACO-X: 수치 동일, 글자만 변경
```

## 7. 코드 영향 (데이터 구조 변경)

```rust
// v1.x — 더 이상 사용하지 않음
pub struct BigFivePersonality {
    pub openness: f32,
    pub conscientiousness: f32,
    pub extraversion: f32,
    pub agreeableness: f32,
    pub neuroticism: f32,
}

// v2.0 — 현행
pub struct HexacoPersonality {
    pub honesty_humility: f32,  // H 정직-겸손 ★ 신규
    pub emotionality: f32,      // E 정서성 (BigFive-N에서 재편)
    pub extraversion: f32,      // X 외향성 (BigFive-E와 동일)
    pub agreeableness: f32,     // A 친화성 (BigFive-A에서 재편)
    pub conscientiousness: f32, // C 성실성 (동일)
    pub openness: f32,          // O 개방성 (동일)
}
```
