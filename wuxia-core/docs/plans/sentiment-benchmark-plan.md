```

             ↓ 임베딩
앵커와 유사도 비교 → 따뜻(+delta) / 차가움(-delta) / 중립(0)

이 판별이 80% 이상 정확해야 Step 4 구현을 진행한다.
```

## 3. 유사도 계산 방식 비교

### 3.1 방식A — 평균벡터 차이값

```
warmth_avg = mean(warmth 앵커 임베딩들)  ← 1개 벡터
coldness_avg = mean(coldness 앵커 임베딩들)  ← 1개 벡터

score = cos(대사, warmth_avg) - cos(대사, coldness_avg)

  score > 0 → 따뜻 방향
  score < 0 → 차가운 방향
  score ≈ 0 → 중립

delta 매핑 (임계치는 벤치마크에서 조정):
  score ≥ +0.15  → +3
  score ≥ +0.05  → +1
  score ≥ -0.05  →  0
  score ≥ -0.15  → -1
  score <  -0.15 → -3

특징:
  + cosine 2회로 완료 (빠름)
  + 평균이라 표현 편향 감소
  - 개별 앵커의 특수성이 평균에 묻힘
```

### 3.2 방식B — 개별앵커 max 비교 (mechanic §4.3)

```
warmth_sim = max(cos(대사, 각 warmth앵커))  ← 가장 가까운 앵커 1개
coldness_sim = max(cos(대사, 각 coldness앵커))  ← 가장 가까운 앵커 1개

판정:
  if warmth_sim > coldness_sim AND warmth_sim >= 0.55:
      delta = +map_to_delta(warmth_sim)
  elif coldness_sim > warmth_sim AND coldness_sim >= 0.55:
      delta = -map_to_delta(coldness_sim)
  else:
      delta = 0

delta 매핑 (similarity 절대값 기준):
  0.55~0.65  → ±1
  0.65~0.75  → ±2
  0.75+      → ±3

특징:
  + "존경" 앵커에 가까우면 바로 반응 (특수 감정 포착)
  + 절대 임계치(0.55)로 중립 자연 분류
  - cosine N회 (앵커 수만큼, 느림)
  - 하나의 극단 앵커에 과반응 가능
```

### 3.3 벤치마크 비교 항목

```
방식A vs 방식B 각각에 대해:
  ① 정확도 (방향 일치율)
  ② 중립 분류 정확도 (false positive 비율)
  ③ 애매한 대사에서의 분포
  ④ 감정 유형별 포착률 (존경, 연민 등 잘 잡히나?)
  ⑤ 처리 시간 (embed 1회 + cosine 계산)
  ⑥ 앵커 수 증가 시 정확도 변화 곡선
```

### 4.2 구현 개요

```rust
// sentiment_benchmark.rs 개요
//
// 기존 embedding_benchmark 패턴과 동일.
// EmbeddingPort (FastEmbedAdapter) 직접 사용.
//
// 흐름:
// 1. 앵커 문장 정의 (하드코딩 or toml)
// 2. 테스트 대사 정의 (70개, 카테고리 라벨 포함)
// 3. EmbeddingPort로 모든 텍스트 임베딩
// 4. 앵커 수별 (5, 10, 20, 30) × 방식별 (A, B) 루프:
//    a. 방식A: 앵커 평균벡터 계산 → score = cos차이
//    b. 방식B: 개별앵커 max → 큰 쪽 + 절대임계치
//    c. 각 대사의 score/delta 계산
//    d. 기대 라벨과 비교 → 정확도 집계
// 5. 리포트 출력:
//    - 조합별 정확도 테이블
//    - 감정 유형별 오분류 패턴
//    - 처리 시간
//    - 최적 조합 추천
```

## 5. 합격 기준 및 분기

```
정확도 ≥ 80%
  → 해당 조합(방식+앵커수)으로 확정
  → step4-embedding-sentiment-plan.md의 Iter 4.2부터 진행
  → SentimentConfig 임계치를 벤치마크 결과 값으로 설정

정확도 70~80%
  → 오분류 패턴 분석
  → 부족한 감정 유형 앵커 보강 (문장 추가)
  → 재측정 (1~2회 반복)
  → 그래도 80% 미달이면 LLM 판정 병행 검토

정확도 < 70%
  → 앵커 문장 30개까지 확장 후 재측정
  → 그래도 부족하면 다축 감정 앵커(방법C) 검토:

    방법C (다축 감정 앵커):
      감정 유형별로 앵커 축을 분리
      따뜻한 축: 호감/감사/존경/연민 각 3~5문장
      차가운 축: 반감/분노/경멸/무시 각 3~5문장
      대사 → 각 축별 유사도 → 가중합 → delta

      장점: 정밀한 감정 포착
      단점: 계산량 증가, 가중치 튜닝 필요
      ※ Relationship 2축(호감/신뢰)과는 별개 개념

  → 방법C로도 부족하면 임베딩 단독 방식 포기, LLM 판정 필수로 전환
```
