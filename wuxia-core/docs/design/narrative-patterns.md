## 1. 영웅 성장 곡선 패턴

### 1.1 사조영웅전: "우직한 영웅" 곡선

```
능력
 ▲
 │                                          ┌──── 대협(大俠)
 │                                     ┌────┘
 │                                ┌────┘  항룡십팔장 체득
 │                           ┌────┘
 │              정체기   ┌────┘  다양한 사부 편력
 │         ┌────────────┘
 │    ┌────┘  강남칠괴의 기초 수련
 │────┘ 몽골 초원의 순박한 소년
 └──────────────────────────────────────────► 시간
```

핵심 패턴: **늦은 출발 + 다중 사사(師事) + 돌파 계기**
- 곽정: 재능 낮음 → 끈기로 극복 → 여러 사부에게 배움 → 결정적 무공 체득으로 비약
- 대비 인물 양강: 재능 높음 → 타락 → 몰락 (환경이 인간을 만든다)

### 1.2 와호장룡/청강만리: "억눌린 천재" 곡선

```
능력
 ▲
 │  ┌──── 옥교룡 (천재적 재능, 억눌린 성장)
 │  │         비밀 수련 → 폭발적 성장 → 자유를 향한 투쟁
 │  │
 │  │  ┌─── 이모백 (완성된 고수, 내면의 갈등)
 │  │  │         무공은 정점 → 감정/인연에서 미완성
 │  │  │
 │  │  │  ┌── 유수련 (실전형 성장)
 │  │  │  │       표국 운영 → 현실적 강인함 → 사랑 앞에 무력
 │  └──┤  │
 │      │  │
 └──────┴──┴──────────────────────────────────► 시간
```

핵심 패턴: **무공 성장 ≠ 인간 성장**
- 이모백은 천하 최고의 무공을 가졌지만, 유수련에게 사랑을 고백하지 못함
- 옥교룡은 가문의 인습을 벗어나려 하지만, 그 과정에서 파괴적 선택

### 1.3 녹정기: "反무협 생존자" 곡선 ⭐ [v1.1]

```
능력/영향력
 ▲
 │                                    ┌──── 황제도 됨 (최종)
 │                              ┌─────┘  
 │                        ┌─────┘  황궁 잠입 성공
 │                  ┌─────┘  천지회 백룡사
 │            ┌─────┘  신룡교 교주부인 사귐
 │      ┌─────┘  황궁에서 태감으로 위장
 │  ┌───┘  양주 시정 잡배 출신
 │──┘  무공? 거의 없음. 말재주와 관계망이 전부.
 └──────────────────────────────────────────► 시간
```

핵심 패턴: **무공 성장 없이 권력 정점 도달**
- 위소보: 무공 재능 거의 없음 → 말재주 + 관계 + 운 → 최고 권력자
- **전통 무협의 전복**: 수련 대신 거래, 무력 대신 협상, 의리 대신 실리
- **그럼에도 사랑받는 이유**: 솔직함, 의리(자기 방식대로), 진심

```
위소보의 "능력치" (전통 무협 vs 녹정기):

전통 무협           위소보
─────────────────────────────
내공: 80         →  내공: 5
검법: 90         →  검법: 10
책략: 60         →  책략: 95 (거짓말, 즉흥 대응)
관계망: 40       →  관계망: 98 (황제~거지까지)
의리: 70         →  의리: 65 (자기식 의리)
운: 50           →  운: 99 (주인공 보정 최대치)
```

### 1.4 수호전: "밀려난 영웅" 곡선 ⭐ **[v1.2 신규]**

> **원전 근거**: 수호전의 108 호걸 대부분은 자발적으로 도적이 된 것이 아니다.
> 원전 Introduction: "driven to become outlaws or refugees from a harsh, unjust society 
> and the corrupt officials of the Song government"

```
능력/지위
 ▲
 │  ┌──── 체제 내 선량인 (관리/군관/상인)
 │  │
 │  │         부패한 권력자의 모함
 │  │              │
 │  │              ▼
 │  │         누명/억울함 ────→ 법적 해결 시도 실패
 │  │                              │
 │  │                    ┌─────────┤
 │  │                    ▼         ▼
 │  │              폭발/살인    유배/도주
 │  │                    │         │
 │  │                    └────┬────┘
 │  │                         ▼
 │  │                    양산박 합류 (비상양산 逼上梁山)
 │  │                         │
 │  │                         ▼
 │  │                    영웅으로 재탄생
 │  └──────────────────────────────────────────► 시간
```

핵심 패턴: **체제에 의한 축출 → 강제적 신분 전환 → 역설적 영웅화**

**원전에서 확인한 대표 사례:**
- **임충(林冲)**: 80만 금군 교두(무관 엘리트). 아내가 고관의 아들에게 희롱당함 → 누명 → 유배 → 사초장 방화 암살 시도 → 폭발하여 양산박 합류
- **무송(武松)**: 맹호를 맨손으로 때려잡은 영웅. 형이 독살 → 관아가 외면 → 직접 복수 → 도적
- **노지심(魯智深/魯達)**: 군관. 약자를 위해 정육점 주인을 때려죽임 → 승려로 위장 → 양산박
- **송강(宋江)**: 현의 하급 관리. 원전: "even after he accidentally kills his greedy mistress... Song Jiang yearns for Imperial amnesty"

**기존 유형과의 차이**:
```
곽정(대기만성형): 자발적 수련 → 자발적 성장
옥교룡(천재형):   억압은 있지만 체제 내부에서 발생
위소보(생존자형): 체제 밖에서 시작, 체제 안으로 침투
임충(밀려난형):   체제 안에서 체제에 의해 추방당함 ← 핵심 차이
                  본인은 체제로 돌아가고 싶지만 돌아갈 수 없음
```

**임충의 심리적 곡선 — "참는 영웅"의 한계점**:
```
인내심
 ▲
 │  ┌─────────── 참는다, 참는다, 참는다...
 │  │
 │  │                              ✕ 한계점(臨界點)
 │  │                              │
 │  │                              ▼ 폭발
 │  │                              │
 │  │                              └── 돌이킬 수 없는 행동
 │  │
 └──┴──────────────────────────────────────► 억울한 사건 누적

임충의 인내 이력:
  사건1: 아내 희롱 — 참음 (체면, 법을 믿음)
  사건2: 누명으로 유배 — 참음 (복직 희망)
  사건3: 유배지에서 암살 시도 — 참음 (증거 불충분)
  사건4: 사초장 방화 — 참을 수 없음 → 3명 살해 → 양산박

→ 매번 "참는 이유"가 있었고, 그 이유가 하나씩 사라짐
```

### 1.5 칠국춘추 적용: 성장 곡선 유형 시스템 — [v1.2 업데이트]

```
NPC 성장 유형:
├── 대기만성형 (곽정): 낮은 초기값 + 높은 성장률 + 돌파 이벤트 필요
├── 천재형 (옥교룡): 높은 초기값 + 억압 요인 → 해소 시 폭발
├── 완성형 (이모백): 높은 능력 + 내면 갈등 = 행동 제약
├── 실전형 (유수련): 균형 성장 + 경험 기반
├── 타락형 (양강): 높은 재능 + 환경 부패 → 능력은 성장하나 인간성 퇴보
├── 생존자형 (위소보): 무공 낮음 + 관계망 극대화 → 비전통 경로 성공 [v1.1]
└── 밀려난형 (임충): 높은 초기능력 + 체제 축출 → 신분 전환 후 재성장 ⭐ [v1.2]
```

**밀려난형 NPC 구현**:
```
밀려난형 NPC 파라미터:

  초기 상태:
  ├── 능력: 중~고 (이미 훈련된 사람)
  ├── 사회적 지위: 높음 (관리, 군인, 상인)
  ├── 체제 순응도: 높음 (법과 질서를 믿음)
  └── 인내 임계값: 개인차 (임충=높음, 노지심=낮음)

  축출 트리거:
  ├── 권력자 NPC의 모함 이벤트
  ├── 부당한 처벌 이벤트
  └── 사랑하는 사람 위협 이벤트

  축출 후 변화:
  ├── 체제 순응도 급락 (-50 이상)
  ├── 복수심 상승
  ├── 새 소속 탐색 (양산박 = 칠국춘추의 사파/자유도시/반란군)
  └── 무공은 유지되나, 싸우는 이유가 바뀜

  칠국춘추 적용 NPC 예시:
  ├── 무고(武孤): 봉황국 군관 출신 → 정변으로 누명 → 사파 합류?
  ├── 조고의 부하 중 "밀려난형": 원래 선량했으나 조고에게 이용당함
  └── 플레이어도 이 경로 가능: 문파에서 쫓겨나면 어디로 가는가?
```

**칠국춘추 적용 포인트**:
- **위소보형 NPC 가능성**: 무공 없이도 영향력 있는 NPC (상인, 정보상, 관리)
- **플레이어 선택지 확장**: "무공 수련"만이 아니라 "관계 구축"도 정당한 성장 경로
- **소연(천이방 운영)이 위소보형**: 무공보다 정보망으로 생존/성공
- **밀려난형 NPC의 서사 잠재력** ⭐ [v1.2]: 플레이어가 이들을 구하면 강력한 동맹, 방관하면 적이 될 수 있음

## 2. 갈등 구조 패턴

### 2.1 핵심 갈등 유형 분류 — [v1.2 업데이트]

```
┌──────────────────────────────────────────────────────┐
│              무협 갈등 분류 체계                        │
├──────────────────────────────────────────────────────┤
│                                                      │
│  개인 내면 갈등                                        │
│  ├── 의(義) vs 정(情): 의리와 사랑의 충돌               │
│  ├── 충(忠) vs 효(孝): 국가와 가문의 충돌               │
│  ├── 복수 vs 용서: 원한의 대물림                        │
│  ├── 자유 vs 책임: 강호 방랑 vs 문파 의무               │
│  ├── 실리 vs 명분: 생존 vs 원칙 (녹정기) [v1.1]        │
│  ├── 순응 vs 정의: 체제를 믿을 것인가 (수호전) ⭐ [v1.2]│
│  └── 인내 vs 폭발: 참을 것인가 행동할 것인가 ⭐ [v1.2]  │
│                                                      │
│  인물 간 갈등                                          │
│  ├── 사부-제자: 가르침의 방향, 배신, 계승               │
│  ├── 동문-동문: 같은 문하 내 경쟁과 질투                │
│  ├── 연인: 가문/문파 간 금지된 사랑                     │
│  ├── 부모-자식: 기대와 자아실현의 충돌                  │
│  ├── 다중 충성: 여러 세력 사이 줄타기 (녹정기) [v1.1]   │
│  └── 의형제: 맹약의 의무 vs 노선 차이 (수호전) ⭐ [v1.2]│
│                                                      │
│  집단 간 갈등                                          │
│  ├── 정파 vs 사파: 정통성과 방법론의 대립               │
│  ├── 문파 vs 문파: 영역, 비급, 명예 다툼                │
│  ├── 강호 vs 조정: 자유 vs 권력                        │
│  ├── 내부 분열: 노선 갈등, 권력 투쟁                    │
│  ├── 한족 vs 만주: 민족/정체성 충돌 (녹정기) [v1.1]     │
│  └── 명분 vs 실상: 충의당의 역설 (수호전) ⭐ [v1.2]     │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 2.2 작품별 핵심 갈등

**사조영웅전**
- 곽정 vs 칭기즈칸: 의형제의 의리 vs 조국(송나라) 수호 → **충 vs 의**
- 곽정 vs 양강: 같은 뿌리에서 출발, 환경에 의한 극단적 분화 → **성선설 vs 성악설**
- 건곤오절(동사서독남제북개중신통): 최고수 5인의 각각 다른 가치관 충돌

**와호장룡/청강만리**
- 이모백 & 유수련: 사형(맹사소)의 죽음이 남긴 인습의 강 → **과거의 의리 vs 현재의 사랑**
- 옥교룡: 귀족 가문의 규범 vs 자유로운 삶에 대한 갈망 → **제도 vs 자아**
- 세대 간: 이모백(구세대 협객) vs 옥교룡(신세대의 반항)

**수호전** — [v1.2 심층 분석]
- 108 호걸 집결: 부패한 조정에 밀려난 다양한 출신의 인물들 → **정의 vs 체제**
- 송강의 딜레마: 체천행도(하늘을 대신해 도를 행함) vs 초안(조정 귀순) → **혁명 vs 타협**
- 내부 서열: 충의를 내세우면서도 혈통/공적/인맥으로 서열 결정 → **이상 vs 현실**
- ⭐ **逼上梁山(비상양산)**: 선량한 사람이 부패한 체제에 의해 강제로 도적이 됨 → **순응 vs 생존** [v1.2]
- ⭐ **송강의 양면성**: 인자함과 잔인함의 공존 → **위선적 리더십의 딜레마** [v1.2]
- ⭐ **의형제 서열**: 108명이 "형제"를 맹세하나 36천강성/72지살성 서열 존재 → **평등 명분 vs 위계 현실** [v1.2]

```
수호전 원전에서 확인한 송강의 양면성:

  밝은 면 (원전 근거):
  ├── "renowned throughout the land for his filial piety,
  │    benevolence, compassion, and generosity"
  ├── "he is the help of the poor and the helpless"
  └── 장청을 용서하며 "If we seek revenge Heaven will not support us"
  
  어두운 면 (금성탄 해석):
  ├── 정부(情婦) 염파석을 실수로 살해
  ├── 양산박 합류를 위해 속임수/강제 사용 (노준의 유인)
  └── 금성탄: "undermining Song Jiang's values of loyalty and justice
       at every turn, by contrasting it with expressions of 
       callousness and barbarism"
  
  → 송강은 "좋은 사람"인가 "교활한 리더"인가?
     원전 자체가 이 질문에 답하지 않음 — 독자/플레이어의 판단에 맡김
```

**녹정기** [v1.1]
- 위소보 vs 스스로: 황제(강희제) 의형제 vs 천지회(반청복명) 소속 → **다중 충성의 딜레마**
- 강희제 vs 천지회: 친구이자 군신 vs 혁명 조직 → **개인 정(情) vs 정치 대의**
- 아청/쌍아/목검평 vs 나머지 부인들: 순수한 사랑 vs 정략적 결혼 → **진심 vs 거래**
- **핵심 갈등**: "의리는 지키고 싶은데, 양쪽 다 죽이고 싶지 않다" → **불가능한 양립**

```
위소보의 다중 충성 네트워크:

       강희제 (황제, 의형제)
           │
           │ 충성 ↔ 친구
           │
       ┌───▼───┐
       │ 위소보 │
       └───┬───┘
           │
  ┌────────┼────────┐
  │                 │
천지회 (반청복명)  신룡교 (아내)
  │                 │
  │                 │
오삼계 (이용)     홍안통 (위협)

→ 모든 관계가 충돌 가능. 결말은? "도망친다" (양립 불가능을 인정)
```

```

     ├─ 청목당 (진근남)
     ├─ 홍화당 (풍석판)
     └─ 기타 분당
  
  신룡교 (홍안통, 아내 아청)
     ↕ 적대 관계
  러시아 공주 (쌍아)
  
  오삼계 (운남 반란)
  
→ 위소보는 이 모든 세력에 동시에 발을 걸침.
   어느 하나도 완전히 배신하지 않고, 모두를 적당히 속임.
```

**핵심 패턴**:
- 전통 무협: 하나의 문파/세력에 충성 → 그 안에서 갈등
- 녹정기: 여러 세력 동시 소속 → 충성 자체가 불가능 → 줄타기

### 5.3 칠국춘추 문파 역학 시스템

```
문파 상태 변수:
├── 결속력 (내부 충성도)
├── 명성 (외부 평판)
├── 전력 (구성원 무력 합산)
├── 재정 (자원)
├── 노선 (정파도/사파도 스펙트럼)
├── 이중 스파이 위험도 (위소보형 NPC 존재 시) [v1.1]
└── 구성원 가입 동기 분포 (자발/억울함/속임수/감동/강제) ⭐ [v1.2]

문파 이벤트 트리거:
  결속력 < 30% → "내부 분열" 이벤트
  명성 > 80% AND 재정 < 20% → "외부 도전" 이벤트
  구성원 사망 > 30% → "와해 위기" 이벤트
  두 노선의 차이 > 50% → "노선 투쟁" 이벤트
  이중 스파이 발각 → "숙청" 또는 "거래" 이벤트 [v1.1]
  강제가입 NPC > 40% → "탈주/반란" 위험 이벤트 ⭐ [v1.2]
```

**위소보형 NPC 메카닉** [v1.1]:
```
소연(천이방 정보상) = 칠국춘추의 "위소보 포지션"

  특징:
  ├── 무공 약함 (연비신법·풍진수만 숙련)
  ├── 정보망 극강 (천이통 = 위소보의 입담)
  ├── 여러 세력과 거래 (진대인, 플레이어, 사부, 조고?)
  ├── 복수 vs 생존 갈등 (위소보의 충성 딜레마와 유사)
  └── "거짓말 잘함" 잠재 스탯 (??)
  
  플레이어와의 관계:
  - 초반: 거래 상대 (정보 사고팔기)
  - 중반: 동맹 (공통의 적 조고/혈교)
  - 후반: 배신 가능성? (만약 플레이어가 사부 위협 시)
  
  → "믿을 수 있는가, 없는가"가 핵심 재미
     (위소보도 끝까지 양면성 유지)
```

## 6. 천명(天命)과 운명론 패턴 ⭐ **[v1.2 신규]**

> **원전 근거**: 수호전 프롤로그에서 108 마성(魔星)이 봉인에서 풀려나옴.
> 홍태위가 경고를 무시하고 봉인을 해제 → 36 천강성 + 72 지살성 = 108 마성 탈출
> 이후 70장에서 석비(石碑) 발견: "A Stone Tablet Is Found with Heaven's Commands"
> → 하늘이 108명의 이름과 역할을 미리 정해둠

### 6.1 천명론의 서사적 기능

```
수호전의 천명 구조:

  Layer 1 — 프롤로그 (초자연):
    108 마성이 하늘에서 내려옴
    → 인간의 의지와 무관하게, 이 108명은 만나게 되어 있음
    
  Layer 2 — 석비 발견 (정당화):
    70장: 하늘의 명령이 적힌 석비 출토
    → "우리가 모인 것은 하늘의 뜻이다"
    → 도적 집단에 "천명"이라는 정당성 부여
    
  Layer 3 — 유교적 맥락 (정치):
    천명(天命) = 하늘이 통치자에게 주는 권한
    → 부패한 황제는 천명을 잃음
    → 양산박 도적이 오히려 천명을 대행함?
    → 원전 Introduction: "Heaven sees as the people see, 
       Heaven hears as the people hear" (맹자)
    
  서사적 효과:
    표면: 108명의 모임은 "운명"
    이면: 각자의 억울함과 선택이 만든 "필연"
    → 우연과 필연의 경계가 흐려짐
```

### 6.2 칠국춘추 적용: 운명과 기연의 연결

```
기존 기연 시스템 (5가지 조건):
  장소(場) + 사람(人) + 아이템(物) + 감정(心) + 시기(時)
  → 확률적 발동

v1.2 추가 — "운명적 만남" 카테고리:
  
  수호전의 천명 패턴에서 착안:
  "우연처럼 보이지만, 세계관 차원의 숨겨진 운명선이 존재"
  
  구현:
  ├── 서사 도메인에 "운명선(DestinyThread)" 데이터 추가
  │    예: "붉은 밤 생존 아이들은 결국 만나게 되어 있다"
  │    예: "혈교 부활의 징조가 나타나면, 특정 NPC들이 움직인다"
  │
  ├── 운명적 만남 이벤트:
  │    조건: 운명선에 연결된 NPC 2명 이상이 같은 장소
  │    효과: 기연 조건② "사람(人)" 자동 충족
  │          + 특수 대화 이벤트 트리거
  │          + "이상한 기시감" 감정 부여 (LLM 대사에 반영)
  │
  └── 플레이어에게는 숨김:
       → 시스템이 운명선을 알지만 플레이어는 모름
       → "왜 이 사람과 만나면 특별한 일이 일어나지?"
       → 나중에 단서를 모아 추론 가능 (퀘스트)

  수호전 석비 패턴 적용:
  ├── 게임 중반: "고대 비문" 발견 이벤트
  │    → 붉은 밤 이전의 예언 기록
  │    → 특정 인물들의 운명이 적혀 있음
  └── 플레이어 선택: 운명을 따를 것인가, 거부할 것인가?
       → 칠국춘추 테마: "어른들이 정한 운명 vs 아이들의 새로운 선택"
```

### 6.3 천명론과 칠국춘추 테마의 충돌

```
수호전의 메시지:    "108 호걸의 모임은 천명이었다"
                    → 개인의 의지보다 운명이 크다

칠국춘추의 메시지:  "어른들의 전쟁을 살아남은 아이들이
                    자신의 이야기를 쓰기 시작한다"
                    → 운명을 거부하고 새로운 길을 개척

이 충돌이 만드는 서사 긴장:
  
  "붉은 밤"의 생존자들이 만나는 것은 운명인가?
  ├── 운명이라면: 이 만남 자체가 다시 전쟁의 시작?
  ├── 우연이라면: 아이들은 정말 자유로운가?
  └── 칠국춘추의 답: 만남은 운명이지만, 그 후의 선택은 자유다
  
  → 수호전과의 차이:
    수호전 108 호걸: 운명에 이끌려 모이고, 운명에 의해 파멸
    칠국춘추 주인공들: 운명에 의해 모이지만, 운명을 넘어서려 함
```

## 7. 무협 세계관 핵심 개념 → 게임 메카닉

### 7.1 의(義)와 협(俠) 시스템

**자객열전/유협열전에서 추출:**
- 협객의 4대 이상: 이타주의, 정의감, 용기, 신의
- 핵심: "불의를 보면 칼을 뽑는다" (路見不平 拔刀相助)

```
협의값 (俠義值) 시스템:
  
  +협의: 약자 구제, 약속 이행, 의로운 전투
  -협의: 약자 착취, 배신, 비겁한 행동
  
  협의값에 따른 세계 반응:
  ├── 높음 (>80): NPC들이 자발적 협조, 정보 제공, 명성 확산
  ├── 중간 (40-80): 중립적 대우
  ├── 낮음 (<40): 의뢰 거절, 정파 문파 적대
  └── 극저 (<10): 현상금, 자객 파견
```

**녹정기 적용** [v1.1]:
```
위소보의 협의값 = ???

  전통 기준으로는:
  - 거짓말 일삼음 → -협의
  - 약자 구제 안 함 → -협의
  - 비겁함 (도망 잘 침) → -협의
  → 협의값 10 미만 = 사파?
  
  그런데 실제로는:
  - 친구 배신 안 함 (자기 방식 의리) → +협의
  - 황제 살림 (간접적 백성 구제?) → +협의
  - 솔직함 (자기가 비겁한 줄 암) → +공감
  → 대부분 NPC가 좋아함
  
  → 새로운 협의 체계 필요: "비정통 협의"
```

**칠국춘추 적용 — 이중 평판 시스템**:
```
정통 협의 (正統俠義)
  ├── 정파 문파가 인정
  └── 곽정, 령호충, 양과형

비정통 협의 (非正統俠義) [v1.1]
  ├── 방법은 비겁하지만, 결과는 괜찮음
  ├── 사파/상인/백성 층이 더 좋아함
  └── 위소보, 소연(?)

플레이어 선택:
  "어떤 협의로 살 것인가?"
  - 정통 → 명예롭지만 융통성 없음
  - 비정통 → 유연하지만 정파에서 배척
```

### 7.2 화산논검(華山論劍) 패턴: 최강자 결정전

## 8. NPC 서사 표현 기법: "외부 관찰" 원칙 ⭐ **[v1.2 신규]**

> **원전 근거**: James J.Y. Liu, "The Chinese Knight-Errant"에서 수호전의 서사 기법 분석:
> "characters are observed as it were from the outside: they are revealed through 
> their action and words, rather than their thoughts and feelings"

### 8.1 수호전의 인물 표현 기법

```
수호전이 인물을 보여주는 방법:

  ╳ 직접 설명하지 않음:
    "임충은 참을성이 강하고 체제에 순응적인 사람이다"
    
  ◯ 행동과 대사로 보여줌:
    - 아내가 희롱당했을 때 → 참음 (행동)
    - 누명을 쓰고 유배될 때 → "증거를 모아서..." (대사)
    - 사초장에서 암살당할 뻔했을 때 → 폭발하여 3명 살해 (행동)
    → 독자가 "아, 이 사람은 참다 참다 폭발하는 유형이구나" 추론

  ◯ 대비를 통해 보여줌:
    임충 (참고 참다 폭발) vs 노지심 (불의를 보면 즉시 행동)
    → 같은 "정의감"이지만 완전히 다른 표현 방식
```

### 8.2 칠국춘추 AI NPC 적용 원칙

```
NPC 설계 원칙: "보여주되, 설명하지 마라" (Show, Don't Tell)

  시스템이 아는 것 (내부):           플레이어에게 보이는 것 (외부):
  ──────────────────────           ──────────────────────
  성격: 친화성 0.3 (낮음)           "그 NPC는 나를 불편하게 대했다"
  가치관: 정의 0.9 (높음)           "그런데 위험한 상황에서 나를 구해줬다"
  인내 임계값: 80                    "여러 번 참는 모습을 봤다"
  인내 소모: 75 (폭발 직전)          "요즘 표정이 어둡다, 뭔가 곧 터질 것 같다"
  
  → NPC의 내면 수치를 직접 공개하지 않음
  → 행동과 대사 패턴의 변화로 플레이어가 추론
  
  LLM 대사 생성 시 반영:
  ├── 인내 소모 50% 이하: 평소 톤
  ├── 인내 소모 50~80%: 대사에 피로감/짜증 반영
  ├── 인내 소모 80~100%: 대사에 분노 암시, 행동 변화
  └── 폭발 후: 완전히 다른 사람 (톤, 어휘, 행동 모두 변경)
  
  플레이어의 추론 보상:
  ├── 폭발 전에 도와주면 → "당신만이 알아챘군요" (특수 대사)
  ├── 폭발 후에 만나면 → "왜 아무도 도와주지 않았는가" (원망 대사)
  └── 패턴을 읽는 플레이어에게 더 깊은 관계 기회
```

### 8.3 "양면적 리더" NPC 패턴

> **원전 근거**: 금성탄은 송강의 충의를 칭송하면서도 동시에 잔인함과 대비시킴.
> 원전: 장청 부부를 용서하는 관용 vs 노준의를 속여서 끌어들이는 교활함


## 9. 신분 전환 패턴 ⭐ **[v1.2 신규]**

> **원전 근거**: 수호전 인물 대부분이 순차적 신분 전환을 경험함.
> 관리→도적(송강), 군관→승려→도적(노지심), 상인→도적(여러 인물)
> 초안 후에는 도적→관군으로 역전환.

### 9.1 수호전의 신분 전환

```
임충의 신분 변화:
  80만 금군 교두 (엘리트 군인)
    ↓ 누명
  유배수 (죄인)
    ↓ 암살 시도
  탈주자 (도망자)
    ↓ 양산박 합류
  양산박 두령 (도적)
    ↓ 초안
  관군 장수 (다시 군인)

노지심의 신분 변화:
  군관 (관리)
    ↓ 살인
  승려 (종교인)
    ↓ 규율 위반
  방랑 승려 (자유인)
    ↓ 양산박 합류
  양산박 두령 (도적)

핵심 관찰:
  같은 사람이 같은 행동을 해도,
  "군관"일 때 → "정의 구현"
  "도적"일 때 → "범죄"
  → 신분이 바뀌면 정체성이 흔들림
```

### 9.2 녹정기 vs 수호전 신분 패턴 비교

```
  수호전 인물:  순차적 신분 전환 (A→B→C)
               한 번에 하나의 신분만 가짐
               전환 시 고통과 정체성 위기 동반
               
  녹정기 위소보: 동시적 다중 신분
               여러 신분을 동시에 유지
               정체성 위기 없음 (원래 신분이 없으니까)
               
  칠국춘추 적용:
  ├── "임충형" NPC: 순차적 전환 → 정체성 갈등 이벤트 발생
  │    "나는 아직 화산파 제자인가, 아니면 이제 떠돌이인가?"
  │    → 심리 도메인의 가치관 변동 + 감정 이벤트
  │
  └── "위소보형" NPC: 동시적 다중 → 충성 갈등 이벤트 발생
       "나는 모든 곳에 속하면서 어디에도 속하지 않는다"
       → 관계 도메인의 다중 소속 + 거짓말 시스템
```

### 9.3 칠국춘추 신분 전환 메카닉

```
신분 전환 시스템:

  NPC/플레이어의 "공식 신분" 변경 이벤트:
  
  트리거:
  ├── 문파 축출 (강제)
  ├── 자발적 탈문 (선택)
  ├── 국가 망명 (정치)
  ├── 사파 전향 (가치관)
  └── 신분 위장 (속임수)
  
  전환 시 영향:
  ├── 이전 소속 관계: 적대로 전환 or 비밀 유지
  ├── 새 소속 관계: 의심 상태에서 시작 (신뢰 구축 필요)
  ├── 심리: 정체성 혼란 이벤트 (감정 불안정)
  │    → "나는 누구인가?" 내적 독백 (LLM 대사)
  ├── 무공: 이전 문파 무공 사용 시 "정체 발각" 위험
  └── 평판: 이전 평판 일부 유지, 새 환경에서 재구축
  
  신분 전환이 만드는 서사:
  ├── 정파 → 사파: "나는 버림받았다. 이제 내 방식대로 산다"
  ├── 사파 → 정파: "과거를 숨기고 새 삶을 시작한다" (들킬 위험)
  ├── 강호 → 조정: "검을 버리고 붓을 잡았다" (자유 상실)
  └── 조정 → 강호: "관복을 벗고 검을 들었다" (逼上梁山)
```

## 11. 칠국춘추 고유 테마와의 연결 — [v1.2 업데이트]

칠국춘추의 핵심 테마: **"어른들의 전쟁을 살아남은 아이들이 자신의 이야기를 쓰기 시작한다"**

이것은 기존 무협 서사와 다른 독자적 지점:
- 사조영웅전: 아버지 세대의 의형제 맹세가 자식 세대에 갈등으로 전이
- 수호전: 부패한 기성 체제에 대한 반란이지만, 결국 기성 체제에 흡수
- 와호장룡: 구세대(이모백)의 미완성을 신세대(옥교룡)가 파격적으로 해결 시도
- 녹정기: 체제 밖 인간(위소보)이 체제 안으로 들어가 살아남기 [v1.1]

칠국춘추는 이 모든 패턴의 **"다음 세대" 이야기**:
- 기존 NPC 전기에서 부모/사부 세대의 전쟁과 비극이 설정됨
- 플레이어와 젊은 NPC들이 그 유산 위에서 새로운 선택을 함
- 같은 갈등이라도 다른 해결이 가능 (기존 무협과 차별화)

**수호전 원전이 칠국춘추에 주는 교훈** ⭐ **[v1.2 신규]**:
```
1. "영웅은 선택이 아니라 환경이 만든다" (逼上梁山)
   → 칠국춘추의 NPC도 원래 선량했다가 밀려난 사람들
   → 붉은 밤의 생존 아이들 = 환경이 만든 영웅 후보
   
2. "정의로운 집단도 불의한 방법을 쓴다" (충의당의 역설)
   → 정파 문파도 때로는 속임수와 강제를 사용
   → 도덕적 흑백이 아닌 회색지대의 풍부함
   
3. "의형제의 맹약은 강하지만 노선 차이를 이기지 못한다"
   → 플레이어와 NPC의 맹약도 영원하지 않을 수 있음
   → "우리는 형제이지만, 길이 다르다"의 비극적 아름다움
   
4. "운명은 만남을 만들지만, 결말은 정하지 않는다"
   → 수호전에서 천명은 모임을 정했지만 결말은 비극
   → 칠국춘추에서 같은 운명적 만남이 다른 결말을 만들 수 있음
   
5. "인물은 행동으로 보여주는 것이다" (Show Don't Tell)
   → NPC의 내면을 직접 공개하지 않고 행동/대사로 표현
   → 플레이어가 NPC를 "읽는" 것 자체가 게임플레이
```

**녹정기가 칠국춘추에 주는 교훈** [v1.1]:
```
1. "무공 최강자"만이 주인공일 필요 없다
   → 소연(정보상), 진대인(상인) 같은 NPC도 중요 인물
   
2. "충성"이 아니라 "생존"이 동기여도 괜찮다
   → 플레이어가 완벽한 협객일 필요 없음
   
3. "거짓말"과 "배신"도 서사의 일부다
   → 도덕적 흑백 아닌 회색지대 탐험
   
4. "여러 세력 줄타기"는 흥미로운 플레이 패턴이다
   → 정파/사파 양쪽에 관계 맺기 허용
   
5. "운(運)"도 능력이다
   → 기연 시스템에서 "운" 조건 중요성
```

## 12. 녹정기 고유 메카닉 제안 [v1.1]

### 12.1 거짓말 시스템

```
NPC와 대화 시 플레이어 선택:
  [진실을 말한다]  vs  [거짓말을 한다]
  
거짓말 성공 판정:
  f(플레이어 책략, NPC 지혜, 관계값, 과거 거짓말 이력)
  
성공 시:
  - NPC 속음, 원하는 결과 획득
  - 그러나 나중에 들통날 위험
  
실패 시:
  - 즉시 관계 -30
  - 해당 NPC와 연결된 NPC들에게도 평판 하락
  
들통났을 때:
  - 관계 -50 이상
  - "배신자" 꼬리표
  - 그러나 변명/해명 기회 (추가 거짓말 가능)
  
→ 위소보형 플레이: 끊임없이 거짓말하면서 균형 유지
   위험하지만 재미있는 선택지
```

### 12.2 다중 충성 관리

```
플레이어가 3개 이상 세력에 동시 소속 가능:
  - 화산파 제자
  - 진대인 상회 협력자
  - 조고의 밀정 (위장)
  
각 세력은 상호 적대:
  화산파 vs 조고 (조정 vs 정파)
  
플레이어 임무:
  화산파: "조고의 정보를 알아내라"
  조고: "화산파의 움직임을 보고하라"
  
→ 양쪽 다 거짓 정보 제공 가능
   그러나 들키면? 양쪽 모두 적
   
성공 시: 양쪽에서 보상
실패 시: 양쪽에서 추격
도망 시: 위소보 엔딩 (해외 도피)
```

### 12.3 비전투 퀘스트 해결

```
전통 무협 퀘스트:
  "사파 무사를 무찌르고 비급을 되찾아라"
  해결: 전투 승리
  
녹정기형 퀘스트:
  "사파 무사를 무찌르고 비급을 되찾아라"
  
  해결 방법 1: 전투 (전통)
  해결 방법 2: 매수 (돈으로 비급 사기)
  해결 방법 3: 협상 (사파에게 다른 것 제공)
  해결 방법 4: 속임수 (가짜 비급 주기)
  해결 방법 5: 훔치기 (사파 무사 잠든 사이)
  
→ 모든 해결에 경험치 부여
   단, 결과는 다름:
   - 전투: 무공 경험치 + 명성
   - 매수: 돈 소비 + 관계
   - 협상: 책략 경험치 + 복잡한 관계
   - 속임수: 단기 성공 + 장기 위험 (들통)
   - 훔치기: 경공 경험치 + 비겁함 평판
```

**핵심 요약 v1.2**:

수호전 원전은 세 가지 핵심 질문을 던지며, 이는 칠국춘추의 게임플레이에 직결됩니다:

1. **"선량한 사람이 체제에 밀려나면 어떻게 되는가?"** (逼上梁山)
   → 밀려난형 NPC 이벤트 체인 + 인내 임계점 시스템

2. **"형제의 맹약은 노선 차이를 이길 수 있는가?"** (충의당의 역설)
   → 맹약 시스템 + 세력 가입 5유형 + 노선 갈등

3. **"우리의 만남은 운명인가, 선택인가?"** (천명론)
   → 운명선 시스템 + 칠국춘추 테마("운명을 넘어서는 아이들")

기존 녹정기 분석(v1.1)과 합치면, 칠국춘추는 플레이어에게 **네 가지 정당한 경로**를 제공합니다:

```
경로 1 (전통 무협):  수련 → 무공 → 강함 → 존경
경로 2 (녹정기):     관계 → 거래 → 영향력 → 성공
경로 3 (수호전):     억울함 → 집결 → 투쟁 → 새 질서 ⭐ [v1.2]
경로 4 (칠국춘추):   운명 → 만남 → 선택 → 세대 교체 ⭐ [v1.2]
```
