# 1층(성격)과 2층(가치관)의 관계

> **버전**: v1.0 | **최종 수정**: 2026-02-27
> **목적**: 1층(HEXACO 성격)이 2층(3축 가치관 + 5가치)에 어떤 영향을 주고, 반대 방향은 어떤지, 불일치가 왜 자연스럽고 중요한지를 정리한다
> 📎 원본: [npc-psychology-architecture.md](npc-psychology-architecture.md)
> 📎 유형 정리: [character-typology.md](character-typology.md)

---

## 1. 핵심 원칙: 1층과 2층은 독립적이되, 서로 영향을 준다

```
  1층 (성격, HEXACO)
    "이 사람은 원래 어떤 사람인가" — 수단의 성향
    거의 변하지 않는다 (Tier4에서만 ±5)

       ↕ 영향은 있지만, 결정하지 않는다

  2층-A (3축 가치관: 믿음/옳음/바람)
    "이 사람은 어떤 존재인가" — 방향의 선택
    천천히 변한다 (Tier 2~4)

       ↕ 해석 관계 (자동계산 아님, 완전 독립도 아님)

  2층-B (5가치: 충/의/효/복수/야망)
    "구체적 상황에서 어떻게 판단하는가" — 실전값
    중간 속도로 변한다 (Tier 1~4)
```

**세 가지 관계 유형:**

```
  ① 1층 → 2층: "기질적 토양"
     성격은 특정 가치관이 형성되기 쉬운 토양을 제공한다.
     그러나 토양이 작물을 결정하지는 않는다.
     사막에서도 선인장이 자라고, 비옥한 땅에서도 독초가 자란다.

  ② 2층 → 1층: "극히 드문 역류"
     가치관이 성격을 바꾸는 경우는 Tier4 인생 성찰에서만 가능.
     인생을 뒤흔드는 경험이 기질 자체를 미세하게 바꾼다.

  ③ 1층 ↔ 2층 불일치: "캐릭터의 깊이"
     성격과 가치관이 어긋나는 것은 버그가 아니라 인간다움이다.
     불일치가 내면 갈등을 만들고, 갈등이 서사를 만든다.
```

## 2. 1층 → 2층: 성격이 가치관에 미치는 영향

### 2.1 관계의 본질: "토양"

```
  성격은 가치관을 결정하지 않는다.
  성격은 특정 가치관이 "자연스럽게 형성되기 쉬운 조건"을 만든다.

  비유:
  · 토양(성격)이 비옥하다고 반드시 밀(도덕적 가치관)이 자라는 건 아니다
  · 씨앗(경험)과 기후(환경)가 무엇이냐에 따라
    같은 토양에서 밀도 자라고 독초도 자란다
  · 척박한 토양에서도 뿌리 깊은 나무가 자랄 수 있다
```

### 2.2 HEXACO 6요인별 → 2층 영향 경로

각 성격 요인이 2층의 세 구성요소 — ①3축 강도, ②3축 신조, ③5가치 — 에 어떻게 영향을 주는지 분리하여 검토한다.

---

**H (정직-겸손)**

> ⚠️ H 주석 (원칙/실리): H는 "공정한 수단 vs 착취적 수단"의 성향이다.
> H↑ = 선인, H↓ = 악인이라는 등식은 성립하지 않는다.
> 도덕 방향은 신조(2층)가 결정한다.

```
  ① 3축 강도에 미치는 영향
  ─────────────────────────────────────────
  · 옳음(正) 강도와 가장 자연스럽게 연결
    H↑ → 원칙에 대한 확신이 강해지기 쉬운 토양
    H↓ → 원칙보다 실리를 택하므로 옳음 강도가 낮아지기 쉬움
    그러나: H↓인 조고도 옳음 90 ("힘이 정의다")
    → 강도는 높을 수 있다. "무엇이 옳은가"의 내용이 다를 뿐.

  · 믿음(信) 강도에 간접 영향
    H↑ → 공정한 관계를 맺으므로 상호 신뢰가 쌓이기 쉬움
    H↓ → 관계를 이용으로 보므로 진정한 신뢰가 형성되기 어려움
    그러나: 이것은 "경향"이지 "결정"이 아님

  ② 3축 신조에 미치는 영향
  ─────────────────────────────────────────
  · H는 신조의 "방향"을 결정하지 않는다
    H↑이라도 "이단은 멸해야 한다"가 옳음의 신조가 될 수 있음
    H↓이라도 "내 세력은 지킨다"가 믿음의 신조가 될 수 있음

  · H가 영향을 주는 것은 수단의 톤:
    같은 옳음 90이라도
    H↑ 신조: "도의를 지켜야 한다" (공정한 수단으로)
    H↓ 신조: "힘이 곧 정의다" (착취적 수단도 불사)

  ③ 5가치에 미치는 영향
  ─────────────────────────────────────────
  · 충(忠)/의(義): 가장 직접적 연결
    H↑ → 충/의가 높아지기 쉬운 토양
    H↓ → 충/의가 낮아지기 쉬운 토양
    불일치 가능: 조조 H↓이지만 자기 세력에 대한 충은 높았음

  · 야망(野): H↓이면 착취적 수단을 동원한 야망이 자라기 쉬움
  · 복수(復): H↓이면 보복에 거리낌이 적어 복수가 높아지기 쉬움
  · 효(孝): H와 직접 연결 약함 (효는 E와 더 강하게 연결)

  역사 예시:
  · 악비 — H↑, 충/의 자연스럽게 높음. 토양과 작물이 일치
  · 조조 — H↓이지만 자기 세력에 충 높음. 불일치가 "간웅" 평가를 만듦
  · 토르케마다 — H↑이지만 의의 신조가 "이단 박멸". 토양이 좋아도 독초 가능
```

**E (정서성)**

```
  ① 3축 강도에 미치는 영향
  ─────────────────────────────────────────
  · 믿음(信) 강도에 양방향 영향
    E↑ → 공감이 강해 타인에 대한 믿음이 넓어지기 쉬움
    E↑ → 그러나 두려움이 과하면 "다칠까봐 못 믿겠다" → 오히려 닫힘
    E↓ → 냉담해서 감정적 신뢰가 형성되기 어려움
    E↓ → 그러나 "실적으로 판단한다"는 합리적 믿음은 가능

  · 바람(願) 강도에 간접 영향
    E↑ → 가까운 사람을 위한 바람이 강해지기 쉬움
         ("이 아이만은 지켜야 한다")
    E↑ → 동시에 두려움이 과하면 바람 자체를 포기하기도
         ("원하면 잃을까봐 차라리 안 원한다")
    E↓ → 바람이 개인적/전략적 방향으로 형성되기 쉬움

  ② 3축 신조에 미치는 영향
  ─────────────────────────────────────────
  · 믿음의 신조 톤에 영향
    E↑ 신조: "사람의 고통을 외면하지 않는다" (공감 기반)
    E↓ 신조: "쓸모 있는 관계를 유지한다" (합리 기반)

  · 옳음의 신조 실행 방식에 영향
    E↑ → 옳음을 느끼면서도 두려움에 실행을 망설임
    E↓ → 옳다고 판단하면 두려움 없이 밀어붙임

  ③ 5가치에 미치는 영향
  ─────────────────────────────────────────
  · 효(孝): 가장 직접적. E↑ → 가족 걱정 → 효 높아지기 쉬움
  · 충(忠): E↑이면 조직보다 개인 안전 우선 → 충이 약화될 수 있음
           E↓이면 두려움 없이 조직에 몰두 → 충이 높아지기 쉬움
  · 복수(復): E↑이면 두려움이 복수 실행을 지연/방해
             E↓이면 대담하게 복수를 밀어붙임
  · 의(義): 직접 연결 약함 (의는 H, A와 더 강하게 연결)
  · 야망(野): E↑이면 실패 두려움이 야망을 억제할 수 있음

  역사 예시:
  · 해서 — E↑이되 믿음↑. 두려움이 많지만(상소 전 관 준비),
    그 두려움을 넘어 공정함을 택함. 공감이 높아 백성 고통을 외면 못함
  · 사마의 — E↓이되 가문에 대한 효는 높았음.
    → E↓라도 "누구에게" 향하느냐에 따라 효가 달라짐
```

**X (외향성)**

```
  ① 3축 강도에 미치는 영향
  ─────────────────────────────────────────
  · X는 강도 자체를 바꾸기보다 "강도의 범위"에 영향
    X↑ → 믿음(信)이 넓어지기 쉬움 (사람을 많이 만나므로)
    X↓ → 믿음(信)이 좁고 깊어지기 쉬움 (소수에게 집중)
    둘 다 믿음 강도 80일 수 있다. 범위가 다를 뿐.

  · 바람(願) 강도에 간접 영향
    X↑ → 사회적 인정 욕구가 바람 강도를 끌어올리기 쉬움
    X↓ → 내면 지향이라 바람이 조용하거나 내적 성취 방향

  ② 3축 신조에 미치는 영향
  ─────────────────────────────────────────
  · 바람의 신조 방향에 영향
    X↑ 바람 신조: "인정받겠다" "세력을 모으겠다" (사회적)
    X↓ 바람 신조: "조용히 살겠다" "내 수련에 전념하겠다" (내면적)

  · 옳음의 신조에는 직접 영향 약함
    단, 같은 신조의 "실현 경로"를 바꿈:
    옳음 90 + X↑ → 혁명가 ("세상을 바꾸겠다")
    옳음 90 + X↓ → 은둔 현자 ("내 삶으로 보여주겠다")

  ③ 5가치에 미치는 영향
  ─────────────────────────────────────────
  · 야망(野): X↑ → 사회적 야망 발현 쉬움 (지위, 인정, 세력)
  · 충(忠): X↑ → 조직 참여도 높아 충이 높아지기 쉬움
           X↓ → 조직과 거리를 두므로 충이 낮아지기 쉬움
  · 의(義)/효(孝)/복수(復): 직접 연결 약함

  주의: X는 가치관의 "내용"을 바꾸지 않는다.
        바꾸는 것은 "표현 방식"과 "실현 경로"다.

  역사 예시:
  · 왕안석(X↑) vs 도연명(X↓) — 옳음 모두 높지만
    왕안석: 적극적으로 개혁을 밀어붙임
    도연명: 은둔하여 시로만 뜻을 표현
    → 같은 원칙이 X에 따라 전혀 다른 행동으로 나타남
```

**A (친화성)**

```
  ① 3축 강도에 미치는 영향
  ─────────────────────────────────────────
  · 옳음(正) 강도에 간접 영향
    A↓ → 불의를 참지 못하는 기질 → 옳음 강도가 "격렬하게" 표현
    A↑ → 불의를 봐도 인내 → 옳음이 있어도 드러나지 않을 수 있음
    주의: A↓이라고 옳음이 높은 건 아님. "표현의 격렬함"이 다를 뿐.

  · 믿음(信) 강도에 간접 영향
    A↑ → 용서할 수 있으므로 신뢰가 유지되기 쉬움
    A↓ → 한 번의 배신에 신뢰가 깨지고 돌아오지 않음

  ② 3축 신조에 미치는 영향
  ─────────────────────────────────────────
  · 옳음의 신조 톤에 영향
    A↓ 옳음 신조: "불의는 반드시 바로잡아야 한다" (전투적)
    A↑ 옳음 신조: "화합으로 세상을 바로잡는다" (중재적)

  · 믿음의 신조 톤에 영향
    A↓ 믿음 신조: "배신하면 끝이다" (절단형)
    A↑ 믿음 신조: "사람은 실수할 수 있다" (용서형)

  ③ 5가치에 미치는 영향
  ─────────────────────────────────────────
  · 복수(復): 가장 직접적
    A↓ → 분노/원한이 깊어 복수가 높아지기 쉬움
    A↑ → 원한을 오래 품지 않아 복수가 낮아지기 쉬움

  · 의(義): A↓ → "불같은 의리" / A↑ → "타협적 의리"
    같은 의 80이라도 A↓이면 불의를 참지 못해 싸우고,
    A↑이면 대화와 중재로 의리를 지킴

  · 충(忠)/효(孝)/야망(野): 직접 연결 약함

  역사 예시:
  · 장비 — A↓ + 의↑. 의리는 극강이나 분노 조절 불가.
    부하에게 화를 참지 못해 결국 잠든 사이 살해당함
  · 노숙 — A↑ + 의 중간. 갈등을 인내하며 중재를 택함.
    관용이 의리를 "중재자의 의리"로 변형시킴
```

**C (성실성)**

```
  ① 3축 강도에 미치는 영향
  ─────────────────────────────────────────
  · C는 강도를 직접 바꾸기보다 "강도의 유지력"에 영향
    C↑ → 옳음/바람 강도가 흔들려도 행동 관성이 유지를 도움
    C↓ → 강도가 높아도 행동이 따라가지 못해 점점 무의미해짐

  · 바람(願) 강도에 간접 영향
    C↑ → 장기 목표를 유지하므로 바람 강도가 안정적
    C↓ → 좌절이 반복되면 바람 자체가 꺼짐
    C↓ + 바람↓ = "부서진 인물" (의지와 계획 모두 상실)

  ② 3축 신조에 미치는 영향
  ─────────────────────────────────────────
  · C는 신조의 "내용"을 바꾸지 않는다
    바꾸는 것은 "신조의 실행 방식":
    같은 "천하를 바로잡겠다"라도
    C↑: 30년 일관된 계획 (제갈량)
    C↓: 즉흥적 돌진과 좌절의 반복 (항우)

  · 단, C↑은 잔혹한 신조도 체계적으로 실행함
    → C는 도덕적으로 중립적 능력

  ③ 5가치에 미치는 영향
  ─────────────────────────────────────────
  · 야망(野): C↑ → 야망이 장기 전략으로 실현되기 쉬움
             C↓ → 야망은 높아도 실현이 좌절
  · 전반적: C↑이면 모든 가치의 행동 일관성이 높아짐
           C↓이면 가치가 있어도 행동이 들쑥날쑥

  · 충(忠)/의(義)/효(孝)/복수(復): 직접 연결보다
    "이미 형성된 가치를 얼마나 일관되게 실행하는가"에 영향

  역사 예시:
  · 제갈량 — C↑ + 옳음↑ + 충↑. 출사표~북벌까지 30년 일관 실행
  · 항우 — C↓ + 바람↑ + 야망↑. 논공행상 실패, 전략보다 즉흥 의존
    → C↓이 야심의 실현을 방해
```

**O (개방성)**

```
  ① 3축 강도에 미치는 영향
  ─────────────────────────────────────────
  · 강도의 "변동 폭"에 영향
    O↑ → 경험에 따라 강도가 유연하게 오르내림
         새로운 관점을 만나면 기존 강도가 흔들리기 쉬움
    O↓ → 한번 형성된 강도가 극도로 단단함
         같은 사건을 겪어도 강도 변화 폭이 작음

  · Tier 2~3 성찰에서 강도 변화 delta에 O가 관여
    O↑인 NPC는 같은 사건에도 강도 변화가 더 클 수 있음
    O↓인 NPC는 강도가 잘 안 움직임

  ② 3축 신조에 미치는 영향 ← 6요인 중 가장 직접적
  ─────────────────────────────────────────
  · 신조 전환 가능성에 가장 강한 영향
    O↑ → 대안 신조를 수용할 확률 높음
         다른 신조를 가진 NPC와 대화 시 공명도(resonance)가 빨리 상승
         Tier 3~4에서 신조 전환이 실제로 일어나기 쉬움

    O↓ → 기존 신조를 고수. 대안을 접해도 공명하지 않음
         신조가 한번 형성되면 극도로 견고
         "고집"과 "신념"의 경계가 모호

  · 복합 신조 가능 여부
    O↑ → 충돌하는 두 신조를 동시에 품을 수 있음
         ("정의도 중요하고, 생존도 중요하다" — 갈등을 수용)
    O↓ → 단순명료한 하나의 신조로 귀결
         ("법은 법이다" — 예외 불인정)

  ③ 5가치에 미치는 영향
  ─────────────────────────────────────────
  · 5가치 자체보다 "5가치 조합의 복잡도"에 영향
    O↑ → 서로 충돌하는 가치를 동시에 높게 유지 가능
         (의 80 + 복수 70 — "의리도 지키고 싶고 원수도 갚고 싶다")
    O↓ → 가치 간 충돌을 단순화하는 경향
         (의 80이면 복수 30 — "의리가 우선이니 복수는 접자")

  · Tier 2~3 성찰에서 5가치 조정 방식에 O가 관여
    O↑ LLM: 여러 가치를 동시에 조정하는 복합 판단
    O↓ LLM: 하나의 가치를 우선시하는 단순 판단

  역사 예시:
  · 왕양명(O↑ + 옳음↑) — 주자학에 의문 → 양명학 창시
    O↑이 신조의 진화를 가능하게 함
  · 해서(O↓ + 옳음↑) — "법은 법이다" 30년간 흔들림 없음
    O↓이 신조의 견고함을 만듦. 그러나 융통성 없이 고립
```

## 3. 2층 → 1층: 가치관이 성격을 바꾸는 경우

### 3.1 원칙: 극히 드물고, 극히 작다

```
  · 성격이 변하는 유일한 경로: Tier 4 (인생 성찰)
  · 한 번에 ±5, 최대 2개 요인
  · 인생에서 손에 꼽을 만큼 드묾

  비유: 바위(성격)에 물(경험)이 흐른다
       수십 년 흘러야 바위가 미세하게 깎인다
       그것도 폭포(Tier4급 사건)일 때만
```

### 3.2 역류가 일어나는 조건

```
  ① 가치관과 성격이 장기간 충돌할 때
     · 성격상 내성적(X↓)인 사람이 리더 역할을 수십 년 수행
       → 경험이 X를 미세하게 끌어올림

  ② 가치관의 극적 전환이 행동 패턴을 바꿀 때
     · 믿음(信)이 붕괴 → 모든 관계를 차단 → E가 미세하게 하락
       (공감할 대상 자체가 사라지므로)

  ③ 가치관 실현 과정에서 성격의 한계를 넘을 때
     · 복수(復)가 극도로 높은 사람이 C↓(충동적)이지만
       복수를 위해 수년간 인내 → C가 미세하게 상승
```

### 3.3 역사·소설 예시

```
  가치관 → 성격 변화의 사례:
  ─────────────────────────────────────

  유방(劉邦) — 방탕한 성격(C↓)이 천하 쟁패 과정에서
    장량·소하의 조언을 수용하며 미세하게 C↑
    "무뢰한"이 "군주"로 변하는 과정에서
    가치관(바람: "천하를 취하겠다")이 행동 습관을 바꿈
    그러나 본질적 기질은 크게 변하지 않았음
    → 천하 통일 후 다시 방탕한 모습이 드러남

  《레 미제라블》 장 발장 — 주교의 은총이 가치관을 바꾸고
    그 가치관이 수십 년에 걸쳐 성격을 미세하게 바꿈
    · 옳음(正) 전환: "세상은 적이다" → "선으로 갚겠다"
    · H: 감옥 시절(H↓) → 시장 시절(H 서서히 ↑)
    · A: 분노와 원한(A↓) → 관용과 인내(A 서서히 ↑)
    → 가치관이 성격을 바꾼 가장 극적인 문학적 사례
    → 그러나 20년이 걸렸고, 완전히 변한 건 아님
      (자베르 앞에서 도망치는 두려움은 끝까지 남아있음)

  《삼국지연의》 관우 — 옳음(正 "의리는 목숨보다 무겁다") 실천이
    원래 다혈질(A↓ 추정)이었을 성격을
    수십 년간 의리를 지키는 과정에서 인내로 단련시킴
    → 그러나 오관참장에서 보듯 분노의 기질은 완전히 사라지지 않음
    → A가 미세하게 상승했을 뿐, 본질적으로 A↓ 기질은 남아있음
```

## 4. 불일치가 만드는 캐릭터의 깊이

### 4.1 왜 불일치가 자연스러운가

```
  성격 = 타고난 기질 (거의 변하지 않음)
  가치관 = 살면서 형성된 것 (경험에 의해 변함)

  사람은 자기 기질과 다른 가치관을 가질 수 있다.
  · 겁 많은 사람(E↑)이 용기를 요구하는 가치관을 가질 수 있다
  · 착취적 기질(H↓)의 사람이 의리의 가치를 습관으로 체화할 수 있다
  · 충동적 기질(C↓)의 사람이 인내를 요구하는 목표를 품을 수 있다

  이 불일치가 바로 "내면 갈등"이다.
  내면 갈등이 없는 캐릭터는 평면적이다.
```

### 4.2 불일치의 네 가지 유형

**유형 1: 기질은 공정하나 가치관이 부서진 경우 (H↑ + 옳음↓)**

```
  "본성은 좋은데 세상에 치여 원칙을 잃은 사람"

  내면 갈등:
  · H↑이므로 불공정한 일을 보면 죄책감이 일어남
  · 그러나 옳음(正)이 낮아져 "그래서 뭐 어쩌라고"로 귀결
  · 죄책감과 무력감 사이에서 시달림

  소설 예시: 《죄와 벌》 라즈콜니코프 (시베리아 이후)
  · 본성의 공정함(H↑)은 남아있으나
  · 자신의 "비범인 이론"(옳음)이 무너진 후
  · 새로운 원칙을 찾지 못한 상태
  · → 이 공백이 소냐와의 관계에서 서서히 채워지는 서사

  역사 예시: 굴원(屈原)
  · 본성이 공정하고 겸손(H↑)했으나
  · 초나라 조정의 부패 앞에서 옳음(正)이 흔들림
  · "충성해봤자 소용없다"는 회의와
    "그래도 나라를 버릴 수 없다"는 기질적 공정함의 충돌
  · → 멱라수에 투신하는 비극적 결말
```

**유형 2: 기질은 착취적이나 가치관이 충성인 경우 (H↓ + 충↑)**

```
  "본성은 이기적인데 습관으로 의리를 지키는 사람"

  내면 갈등:
  · H↓이므로 "이용하면 편할 텐데"라는 유혹이 늘 있음
  · 그러나 충(忠)이 높아 배신의 문턱이 높음
  · 이기심과 충성 사이에서 줄타기

  소설 예시: 《삼국지연의》 가후(賈詡)
  · H↓: 도덕보다 실리를 우선하는 기질
  · 충 70: 현재 주군에게는 충실히 조언
  · 그러나 주군이 망하면 즉시 다음 주군으로 전환
  · → "충성의 대상은 바뀌어도 충성 자체는 유지"하는 역설
  · → 착취적 기질이 충성의 형태를 "조건부 충성"으로 변형

  역사 예시: 조조(曹操)
  · H↓: 기만과 술수에 거리낌 없음
  · 충 높음 (자기 세력에 한정)
  · "간웅"이라는 평가 자체가 이 불일치의 산물
  · → H↓이 충의 형태를 "독점적 충성"으로 변형
```

**유형 3: 기질은 소심하나 가치관이 용기를 요구하는 경우 (E↑ + 옳음↑ + 바람↑)**

```
  "겁은 많은데 해야 할 일은 아는 사람"

  내면 갈등:
  · E↑이므로 위험 앞에서 두려움이 몰려옴
  · 그러나 옳음(正)이 높아 "이건 해야 한다"고 판단
  · 두려움과 의무 사이에서 매번 고통스럽게 선택

  소설 예시: 《반지의 제왕》 프로도 배긴스
  · E↑: 끊임없는 두려움과 걱정
  · 옳음 높음: "반지는 파괴해야 한다"
  · 매 순간 도망치고 싶지만, 원칙이 발을 묶음
  · → 이 불일치가 "평범한 호빗의 영웅서사"의 핵심 동력

  역사 예시: 해서(海瑞)
  · E↑: 상소 전 관을 미리 준비할 만큼 두려움이 큼
  · 옳음 높음: "황제라도 잘못하면 간해야 한다"
  · → 두려워하면서도 직언하는 것이
    두려움 없이 직언하는 것보다 더 강렬한 서사
```

**유형 4: 기질은 열려있으나 가치관이 닫힌 경우 (O↑ + 옳음↑ + 신조 고착)**

```
  "새로운 걸 이해할 수 있는데, 이해하면서도 거부하는 사람"

  내면 갈등:
  · O↑이므로 상대 논리를 이해할 수 있음
  · 그러나 옳음(正)의 신조가 확고하여 수용을 거부
  · "네 말이 맞을 수도 있다. 그래도 나는 이 길을 간다"

  소설 예시: 《카라마조프가의 형제들》 이반 카라마조프
  · O↑: 신학·철학·도덕을 깊이 이해하는 지적 능력
  · 옳음 높음: "신이 만든 세상의 부조리를 받아들일 수 없다"
  · 이해하면서도 받아들이지 못하는 것이 광기로 향하는 길
  · → O↑+옳음↑의 조합이 만드는 "지적 비극"

  역사 예시: 왕안석(王安石)
  · O↑: 기존 제도의 문제를 정확히 이해하고 대안을 설계
  · 옳음 높음: "이 개혁이 옳다"는 확신
  · 반대파의 논리도 이해하지만 수용하지 않음
  · → O↑이 이해력은 높이되 A↓과 결합하여 독선으로 흐름
```

### 4.3 불일치가 서사에서 하는 역할

```
  1. 내면 독백의 원천
     · 불일치가 없으면 NPC가 고민할 이유가 없다
     · "나는 왜 이런 짓을 하는가" = 기질과 가치관의 충돌

  2. 선택의 무게
     · 성격과 가치관이 일치하면 선택이 쉽다 (갈등 없음)
     · 불일치할 때 선택이 어렵고, 그 선택에 무게가 실린다

  3. 변화의 방향 암시
     · 기질은 변하기 어렵다 → 가치관이 기질 쪽으로 수렴할 가능성
     · 또는 가치관이 기질을 미세하게 바꿀 가능성
     · 어느 쪽이든, 불일치는 "이 캐릭터가 앞으로 어떻게 될 것인가"의 힌트

  4. 관계 갈등의 동력
     · NPC A의 불일치가 NPC B의 가치관과 부딪힘
     · "너는 본성은 좋은데 왜 그렇게 사냐" — 이 대사 자체가
       상대방의 1층↔2층 불일치를 지적하는 것
```

## 5. 2층 내부 관계: 3축 ↔ 5가치

> 이 절은 원본 아키텍처 문서 §5의 핵심을 요약한다.

### 5.1 해석 관계

```
  3축(믿음/옳음/바람)과 5가치(충/의/효/복수/야망)는:

  ❌ 자동계산이 아니다
     "옳음 90이면 충 = 옳음×0.8 = 72" → 신조를 무시하는 오류

  ❌ 완전 독립도 아니다
     "둘 다 따로 변함" → 3축의 존재 이유가 없음

  ✅ 해석 관계다
     3축+신조가 5가치의 "왜?"를 설명한다.
     5가치는 그 범위 안에서 경험에 의해 독자적으로 변한다.
```

### 5.2 핵심: 신조가 해석의 방향을 결정한다

```
  같은 옳음 90이라도:
  ─────────────────────────────────────
  · "도의를 지킨다" → 충↑ 의↑ 야망↓
  · "힘이 정의다"   → 충↓ 의↓ 야망↑

  같은 바람 80이라도:
  ─────────────────────────────────────
  · "자유를 원한다"  → 야망 중간 (권력이 목적이 아니므로)
  · "왕좌를 원한다"  → 야망↑ (권력이 직접 목적)
  · "원수를 갚겠다"  → 복수↑ (야망과 질적으로 다른 감정)
```

### 5.3 불일치(관성)는 자연스럽다

```
  3축이 변해도 5가치가 즉시 따라가지 않는다.
  이것이 "관성"이다.

  역사 예시:
  · 관우 말년 — 옳음(正)은 여전히 높지만
    오만함이 쌓이면서 의(義)의 실천이 왜곡됨
    → 옳음 수치와 의 수치의 불일치가 커짐
    → 이 관성이 "맥성의 비극"을 만듦

  소설 예시:
  · 《햄릿》 — 바람(願 "복수") 80이지만
    옳음(正 "정당한 방법으로") 70이 발목을 잡음
    → 바람은 복수를 원하는데 옳음이 수단을 제한
    → 3축 내부의 충돌이 5가치(복수↑ vs 의↑)로 번역됨
```

### 5.4 하향 압력: 3축+신조 → 5가치

3축이 크게 변하면 5가치에 "압력"이 생긴다. 즉시 변화가 아니라, 다음 성찰(Tier 2~3)에서 LLM이 조정한다.

**믿음(信) + 신조 → 5가치**

```
  믿음 강도가 변하면:
  ─────────────────────────────────────────
  · 충(忠)에 압력
    믿음↑ → 조직/주군을 신뢰 → 충에 상승 압력
    믿음↓ → "믿을 수 없다" → 충에 하락 압력
    단, 신조가 방향을 결정:
      "사부만 믿는다" → 사부 관련 충만 상승, 조직 충은 무관
      "모든 관계는 거래다" → 충이 올라가도 "조건부 충성"

  · 효(孝)에 압력
    믿음↑ → 가족에 대한 신뢰 → 효에 상승 압력
    믿음↓ → 가족마저 못 믿음 → 효에 하락 압력
    단, 믿음의 범위에 따라 다름:
      넓은 믿음(세상 전체) → 효에 간접적
      좁은 믿음(가족에 집중) → 효에 직접적

  · 의(義)/복수(復)/야망(野)에는 약한 간접 압력만
    믿음이 무너지면 → 배신감 → 복수에 미약한 상승 압력
    믿음이 무너지면 → "혼자 살아야 한다" → 야망에 미약한 상승 압력

  예시:
  · 오자서 — 초왕에 대한 믿음 붕괴
    → 충 급락 (초나라에 대한 충성 소멸)
    → 복수 급상승 (배신감이 원한으로 전환)
    → 야망은 무관 (목적이 권력이 아니라 복수이므로)
```

**옳음(正) + 신조 → 5가치**

```
  옳음 강도가 변하면:
  ─────────────────────────────────────────
  · 의(義)에 가장 직접적 압력
    옳음↑ → "도리를 지켜야 한다" → 의에 상승 압력
    옳음↓ → "원칙이 뭐가 중요해" → 의에 하락 압력
    단, 신조가 방향을 결정:
      "도의를 지킨다" → 의↑ (강호 도리와 일치)
      "힘이 정의다"   → 의↓ (강호 도리를 부정)

  · 충(忠)에 압력
    옳음 + 신조가 조직 충성과 일치하면 → 충↑
    옳음 + 신조가 조직과 충돌하면 → 충↓
      "나라가 옳지 않으면 떠난다" → 옳음↑이 충↓을 유발

  · 복수(復)에 압력
    옳음↑ + "불의는 바로잡아야 한다" → 복수에 상승 압력
    옳음↑ + "용서가 도리다" → 복수에 하락 압력
    옳음↓ → 복수의 정당성 자체에 무관심 → 압력 약함

  · 야망(野)에 압력
    옳음 + "능력 있는 자가 자리에 앉아야" → 야망↑
    옳음 + "도의를 지키는 게 먼저" → 야망↓ (개인 욕심 억제)

  · 효(孝)에는 약한 간접 압력만
    옳음의 신조가 가족 도리를 포함하면 효↑, 아니면 무관

  예시:
  · 악비 — 옳음 높음 "충군보국"
    → 충↑, 의↑, 야망↓ (개인 야심 없음)
  · 조조 — 옳음 높음 "힘이 정의다"
    → 충↓ (한실에 대한 충성 부정), 의↓, 야망↑
  · 왕안석 — 옳음 높음 "백성을 위한 개혁"
    → 의↑ (자신의 도리), 충↑ (황제를 위한 개혁),
      그러나 야망↑도 동시에 (개혁을 위해 권력이 필요하므로)
```

**바람(願) + 신조 → 5가치**

```
  바람 강도가 변하면:
  ─────────────────────────────────────────
  · 야망(野)에 가장 직접적 압력 — 단, 신조에 따라 완전히 다름
    바람↑ + "왕좌를 원한다" → 야망↑ (직접 전환)
    바람↑ + "자유를 원한다" → 야망 중간 (권력이 아닌 독립)
    바람↑ + "원수를 갚겠다" → 야망과 무관, 복수↑
    바람↓ → 야망에 하락 압력 ("아무것도 원하지 않으니")

  · 복수(復)에 압력
    바람 + "원수를 갚겠다" → 복수에 직접 상승 압력
    바람 + 다른 신조 → 복수와 무관
    바람↓ → "복수할 의지도 없다" → 복수에 하락 압력

  · 충(忠)에 간접 압력
    바람 + "이 조직을 키우겠다" → 충↑
    바람 + "이 조직을 뒤집겠다" → 충↓
    바람↓ → 충에 미약한 하락 압력 (의지 자체가 없으므로)

  · 의(義)/효(孝)에는 약한 간접 압력만
    바람의 신조가 가족이나 도리 관련이면 연결되지만,
    대부분의 바람은 야망/복수 방향이므로 의/효에 직접적이지 않음

  예시:
  · 유비 말년 — 바람 "한실 부흥" → 바람 "의형제 복수"로 전환
    → 야망↓ (천하보다 복수), 복수↑ (관우·장비의 원수)
    → 충↓ (신하들의 만류를 무시), 의↑ (형제 의리)
    → 바람의 신조 전환이 5가치 분포를 근본적으로 재편
```

**하향 압력의 작동 방식:**

```
  1. 3축 강도나 신조가 크게 변함 (Tier 2~4 성찰에서)
  2. 다음 성찰 시 LLM이 현재 3축+신조와 5가치의 불일치를 감지
  3. LLM이 5가치 조정을 제안 (코드가 Tier별 ±범위로 clamp)
  4. 즉시 반영이 아님 — 1~2회 성찰에 걸쳐 서서히 조정
  5. 불일치가 해소되지 않으면 "관성"으로 남음 → 이것이 캐릭터 깊이
```

### 5.5 상향 신호: 5가치 → 3축

5가치의 누적 변화가 쌓이면 Tier 3~4 성찰에서 3축 강도와 신조에 영향을 준다. 하향 압력보다 느리고, 더 큰 사건이 필요하다.

**충(忠) → 3축**

```
  충의 누적 변화가 3축에 보내는 신호:
  ─────────────────────────────────────────
  · 충↑ 누적 → 믿음(信) 강도에 상승 신호
    "이 조직에 오래 충성했다" → "사람을 믿을 수 있다"
    조직 경험이 대인 신뢰로 확장

  · 충↓ 누적 → 믿음(信) 강도에 하락 신호
    "충성했는데 버림받았다" → "사람을 믿어봤자 소용없다"
    → Tier 3~4에서 믿음 신조 자체에 균열 가능

  · 충↓ 누적 → 옳음(正) 신조에 균열 신호
    "충성이 바보짓이었나" → "내가 믿던 도리가 틀렸나"
    → 충의 반복적 좌절이 옳음의 근본을 흔듦

  예시:
  · 한신 — 유방에 대한 충이 반복적으로 좌절
    → 믿음↓, 옳음 신조 "능력으로 인정받겠다"에 균열
    → 결국 모반의 빌미를 잡힘
```

**의(義) → 3축**

```
  의의 누적 변화가 3축에 보내는 신호:
  ─────────────────────────────────────────
  · 의↑ 누적 → 옳음(正) 강도에 상승 신호
    "도리를 지키니 세상이 맞다" → 옳음이 단단해짐
    의리를 지킨 경험이 원칙에 대한 확신을 강화

  · 의↓ 누적 → 옳음(正) 강도에 하락 신호 + 신조 균열
    "의리를 지켰는데 배반당했다" × 반복
    → 옳음 강도 하락 ("원칙이 뭐가 중요해")
    → Tier 3~4에서 옳음 신조 전환 가능
      "도의를 지킨다" → "생존이 먼저다"

  · 의↓ 누적 → 믿음(信) 강도에 하락 신호
    "의리가 통하지 않는 세상" → "사람을 믿어봤자"

  예시:
  · 오자서 — 초나라에 대한 의가 배신으로 붕괴
    → 옳음 신조 전환 ("충군" → "복수가 정의")
    → 믿음↓ (초왕을 믿었던 자신에 대한 분노)
```

**효(孝) → 3축**

```
  효의 누적 변화가 3축에 보내는 신호:
  ─────────────────────────────────────────
  · 효↑ 누적 → 믿음(信) 강도에 상승 신호
    가족 유대가 강할수록 "사람을 믿을 수 있다"의 근거가 됨
    가장 가까운 관계의 신뢰가 대인 신뢰의 기반

  · 효↓ 누적 → 믿음(信) 강도에 하락 신호
    "가족마저 날 버렸다" → 가장 기본적 신뢰의 붕괴
    → Tier 3~4에서 믿음 신조에 근본적 균열

  · 효는 옳음(正)에 약한 신호만
    효 경험이 "가족 도리"를 포함하는 옳음 신조를 강화할 수 있음
    그러나 효 자체가 옳음의 방향을 바꾸지는 않음

  · 효는 바람(願)에 간접 신호
    효↑ → "가족을 지키겠다"가 바람의 신조 후보로 등록될 수 있음
    효↓ → "가족은 포기했다" → 바람이 다른 방향으로 재편

  예시:
  · 오자서 — 부형의 죽음으로 효의 대상 자체가 소멸
    → 믿음 붕괴, 바람 전환 ("복수")
    → 효가 무너진 자리에 복수가 들어선 사례
```

**복수(復) → 3축**

```
  복수의 누적 변화가 3축에 보내는 신호:
  ─────────────────────────────────────────
  · 복수↑ 누적 → 바람(願) 강도에 상승 신호
    "원수를 갚겠다"가 인생의 목적이 되면
    바람 강도 자체가 올라가고, 신조가 복수 방향으로 수렴

  · 복수↑ 누적 → 옳음(正) 신조에 왜곡 압력
    복수가 강해지면 "복수가 곧 정의"로 옳음이 변형될 수 있음
    "도의를 지킨다" → "원수를 갚는 것이 도리다"

  · 복수↑ 누적 → 믿음(信) 강도에 하락 신호
    복수에 몰두할수록 타인에 대한 신뢰가 도구적으로 변함
    "이 사람이 복수에 도움이 되는가?"로 관계를 판단

  · 복수 달성/포기 → 바람(願)에 공백 생성
    복수를 갚은 후 "이제 뭘 하지?" → 바람↓ 또는 신조 전환
    복수를 포기하면 → 바람의 신조가 새로운 방향을 찾아야 함

  예시:
  · 몬테크리스토 백작 — 복수↑↑ 누적
    → 바람 = "복수", 옳음 = "복수가 정의"로 수렴
    → 믿음↓ (모든 관계가 복수의 도구)
    → 복수 완료 후 바람에 공백 → 신조 전환 필요
```

**야망(野) → 3축**

```
  야망의 누적 변화가 3축에 보내는 신호:
  ─────────────────────────────────────────
  · 야망↑ 누적 → 바람(願) 강도에 상승 신호
    야망이 반복적으로 충족되면 → 바람이 더 커짐 ("더 높이")
    야망이 반복적으로 좌절되면 → 바람에 양방향 가능:
      "그래도 원한다" → 바람 유지/강화
      "포기하겠다" → 바람↓

  · 야망↑ 누적 → 옳음(正) 신조에 침식 압력
    "목적을 위해 수단을 가리지 않게" 되면
    옳음의 신조가 야망 방향으로 변형
    "도의를 지킨다" → "이기는 것이 중요하다"

  · 야망↑ 누적 → 충(忠)에 양방향 신호
    야망과 조직이 일치하면 → 충↑ 신호
    야망과 조직이 충돌하면 → 충↓ 신호 ("이 조직은 나를 막는다")

  · 야망↓ 누적 → 바람(願) 강도에 하락 신호
    "아무것도 이루지 못했다" → 바람↓ ("원하는 것이 없다")

  예시:
  · 맥베스 — 야망↑ 누적
    → 옳음 신조 침식 ("왕위는 정당하다" → 수단 불문)
    → 믿음↓ (의심과 공포), 충↓ (왕에 대한 충성 파괴)
    → 야망이 모든 3축을 잠식한 사례
```

### 5.6 상호 영향 요약

```
  ⬇ 하향 압력 (3축 → 5가치):
  ─────────────────────────────────────────
  · 믿음(信) → 주로 충·효에 압력. 신조의 범위가 방향을 결정
  · 옳음(正) → 주로 의·충·야망에 압력. 신조가 5가치 분포를 좌우
  · 바람(願) → 주로 야망·복수에 압력. 신조가 어디로 향하느냐가 핵심

  ⬆ 상향 신호 (5가치 → 3축):
  ─────────────────────────────────────────
  · 충(忠) → 주로 믿음·옳음에 신호. 충의 좌절이 신조를 흔듦
  · 의(義) → 주로 옳음에 신호. 의의 좌절이 원칙을 무너뜨림
  · 효(孝) → 주로 믿음에 신호. 가족 신뢰가 대인 신뢰의 기반
  · 복수(復) → 주로 바람·옳음에 신호. 복수가 인생 목적을 잠식
  · 야망(野) → 주로 바람·옳음에 신호. 야망이 원칙을 침식

  Tier별 작동 방향:
  ─────────────────────────────────────────
  · Tier 2 (일상 성찰): 하향만 — 3축 → 5가치 조정
  · Tier 3 (전환점):    양방향 — 아래 순차 처리 규칙 적용
  · Tier 4 (인생 성찰): 양방향 — 아래 순차 처리 규칙 적용
```

**Tier 3~4 양방향 처리: 순차 규칙**

Tier 3~4에서는 상향 신호와 하향 압력이 동시에 발생한다.
순환 고리를 방지하기 위해, **한 번의 성찰에서 2단계 순차 처리**한다.

```
  ┌─────────────────────────────────────────────────────┐
  │  Tier 3~4 성찰 처리 순서                             │
  │                                                      │
  │  1단계: 상향 먼저 (5가치 → 3축)                      │
  │  ────────────────────────────────                     │
  │  · 누적된 5가치 변화를 보고 3축 강도·신조를 조정      │
  │  · 근거: 5가치는 Tier 1부터 매 사건마다 이미 바뀌어   │
  │    왔으므로, 쌓인 변화를 먼저 3축에 반영하는 것이     │
  │    자연스럽다                                         │
  │  · 예: 의(義)가 Tier 1~2에서 80→60으로 누적 하락     │
  │    → 이 성찰에서 옳음(正) 강도에 하락 반영            │
  │                                                      │
  │  2단계: 하향 다음 (3축 → 5가치)                      │
  │  ────────────────────────────────                     │
  │  · 1단계에서 조정된 3축+신조를 보고 5가치를 조정      │
  │  · 예: 옳음(正) 강도가 하락하고 신조가 흔들렸으므로   │
  │    → 충(忠)에 하락 압력 반영                          │
  │                                                      │
  │  3단계: 남은 불일치 → 관성                            │
  │  ────────────────────────────────                     │
  │  · 2단계 이후에도 3축과 5가치의 불일치가 남을 수 있음 │
  │  · 이것은 다음 Tier 2에서 서서히 해소되거나            │
  │    해소되지 않으면 "관성"으로 남아 캐릭터 깊이가 됨   │
  │                                                      │
  │  핵심: 한 번의 성찰에서 1회전만. 순환 금지.           │
  │  2단계 결과가 다시 3축을 바꾸진 않는다.               │
  │  그 반영은 다음 성찰(Tier 2)의 몫이다.               │
  └─────────────────────────────────────────────────────┘
```

**예시: 사부의 죽음 (Tier 3)**

```
  사건 전 상태:
  · 옳음(正) 80, 신조 "도의를 지킨다"
  · 의(義) 80, 충(忠) 70

  Tier 1~2에서 이미 일어난 일:
  · 사부 위독 소식 → 의 80→75, 효 급상승 (Tier 1)
  · 구하지 못함 → 의 75→65, 충 70→60 (Tier 1~2 누적)

  Tier 3 성찰 (사부 사망 직후):

  1단계 상향:
  · 의가 80→65로 누적 하락, 충도 70→60으로 하락
  · LLM 판단: "도의를 지켰는데 사부를 잃었다"
  · → 옳음(正) 강도 80→65로 하락 (-15, Tier3 ±20 범위 내)
  · → 옳음 신조 뉘앙스 변화:
      "도의를 지킨다" → "도의를 지켜도 지킬 수 없었다"

  2단계 하향:
  · 옳음이 65로 떨어지고 신조가 흔들렸으므로
  · LLM 판단: 충에 추가 하락 압력
  · → 충 60→55 (-5, Tier3 ±20 범위 내)
  · → 의는 이미 충분히 떨어졌으므로 추가 하락 미미

  3단계 남은 불일치:
  · 옳음 65인데 의 65 — 이 정도면 일치
  · 옳음 65인데 충 55 — 약간의 불일치가 관성으로 남음
  · → 다음 Tier 2에서 서서히 조정되거나,
      충이 더 떨어지는 경험이 반복되면 Tier 3~4에서 재처리
```

```
  원칙:
  ─────────────────────────────────────────
  · 하향이 더 빠르고, 상향이 더 느리다
  · Tier 2에서는 하향만, Tier 3~4에서는 상향 먼저 → 하향 순차
  · 한 성찰에서 1회전만. 순환 금지
  · 즉시 동기화는 없다. 시간차(관성)가 깊이를 만든다
```

## 6. 변화의 계기: Tier 1~4 성찰 체계

> 이 문서 전체에서 "Tier"를 반복 참조한다. 여기서 풀어 설명한다.
> 원본: npc-psychology-architecture.md §9

### 6.1 4단계 요약

사람의 내면 변화는 모두 같은 무게가 아니다. 오늘 짜증나는 일과, 사부의 죽음과, 인생 전체를 뒤흔드는 깨달음은 질적으로 다르다. 이 차이를 4단계로 나눈다.

```
  Tier 1 ─ 순간 반응      매 사건마다.  파도의 물결.
  Tier 2 ─ 일상 성찰      하루 끝에.    하루를 돌아보는 일기.
  Tier 3 ─ 전환점 성찰    중대 사건에.  인생의 분기점.
  Tier 4 ─ 인생 성찰      누적된 고비.  사람이 달라지는 순간.

  깊이 ↑   빈도 ↓   영향 범위 ↑   비용 ↑
```

### 6.2 1층·2층 Tier별 변화 범위

```
  ┌────────────┬────────┬────────┬────────┬────────┐
  │            │ Tier 1 │ Tier 2 │ Tier 3 │ Tier 4 │
  │            │ 순간   │ 일상   │ 전환점 │ 인생   │
  │            │ 🔧코드 │ 🧠LLM │ 🧠LLM │ 🧠LLM │
  ├────────────┼────────┼────────┼────────┼────────┤
  │ 1층 성격   │   -    │   -    │   -    │  ±5   │
  │ (HEXACO)   │        │        │        │ 최대2  │
  ├────────────┼────────┼────────┼────────┼────────┤
  │ 2층 3축    │   -    │  ±10  │  ±20  │  ±30  │
  │ (강도)     │        │        │        │        │
  ├────────────┼────────┼────────┼────────┼────────┤
  │ 2층 3축    │   -    │ 뉘앙스 │ 전환   │ 전환   │
  │ (신조)     │        │ 미세   │ 가능   │ 가능   │
  ├────────────┼────────┼────────┼────────┼────────┤
  │ 2층 5가치  │  ±5   │  ±10  │  ±20  │  ±20  │
  └────────────┴────────┴────────┴────────┴────────┘
```

**읽는 법:**

```
  1층 성격:    Tier 4에서만 변한다 (±5, 최대 2요인)
  2층-A 강도:  Tier 2~4에서 변한다 (신조의 "무게"가 흔들림)
  2층-A 신조:  Tier 3~4에서만 전환 가능 (Tier 2는 뉘앙스만)
  2층-B 5가치: Tier 1~4 모두에서 변한다 (실전값이므로 매 사건 반응)

  → 위로 갈수록 안정적, 아래로 갈수록 민감
  → 1층은 거의 불변, 2층-A는 천천히, 2층-B는 매일 출렁임
```

## 7. 전체 관계 요약도

```
  ┌──────────────────────────────────────────────────────┐
  │                                                      │
  │   1층 성격 (HEXACO)                                  │
  │   "원래 어떤 사람인가" — 거의 변하지 않음              │
  │                                                      │
  │          │ (토양 제공)              ▲ (극히 드문 역류) │
  │          │ 결정 ✗, 확률 변경 ✓     │ Tier4에서만      │
  │          ▼                          │ ±5, 최대 2요인  │
  │                                                      │
  │   2층-A 3축 가치관 (믿음/옳음/바람)                   │
  │   "어떤 존재인가" — 천천히 변함                        │
  │   강도: Tier 2~4 / 신조: Tier 3~4                    │
  │                                                      │
  │          │ (하향 압력)              ▲ (상향 신호)     │
  │          │ 즉시 ✗, 성찰 시 조정    │ 누적 변화 →     │
  │          ▼                          │ Tier3~4에서     │
  │                                                      │
  │   2층-B 5가치 (충/의/효/복수/야망)                    │
  │   "어떻게 판단하는가" — 중간 속도로 변함               │
  │   Tier 1~4 (실전값이므로 매 사건 반응)               │
  │                                                      │
  │   ※ 불일치는 자연스럽고, 이것이 캐릭터의 깊이다       │
  │                                                      │
  └──────────────────────────────────────────────────────┘
```

**설계 규칙 요약:**

```
  1. 성격은 가치관을 결정하지 않는다 (토양 ≠ 작물)
  2. 가치관은 성격을 거의 바꾸지 못한다 (물 ≠ 바위)
  3. 불일치는 버그가 아니라 인간다움이다
  4. H는 수단의 성향이다. 도덕 판단은 2층의 영역이다
  5. 신조(방향)가 없으면 수치만으로 인물을 구분할 수 없다
  6. 즉시 동기화는 없다. 시간차(관성)가 깊이를 만든다
```
