## 0. 작명 원칙 요약

```
소속별 이름 체계:

  불교 (소림)     →  법호: 돌림자 + 의미자. 예) 혜(慧)안, 혜(慧)통
  도교 (무당/화산/청성/공동) →  도호: 자연+성품 + "진인/자". 예) 현무진인
  세속 (해남/점창/아미/개방) →  성(姓) + 이름 or 별호. 예) 명경 사태
  왕족              →  성 + 이름 + 시호/연호. 예) 진천명, 태광제
  유목/부족 (남만/북원)     →  고유 음절. 한자는 음차. 예) 바투, 아골
  군벌/장군           →  성 + 강한 이름. 예) 곽천풍

작명 시 고려하는 것:
  ① 한자 뜻이 인물의 역할이나 성격을 반영하는가?
  ② 같은 문파의 다른 세대 인물과 이름 체계가 일관되는가?
  ③ 게임에서 NPC가 이름을 부를 때 자연스러운가?
  ④ 아이러니가 있는가? (이름과 행동이 대조되면 기억에 남음)
```

## 1. 30년차 (240년 전) — 병권 회수 시도

### 1.1 청성 장문인: 벽운자 (碧雲子)

```
한자 분석:
  碧 (벽) = 푸른 옥, 맑고 푸른 빛
  雲 (운) = 구름
  子 (자) = 도교 존칭 접미사

의미: "푸른 구름의 사람"

작명 근거:
  ① 청성산(靑城山)의 "푸른 산세"를 반영 → 소속 암시
  ② 구름 = 자유롭고 붙잡을 수 없음 → 독립 노선의 성격
  ③ 도교 문파 장문인의 표준 명명법 ("~자") 준수

NPC 대사 예시:
  "벽운자 사숙은 '검은 구름처럼 자유로워야 한다'고 하셨지.
   등록이란 구름을 상자에 가두는 것과 같다고."
```

### 1.2 무당 장문인: 태허진인 (太虛眞人)

```
한자 분석:
  太 (태) = 크다, 지극하다
  虛 (허) = 비어 있음, 무위(無爲)
  眞人 (진인) = 도교 고위 수행자 존칭

의미: "지극한 허공에 이른 진인"

작명 근거:
  ① 무당파 = 도교 정통 → "태허"는 도가 최고 경지의 용어
  ② 虛(허) = 비어 있으므로 어느 편도 아님 → 중재자 성격
  ③ 초대 맹주 현무진인(玄武眞人)과 같은 "~진인" 체계 유지
  ④ 아이러니: "비워야 한다"고 가르쳤으나, 무림 분열은 막지 못함

NPC 대사 예시:
  "태허진인 사조께서는 '비우면 담을 수 있다'고 하셨다.
   그분이 중재에 나서신 덕에 무림이 두 쪽으로 갈라지진 않았지."
```

## 2. 70년차 (200년 전) — 교역로 완성

### 2.1 해남 장문인: 육해천 (陸海天)

```
한자 분석:
  陸 (육) = 성씨. 뭍, 땅
  海 (해) = 바다
  天 (천) = 하늘

의미: "땅과 바다와 하늘을 아우르는 사람"

작명 근거:
  ① 해남파 = 해양 문파 → "해(海)"를 이름에 포함
  ② 교역로 개척 시기의 장문인 → 육로+해로를 연결하는 사람
  ③ 세속 문파이므로 "성+이름" 체계
  ④ 거창한 이름 = 상인 기질, "크게 벌려라" 정신

별호: 창파검 (蒼波劍) — "푸른 파도의 검"

NPC 대사 예시 (상인):
  "창파검 육 장문인이 우리 배를 호위해줬지.
   그때부터 해남파와 상방은 한 배를 탄 거야."
```

## 3. 100년차 (170년 전) — 무림대회 분쟁

### 3.1 개방 방주: 일소옹 (一笑翁)

```
한자 분석:
  一 (일) = 하나
  笑 (소) = 웃다
  翁 (옹) = 노인, 어르신

의미: "한 번 웃는 늙은이" — 무엇이든 웃어넘기는 사람

작명 근거:
  ① 개방 방주 = 걸인의 우두머리 → 격식보다 호탕함
  ② 양쪽 모두와 교류하며 중재 → "웃어넘기는" 성격이 핵심
  ③ 별호 형태: 개방은 법호/도호가 아닌 별호(別號) 전통
  ④ "옹(翁)" = 연장자 + 경험 → 정보망의 수장답게

NPC 대사 예시:
  "일소옹 방주께서 비무장에 오셔서 딱 한마디 하셨대.
   '싸우든 말든, 밥은 먹어야지.' 그 한마디에 쉬는 시간이 생겼고,
   쉬는 동안 머리가 좀 식었다더군."
```

## 4. 130년차 (140년 전) — 사파 형성기

### 4.1 소림 방장: 정심 대사 (淨心大師)

```
한자 분석:
  淨 (정) = 깨끗하다, 정화하다
  心 (심) = 마음
  大師 (대사) = 불교 고승 존칭

의미: "마음을 깨끗이 한 큰 스님"

작명 근거:
  ① 소림 방장 = 불교 법호 → "정(淨)" 세대
  ② 이 사람이 "정도(正道)의 기준"을 엄격히 하여 파문을 결정
  ③ 아이러니가 핵심:
     "깨끗한 마음"이라는 이름의 사람이
     → "네 마음이 더럽다"며 제자를 쫓아냄
     → 쫓겨난 자가 천마신교를 세움
     → "깨끗함"을 추구한 결과가 사파 탄생

NPC 대사 예시 (사파):
  "정심? 깨끗한 마음? 웃기지 마라.
   자기 기준에 맞지 않으면 쓰레기통에 버리는 게 '깨끗함'이냐?"

NPC 대사 예시 (정파):
  "정심 대사께서는 고통스러운 결정을 하셨다.
   하지만 혈교 무공을 연구하는 자를 그냥 둘 수는 없었다."
```

## 5. 160년차 (110년 전) — 지방 자치 운동

### 5.1 남만 부족장: 아골타 (阿骨打)

```
한자 분석:
  阿骨打 = 음차(音借). 남만 고유어의 한자 표기
  실제 뜻은 남만어로 "산의 아들" 정도의 의미 설정

작명 근거:
  ① 남만 = 대진과 다른 민족/문화권 → 한자 이름이 아님
  ② 음차 방식: 실제 무협소설에서 이민족은 음차 이름 사용
     (예: 금용 소설의 금나라 이름들)
  ③ "우리는 대진이 아니다"를 최초 선언한 인물
     → 이름 자체가 대진식이 아닌 것이 정체성의 증거
  ④ 역사 참조: 금나라 태조 완안아골타에서 음감 차용
     (직접 차용이 아닌, "이민족 이름"의 전형적 음감으로 활용)

NPC 대사 예시:
  "아골타 대족장이 중원 관리를 쫓아낸 날, 
   남만의 하늘이 처음으로 우리 것이 되었다."
```

### 5.2 서량 장군: 곽천풍 (霍天風)

```
한자 분석:
  霍 (곽) = 성씨. 번개, 빠르다
  天 (천) = 하늘
  風 (풍) = 바람

의미: "하늘의 바람처럼 빠른 사람"

작명 근거:
  ① 서량 = 변경 군벌 → 무인다운 강한 이름
  ② 霍 = 한나라 명장 곽거병(霍去病)의 성 → 변경 장군 이미지
  ③ 天風 = 광활한 초원/사막의 바람 → 서량의 지리적 특성
  ④ 세습 시작 → "곽씨 장군 가문"이 서량 왕조의 기원

별호: 질풍장군 (疾風將軍)

NPC 대사 예시:
  "질풍장군 곽천풍이 말 위에서 선언했다 — 
   '서량의 땅은 서량의 피로 지킨다. 낙양의 명령은 여기까지 오지 않는다.'"
```

## 6. 190년차 (80년 전) — 혈교 잔당 발견

### 6.1 소림 방장: 각원 대사 (覺遠大師)

```
한자 분석:
  覺 (각) = 깨닫다
  遠 (원) = 멀다
  大師 (대사) = 불교 고승 존칭

의미: "깨달음이 먼 사람" — 또는 "먼 곳까지 깨달은 사람"

작명 근거:
  ① 이중적 해석이 핵심:
     정파 해석: "깊고 먼 곳까지 깨달은 대사"
     사후 평가: "깨달아야 할 것을 보지 못한 사람"
  ② 화산파의 혈교 경고를 "과거일" 이라며 무시한 장본인
  ③ 覺(각) = 정심 대사의 "淨" 세대와 다른 세대 (60년 후)

아이러니 구조:
  이름: "깨달음이 먼 곳까지 미친다"
  현실: 바로 눈앞의 위험을 보지 못함
  → 80년 후 혈교가 실제 부활했을 때, 이 이름이 비판의 상징이 됨

NPC 대사 예시:
  "각원 대사... 이름은 '깨달음이 멀리까지'인데, 
   정작 코앞의 혈교를 못 보셨지. 아, 아이러니라는 게 이런 건가."
```

### 6.2 화산 장문인: 수월진인 (守月眞人)

```
한자 분석:
  守 (수) = 지키다
  月 (월) = 달
  眞人 (진인) = 도교 고위 수행자

의미: "달을 지키는 진인" — 밤을 경계하는 사람

작명 근거:
  ① 守(수) = 지키다, 경계하다 → 혈교 감시 체계를 수립한 역할
  ② 月(월) = 밤 → "남들이 잠든 밤에도 깨어 지키는 사람"
  ③ 화산파 도호 체계: 자양진인(개조) → 수월진인 (80년 전)
  ④ 달 = 빛은 있으나 태양만큼 밝지 않음 → 경고했으나 세상을 바꾸진 못함

NPC 대사 예시:
  "수월진인 사조께서 혈교감시단을 세우셨다.
   '달이 뜬다는 것은 밤이라는 뜻이다. 밤에는 깨어 있어야 한다.'
   그 말씀을 아무도 귀담아 듣지 않았지."
```

## 7. 237~260년차 — 마지막 화산파 장문인과 구출자

### 7.1 화산 마지막 장문인: 추양진인 (秋陽眞人)

```
한자 분석:
  秋 (추) = 가을
  陽 (양) = 해, 빛
  眞人 (진인) = 도교 고위 수행자

의미: "가을 햇살의 진인" — 지는 해

작명 근거:
  ① 秋(추) = 가을 = 쇠퇴, 끝이 다가옴 → 화산파의 마지막
  ② 陽(양) = 빛, 따뜻함 → 끝까지 빛을 내려 한 사람
  ③ "가을 해" = 아름답지만 곧 진다 → 비극적 영웅의 이미지
  ④ 화산파 도호 계보:
     자양진인(개조) → 진무양(240년전) → 수월진인(80년전) → 추양진인(마지막)
     "양(陽)"이 개조와 마지막에 모두 있음 → 순환 구조

시간선:
  33년 전: 태무제에 대항. "혈교와 거래하는 황제를 인정할 수 없다"
  12년 전: 피의 실종 사건 중 화산파 제자 보호
  10년 전: 붉은 밤의 변. 최후까지 저항하며 제자들 탈출 시도. 전사.

NPC 대사 예시:
  "추양진인... 가을 해처럼 끝까지 빛나셨다.
   화산이 불타는 밤에도 칼을 놓지 않으셨어."
```

### 7.2 플레이어 구출자: 임서운 (林書雲)

```
한자 분석:
  林 (임) = 성씨. 숲
  書 (서) = 글, 기록하다
  雲 (운) = 구름

의미: "구름에 글을 쓰는 사람" — 사라지는 기록자

작명 근거:
  ① 林(임) = 기존 "임모"에서 성씨 유지
  ② 書(서) = 기록 → 화산파의 기억을 플레이어에게 전달하는 역할
  ③ 雲(운) = 구름 → 사라진다 (행방불명)
  ④ "구름에 쓴 글" = 흔적은 남기되 붙잡을 수 없음
     → 플레이어가 찾아 헤매는 대상

화산파 내 위치:
  추양진인의 수제자. 30대. 혈교감시단 실무 담당.
  붉은 밤에 추양진인의 명으로 7세 플레이어 + 혈매화검을 가지고 탈출.
  이후 행방불명 → "임서운을 찾아라"가 메인 퀘스트 축 중 하나.

NPC 대사 예시 (자유도시 정보상):
  "임서운? ...10년 전에 피투성이로 아이 하나를 안고 나타났다가
   사라진 사람 말이야? 아직 살아있는지는 모르겠는데..."
```

## 8. 240년차 (30년 전) — 타락한 영웅들

### 8.1 영웅 ①: 풍만리 (風萬里)

```
한자 분석:
  風 (풍) = 바람
  萬 (만) = 만, 수많은
  里 (리) = 거리 단위 (약 400m)

의미: "만 리의 바람" — 천하를 누비는 영웅

작명 근거:
  ① 거창한 영웅적 이름 → 타락 이전의 명성을 반영
  ② 風(풍) = 자유, 빠름 → 경공의 달인
  ③ 萬里 = "만 리를 간다" → 실제로 천하를 떠돌었던 방랑 협객
  ④ 타락 후: "만 리를 달려도 도망칠 수 없는 것이 있다"
  ⑤ 무소속 → 정파에도 사파에도 속하지 않은 독립 무인

타락 방식: 혈교 비술로 수명 연장 → 80대인데 40대 외모
현재 상태: 생존 여부 불명. "어딘가에 숨어 있다"는 소문

NPC 대사 예시:
  "풍만리... 30년 전에는 정말 바람 같은 사람이었어.
   혈교를 치러 가면서도 웃고 있었지.
   그런데 돌아온 뒤... 눈이 달라졌더라고."
```

### 8.2 영웅 ②: 설무한 (薛無恨)

```
한자 분석:
  薛 (설) = 성씨
  無 (무) = 없다
  恨 (한) = 한, 원망

의미: "원한이 없는 사람" — 의로운 무인

작명 근거:
  ① 無恨(무한) = "원한 없이 산다" → 원래 너그러운 성격
  ② 타락 후 아이러니:
     "원한이 없다"던 사람이
     → 혈교 비술에 물든 뒤 "원한만 남은 사람"이 됨
  ③ 소림 속가 제자 출신 → 불교적 이름 영향
  ④ 30년 전 전쟁에서 명경(아미)과 함께 전장에 있었음

타락 방식: 혈교와의 전투 중 마공에 감염 → 성격 변질
현재 상태: 대진 어딘가에 잠적. 조고와 연결 의혹.

NPC 대사 예시 (명경):
  "설무한... 전장에서 그 사람이 나를 두 번이나 살려줬어.
   원한 없이 사는 사람. 정말 그런 사람이었는데.
   ...지금 그가 어떻게 되었는지는 묻지 마."
```
