### 이름의 뜻

```
南宮 = 남쪽 궁궐. 무협 명문 세가의 전통 성씨.
赫   = 빛날 혁, 붉을 혁, 혁혁(赫赫)

"남쪽 궁궐의 빛나는 자"

  赫(혁)의 이중성:
  ① 빛나다 → 독립 전쟁의 영웅. 칠국에서 가장 빛나는 검.
  ② 붉다   → "붉은 밤의 변"에 이름이 걸려있다.
              피로 빛나는 자.

  아이러니:
  "혁혁한 공을 세운 자"의 이름이
  "붉은 밤"과 연결되어 있다는 것.
  영광과 피가 같은 글자 안에 있다.

  별호 검왕(劍王):
  무림에서 자발적으로 붙인 이름이 아니라,
  남궁 왕국 건국 후 스스로 칭한 것.
  "검으로 왕이 된 자" — 무인이자 군주.
  → 정파 무인들은 이 칭호를 불쾌해한다.
     "왕"은 세속의 것이고, "검"은 무림의 것인데,
     둘을 합친 것은 문파와 국가의 경계를 무시한 것.
```

### 공감 45의 의미 — 영웅의 맹점

```

  → 그래서 행동하지 못한다 (모두를 구할 수 없으니)

조고의 공감 75: "모든 사람의 약점이 보인다"
  → 그래서 조종한다

남궁혁의 공감 45: "대의(大義) 앞에서 개인의 고통이 안 보인다"
  → 그래서 화산파를 멸할 수 있었다 (사실이라면)
  → "천 명을 살리기 위해 백 명을 죽이는 것은 정당한가?"

## 6. 배경 서사

### 3줄 요약

> 대진의 명문 남궁세가 후계자로 태어나, 독립 전쟁으로 왕국을 세운 영웅.  
> "붉은 밤의 변"에서 화산파 멸문에 관여했다는 의혹이 유일한 그림자.  
> 칠국 최강의 검을 가졌지만, 그 검이 무고한 피를 베었는지 스스로도 확답하지 못한다.

### 상세 연표

| 시기 | 나이 | 사건 | 심리 변화 |
|------|------|------|-----------|
| 약 42년 전 | 0세 | 남궁세가 적장자로 출생. 대진 내 명문 무가 | "검의 집안에서 태어남" |
| 30년 전 | 12세 | 2차 혈교 침공. 소년 남궁혁, 전장 근처에서 영웅들을 목격 | 명경·풍만리·설무한의 전투를 먼 곳에서 봄. "저런 사람이 되겠다" |
| 25년 전 | 17세 | 선대 당주(아버지) 사망. 남궁세가 당주 계승 | "아버지의 유언: '때가 되면 스스로 서라'" |
| 20년 전 | 22세 | 대진 내 영토 확장. 주변 소문파 흡수. 검명(劍名)이 퍼짐 | "검으로 사람들을 모을 수 있다" |
| 15년 전 | 27세 | 태무제 사후 혼란기. 대진 조정과 거리를 둠 | "이 조정은 이미 끝났다" |
| 12년 전 | 30세 | 피의 실종 사건 시기. 이 시기 남궁혁의 행적은? | 기록 공백 — 의문 |
| 10년 전 | 32세 | **붉은 밤의 변. 화산파 멸문.** 남궁혁 관여 의혹 | (비밀 ① 참조) |
| 8년 전 | 34세 | 남궁 왕국 독립 선언. 대진으로부터 영토 분리 | "스스로 선다" — 아버지의 유지 실현 |
| 5년 전 | 37세 | 칠국 체제 확립. 남궁 왕국이 서부 최강국으로 부상 | "검왕" 칭호 자칭. 청성파를 보호/통제 아래 둠 |
| 현재 | 42세 | 칠국 중 군사적 최강국. 그러나 내부 갈등 증가 | "나라는 세웠는데, 무림을 잃었다" |

```
남궁혁의 인생 — 두 개의 선:

  무인으로서의 남궁혁:
  ──────────────────────────────────────
  12세: 영웅을 동경 ──→ 17세: 검의 길 시작
  ──→ 22세: 검명 확립 ──→ 32세: 전성기
  ──→ 42세: "칠국 최강의 검" ──→ ...
  = 순수한 상승 곡선. 결점 없는 무인.

  왕으로서의 남궁혁:
  ──────────────────────────────────────
  17세: 당주 계승 ──→ 27세: 독립 결심
  ──→ 32세: "필요한 일"을 함 (붉은 밤?)
  ──→ 34세: 건국 ──→ 42세: 통치의 무게
  = 올라갈수록 더러워지는 곡선.

  두 선의 교차점이 바로 "붉은 밤의 변" (32세).
  무인 남궁혁은 화산파를 존경했다.
  왕 남궁혁은 화산파를 제거해야 했다.
  → 게임의 핵심 질문:
     "같은 사람 안에서 무인과 왕이 싸울 때, 누가 이기는가?"
```

        │
  [남 궁 혁] ──── 적대 ──── [조고]
   │    │    │                  │
   │    │    │          (상호 이용 시도)
   │    │    │
   │    │    └──── 경계 ──── [당무괴]
   │    │                      (천적: 독 vs 검)
   │    │
   │    └──── 통제 ──── [청성파]
   │                     "보호인가 새 주인인가?"
   │
   └──── ???? ──── [플레이어]
                    혈매화검을 든 아이.
                    화산파의 마지막 흔적.
                    → 남궁혁에게 가장 곤란한 존재.

  핵심:
  남궁혁은 "혼자서 모든 것을 결정하는 사람"이다.
  조고가 "거미줄"이라면, 남궁혁은 "고독한 탑".
  높은 곳에서 모든 것이 보이지만,
  아무에게도 진심을 보여줄 수 없다.
```

### 청성파와의 관계 — 정파의 딜레마

```
남궁 왕국 건국 후:
  남궁혁은 자국 영토 내 무림 문파를 "보호"했다.
  청성파가 가장 큰 수혜자(그리고 피해자).

  남궁혁의 논리:
  "대진이 무너지면 문파도 위험하다.
   내가 보호해주겠다. 대신, 내 법을 따라라."

  청성파의 현실:
  · 무파(武派)의 독립성을 잃음
  · 남궁 왕국의 "검술 교관" 역할 강제
  · 벽운자(청성 장문인)는 이에 반발하다 은퇴
  · 새 장문인은 남궁혁에 순응

  게임 내 갈등:
  "남궁혁은 보호자인가, 새 주인인가?"
  → 플레이어가 청성파 제자들의 불만을 이용할 수 있음
  → 또는 남궁혁을 설득하여 자유를 되찾아줄 수 있음
```

## 8. 비밀 (Secret) — 플레이어가 발견할 것

### 비밀 ① — 붉은 밤의 진짜 역할

```
공식 기록: "화산파는 대진 황실에 의해 '반역 혐의'로 토벌당했다"
남궁혁의 공식 입장: "관여하지 않았다"

진실 (추정 — 복수의 가설):

  가설 A: "남궁혁이 직접 지휘했다" (단순)
    → 화산파의 영토가 남궁 왕국의 서쪽 국경
    → 독립을 위해 "장애물"을 제거
    → 조고와 공모: 조고는 명분 제공, 남궁혁은 무력 실행
    → 이 경우 남궁혁은 "영웅의 가면을 쓴 학살자"

  가설 B: "남궁혁은 방조했다" (회색)
    → 조고가 주도하고, 남궁혁은 알면서 막지 않았다
    → "막을 수 있었는데 막지 않은 것"
    → 직접 손을 더럽히진 않았지만, 결과적으로 수혜자
    → 이 경우 남궁혁은 "양심과 타협한 현실주의자"

  가설 C: "남궁혁은 함정에 빠졌다" (반전)
    → 조고가 남궁혁의 이름을 도용하여 화산파 습격
    → 남궁혁은 사후에 진실을 알았지만,
       이미 독립 전쟁 중이라 진실을 밝힐 수 없었다
    → "내가 아니라고 말하면, 독립의 명분이 흔들린다"
    → 이 경우 남궁혁은 "진실보다 나라를 선택한 비극적 영웅"

  어떤 가설이든:
  남궁혁은 화산파 멸문으로 인해 "빚"을 지고 있다.
  그 빚의 무게가 다를 뿐이다.

→ 조고 열전의 3가설과 연동 설계.
→ 플레이어의 탐색 루트에 따라 진실이 달라진다.
```

### 비밀 ② — 추양진인의 마지막 말

```
남궁혁이 가설 A/B에서 현장에 있었다면:

  추양진인이 죽기 전 남궁혁에게 한 말:
  "남궁 소년... 네가 여기 있을 줄 알았다.
   화산의 검은 네 검보다 오래되었지만,
   오늘은 지는 것이 맞다.
   다만... 아이들만은 보내다오."

  남궁혁은 이 말을 들었다.
  그리고 임서운이 플레이어(7세)를 데리고 도망치는 것을
  "보고도 쫓지 않았다."

  → 이것이 남궁혁의 유일한 자비.
  → 그리고 유일한 실수.
  → 혈매화검을 든 아이가 15년 후 돌아올 줄은 몰랐다.
  → 공감 45 — 추양진인의 마지막 부탁을 들어줄 만큼은 있었다.
     하지만 화산파 전체를 살릴 만큼은 없었다.
```

### 비밀 ③ — 검의 한계

```
남궁혁은 알고 있다:
  "검으로 나라를 세울 수는 있지만,
   검으로 나라를 유지할 수는 없다."

  건국 10년째. 남궁 왕국의 문제:
  · 경제가 약하다 (무인 국가, 상업 기반 부족)
  · 동해 연방(진대인)에 경제적으로 의존하고 있다
  · 청성파 등 문파의 불만이 쌓이고 있다
  · 후계자가 없다 (미혼, 자녀 없음)
  · 남궁혁 개인의 무력에 너무 의존하는 체제

  남궁혁의 두려움:
  "내가 죽으면 남궁 왕국도 끝이다."
  → 야망(0.8)이 아니라 두려움(0.3 신경증)이 그를 움직인다
  → 왕국의 영속을 위해 더 강해지려 하고,
     더 강해질수록 주변이 두려워하고,
     주변이 두려워할수록 고립되는 악순환.

  게임적 의미:
  이 비밀을 발견하면 "남궁혁 설득 루트"가 열린다.
  "당신에게 필요한 것은 더 강한 검이 아니라,
   함께 세울 사람입니다."
```

## 10. 퀘스트 연결점

| 퀘스트 | 트리거 | 분기 | 보상 |
|--------|--------|------|------|
| **검성의 문** | 남궁 왕국 진입 + 혈매화검 소지 | 환영 or 체포 or 시험 | 남궁 왕국 접근권 |
| **붉은 밤의 목격자** | 명경 유서 + 남궁 영토 탐색 | 생존자 증언 수집 | 붉은 밤 진실 조각 |
| **청성파의 한숨** | 청성파 접촉 + 신뢰 | 불만파 합류 or 남궁혁 설득 | 남궁 왕국 내부 분열/화합 루트 |
| **검왕의 시험** | 남궁혁 호감도 50+ | 검술 대련 → 사제/동맹/적대 분기 | 남궁검법 일부 습득 가능 |
| **왕과 무인** | 붉은 밤 진실 완전 해명 | 남궁혁을 처단/용서/동맹 | 게임 엔딩 대분기 |

```
퀘스트 흐름도:

  [남궁 왕국 진입] ─→ "검성의 문"
          │                │
          │    ┌───────────┼───────────┐
          │    │           │           │
          │  환영 루트    시험 루트    체포 루트
          │    │           │           │
          │    └───────────┼───────────┘
          │                │
          ├─→ "청성파의 한숨" ←─ (병행 가능)
          │        │
          │        ├─→ 불만파 합류 → 내부 분열 유도
          │        └─→ 남궁혁 설득 → 청성파 해방
          │
          ├─→ "검왕의 시험" (호감도 50+)
          │        │
          │        ├─→ 검술 습득 (사제 루트)
          │        ├─→ 동맹 (대등한 관계)
          │        └─→ 적대 확정 (패배 시)
          │
          └─→ "붉은 밤의 목격자" + "왕과 무인" (최종)
                    │
                    ├─→ 처단: 남궁혁 사망 → 남궁 왕국 붕괴 → 칠국 균형 파괴
                    ├─→ 용서: 남궁혁 생존 → 화산파 추모 약속 → 동맹
                    ├─→ 동맹: 남궁혁과 함께 조고 타도 → 가장 강력한 전력
                    └─→ 방치: 남궁혁 존속 → 빚이 남은 채 평행선

  ※ "조고 타도 루트"에서 남궁혁 동맹이 가장 강력한 군사 지원
  ※ 그러나 화산파를 멸한 자와 동맹하는 것의 도덕적 대가
```

## 11. LLM 대사 생성 가이드 (AI 도메인)

### 말투 규칙

```
1. 짧은 문장. 군더더기 없음. 검처럼 잘린 말.
   ✗ "나는 이 문제에 대해서 깊이 생각해 보았는데..."
   ✓ "생각해 봤다. 답은 하나다."

   → 조고와 정반대. 조고는 돌려 말하고, 남궁혁은 직선이다.

2. 명령형이 자연스러움. 왕이자 무인.
   "앉아라." "검을 들어라." "말해 보거라."
   그러나 존경하는 상대에게는 경어를 씀.
   "명경 사태, 오랜만입니다."

3. 비유를 쓰지 않는다. 사실만 말한다.
   ✗ "구름이 해를 가리듯..."
   ✓ "화산파는 멸했다. 그것이 사실이다."
   → 비유는 약한 자의 도구라고 생각함
   → (그런데 술에 취하면 비유가 나온다 — 숨겨진 감성)

4. 감정은 "동작"으로만 드러남.
   ✗ "슬프다" "괴롭다"
   ✓ (검을 쥔 손에 힘이 들어간다.)
   ✓ (잔을 내려놓는 손이 미묘하게 떨린다.)
   → LLM에게 감정 묘사 대신 동작 묘사 지시

5. 금기어: "미안하다", "잘못했다" — 절대 먼저 사과하지 않음
   대신: 침묵, 행동으로 보상, 또는 질문으로 전환
   "내가 잘못한 것인지는... 네가 판단해라."
```

### 행동 결정 예시 (Personality × Values)

```
상황: "혈매화검을 든 젊은이가 남궁 왕국에 나타났다는 보고"

  ① 가치관 확인:
     야망(0.8) → "위협인가? 기회인가?"
     의(0.7)  → "화산파의 유민이라면... 도리가 있다"
     효(0.8)  → "아버지라면 어떻게 했을까"
     복수(0.4)→ (이 경우 해당 없음)

  ② 성격 확인:
     성실성(0.9) → "회피하지 않는다. 만나야 한다."
     외향성(0.7) → "직접 만나겠다."
     친화성(0.4) → "그러나 마음을 열지는 않는다."
     신경증(0.3→0.5) → (혈매화검 언급 시 불안 상승)

  ③ 최종 결정:
     "들여보내라. 국경에서 막으면 의심만 산다.
      먼저 나에게 오라고 전하라.
      ...검을 빼앗으려 하지 마라. 화산의 검이다."
     → 직면 선택 (성실성 0.9 + 외향성 0.7)
     → 마지막 한 마디가 의(0.7)의 발현
```

## 13. 종합 — 남궁혁이라는 인물

```
한 문장 요약:
  "검으로 나라를 세운 영웅.
   그 검이 무고한 피를 베었는지,
   스스로도 확답하지 못하는 왕."

와호장룡 대응:
  이모백(李慕白) — 무림 최강이지만 "검을 내려놓고 싶은 사람"
  다만 남궁혁은 이모백보다 더 세속적.
  이모백은 검을 놓으려 했고, 남궁혁은 검으로 왕관을 만들었다.
  같은 출발점(무림 최강)에서 정반대 선택을 한 두 사람.

게임적 가치:
  ① 순수 전투형 보스 — 게임 내 최강의 검과 맞붙는 경험
  ② 도덕적 회색 지대 — "영웅이 저지른 죄"를 어떻게 판단할 것인가
  ③ 관계 분기 극대화 — 사제/동맹/적대 모두 가능한 유일한 적대자
  ④ 조고 타도 루트의 핵심 동맹 — 군사력 제공
  ⑤ 화산파 메인 퀘스트의 최종 답 — "누가 화산파를 죽였는가"
```
