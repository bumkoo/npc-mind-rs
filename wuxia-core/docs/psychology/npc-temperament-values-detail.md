# NPC 기질·가치관 상세 설계

> **버전**: v1.2 | **최종 수정**: 2026-02-28  
> **범위**: ①층 기질(HEXACO) + ②층 가치관(3축+5가치) 상세 설계  
> **상위 문서**: [npc-psychology-architecture.md](npc-psychology-architecture.md)  
> 📎 HEXACO 참조: Lee & Ashton (2012) "The H Factor of Personality"  
> 📎 진화적 해석: Ashton & Lee (2007) "Empirical, Theoretical, and Practical Advantages of the HEXACO Model"
>
> ⚠️ **H 요인 표기 규칙**  
> 학술 원본 명칭 `Honesty-Humility(정직-겸손)`을 유지하되,  
> 게임 시스템 해석으로 **`(원칙↔실리)`** 주석을 병기한다.  
> 이는 "높다=좋다"는 도덕적 편향을 방지하기 위함이다.  
> 이 문서를 참조하는 모든 하위 설계 문서에서도 이 규칙을 따른다.

---

## 0. 이 문서의 목적

```
  이 문서는 두 가지를 상세히 설계한다:

  ① 기질 (HEXACO) — "이 사람은 태어날 때부터 어떤 사람인가"
  ② 가치관 (3축 + 5가치) — "살면서 무엇을 믿고, 무엇을 따르게 되었나"

  그리고 다음을 밝힌다:
  · 두 층의 조합에서 어떤 인물 유형이 도출되는가
  · 두 층 사이에 어떤 관계가 있는가
  · 두 층은 어떻게 뚜렷이 구분되는가

  인물 원형 예시는 역사·문학·영화의 유명 인물을 사용한다.
  이는 게임 고유 NPC 설계 시 레퍼런스로 활용하기 위함이다.
```

## 1. 기질과 가치관의 근본적 차이

두 층은 근본적으로 다른 것을 표현한다. 이것이 흐려지면 시스템 전체가 무너진다.

### 1.1 핵심 구분

```
  ┌──────────────────────────────────────────────────────────────────┐
  │                   기질 (①층)          가치관 (②층)              │
  ├──────────────────────────────────────────────────────────────────┤
  │ 본질         반응의 스타일           판단의 기준                 │
  │ 비유         그릇의 모양             그릇에 담긴 내용물          │
  │ 질문         "어떻게 반응하는가"     "무엇을 기준으로 판단하는가"│
  │ 형성 시기    태어날 때 대부분 결정   살면서 경험으로 형성        │
  │ 변화 속도    극히 느림               천천히 (때로 급변)          │
  │ 변화 원인    인생급 충격만           경험 누적 + 선택            │
  │ 도덕적 방향  없음 (높다고 좋지 않음) 있을 수 있음 (신조에 따라)  │
  │ 의식 접근성  본인도 잘 모름          본인이 말로 표현 가능       │
  │ 유전 기여도  20~50%                  낮음 (환경이 주도)          │
  │ 척도         0~100                   0~100 + 신조(텍스트)        │
  └──────────────────────────────────────────────────────────────────┘
```

### 1.2 같은 행동, 다른 원천 — 구분이 왜 중요한가

```
  "어떤 장수가 부하를 보호한다" — 왜?

  기질 설명 (①층):
  · H 높음(원칙) → 본능적으로 공정함을 추구한다
  · E 중간 → 적당히 걱정하지만 과도하지 않다
  · A 높음 → 갈등보다 보호를 선호한다
  → 기질은 "보호 행동이 자연스러운 사람"이라고 말한다

  가치관 설명 (②층):
  · 옳음 90 "아랫사람을 지켜야 한다" → 보호는 장수의 도리
  · 충 90 → 맡은 바에 충실
  · 효 80 → 윗사람-아랫사람 관계의 책임
  → 가치관은 "왜 보호해야 하는지 이유를 안다"고 말한다

  둘 다 필요한 이유:
  · 기질만 있으면: "공정한 사람"이지만 왜 부하를 보호하는지 모른다
  · 가치관만 있으면: "도의를 지킨다"지만 다른 도의파와 구분이 안 된다
  · 둘의 조합: "본능적으로 공정하고(기질) + 도의를 체화한(가치관) 사람"
```

### 1.3 결정적 테스트 — "이것은 기질인가 가치관인가?"

```
  질문                                          답이 기질    답이 가치관
  ────────────────────────────────────────────────────────────────────
  "쌍둥이가 다른 환경에서 자라도 비슷할까?"      예          아니오
  "본인이 왜 그런지 설명할 수 있는가?"            어려움      가능
  "10년 전에도 이랬을까?"                         대체로 예   상황에 따라
  "큰 사건 하나로 바뀔 수 있는가?"                거의 불가   가능
  "문화가 다르면 달라지는가?"                     약간        크게
  "의식적으로 노력하면 바꿀 수 있는가?"           매우 어려움 가능 (느리지만)
```

## 2. ①층 기질 (HEXACO) 상세 정의

> "이 사람은 원래 어떤 사람인가" (性)

### 2.1 6요인 정의 (0~100 척도)

```
  요인                    척도      핵심 질문
  ────────────────────────────────────────────────────────────────────

  H (정직-겸손)           0~100    "원칙을 따르는가, 실리를 따르는가?"
  Honesty-Humility                  ※ 게임 해석: 원칙(原則) ↔ 실리(實利)
  (원칙↔실리)                       높음(70+): 규칙 준수, 공정, 겸손, 탐욕 적음
                                    중간(30~70): 상황에 따라 유연
                                    낮음(~30): 실리 추구, 유연한 수단, 기회 포착, 전략적

  E (정서성)              0~100    "자신과 가족의 안전에 민감한가?"
  Emotionality                      높음(70+): 두려움, 걱정, 공감, 애착 강함
                                    중간(30~70): 적절한 경계심
                                    낮음(~30): 대담, 냉담, 독립적, 위험 불감증

  X (외향성)              0~100    "사회적으로 자신감 있고 활발한가?"
  eXtraversion                      높음(70+): 사교적, 자신감, 활력, 주도적
                                    중간(30~70): 필요할 때 사교적
                                    낮음(~30): 내성적, 조용, 혼자를 선호

  A (친화성)              0~100    "도발에 참을 수 있고 용서하는가?"
  Agreeableness                     높음(70+): 관용, 인내, 유연, 용서
                                    중간(30~70): 보통의 인내심
                                    낮음(~30): 분노, 원한, 고집, 비판적

  C (성실성)              0~100    "규율 있고 계획적인가?"
  Conscientiousness                 높음(70+): 근면, 체계적, 신중, 완벽주의
                                    중간(30~70): 적당히 계획적
                                    낮음(~30): 충동적, 무계획, 태만, 즉흥적

  O (개방성)              0~100    "새로운 경험과 사고에 열린가?"
  Openness                          높음(70+): 창의적, 지적 호기심, 유연한 사고
                                    중간(30~70): 실용적 호기심
                                    낮음(~30): 관습적, 실용적, 보수적
```

### 2.2 진화적 의미 — 왜 6개인가

Ashton & Lee(2007)에 따르면 6요인은 생존에 필요한 두 가지 맥락에서 진화했다.

```
  ━━━ 맥락 1: 호혜적/혈연 이타주의 (타인과의 협력) ━━━

  H (정직-겸손 | 원칙↔실리) = 협력 전략 선택
    · 높으면(원칙): 남을 속이지 않아 장기 신뢰 획득에 유리
    · 비용: 실리적 기회를 놓침
    · 낮으면(실리): 유연한 수단으로 단기 이득 획득에 유리
    · 비용: 장기 신뢰 형성이 어려움

  A (친화성) = 관용 기반 협력
    · 높으면: 갈등에서 용서하여 관계 유지에 유리
    · 비용: 이용당해도 참아서 손해를 봄

  E (정서성) = 혈연 보호 본능
    · 높으면: 가족/친구에 대한 투자와 보호 강함
    · 비용: 개인적 이득을 위한 모험을 못 함

  ━━━ 맥락 2: 환경 몰입 (세상과의 관계) ━━━

  X (외향성) = 사회적 몰입
    · 높으면: 사회적 자원(동맹, 정보) 획득에 유리
    · 비용: 에너지 소모, 갈등 노출 증가

  C (성실성) = 과업 몰입
    · 높으면: 장기 목표 달성에 유리
    · 비용: 유연성 부족, 기회 비용

  O (개방성) = 아이디어/탐구 몰입
    · 높으면: 혁신, 새로운 환경 적응에 유리
    · 비용: 검증 안 된 아이디어에 에너지 낭비
```

**이것이 NPC 설계에 주는 의미**: 모든 기질 값에는 이득과 비용이 있다.
높다고 좋은 게 아니고 낮다고 나쁜 게 아니다.
이것이 기질이 "도덕적 방향이 없다"는 말의 구체적 근거다.

### 2.3 2요인 조합으로 보는 인물 원형 16가지

6요인 전부를 한꺼번에 보면 복잡하다.
핵심 2요인씩 조합하면 직관적인 인물 원형이 나온다.
**예시는 역사·문학·영화의 유명 인물을 사용한다.**

#### H × A 조합: "원칙↔실리 × 분노 조절" — 대인관계의 핵심

```
  ┌─────────────────────┬──────────────────────────────────────────┐
  │                     │         A (친화성)                       │
  │ H (정직-겸손)       │   낮음(~30)            높음(70+)         │
  │ (원칙↔실리)         │                                          │
  ├─────────────────────┼──────────────────────────────────────────┤
  │                     │                                          │
  │ 높음(70+)           │ 【원칙적 분노가】      【인자한 군자】   │
  │ (원칙)              │ 공정하지만              공정하고          │
  │                     │ 부정에 참지 못함        부정에도 관용     │
  │                     │                                          │
  │                     │ 예: 관우(삼국지)        예: 유비(삼국지)  │
  │                     │ · 의리에는 곧지만       · 원칙을 지키되  │
  │                     │   적에게 가차없음         원수에게도 관대 │
  │                     │                                          │
  │                     │ 예: 장발장(레미제라블)  예: 아틱 핀치     │
  │                     │ · 정의감이 강하나       (앵무새 죽이기)   │
  │                     │   부조리에 격분         · 인종차별 앞에서 │
  │                     │                          도 침착한 관용   │
  │                     │                                          │
  │ 낮음(~30)           │ 【잔인한 폭군】         【웃는 독사】    │
  │ (실리)              │ 실리적이고              실리적이지만      │
  │                     │ 분노도 격함             표면은 온화       │
  │                     │                                          │
  │                     │ 예: 동탁(삼국지)        예: 이아고        │
  │                     │ · 탐욕스럽고 잔혹       (셰익스피어 오셀로)│
  │                     │   반항하면 학살         · 친근한 얼굴로   │
  │                     │                          뒤에서 완벽하게  │
  │                     │                          조작             │
  │                     │                                          │
  │                     │ 예: 진시황              예: 리틀핑거      │
  │                     │ · 실리와 분노가         (왕좌의 게임)     │
  │                     │   결합된 정복자         · 미소 뒤의       │
  │                     │                          계산기           │
  └─────────────────────┴──────────────────────────────────────────┘
```

#### X × C 조합: "사회성 × 규율" — 행동 방식 결정

```
  ┌─────────────────────┬──────────────────────────────────────────┐
  │                     │         C (성실성)                       │
  │ X (외향성)          │   낮음(~30)            높음(70+)         │
  ├─────────────────────┼──────────────────────────────────────────┤
  │                     │                                          │
  │ 높음(70+)           │ 【자유로운 풍류객】    【전략적 지도자】 │
  │                     │ 사교적+충동적          사교적+체계적      │
  │                     │ 흥이 나면 즉흥         카리스마+계획성    │
  │                     │                                          │
  │                     │ 예: 돈키호테           예: 제갈량(삼국지) │
  │                     │ (세르반테스)           · 사교력으로 동맹  │
  │                     │ · 열정적이지만           을 엮고 체계적   │
  │                     │   계획 없는 돌진         으로 전략을 짬   │
  │                     │                                          │
  │                     │ 예: 잭 스패로우        예: 타이윈 라니스터│

### 2.4 H(원칙↔실리) 가치 중립성 경고

> ⚠️ **이 절은 NPC를 설계하는 모든 사람이 반드시 읽어야 한다.**

"정직-겸손"이라는 이름은 이미 도덕적 판단을 품고 있다.
하지만 기질은 도덕적 방향이 없다. 이것이 핵심 원칙이다.

Lee & Ashton도 학술적으로 H가 실제로 측정하는 것을 이렇게 정의한다:

```
  H가 실제로 측정하는 것:
  · "타인을 이용할 기회가 있을 때 이용하는가, 안 하는가"
  · "자기 이익을 위해 규칙을 무시할 수 있는가"
  · "특별 대우를 받을 자격이 있다고 느끼는가"

  이것은 "원칙 전략 vs 실리 전략"이지
  "좋은 사람 vs 나쁜 사람"이 아니다.
```

진화적으로 Low-H는 **실리 전략**이다.
특정 환경에서 생존에 유리한 전략이며, "나쁜 전략"이 아니라 "다른 전략"이다.

**그래서 이 문서에서는:**
- 학술명 `Honesty-Humility(정직-겸손)`을 원본으로 유지하되
- 게임 해석으로 `(원칙↔실리)`를 항상 병기한다
- H 높음 = 원칙형, H 낮음 = 실리형으로 읽는다

#### Low-H(실리형)가 긍정적인 인물 유형 5가지

Low-H는 서사에서 매우 매력적인 인물을 만든다.
"곧은 사람"보다 "약삭빠른 사람"이 더 재미있는 경우가 많다.
다양한 장르에서 Low-H 영웅/매력적 인물은 넘친다.

```
  ━━━ 유형 1: 의적/쾌도 — "훔치되 의롭다" ━━━

  H ~20 + 의(義) 높음 + 바람 높음 "약자를 지킨다"

  · 거짓말, 위장, 속임수를 일상적으로 사용
  · 하지만 그 대상은 권력자, 목적은 약자 보호
  · 규칙을 무시하지만 자기만의 도리가 있다

  예시:
  · 로빈 후드(영국 전설) — 귀족의 재산을 훔쳐 빈민에게 나눈다
  · 아르센 뤼팽(모리스 르블랑) — 도둑이지만 약자 편에 선다
  · 쥐도적 지로키치(일본 전설) — 에도 시대의 의적

  핵심: H가 낮아서(속임수 능숙) 의를 실현할 수 있다.
        H가 높았으면 이 역할을 못 한다.


  ━━━ 유형 2: 모사/군사 — "계략으로 주군을 지킨다" ━━━

  H ~15 + 충(忠) 높음 + 옳음 높음 "주군의 대업"

  · 적을 속이고, 이간질하고, 함정을 파는 데 거리낌 없음
  · 하지만 그 모든 것이 주군과 대의를 위한 것
  · "내가 더러운 일을 해야 주군의 손이 깨끗하다"

  예시:
  · 장량(한나라 건국 공신) — 유방을 위해 책략을 짜는 모사
  · 오딧세우스(그리스 신화) — 트로이 목마를 고안한 꾀 많은 영웅
  · 티리온 라니스터(왕좌의 게임) — 음모와 협상으로 왕국을 지킨다

  핵심: 충성을 실현하는 수단이 실리 전략.
        H 높은 사람은 이 역할에 부적합.


  ━━━ 유형 3: 약삭빠른 생존자 — "거짓말쟁이지만 사랑받는다" ━━━

  H ~10 + X 높음 + E 중간 + 믿음 중간

  · 거짓말이 밥 먹듯, 과장이 일상, 약삭빠름
  · 하지만 위기 순간에 동료를 버리지 않는다
  · 규칙/원칙/도덕 따위는 모르지만 "정(情)"이 있다

  예시:
  · 위소보(김용 '녹정기') — 거짓말의 천재, 하지만 친구는 안 버린다
  · 잭 스패로우(캐리비안의 해적) — 사기꾼이지만 끝에는 옳은 편
  · 오스카 쉰들러(쉰들러 리스트) — 사업가+사기꾼의 수완으로 생명을 구함

  핵심: H가 낮아서 매력적인 것.
        H가 높으면 이 캐릭터가 아니라 그냥 평범한 선인.


  ━━━ 유형 4: 첩보원/정보상 — "진실은 무기다" ━━━

  H ~20 + C 높음 + 옳음 중상 + 야망 중상

  · 모든 관계에서 정보를 수집하고 이용한다
  · 거래와 조작이 일상이지만, 자기 조직에는 충실
  · "정보가 무공보다 강하다"는 신조

  예시:
  · 바리스(왕좌의 게임) — 정보망의 군주, 왕국을 위해 일한다고 믿음
  · 조지 스마일리(르 카레 소설) — 냉전 첩보원, 속임수가 직업적 미덕
  · 이몽룡의 암행어사 — 신분을 숨기고 조사하는 것 자체가 직무

  핵심: Low-H가 직업적 강점이자 생존 전략.


  ━━━ 유형 5: 실리적 질서 수립자 — "힘과 계략으로 평화를 세운다" ━━━

  H ~15 + 옳음 높음 "약육강식이 자연" + X 높음 + A 낮음

  · 착취적이고 계산적이지만
  · 혼란스러운 세상에 질서를 부여한다
  · 원칙형이 만들지 못한 현실적 평화를 실리로 만듦

  예시:
  · 조조(삼국지) — "차라리 내가 천하를 저버리겠다", 하지만 위나라를 세움
  · 마키아벨리의 군주론 — "사랑받는 것보다 두려움의 대상이 나은" 실용 리더
  · 비스마르크(프로이센) — "철혈 정책"으로 독일 통일

  핵심: 같은 Low-H라도 신조(방향)가 다르면
        "파괴하는 폭군"이 아니라 "세우는 패권자"가 된다.
```

**Low-H가 긍정적 인물이 되는 조건 요약:**

```
  1. 실리의 대상이 "악"인 경우
     · 의적: 권력자를 속임 → 영웅
     · 첩보원: 적을 속임 → 충신

  2. 실리 능력이 "도구"인 경우
     · 군사: 계략은 수단, 충성이 목적
     · 정보상: 조작 능력이 생존 기술

  3. Low-H와 높은 가치관이 결합하는 경우
     · H 15 + 의 80 = "유연한 수단으로 의를 실현"
     · H 20 + 충 90 = "계략으로 주군을 지킴"
     · H 10 + 믿음 60 = "사기꾼이지만 정은 있다"

  4. 서사적으로 가장 중요한 것:
     Low-H 자체가 매력이 되는 경우가 있다.
     "곧은 사람"보다 "약삭빠른 사람"이 더 재미있는 서사.
     위소보, 잭 스패로우, 오딧세우스가 그 증거.
```

## 3. ②층 가치관 상세 정의

> "살면서 무엇을 믿고, 무엇을 따르게 되었나"

가치관은 2개 하위층으로 나뉜다.
이것은 하나의 내면을 두 가지 언어로 표현한 것이다.

```
  ②-1  3축 가치관 (믿음/옳음/바람) = 소설의 언어 → LLM이 읽는다
  ②-2  5가치 (충/의/효/복수/야망)  = 게임 엔진의 언어 → 코드가 계산한다
```

### 3.1  ②-1 3축 가치관

```
  축              핵심 질문                        척도
  ─────────────────────────────────────────────────────────────
  믿음(信)        "사람을 믿을 수 있는가?"          0 (불신) ~ 100 (깊은 신뢰)
  Trust

  옳음(正)        "옳은 것을 위해 잃을 수 있는가?"  0 (무원칙) ~ 100 (확고한 신념)
  Rightness

  바람(願)        "나는 무엇을 바라는가?"           0 (무욕) ~ 100 (강한 바람)
  Want
```

**각 축의 구조**:

```
  강도(0~100)    = "얼마나 강하게" (수치)
  신조(텍스트)    = "어떤 내용으로" (방향)
  형성기억(목록)  = "왜 이렇게 되었나" (원인)
  대안후보(목록)  = "다른 방향의 씨앗" (변화 가능성)
```

**핵심 설계 원칙**:
강도에 도덕적 위계가 없다. 높다고 좋은 게 아니다.
같은 수치라도 신조(방향)가 다르면 완전히 다른 인물이다.

```
  옳음 90 × 2명 (역사 예시):

  · 간디 "비폭력이 최고의 도덕이다"
    → 고통받으면서도 폭력을 거부, 독립 운동

  · 로베스피에르 "공화국의 적은 제거해야 한다"
    → 공포정치로 수천 명을 단두대에 올림

  수치는 같다. 방향이 정반대다. 둘 다 확신은 흔들리지 않았다.
```

### 3.2  ②-2 5가치

```
  가치        핵심 질문                       범위     OCC 트리거
  ──────────────────────────────────────────────────────────────────
  충(忠)      조직/주군에 헌신하는가?          0~100   조직 위협 → 분노/두려움
  Loyalty

  의(義)      강호 도리를 지키는가?            0~100   도리 위반 → 분노/경멸
  Righteousness

  효(孝)      가족/스승에 도리를 다하는가?     0~100   가족 위험 → 걱정/공포
  Filial Piety

  복수(復)    원한을 갚으려 하는가?            0~100   원수 출현 → 증오/결의
  Vengeance

  야망(野)    높은 곳을 원하는가?              0~100   기회 → 흥분 / 좌절 → 분노
  Ambition
```

### 3.3  3축과 5가치의 관계: "해석 관계"

3축과 5가치는 자동계산도 아니고 완전 독립도 아니다.

```
  ❌ 자동계산 (파생):
     "옳음 90이면 충 = 옳음×0.8 = 72"
     → 로베스피에르의 충이 72? 말이 안 됨

  ❌ 완전 독립:
     "둘 다 따로 변함" → 3축의 존재 이유가 없음

  ✅ 해석 관계:
     3축+신조가 5가치의 "왜?"를 설명한다.
     5가치는 그 범위 안에서 경험에 의해 독자적으로 변한다.
     불일치는 자연스럽고, 그것이 캐릭터의 깊이다.
```

### 3.4  3축 ↔ 5가치 역할 분담

```
  ┌──────────────────────────────────────────────────────────────┐
  │              3축 (믿음/옳음/바람)  5가치 (충/의/효/복수/야망) │
  ├──────────────────────────────────────────────────────────────┤
  │ 본질      "이 사람은 누구인가"   "구체적으로 어떻게 판단"    │
  │ 수준      근본적/철학적          실전적/상황적               │
  │ 사용처    LLM 프롬프트           OCC 감정 평가 수식          │
  │ 변화속도  느림 (Tier 2~4)        중간 (Tier 1~3)            │
  │ 구성      강도+신조+형성기억     수치만                     │
  └──────────────────────────────────────────────────────────────┘
```

### 3.5 가치관 변화 규칙

```

## 4. 두 층의 관계: 기질은 가치관에 어떤 영향을 주는가

### 4.1 관계의 본질: "토양과 씨앗"

기질은 토양이고 가치관은 씨앗이다.
같은 씨앗(경험)도 다른 토양(기질)에서 다른 꽃을 피운다.

```
  기질(①) → 가치관(②)의 관계:
  ────────────────────────────────────────────

  기질은 가치관을 결정하지 않는다.
  기질은 가치관이 형성될 때 "어떤 방향이 자연스러운가"에 영향을 준다.
  같은 경험이라도 기질에 따라 다른 가치관이 형성된다.

  비유:
  · H 높은(원칙형) 사람이 배신을 경험하면 → "세상에는 의리가 필요하다" (옳음↑)
  · H 낮은(실리형) 사람이 배신을 경험하면 → "먼저 배신하지 않으면 당한다" (야망↑)
  · 같은 사건, 다른 기질, 다른 가치관

  역사 예시:
  · 같은 "전쟁터에서 동료가 죽는 것을 목격"한 경험
    - 원칙형(H↑): 유비 → "의형제를 반드시 지킨다" (효↑ 의↑)
    - 실리형(H↓): 조조 → "나만은 반드시 살아남는다" (야망↑)
```

### 4.2 기질 → 가치관 형성 경향 (확률적, 결정적 아님)

특정 기질은 특정 가치관이 형성되기 쉬운 토양을 만든다.
하지만 이것은 "경향"이지 "결정"이 아니다.

```
  기질 요인        자연스러운 경향                반직관적이지만 가능한 경우
  ────────────────────────────────────────────────────────────────────────

  H 높음(원칙)     충↑ 의↑                       야망↑ (정의를 세우겠다는 야심)
                   (공정함이 의리로 발현)         예: 링컨 — 원칙형이지만 야심가

  H 낮음(실리)     야망↑                          의↑ (습관/두려움으로 의리를 지킴)
                   (실리가 권력욕으로 발현)       예: 한신 — 실리형이지만 유방에 충성

  E 높음           효↑                            복수↑ (사랑하는 자의 원수를 못 잊음)
                   (가족 걱정이 효도로)           예: 몬테크리스토 백작

  E 낮음           복수↓                          충↑ (두려움 없이 조직에 헌신)
                   (원한 자체를 잘 안 느낌)       예: 스토아 학파 전사

  A 높음           복수↓                          충↑ 의↑ (관용이 관계 유지로)
                   (용서해버림)                   예: 넬슨 만델라

  A 낮음           복수↑                          의↑ (분노가 정의감으로 승화)
                   (원한이 깊고 오래감)           예: 이순신 — 분노가 나라 지키는 힘

  X 높음           야망↑                          충↑ (리더십이 조직 헌신으로)
                   (사회적 에너지가 포부로)       예: 마틴 루터 킹

  X 낮음           야망↓                          옳음↑ (고독 속 사색이 원칙으로)
                   (혼자 있고 싶음)               예: 소로(월든) — 은둔이 사상이 됨

  C 높음           충↑                            야망↑ (계획성이 야심으로)
                   (규율이 충성으로)              예: 나폴레옹

  C 낮음           야망↓                          의↑ (즉흥적 정의감)
                   (계획이 없으니 포부도 없음)    예: 돈키호테 — 무계획의 정의

  O 높음           옳음 다양 (여러 사상에 열림)   신조 변화가 잦음
                                                  예: 톨스토이 — 귀족→반전주의자

  O 낮음           옳음 고정 (기존 신조 고수)     신조 변화가 어려움
                                                  예: 가토 — 로마 전통 고수
```

### 4.3 기질이 가치관 "변화 속도"에 미치는 영향

기질은 가치관의 내용뿐 아니라 변화의 용이성에도 영향을 준다.

```
  O (개방성)이 높으면:
  · 새로운 신조를 접했을 때 대안후보 등록이 쉬움
  · 신조 전환 임계값이 낮음 (더 쉽게 변함)
  · 코드 규칙: O > 70이면 creed_candidate 등록에 exposure_count 2회만 필요
                O < 30이면 exposure_count 5회 필요

  A (친화성)이 높으면:
  · 복수(復)값이 잘 올라가지 않음 (용서 경향)
  · 코드 규칙: A > 70이면 복수 상승 시 ×0.7 계수
                A < 30이면 복수 상승 시 ×1.3 계수

  C (성실성)이 높으면:
  · 한번 형성된 가치관이 잘 안 변함 (일관성 추구)
  · 코드 규칙: C > 70이면 3축 강도 변화에 ×0.8 계수 (저항)
                C < 30이면 3축 강도 변화에 ×1.2 계수 (변동성)

  H (정직-겸손 | 원칙↔실리)가 높으면:
  · 죄책감을 통해 가치관이 강화됨 (잘못했다고 느끼면 원칙이 세짐)
  · H가 낮으면 죄책감 자체를 덜 느끼므로 도덕적 가치관 형성이 어려움
  · 단, 비도덕적 가치관(야망, 복수)의 형성에는 영향 없음
```

### 4.4 기질 → 가치관 영향 요약도

```
  ①층 기질 (HEXACO)
  ──────────────────
  H(원칙↔실리) ──→ 충/의의 기질적 토대. "원칙형이 의리도 자연스럽다"
  E ──→ 효의 기질적 토대. "걱정 많은 사람이 가족을 더 챙긴다"
  A ──→ 복수의 억제/촉진. "참을성 있는 사람은 원한이 덜 쌓인다"
  X ──→ 야망의 에너지원. "사교적인 사람이 세상에서 뭔가를 이루려 한다"
  C ──→ 가치관 변화의 저항/유연. "규율 있는 사람은 신념도 일관적이다"
  O ──→ 신조 전환의 용이성. "열린 사람은 새 사상을 더 쉽게 받아들인다"

  이 모든 것은 "경향"이지 "결정"이 아니다.
  경험이 기질의 경향을 이길 수 있다.
  그것이 드라마다.
```

  │ A 낮음(~30)  │ 【불같은 충견】          │ 【외로운 반역자】        │
  │              │ 조직에 충성하지만        │ 조직 충성도 없고         │
  │              │ 적에게는 가차없다        │ 분노도 통제 안 됨        │
  │              │                         │                         │
  │              │ 예: 장비(삼국지)         │ 예: 아킬레우스           │
  │              │ · 유비에게 충성이지만    │ (일리아드)               │
  │              │   적에게는 폭발적 분노   │ · 아가멤논에 반기를 들고 │
  │              │                         │   혼자 싸우길 거부       │
  │              │ 예: 스네이프(해리포터)   │                         │
  │              │ · 릴리에 대한 충성이     │ 예: 여포(삼국지)         │
  │              │   차갑고 집요한 형태     │ · 누구에게도 충성하지    │
  │              │                         │   않고 분노도 통제 불가  │
  └──────────────┴─────────────────────────┴─────────────────────────┘
```

## 6. 거울 인물 분석 — 기질×가치관이 만드는 대비

같은 수치인데 다른 방향, 또는 같은 기질인데 다른 가치관.
이 대비가 서사에서 가장 강력한 갈등을 만든다.

### 6.1 유비 vs 조조: 같은 옳음 90, 반대 H(원칙↔실리)

```
  ┌────────────────────────────────────────────────────────────┐
  │           유비                    조조                     │
  │ 옳음:     90 "인의로 천하를"      90 "힘으로 천하를"       │
  │ H:        80(원칙)                15(실리)                 │
  │ A:        70                      25                       │
  │ E:        60                      20                       │
  │                                                            │
  │ 같은 점: 둘 다 "천하를 바로잡겠다"는 확신이 있다.          │
  │          옳음 90, 바람 90. 흔들리지 않는다.                │
  │                                                            │
  │ 다른 점:                                                   │
  │ · 유비는 원칙적으로(H80) 참으며(A70) 옳음을 실천           │
  │   → 인의를 앞세워 사람의 마음을 얻는다                     │
  │ · 조조는 실리적으로(H15) 분노로(A25) 옳음을 강제           │
  │   → "나를 위해 천하를 쓰겠다" — 힘으로 질서를 세운다      │
  │                                                            │
  │ 서사적 의미:                                               │
  │ · 기질이 같은 신념을 정반대 방향으로 만든 것               │
  │ · 유비의 약점: 원칙 때문에 기회를 놓침 (형주)              │
  │ · 조조의 약점: 실리 때문에 신뢰를 잃음 (반복되는 배신)     │
  │ · 둘 다 "나는 옳다" — 하지만 "옳음"의 내용이 정반대       │
  └────────────────────────────────────────────────────────────┘
```

### 6.2 【정도협객】 vs 【부서진 의인】: 같은 H 높음, 다른 옳음

```
  ┌────────────────────────────────────────────────────────────┐
  │           정도협객                부서진 의인               │
  │ H:        80+(원칙)               70(원칙)                 │
  │ 옳음:     90 (확고)               30 (부서짐)              │
  │                                                            │
  │ 문학 예시:                                                 │
  │ · 정도협객 → 악비(남송), 아틱 핀치(앵무새 죽이기)          │
  │ · 부서진 의인 → 라스콜니코프(죄와 벌), 리어왕 말년         │
  │                                                            │
  │ 같은 점: 둘 다 H가 높다. 본성은 원칙적인 사람.             │
  │                                                            │
  │ 다른 점:                                                   │
  │ · 정도협객: 기질대로 살았다 (H 높음과 옳음 높음이 일치)    │
  │ · 부서진 의인: 기질에 반하는 경험 (H 높지만 옳음이 낮음)   │
  │                                                            │
  │ 서사적 의미:                                               │
  │ · 부서진 의인의 핵심 갈등 = 본성(H)과 가치관(옳음)의 불일치│
  │ · "원래는 원칙적인 사람인데, 세상이 원칙적이지 않다는 걸    │
  │   알았다" — 라스콜니코프가 정확히 이것                     │
  │ · 성장 = 옳음이 H 수준으로 회복되는 과정                   │
  │ · 라스콜니코프가 소냐를 만나 회복하듯, 누군가가 계기가 됨  │
  └────────────────────────────────────────────────────────────┘
```

### 6.3 【비통한 복수자】 vs 【자유로운 풍류객】: 비슷한 바람, 다른 기질

```
  ┌────────────────────────────────────────────────────────────┐
  │           비통한 복수자            자유로운 풍류객           │
  │ 바람:     70~80                    70~80                   │
  │ E:        높음(60+)                낮음(~30)               │
  │ C:        높음(70)                 낮음(~40)               │
  │                                                            │
  │ 문학 예시:                                                 │
  │ · 비통한 복수자 → 몬테크리스토 백작, 메디아                │
  │ · 자유로운 풍류객 → 잭 스패로우, 돈키호테                  │
  │                                                            │
  │ 같은 점: 둘 다 강하게 원하는 것이 있다 (바람 70~80)        │
  │                                                            │
  │ 다른 점:                                                   │
  │ · 비통한 복수자의 바람 = "원수를 갚겠다"                    │
  │   E 높음(걱정)+C 높음(계획) → 치밀하고 감정적인 복수       │
  │ · 자유로운 풍류객의 바람 = "누구에게도 매이지 않겠다"       │
  │   E 낮음(대담)+C 낮음(즉흥) → 자유롭고 충동적인 모험       │
  │                                                            │
  │ 서사적 의미:                                               │
  │ · 같은 "강한 욕망"이 기질에 따라 완전히 다른 형태          │
  │ · 몬테크리스토: 14년의 계획표가 있는 복수 = C 높음의 발현   │
  │ · 잭 스패로우: 바람 부는 대로 = C 낮음의 발현               │
  └────────────────────────────────────────────────────────────┘
```

### 6.4 【모사/군사】 vs 【냉혈 폭군】: 같은 Low-H, 반대 가치관

```
  ┌────────────────────────────────────────────────────────────┐
  │           모사/군사                냉혈 폭군                │
  │ H:        낮음(실리)               낮음(실리)              │
  │ 충:       90                       10                      │
  │ 의:       70                       10                      │
  │                                                            │
  │ 역사/문학 예시:                                            │
  │ · 모사/군사 → 장량(한나라), 오딧세우스, 티리온 라니스터    │
  │ · 냉혈 폭군 → 동탁(삼국지), 진시황 말년                   │
  │                                                            │
  │ 같은 점: 둘 다 H가 낮다. 속이고, 조작하고, 이용한다.       │
  │                                                            │
  │ 다른 점:                                                   │
  │ · 모사/군사: 실리 능력을 "주군을 위해" 사용                │
  │   → 장량은 유방을 위해 계략을 짜고                         │
  │     오딧세우스는 그리스군을 위해 목마를 만든다              │
  │ · 냉혈 폭군: 실리 능력을 "자기 자신만을 위해" 사용         │
  │   → 동탁은 오직 자기 권력과 쾌락을 위해 조작               │
  │                                                            │
  │ 서사적 의미:                                               │
  │ · Low-H는 "도구"다. 가치관(충, 의)이 그 도구의 방향을 정함 │
  │ · 같은 칼이 사람을 살리기도 하고 죽이기도 하듯             │
  │ · 이것이 "기질에는 도덕적 방향이 없다"의 가장 극적인 증거  │
  └────────────────────────────────────────────────────────────┘
```

### 6.5 【대담한 의인】 vs 【냉혈 전략가】: 같은 E 낮음, 반대 H

```
  ┌────────────────────────────────────────────────────────────┐
  │           대담한 의인              냉혈 전략가              │
  │ E:        낮음(~20)                낮음(~20)               │
  │ H:        높음(원칙)               낮음(실리)              │
  │                                                            │
  │ 역사/문학 예시:                                            │
  │ · 대담한 의인 → 악비(남송), 아라곤(반지의 제왕)            │
  │ · 냉혈 전략가 → 조조(삼국지), 카이사르(로마)               │
  │                                                            │
  │ 같은 점: 둘 다 겁이 없다. 위험 앞에서 물러서지 않는다.     │
  │                                                            │
  │ 다른 점:                                                   │
  │ · 대담한 의인: 겁없는 대담함이 원칙을 위해 발휘            │
  │   → 악비는 죽음 앞에서도 "하늘이 맑다(天日昭昭)"           │
  │ · 냉혈 전략가: 겁없는 대담함이 실리를 위해 발휘            │
  │   → 카이사르는 원로원도 두렵지 않은 야심가                 │
  │                                                            │
  │ 서사적 의미:                                               │
  │ · E가 같으면 "겁없다"는 외형이 비슷하지만                  │
  │   H가 다르면 그 대담함의 방향이 완전히 다르다               │
  │ · 겉으로는 비슷한 두 장수가 실은 정반대 사람일 수 있다     │
  │ · NPC 설계에서 "겉보기 유사 + 내면 상이"의 좋은 패턴       │
  └────────────────────────────────────────────────────────────┘
```

## 7. 계층간 관계 규칙 종합

### 7.1 영향의 방향

```
  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │  ①층 기질 (HEXACO)                                         │
  │  ────────────────                                          │
  │      │                                                      │
  │      │  ──→ 형성 경향: 특정 가치관이 형성되기 쉬운 토양     │
  │      │  ──→ 변화 속도: O/C가 가치관 변화 속도에 영향        │
  │      │  ──→ 감정 필터: H/E/A가 OCC 감정 강도에 영향         │
  │      │  ──→ 행동 표현: X/C가 같은 가치관의 행동 표출에 영향 │
  │      │                                                      │
  │      ↓                                                      │
  │  ②층 가치관 (3축 + 5가치)                                   │
  │  ───────────────────────                                   │
  │      │                                                      │
  │      │  ──→ 극히 드물게 기질에 역방향 영향 (Tier 4만)       │
  │      │      예: 30년간의 실리적 삶이 H를 미세하게 낮춤      │
  │      │                                                      │
  └─────────────────────────────────────────────────────────────┘
```

### 7.2 규칙 목록

```
  규칙 1: 기질은 가치관을 결정하지 않는다 (경향만 만든다)
  ────────────────────────────────────────────────────────
  · H 높음(원칙)이라고 충/의가 자동으로 높지 않다
  · 환경과 경험이 기질의 경향을 이길 수 있다
  · 이 불일치가 캐릭터의 깊이를 만든다
  · 예: 라스콜니코프 — H 높지만 옳음 낮음

  규칙 2: 기질은 가치관의 변화 속도에 영향을 준다
  ────────────────────────────────────────────────────────
  · O > 70: 신조 대안후보 등록 임계값 -1회
  · O < 30: 신조 대안후보 등록 임계값 +2회
  · C > 70: 3축 강도 변화 계수 ×0.8 (저항)
  · C < 30: 3축 강도 변화 계수 ×1.2 (변동성)
  · A > 70: 복수값 상승 계수 ×0.7 (억제)
  · A < 30: 복수값 상승 계수 ×1.3 (촉진)

  규칙 3: 기질은 감정 필터로 가치관의 체감에 영향을 준다
  ────────────────────────────────────────────────────────
  · H(원칙↔실리) → 죄책감/통쾌 필터 (도덕적 사건의 감정 강도)
  · E → 두려움/공감 필터 (위협/고통 사건의 감정 강도)
  · A → 분노/원한 필터 (갈등 사건의 감정 강도)
  · 같은 가치관 수치라도 기질에 따라 체감하는 감정이 다르다
  · 예: 의 70인 두 사람이 같은 배신을 목격해도
        A 낮으면 격분하고(장비), A 높으면 실망한다(유비)

  규칙 4: 기질은 행동 표현 방식에 영향을 준다
  ────────────────────────────────────────────────────────
  · 같은 충 90이라도:
    X 높으면 공개적으로 충성을 선언 (관우: "형님을 찾아간다")
    X 낮으면 묵묵히 뒤에서 지킨다 (스네이프: 아무도 모르게)
  · 같은 복수 80이라도:
    C 높으면 14년 계획을 세운다 (몬테크리스토)
    C 낮으면 원수를 보는 즉시 달려든다 (메디아)

  규칙 5: 가치관은 기질에 거의 영향을 주지 않는다
  ────────────────────────────────────────────────────────
  · 유일한 예외: Tier 4 인생 성찰에서 ±5 이내
  · 30년간의 실리적 삶 → H가 5 하락하는 수준
  · 기질 변화는 "인생이 바뀌었다"는 신호로만 사용
```

## 8. 기질 → 가치관 변화 계수 (코드용 규칙)

```

  │  O(개방성)이 신조 대안후보 등록에 필요한 접촉 횟수               │

  │  O > 70 (열린 사람):    2회면 등록                               │

  │  O < 30 (보수적 사람):  5회 필요                                 │

  │  C > 70 (일관적):  변화량 ×0.8 (저항)                            │
  │  C 30~70 (기본):   변화량 ×1.0                                   │
  │  C < 30 (변동적):  변화량 ×1.2 (변동성)                          │
  │                                                                  │
  │  A(친화성)가 복수값 상승에 미치는 계수                           │

  │  A < 30 (분노형):  복수 상승 ×1.3 (촉진)                         │

  │  H(원칙↔실리)가 도덕적 가치관 형성에 미치는 영향                 │
  │  ─────────────────────────────────────────────                   │
  │  H 높음(원칙):  죄책감을 통해 의/충 강화 용이                    │
  │  H 낮음(실리):  죄책감 자체를 덜 느낌 → 도덕적 가치관 형성 어려움│
  │                 단, 야망/복수 등 비도덕 가치관에는 영향 없음      │
  └───────────────────────────────────────────────────────────────────┘
