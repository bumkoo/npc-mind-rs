## 1. 층 구분 개요

```
  ━━━ 1층: 성격 (HEXACO) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  "이 사람은 원래 어떤 사람인가" (性)
  · 행동 패턴의 기질적 토대
  · 거의 변하지 않는다 (Tier4에서만 ±5)
  · 6개 요인: H / E / X / A / C / O

  ━━━ 2층: 가치관 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  2층-A: 3축 가치관 (믿음/옳음/바람)
    "이 사람은 어떤 존재인가" — 서사적 정체성
    · 강도 + 신조(방향) + 형성기억
    · LLM 전용 (대사·성찰·내면 독백)
    · 천천히 변한다 (Tier 2~4)

  2층-B: 5가치 (충/의/효/복수/야망)
    "구체적 상황에서 어떻게 판단하는가" — 실전값
    · 수치만 (0~100)
    · OCC 감정 평가 수식의 직접 입력
    · 중간 속도로 변한다 (Tier 1~3)

  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  핵심: 1층은 "수단의 성향" (어떻게 행동하는가)
       2층은 "방향의 선택" (무엇을 위해, 무엇이 옳은가)
       같은 성격이라도 가치관에 따라 전혀 다른 인물이 된다.
```

## 2. 1층: 성격 (HEXACO) — 정의

### 2.1 6요인 상세 정의

**H (정직-겸손, Honesty-Humility)**
> ⚠️ 주석: H는 "원칙적인가 vs 실리적인가"의 **수단 성향**이다.
> H 높음 = 공정한 수단을 선호, H 낮음 = 착취적 수단을 선호.
> H가 높다고 "좋은 사람", 낮다고 "나쁜 사람"이 아니다.
> H↑이라도 잘못된 신조("이단은 제거해야 한다")를 가지면 독선적 광신자가 된다.
> H↓이라도 자기 나름의 질서("강자가 약자를 보호한다")를 세울 수 있다.
> → 도덕적 판단은 2층(가치관)의 영역이다. H는 그 판단을 실행하는 수단의 성향만 표현한다.

```
  핵심 질문: "남을 이용하지 않고 공정한가?"

  H 높음 (70~100):
    · 공정한 수단, 겸손, 규칙 준수를 선호
    · 타인을 도구로 쓰는 것에 본능적 거부감
    · 죄책감(Guilt/Shame)을 강하게 느낌
    · 남의 불행에서 쾌감(Gloating)을 느끼기 어려움

  H 중간 (30~70):
    · 상황에 따라 공정하기도 하고 실리적이기도 함
    · "이 사람에게는 진심, 저 사람은 거래" 같은 선택적 태도
    · 대부분의 사람이 여기에 해당

  H 낮음 (0~30):
    · 착취적 수단, 조작, 특권의식을 자연스럽게 사용
    · 남을 이용하는 데 심리적 부담이 적음
    · 죄책감이 약하고, 상대 불행에 쾌감을 느낄 수 있음
    · 물욕, 지위욕이 강한 경향
```

**E (정서성, Emotionality)**

```
  핵심 질문: "자신과 가까운 사람의 안전에 민감한가?"

  E 높음: 두려움, 걱정, 공감, 애착이 강함.
          위험에 민감하고 가족·동료 걱정이 많음.
          타인의 고통에 강하게 공감.
  E 낮음: 대담하고 냉담하며 독립적.
          위험 앞에서도 두려움이 적음.
          타인 고통에 무감각할 수 있음.

  BigFive-N(신경증)과의 차이:
    · BigFive-N = 불안 + 분노가 혼합
    · HEXACO-E = 불안·걱정·두려움·공감만 포함 (분노는 A로 이동)
    · "걱정은 많은데 화는 안 내는 사람" 표현 가능
```

**X (외향성, eXtraversion)**

```
  핵심 질문: "사회적으로 자신감 있고 활발한가?"

  X 높음: 사교적, 자신감 있음, 활력 넘침.
          감정을 크게 표현, 대화 개시 확률 높음.
          리더십 발휘, 사람들 사이에서 에너지를 얻음.
  X 낮음: 내성적, 조용, 수줍음.
          강한 감정도 내면에 담아둠.
          혼자 있을 때 편안함.
```

**A (친화성, Agreeableness)**

```
  핵심 질문: "도발에 참을 수 있고 용서하는가?"

  A 높음: 관용, 인내, 유연. 분노를 잘 억제함.
          갈등 회피 성향, 협상을 선호.
  A 낮음: 도발에 즉각 분노, 원한을 오래 간직.
          고집스럽고 비판적. 타협하기 어려움.

  BigFive-A와의 차이:
    · BigFive-A의 "동정심/공감"은 HEXACO-E로 이동
    · HEXACO-A = 순수하게 "분노 조절 + 관용" 영역
    · "공감은 강한데(E↑) 화도 불같은(A↓) 사람" 표현 가능
```

**C (성실성, Conscientiousness)**

```
  핵심 질문: "규율 있고 계획적인가?"

  C 높음: 근면, 체계적, 신중. 감정을 느끼되 행동에 덜 반영(이성적).
          장기 계획 이행률이 높음.
  C 낮음: 충동적, 무계획, 태만. 감정이 바로 행동으로 연결.
          즉흥적이고 자유분방.
```

**O (개방성, Openness)**

```
  핵심 질문: "새로운 경험과 사고에 열린가?"

  O 높음: 창의적, 지적 호기심 강함, 유연한 사고.
          복합 감정(감사+수치 동시 등) 경험 가능.
          새로운 신조를 수용할 확률 높음.
  O 낮음: 관습적, 실용적, 보수적.
          단순 감정으로 귀결되는 경향.
          기존 신조를 고수.
```

### 2.2 H 요인 — 편향 방지 가이드

> ⚠️ H에 대한 도덕적 편향을 경계해야 한다.

```
  H↑ = "좋은 사람"이라는 편향의 반례들:
  ─────────────────────────────────────
  · H 90 + 옳음(正) "이단은 멸해야 한다"
    → 공정하고 겸손하되, 자신의 정의를 위해 잔혹한 인물
    → 역사: 토르케마다 (스페인 종교재판 대심문관)
      원칙적이고 청렴했으나, 그 원칙이 이단 박멸이었음

  · H 80 + 바람(願) 90 "세상을 구원하겠다"
    → 타인을 이용하지 않지만, 자기 확신으로 세상을 불태울 수 있음
    → 소설: 《카라마조프가의 형제들》 이반 카라마조프
      도덕적 결벽이 오히려 파괴적 허무로 전화

  H↓ = "나쁜 사람"이라는 편향의 반례들:
  ─────────────────────────────────────
  · H 20 + 바람(願) "내 사람들을 지키겠다"
    → 수단은 착취적이지만 방향은 보호
    → 역사: 조조(曹操)
      기만과 술수를 자연스럽게 쓰지만, 자기 세력을 키워 난세를 평정하려 함

  · H 30 + 옳음(正) "실리가 정의다"
    → 남을 이용하지만 나름의 합리적 질서를 추구
    → 소설: 《대부》 마이클 콜레오네
      착취적이되 가족이라는 질서 안에서 자신의 "옳음"이 있음

  정리:
    H = 수단의 선호 (공정한 수단 vs 착취적 수단)
    도덕적 방향 = 2층 가치관의 영역
    H는 가치관의 영역을 침범하지 않는다.
```

## 3. 1층 인물 유형 — 주요 HEXACO 조합별

### 유형 1: H↓ + E↓ "탐욕 + 대담" (냉혈 야심가)

```
  특성: 겁 없이 남을 착취. 냉혈하고 권력을 추구.
  감정 특징: 죄책감 약함, 두려움 약함, 남의 불행에 쾌감
  행동 패턴: 위험을 감수하고, 사람을 도구로 씀
```

역사 예시: **여불위(呂不韋)** — 상인 출신으로 자초(子楚)를 왕위에 올리는 투자를 감행. 사람을 상품처럼 계산했고, 위험 앞에서도 대담하게 판을 벌렸다. 겁이 없었고(E↓), 관계를 철저히 이용했다(H↓).

소설 예시: **《삼국지연의》 사마의(司馬懿)** — 조조 밑에서 수십 년을 인내하며 기회를 노렸다. 사람에 대한 공감이 적고(E↓), 필요하면 동료를 제거하는 데 거리낌이 없었다(H↓). 단, C↑(성실·계획적)과 결합되어 충동적이지 않고 장기적으로 움직인 점이 특징.

### 유형 2: H↓ + E↑ "비겁한 간신" (뒤에서 조작하는 자)

```
  특성: 위험은 피하면서 뒤에서 조작. 겁이 많지만 착취적.
  감정 특징: 두려움이 강해 정면 대결 회피, 하지만 남을 이용하는 데 거리낌 없음
  행동 패턴: 모략, 참소, 뒤통수
```

역사 예시: **진회(秦檜)** — 금나라의 위협을 두려워하면서(E↑), 악비를 모함하여 제거했다(H↓). 정면 충돌보다 상소와 정치 공작을 통해 움직였으며, 개인의 안전을 최우선에 두었다.

소설 예시: **《수호전》 고구(高俅)** — 황제 앞에서는 비위를 맞추고, 양산박 호걸들에게는 정면 대결을 피하면서 모략으로 제거하려 했다. 겁이 많으면서도(E↑) 권력을 이용한 조작에 능했다(H↓).

### 유형 3: H↓ + X↑ "나르시시스트" (카리스마 있는 자기과시)

```
  특성: 카리스마와 사교성으로 사람을 끌어들이지만, 관계를 자기과시의 도구로 씀.
  감정 특징: 감정 표현이 크고, 사회적 무대를 즐김
  행동 패턴: 매력으로 사람을 모으고, 이용하고, 버림
```

역사 예시: **항우(項羽)** — 압도적 카리스마와 무력으로 사람을 끌어모았으나(X↑), 논공행상에서 편파적이었고 공신을 의심하여 내쫓았다(H↓). "역발산기개세(力拔山兮氣蓋世)"라는 자기서사가 강했다.

소설 예시: **《바람과 함께 사라지다》 레트 버틀러** — 남부 사교계에서 매력적이고 자신감 넘치지만(X↑), 도덕적 규칙에 무관심하며(H↓), 관계를 자기 방식으로 통제하려 한다.

### 유형 4: H↓ + A↓ "잔인한 폭군" (착취 + 분노)

```
  특성: 착취적이면서 분노도 격렬. 가장 파괴적인 조합.
  감정 특징: 남을 이용하면서 사소한 도발에도 폭발
  행동 패턴: 공포 통치, 즉각적 보복
```

역사 예시: **동탁(董卓)** — 권력을 잡자마자 약탈과 학살을 일삼았고(H↓), 사소한 불만에도 즉각 처형으로 대응했다(A↓). 수도를 불태우는 충동적 파괴까지 보였다.

소설 예시: **《백년의 고독》 아우렐리아노 부엔디아 대령 (후기)** — 전쟁이 길어지면서 점점 착취적으로 변하고(H↓), 반대 의견에 즉각 분노하며(A↓) 처형을 명한다.

### 유형 5: H↑ + A↓ "원칙적이되 불같은" (공정한 분노가)

```
  특성: 공정하고 남을 이용하지 않지만, 도발에 참지 못함.
  감정 특징: 도덕적 분노가 격렬, 불의 앞에서 즉각 폭발
  행동 패턴: 정의로운 행동이지만 방식이 과격
```

역사 예시: **장비(張飛)** — 유비에 대한 의리와 백성에 대한 공정함은 확실했으나(H↑), 부하에게 화를 참지 못해(A↓) 결국 잠든 사이에 살해당했다. "공정하지만 불같은" 전형.

소설 예시: **《레 미제라블》 앙졸라스** — 혁명의 대의에 충실하고 사심이 없지만(H↑), 배신자에 대한 분노가 즉각적이며(A↓) 처형을 주저하지 않는다.

### 유형 6: H↑ + E↑ "의로운 걱정쟁이" (공정하되 소심한)

```
  특성: 공정하고 공감력이 강하지만, 걱정이 많고 소심.
  감정 특징: 죄책감 강함, 두려움도 강함, 타인 고통에 깊이 공감
  행동 패턴: 옳은 일을 하고 싶지만 두려워서 망설임
```

역사 예시: **해서(海瑞)** — 청렴하기로 유명한 명나라 관리. 황제에게 직언하면서도 상소문을 올릴 때 관을 미리 준비할 만큼(E↑) 두려움이 컸다. 그럼에도 공정함을 꺾지 않았다(H↑).

소설 예시: **《반지의 제왕》 프로도 배긴스** — 정직하고 남을 이용하지 않으며(H↑), 위험에 대한 두려움과 걱정이 끊이지 않지만(E↑), 그래도 반지를 운반하는 짐을 놓지 않는다.

### 유형 7: H↑ + X↓ + C↓ "부서진 원칙주의자" (무기력한 공정)

```
  특성: 본성은 공정하나, 은둔적이고 무기력.
  감정 특징: 세상에 대한 실망, 감정을 잘 표현하지 않음
  행동 패턴: 은둔, 방관, 소극적 선행
```

역사 예시: **도연명(陶淵明)** — 관직의 부패에 환멸을 느끼고(H↑) 은둔을 택했다(X↓). 체계적인 재기를 도모하기보다 술과 국화에 빠졌다(C↓). 원칙은 있었으나 세상에 나서지 않았다.

소설 예시: **《죄와 벌》 라즈콜니코프 (결말부)** — 시베리아 유형 후, 본래의 공정한 감각(H↑)은 남아 있으나, 세상에 대한 적극성은 사라지고(X↓) 무기력한 참회 속에 산다.

### 유형 8: E↓ + X↑ + A↑ "냉정한 중재자" (대담 + 사교 + 관용)

```
  특성: 두려움이 적고, 사교적이며, 분노를 잘 다스림.
  감정 특징: 위험에도 침착, 사람들 사이에서 균형을 잡음
  행동 패턴: 위기 상황의 협상가, 중재자
```

역사 예시: **장량(張良)** — 진시황 암살 미수 후에도 침착하게 다음 수를 두었고(E↓), 유방의 진영에서 사교적으로 인맥을 관리하며(X↑), 한신·소하와의 갈등을 중재했다(A↑).

소설 예시: **《삼국지연의》 노숙(魯肅)** — 적벽대전 전후로 손권과 유비 사이에서 동맹을 중재. 위험을 감수하면서도(E↓) 양측 모두와 관계를 유지했고(X↑), 주유의 과격한 주장을 인내했다(A↑).

### 유형 9: C↑ + O↓ + A↑ "충실한 관리자" (근면 + 보수 + 관용)

```
  특성: 맡은 일을 묵묵히 하고, 새로운 것보다 기존 방식을 선호.
  감정 특징: 복잡한 감정 경험이 적고, 안정적
  행동 패턴: 기존 질서 유지, 충실한 실행
```

역사 예시: **소하(蕭何)** — 유방이 전장에 나갈 때 후방을 완벽히 관리(C↑). 혁신보다 기존 진나라 행정 시스템을 그대로 활용(O↓). 한신과의 갈등에서도 인내하며 조율(A↑).

소설 예시: **《반지의 제왕》 샘와이즈 갬지** — 프로도를 향한 헌신을 묵묵히 실행(C↑). 새로운 모험보다는 "집으로 돌아가기"를 바라는 보수적 성향(O↓). 골룸에 대해서도 일정 수준 참는다(A↑).

## 4. 2층-A: 3축 가치관 (믿음/옳음/바람) — 정의

### 4.1 축 정의

3축은 NPC의 근본적 존재 방식을 정의한다. 각 축은 **강도(얼마나 강하게)** + **신조(어떤 방향으로)** + **형성기억(왜 이렇게 되었나)** + **대안후보(변화 가능성의 씨앗)**로 구성된다.

**믿음 (信, Trust)**

```
  핵심 질문: "사람을 믿을 수 있는가?"
  범위: 0 (깊은 불신) ~ 100 (깊은 신뢰)

  이 축이 정하는 것: 타인과의 관계 기본 태도

  · 강도가 같아도 신조가 다르면 전혀 다른 인물:
    믿음 80 "사람의 고통을 외면하지 않는다" — 보편적 신뢰
    믿음 80 "같은 피가 흐르는 자만 믿는다" — 혈연 중심 신뢰

  · 강도가 높다고 좋은 게 아니다:
    믿음 90 "모든 사람은 선하다" — 순진함, 이용당할 위험
    믿음 20 "아무도 믿지 않는다" — 고독하지만 배신당하지 않음
```

**옳음 (正, Rightness)**

```
  핵심 질문: "옳은 것을 위해 잃을 수 있는가?"
  범위: 0 (무원칙) ~ 100 (확고한 신념)

  이 축이 정하는 것: 원칙과 정의에 대한 태도

  · 가장 중요한 것은 신조의 "내용":
    옳음 90 "도의를 지켜야 한다" — 정파적 정의
    옳음 90 "힘이 곧 정의다" — 패권적 정의
    옳음 90 "법 앞에 만인이 평등하다" — 법치적 정의
    → 수치가 같아도 방향이 정반대일 수 있다

  · 강도가 높으면 흔들리지 않는다:
    옳음 90인 사람은 "내가 죽어도 이것은 지킨다"
    옳음 30인 사람은 "상황 봐서 결정한다"
```

**바람 (願, Want)**

```
  핵심 질문: "나는 무엇을 바라는가?"
  범위: 0 (무욕) ~ 100 (강한 바람)

  이 축이 정하는 것: 욕구와 동기의 강도

  · 신조가 바람의 내용을 결정:
    바람 90 "모든 것을 손에 넣겠다" — 권력욕
    바람 80 "누구의 도구도 아닌 나가 되겠다" — 자유
    바람 70 "원수를 갚겠다" — 복수
    바람 20 "조용히 살면 된다" — 무욕

  · 바람이 낮은 건 나쁜 게 아니다:
    은둔자, 달관한 현자, 트라우마 후 무기력 — 모두 바람이 낮다
    그러나 이유(신조)와 맥락이 전혀 다르다
```

### 4.2 3축 설계 원칙

```
  1. 강도에 도덕적 위계가 없다
     · 높다고 좋은 게 아니다. 낮다고 나쁜 게 아니다.

  2. 같은 수치라도 신조가 다르면 완전히 다른 인물이다
     · 수치만으로 구분 불가. 신조가 결정적 차이.

  3. 형성기억이 "왜"를 설명한다
     · 같은 "믿음 20"라도, 배신의 기억인지 타고난 성향인지에 따라
       변화 가능성이 다르다.

  4. 대안후보가 변화의 씨앗이다
     · 다른 신조를 가진 사람과의 만남이 대안후보로 등록된다.
     · 기존 신조가 약해지면 대안이 전환 후보가 된다.
```

## 5. 2층-B: 5가치 (충/의/효/복수/야망) — 정의

### 5.1 5가치 상세 정의

```
  충 (忠, Loyalty)
    핵심 질문: "조직/주군에 헌신하는가?"
    · 조직에 대한 충성심과 헌신의 강도
    · 높으면: 조직 위협에 분노/두려움, 조직을 위한 자기희생
    · 낮으면: 조직에 무관심, 자기 이익 우선
    · OCC 트리거: 조직 위협 → 분노/두려움

  의 (義, Righteousness)
    핵심 질문: "강호 도리를 지키는가?"
    · 사회적 도리·약속·의리에 대한 내면화 강도
    · 높으면: 도리 위반 목격 시 분노/경멸, 약속을 목숨처럼 지킴
    · 낮으면: 약속은 편의에 따라, 도리는 강자의 변명
    · OCC 트리거: 도리 위반 → 분노/경멸

  효 (孝, Filial Piety)
    핵심 질문: "가족/스승에 도리를 다하는가?"
    · 가족·스승·은인에 대한 의무감 강도
    · 높으면: 가족 위험에 극도의 걱정/공포, 부모·스승 뜻에 순종
    · 낮으면: 가족과 거리, 스승의 뜻을 거스르는 데 부담 없음
    · OCC 트리거: 가족 위험 → 걱정/공포

  복수 (復, Vengeance)
    핵심 질문: "원한을 갚으려 하는가?"
    · 원수에 대한 감정 강도와 보복 의지
    · 높으면: 원수 출현 시 증오/결의, 복수를 위해 다른 것 포기 가능
    · 낮으면: 원한이 있어도 시간이 지나면 잊음, 또는 용서
    · OCC 트리거: 원수 출현 → 증오/결의

  야망 (野, Ambition)
    핵심 질문: "높은 곳을 원하는가?"
    · 지위·권력·성취를 향한 추진력
    · 높으면: 기회에 흥분, 좌절에 분노, 수단방법 가리지 않을 수 있음
    · 낮으면: 현재에 만족, 출세에 무관심
    · OCC 트리거: 기회 → 흥분 / 좌절 → 분노
```

### 5.2 5가치 설계 원칙

```
  1. 5개는 서로 환원할 수 없다
     · 충 ≠ 효: 가문에 헌신하지만 왕에게는 반기를 들 수 있다
     · 복수 ≠ 야망: "원수를 갚겠다"와 "높은 자리에 오르겠다"는
       질적으로 다른 감정을 유발한다

  2. 5가치는 코드 전용이다
     · OCC 감정 평가 수식의 직접 입력값
     · Utility AI 행동 점수 계산에 사용
     · LLM 프롬프트에는 3축이 우선

  3. 변화 속도가 3축보다 빠르다
     · 경험에 의해 Tier 1~3에서 ±5~20 변화
     · 3축이 변하지 않아도 5가치는 변할 수 있다 (관성)
```

## 6. 2층 인물 유형 — 3축 × 5가치 조합별

### 유형 A: 높은 옳음 + 높은 충/의 (원칙적 수호자)

```
  3축: 옳음 ↑ (70~100), 신조 = "도의/정의를 지킨다"
  5가치: 충 ↑, 의 ↑, 야망 ↓

  특성: 원칙을 위해 희생할 준비가 된 인물.
        소속 조직과 강호 도리 모두에 충실.
```

역사 예시: **악비(岳飛)** — "진충보국(盡忠報國)"을 등에 새기고 금나라에 맞서 싸웠다. 옳음(正)이 "국가를 지켜야 한다"이며 충과 의 모두 극도로 높았다. 야망은 낮아 "직산(直山)을 탈환하면 된다"는 소박한 바람이었다.

소설 예시: **《삼국지연의》 제갈량** — 유비에 대한 충성(충↑)과 한실 부흥이라는 대의(의↑)가 결합. 옳음(正)의 신조는 "왕도로 천하를 바로잡는다"이며, 개인적 야망은 거의 없었다(야망↓).

### 유형 B: 높은 옳음 + 높은 야망 (야심적 정의)

```
  3축: 옳음 ↑, 바람 ↑, 신조 = "능력 있는 자가 세상을 이끌어야 한다"
  5가치: 의 중간~높음, 야망 ↑, 충 중간 이하

  특성: 자기 나름의 정의를 가지고 있으며, 그것을 실현할 권력을 원한다.
        조직에 대한 충성보다 자기 비전이 우선.
```

역사 예시: **왕안석(王安石)** — 북송의 재상. "천하를 바꿔야 한다"는 강한 옳음(正)과 그것을 실현하겠다는 바람(願)이 결합. 기존 관료 체계에 대한 충성(충)보다 자신의 개혁 비전이 우선이었다.

소설 예시: **《레 미제라블》 자베르 경감** — "법이 곧 정의"라는 확고한 옳음(正)과, 법의 수호자로서 인정받으려는 야망. 의(義)는 "법"의 테두리 안에서만 인정했기에, 법 밖의 자비를 이해하지 못해 파멸했다.

### 유형 C: 높은 바람 + 높은 복수 (복수에 불타는 자)

```
  3축: 바람 ↑, 신조 = "원수를 갚겠다" / "잃은 것을 되찾겠다"
       옳음 중간, 신조 = "받은 것은 갚는다" (은원 논리)
  5가치: 복수 ↑, 야망 중~↑, 의 중간

  특성: 원한이 삶의 동력. 복수를 이루기 위해 힘과 정보를 모음.
```

역사 예시: **오자서(伍子胥)** — 아버지와 형의 원수를 갚기 위해 초나라를 떠나 오나라로 건너갔다. 바람(願)의 신조가 "부형의 원수를 반드시 갚겠다"이며, 복수심(復)이 수십 년간 식지 않았다. 결국 초나라 평왕의 시체를 파내어 채찍질했다.

소설 예시: **《몬테크리스토 백작》 에드몽 당테스** — 14년의 감옥 생활 후, 삶 전체를 복수에 바쳤다. 바람(願)은 "나를 가둔 자들에게 보응하겠다"이며, 복수(復)가 최고치. 야망(野)도 높아 거대한 재산과 사회적 지위를 수단으로 활용했다.

### 유형 D: 높은 믿음 + 낮은 옳음 (따뜻하지만 원칙 없는)

```
  3축: 믿음 ↑, 옳음 ↓~중간
  5가치: 효 ↑, 충 중간, 의 ↓~중간

  특성: 사람을 깊이 믿고 정을 주지만, 원칙이 약해 흔들리기 쉬움.
        상황에 따라 도리를 어기면서도 사랑하는 사람을 택함.
```

역사 예시: **유비(劉備, 연의 버전)** — 사람을 깊이 믿고 정으로 대했으나(믿음↑), 원칙적 판단보다 감정에 이끌리는 경향이 강했다. 관우의 죽음에 이성을 잃고 동오를 침공한 것은 효·의보다 개인적 믿음(信)이 압도한 사례.

소설 예시: **《안나 카레니나》 스티바 오블론스키** — 모든 사람에게 호감을 주고 깊이 신뢰하지만(믿음↑), 도덕적 원칙이 약해(옳음↓) 바람을 피우면서도 죄책감이 금방 사라진다.

### 유형 E: 낮은 믿음 + 높은 바람 (고독한 야심가)

```
  3축: 믿음 ↓, 바람 ↑
  5가치: 야망 ↑, 충 ↓, 의 ↓

  특성: 아무도 믿지 않으면서 강한 목표를 추구. 극도로 고독.
        관계를 이용 가치로만 판단.
```

역사 예시: **이사(李斯)** — 진시황 밑에서 출세했으나, 동문 한비자마저 독살을 방조했다(믿음↓). 천하통일의 야심(바람↑)과 자기 지위를 지키려는 야망(야망↑)이 결합. 결국 조고에게 이용당해 멸족당했다.

소설 예시: **《맥베스》 맥베스** — 왕좌를 원하는 강한 바람(바람↑)에 사로잡혀, 충성하던 왕(충↓)도 죽이고, 친구 뱅코(믿음↓)도 의심하여 살해한다. 점점 누구도 믿지 못하는 고독 속으로 빠져든다.

### 유형 F: 높은 바람(자유) + 낮은 충 (자유로운 방랑자)

```
  3축: 바람 ↑, 신조 = "속박받지 않겠다" / "내 길을 가겠다"
       옳음 중간, 형성 중
  5가치: 야망 중간, 충 ↓, 효 ↓~중간

  특성: 조직이나 가문의 속박을 거부하고 자유를 추구.
        반드시 권력을 원하는 건 아님 — 자유 자체가 목적.
```

역사 예시: **장자(莊子)** — 초나라 위왕이 재상직을 제안했을 때 "나는 진흙 속에서 꼬리를 끄는 거북이 되겠다"며 거절. 바람(願)의 신조가 "속박 없는 자유"이며, 충이나 야망과는 거리가 멀었다.

소설 예시: **《돈키호테》 돈키호테** — 사회적 관습과 기존 질서에서 벗어나 자신만의 기사도를 추구(바람↑, 신조 = "진정한 기사가 되겠다"). 가문에 대한 의무(효/충)보다 자기 내면의 바람이 우선.

## 7. 다양한 조합의 인물 예시 — 1층 × 2층 교차

여기서는 1층(HEXACO)과 2층(3축/5가치)의 다양한 조합이 어떻게 서로 다른 인물을 만드는지 보여준다.

> ※ 1층↔2층의 체계적 상호작용 규칙은 별도 문서에서 다룬다.
> 여기서는 조합 예시만 나열한다.

### 7.1 같은 1층, 다른 2층

**H↑ + A↓ (원칙적 + 불같은) — 그런데 방향이 다른 두 사람:**

| | 악비 | 사보나롤라 |
|---|---|---|
| H(정직-겸손) | 높음 | 높음 |
| A(친화성) | 낮음 | 낮음 |
| 옳음(正) 신조 | "국가를 수호한다" | "교회의 타락을 심판한다" |
| 바람(願) 신조 | "금나라를 몰아내겠다" | "피렌체를 신의 도시로" |
| 5가치 충 | 극도로 높음 (국가) | 낮음 (세속 권력 거부) |
| 결과 | 충신의 비극 | 종교적 광신의 비극 |

→ 성격이 같아도, 가치관의 방향에 따라 충신과 광신자로 갈린다.

**H↓ + C↑ (착취적 + 계획적) — 목적이 다른 두 사람:**

| | 사마의 | 리슐리외 추기경 |
|---|---|---|
| H(정직-겸손) | 낮음 | 낮음 |
| C(성실성) | 높음 | 높음 |
| 옳음(正) 신조 | "천하는 강자의 것" | "프랑스의 영광이 곧 정의" |
| 바람(願) 신조 | "사마 가문이 천하를 취한다" | "왕권을 강화하겠다" |
| 5가치 충 | 표면적으로만 높음 | 왕에게 높음 (국가 충성) |
| 결과 | 위나라를 찬탈 | 프랑스 절대왕정 기틀 마련 |

→ 수단은 비슷하되(착취적+계획적), 충성의 방향이 달라 역사적 평가가 갈린다.

### 7.2 같은 2층, 다른 1층

**옳음 ↑ "정의를 세우겠다" + 충 ↑ — 그런데 성격이 다른:**

| | 제갈량 | 왕안석 |
|---|---|---|
| 옳음(正) | 90 "왕도로 천하를 바로잡는다" | 90 "천변법으로 나라를 바꾼다" |
| 충 | 90 | 80 |
| X(외향성) | 중간 (필요할 때만 나섬) | 높음 (적극적으로 밀어붙임) |
| A(친화성) | 높음 (인내하며 설득) | 낮음 (반대파에 격렬 반응) |
| E(정서성) | 중간 | 낮음 (두려움 적음, 독단적) |
| 결과 | 동맹을 쌓아가며 서서히 추진 | 반대파를 밀어붙여 개혁, 결국 좌절 |

→ 가치관은 비슷하되, 성격(특히 A와 X)에 따라 추진 방식과 결말이 달라진다.

**믿음 ↓ + 바람 ↑ "권력을 잡겠다" — 그런데 성격이 다른:**

| | 조조 (삼국지연의) | 맥베스 |
|---|---|---|
| 믿음(信) | 20 | 20 (후반) |
| 바람(願) | 90 "천하를 평정하겠다" | 90 "왕좌를 차지하겠다" |
| E(정서성) | 낮음 (대담) | 높음 (죄책감·환각에 시달림) |
| C(성실성) | 높음 (치밀한 전략) | 낮음 (충동적, 불안에 휩쓸림) |
| 결과 | 위나라 건국, 후대 평가 양면적 | 정신 붕괴, 파멸 |

→ 같은 "불신 + 야심"이라도, E와 C의 차이로 전략가와 비극적 폭군으로 갈린다.

### 7.3 희소하지만 흥미로운 조합

**H↑ + E↓ + 옳음↑ + 바람↑ (공정 + 대담 + 원칙 + 야심)**

```
  역사 예시: 왕양명(王陽明)
  · H↑: 공정하고 사심 없음 (탐관오리와 달리 청렴)
  · E↓: 대담함. 유배·전장에서도 두려움 없이 행동
  · 옳음 90 "지행합일 — 아는 것과 행하는 것은 하나다"
  · 바람 80 "나의 학문으로 세상을 바꾸겠다"
  → 공정하면서 대담하고, 원칙이 있으면서 야심이 있는 인물
  → "좋은 사람"이 아니라 "무서운 원칙주의자"에 가까움
```

**H↓ + A↑ + 믿음↑ + 충↑ (착취적이되 인내하며 충성하는)**

```
  소설 예시: 《삼국지연의》 가후(賈詡)
  · H↓: 도덕보다 실리. 주군을 여러 번 갈아탐
  · A↑: 화를 잘 내지 않음. 인내하며 조언
  · 믿음 60 "현재 주군을 섬기되, 자신의 목을 지킨다"
  · 충 70 (현재 주군에게 한정. 갈아탈 때는 즉시 전환)
  → "착취적이지만 관용적"이라는 역설적 조합
  → 도덕적으로 깨끗하진 않지만 쓸모 있고 해를 끼치지 않는 참모
```

**E↑ + X↓ + 바람↑(복수) + 옳음↑ (걱정 많고 은둔적이되 복수심 강한)**

```
  소설 예시: 《햄릿》 햄릿
  · E↑: 두려움과 걱정이 많음. 유령의 말에도 확신 못 함
  · X↓: 내성적. 감정을 내면에 담아둠. "사느냐 죽느냐"를 혼자 고민
  · 바람 80 "아버지의 원수를 갚겠다"
  · 옳음 70 "정당한 방법으로 진실을 밝혀야 한다"
  · 복수 80, 의 60
  → 복수심은 강하되 실행력이 부족한 "고뇌하는 복수자"
  → E↓+X↑이었다면 즉시 행동했을 것. 이 조합이 비극을 만듦
```

## 8. 부록: 주요 용어 정리

```
  1층 (성격, HEXACO)
  ─────────────────
  H 정직-겸손    수단의 성향 (공정 vs 착취) ※ 원칙/실리 주석 참조
  E 정서성       안전 민감도 (두려움/공감 vs 대담/냉담)
  X 외향성       사회적 에너지 (사교/표현 vs 내성/침묵)
  A 친화성       분노 조절 (관용/인내 vs 분노/원한)
  C 성실성       자기 통제 (계획/근면 vs 충동/태만)
  O 개방성       사고 유연성 (창의/호기심 vs 관습/보수)

  2층-A (3축 가치관)
  ─────────────────
  믿음(信)   타인 신뢰의 강도 + 방향
  옳음(正)   원칙·정의의 강도 + 방향
  바람(願)   욕구·동기의 강도 + 방향

  2층-B (5가치)
  ─────────────────
  충(忠)    조직/주군에 대한 헌신
  의(義)    강호 도리/약속에 대한 내면화
  효(孝)    가족/스승에 대한 의무
  복수(復)  원한에 대한 보복 의지
  야망(野)  지위/권력/성취에 대한 추진력
```
