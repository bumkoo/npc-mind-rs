## 3. MVP 스프린트 계획

| Sprint | 이름 | 내용 | 기간 |
|:------:|------|------|------|
| 1 | "소연이 말한다" | 대화 시스템 + LLM 연결 | 2~3주 |
| 2 | "소연이 기억한다" | 관계 시스템 + LanceDB 기억 | 2~3주 |
| 3 | "하루가 흐른다" | Watch 구현 + 장소 이동 | 1~2주 |
| 4 | "선택이 갈라진다" | 서사 모듈 + 이벤트 분기 | 2~3주 |
| 5 | "첫 30분 완성" | 통합 + E2E 테스트 | 1~2주 |

총 예상 기간: **8~13주 (약 2~3개월)**

## 5. MVP 성공 기준

### 기술 검증
- [ ] Local LLM이 소연 성격으로 대사를 생성하는가
- [ ] LanceDB에 대화가 저장/검색되는가
- [ ] 시간대 전환이 게임플레이에 영향을 주는가
- [ ] 선택이 관계값을 실제로 바꾸는가

### 경험 검증
- [ ] 소연과의 대화가 "살아있는" 느낌인가
- [ ] 선택이 의미있게 느껴지는가
- [ ] "내일 또 하고 싶다"고 느끼는가
- [ ] 30분이 지루하지 않은가

### 1인 개발 검증
- [ ] 2~3개월 안에 혼자 만들 수 있었는가
- [ ] 아키텍처가 확장에 문제없는가
- [ ] 다음 스프린트 방향이 명확한가
