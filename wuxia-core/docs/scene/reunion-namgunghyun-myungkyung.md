## 1. 트리거 조건

```
필수 조건 (AND):
  ① 명경 호감도 ≥ 85
  ② 남궁현 호감도 ≥ 50
  ③ 남궁현의 "붉은 밤의 서류" 퀘스트 진행 중
     → 남궁현이 "명경에게 서신을 전해달라"고 의뢰한 상태
  ④ 플레이어가 서신을 명경에게 전달 완료
  ⑤ 명경 전기 "금낭화 봉지" 발견 완료 (비밀④)

선택 조건 (분기 변수):
  A. "서량 탈출" 퀘스트 완료 여부
     → 완료: 자유도시에서 재회 (명경이 자유로운 상태)
     → 미완료: 아미산에서 재회 (명경이 당무괴 감시 아래)
  B. 플레이어가 남궁현의 야심을 알고 있는가
     → 안다면: 재회 씬에서 남궁현의 이중성을 관찰 가능
     → 모른다면: 순수한 옛 동료 재회로 보임
```

## 3. 제1막 — "문 앞에서 멈추는 남자"

### 시점: 남궁현

```
[장소에 따른 분기]

A. 아미산 장문인 거처 앞:
   남궁현이 아미산을 올라온다.
   51세 문관의 걸음으로, 산길이 거칠다.
   경공이 없으니(15) 한 걸음 한 걸음 올라야 한다.
   
   → "30년 전에도 이 길을 올라갔다.
      그때는 약재를 짊어지고.
      지금은... 빈손이다."

B. 자유도시 객잔:
   남궁현이 동해 연방 상인 행세로 자유도시에 도착.
   명경이 머무는 객잔 앞에서 멈춘다.
   
   → "검성에서 여기까지, 두 달이 걸렸다.
      두 달 동안 무슨 말을 할지 생각했다.
      아직 정하지 못했다."

[공통]
남궁현이 문 앞에서 멈춘다.
손을 올린다. 두드리지 못한다.
3초.

  이 3초 동안 남궁현의 내면:
  ┌──────────────────────────────────────────┐
  │  야망(0.7): "명경을 우리 편으로 만들면    │
  │             아미파 200명이 지지 세력이다"  │
  │                                          │
  │  진심(???): "...30년이다.                 │
  │             얼굴이 기억나지 않는다.        │
  │             아니, 너무 선명하다.           │
  │             20세의 얼굴만 기억나는 것이    │
  │             문제다."                      │
  │                                          │
  │  인내(82): "문을 두드려라. 기다렸잖아."    │
  │                                          │
  │  신경증(0.4): 안정적. — 그런데 손이 떨린다│
  │  → 평소 0.4인 신경증이                    │
  │    이 순간만 0.8로 뛴다.                  │
  │    남궁현 생애에서 거의 유일한 동요.       │
  └──────────────────────────────────────────┘

문을 두드린다.
```

### 플레이어의 위치

```
플레이어는 이 씬에서 3가지 위치를 선택할 수 있다:

  ① "함께 들어간다" — 소개자 역할
     → 명경에게: "남궁 왕국에서 오신 분이 있습니다"
     → 가장 자연스러운 진입. 명경이 경계를 낮춤.
     → 재회 전 과정을 관찰 가능.

  ② "밖에서 기다린다" — 관찰자 역할
     → 두 사람만의 공간을 만들어줌.
     → 대화를 직접 듣지 못함. 
       나중에 명경 or 남궁현에게 물어봐야 함.
     → 관계 심화 보상: 명경 "네가 자리를 비켜준 것... 고맙다."

  ③ "몰래 듣는다" — 정보 수집 역할  
     → 경공(40+) 체크.
     → 남궁현의 진심과 계산을 동시에 관찰 가능.
     → 발각 시: 명경 호감도 -20, 남궁현 경계 상승.
```

## 4. 제2막 — "현 대인, 오래간만이군요"

### 문이 열린다

```
명경이 문을 연다.

  명경이 보는 것:
  ┌──────────────────────────────────────────┐
  │  51세의 남자가 서 있다.                    │
  │  기억 속의 21세 청년이 아니다.             │
  │  머리에 서리가 내렸다. 이마에 주름이 있다.  │
  │  그런데 눈은 — 눈은 변하지 않았다.        │
  │  약재를 가져오며 고개를 살짝 숙이던 그 눈.  │
  └──────────────────────────────────────────┘

  남궁현이 보는 것:
  ┌──────────────────────────────────────────┐
  │  49세의 여인이 서 있다.                    │
  │  기억 속의 20세 의녀가 아니다.             │
  │  손에 약초 얼룩이 30년치 묻어 있다.        │
  │  입가에 피곤한 주름이 있다.                │
  │  그런데 눈은 — 눈은 변하지 않았다.        │
  │  부상병을 살리겠다고 뛰어다니던 그 눈.     │
  └──────────────────────────────────────────┘

1초의 침묵.

  이 1초 동안 LLM이 처리해야 할 것:
  ├── 남궁현: 인내(82) 발동. 표정을 관리한다. 미소를 만든다.
  │          그러나 목소리가 0.5초 늦게 나온다.
  └── 명경:  공감(82) 발동. "이 사람이 변했다" 즉시 인식.
             그런데 "무엇이" 변했는지 분류가 안 된다.
             성실성(0.9) 발동. 장문인의 얼굴을 만든다.
```

### 첫 대사 — 교차하는 호칭

```
[분기: 누가 먼저 말하는가]

대부분의 경우, 명경이 먼저 말한다.
(성실성 0.9: 손님이 왔으니 맞이해야 한다)

명경: "...현 대인. 오래간만이군요."

  이 대사의 해부:
  ├── "..." = 0.5초의 망설임. 호칭을 정하는 시간.
  │          "현 공자"(30년 전)와 "현 대인"(지금) 사이의 선택.
  │          "현 대인"을 골랐다 = 거리를 유지하기로 결정.
  │
  ├── "오래간만이군요" = 감정 최소화.
  │   ✗ "보고 싶었습니다" — 절대 말하지 않음
  │   ✗ "어떻게 지내셨소" — 너무 개인적
  │   ✓ "오래간만" — 사실만 진술. 안전한 거리.
  │
  └── 목소리 톤: 평소와 같다. — 그것이 이상하다.
      30년 만의 재회인데 목소리가 평소와 같다는 것은
      "감정을 누르고 있다"는 증거.

남궁현: (미소. 평소의 온화한 미소.)
        "사태. 건강하셨소?"

  이 대사의 해부:
  ├── "사태" = 공식 호칭. 예의를 지킨다.
  │   남궁현은 "경아(鏡兒)"라고 부르고 싶다.
  │   그러나 플레이어 앞에서, 또는 공식적 상황에서
  │   그 호칭은 쓸 수 없다.
  │
  ├── "건강하셨소?" = 진심 + 계산의 혼합.
  │   진심: 정말로 건강이 걱정됐다.
  │   계산: 상태를 파악하는 첫 번째 질문.
  │
  └── "미소" = 남궁현의 가면.
      진짜 감정(떨림)을 미소로 덮는다.
      그러나 눈가에 미세한 주름이 깊어진다.
      → LLM 지시: "미소 뒤에 눈이 촉촉하다"

[플레이어가 함께 있을 경우]
플레이어는 이 순간 두 사람의 미세한 변화를 관찰한다:
  · 명경의 손이 문틀을 잡고 있다 (평소에는 손이 자유롭다)
  · 남궁현의 미소가 평소보다 0.5초 늦게 왔다
  → "보여주되 설명하지 마라" 원칙:
     게임이 "두 사람은 동요하고 있습니다"라고 알려주지 않는다.
     플레이어가 행동 묘사를 읽고 추론해야 한다.
```

## 5. 제3막 — "약재는 아직 키우시오?"

### 차를 따르는 시간

```
장문인 거처 안. (또는 객잔 방.)
명경이 차를 끓인다.

  이 장면의 핵심:
  "차를 끓이는 동안은 말을 안 해도 된다."
  → 두 사람 다 말을 꺼내기 어렵다.
  → 차 준비가 시간을 벌어준다.
  → 명경에게 차 끓이기 = 감정을 피하는 의식.

남궁현이 방 안을 둘러본다.
약장이 보인다. 약초 냄새가 난다.
30년 전 야전 병원의 냄새와 같다.

남궁현: "...약재는 아직 키우시오?"

  이 질문의 구조 = "브람스를 좋아하세요?"
  ┌──────────────────────────────────────────┐
  │  겉: 일상적 안부. 약초 키우는지 묻는 것.   │
  │                                          │
  │  속: "당신은 아직 30년 전 그 사람입니까?   │
  │       내가 기억하는 그 사람이               │
  │       아직 여기에 있습니까?"               │
  │                                          │
  │  더 깊은 속:                               │
  │       "나는 변했소. 많이 변했소.            │
  │        당신은 변하지 않았소?                │
  │        변하지 않았기를 바라오.              │
  │        ...그래야 내가 돌아갈 곳이 있으니까." │
  └──────────────────────────────────────────┘

명경: (차를 따르며)
      "...네. 산에서 키울 수 있는 것은 키우고 있습니다."

  이 답변의 구조:
  ├── "네" = 단답. 감정 차단.
  ├── "산에서 키울 수 있는 것은" = 한계를 언급.
  │   서량이 독립하면서 약재 공급이 끊겼다.
  │   당무괴 영토 안에서 구할 수 있는 것만.
  │   → 겉: 약재 상황 설명
  │   → 속: "나도 갇혀 있습니다"
  └── "키우고 있습니다" = 현재 진행형.
      아직 포기하지 않았다는 의미.

남궁현: (찻잔을 받으며)
        "이 차... 28년 전에도 끓여주셨소."

  ★ 위험한 발언.
  남궁현이 "28년 전"이라는 구체적 숫자를 꺼냈다.
  이것은 단순한 안부가 아니라 "기억하고 있다"는 선언.

명경: (손이 멈춘다. 0.5초.)
      "...기억력이 좋으시군요."
      (차를 마저 따른다)

  명경의 내면 (플레이어에게 보이지 않음):
  ┌──────────────────────────────────────────┐
  │  공감(82) 발동:                            │
  │  "이 사람이 28년 전을 기억하고 있다.       │
  │   차까지 기억하고 있다.                    │
  │   ...왜?"                                 │
  │                                          │
  │  신경증(0.65) 상승:                        │
  │  "이 대화가 어디로 가는지 모르겠다.        │
  │   불편하다. 왜 불편한지 모르겠다."          │
  │                                          │
  │  성실성(0.9) 방어:                         │
  │  "화제를 바꾸자."                          │
  └──────────────────────────────────────────┘

명경: "서신에 '때를 기다리시오'라고 하셨는데,
       무슨 뜻이었습니까?"

  → 화제를 공적 영역으로 돌린다.
  → 명경 특유의 감정 회피 패턴:
     사적 화제 → 공적 화제로 전환.
```

### 정치 대화 (표면)

```
남궁현: (표정이 바뀐다. 행정가의 얼굴.)
        "사태도 느끼셨을 거요.
         서량의 상황이 오래 갈 수 없소.
         당무괴가 정파 문파를 어떻게 다루는지..."

명경: "알고 있습니다."

남궁현: "아미파 200명의 제자가 독왕의 손아귀에 있소.
         내가 도울 수 있소."

  이 대화의 이중 구조:
  ├── 표면: 정치적 제안. 아미파 해방 협력.
  │         합리적이고, 논리적이다.
  └── 이면: "당신을 구하고 싶다."
            남궁현 자신도 이 두 가지를 분리하지 못한다.
            (남궁현 전기 §7: "진심과 계산이 분리되지 않는 것이 비극")

명경: (잠시 생각하고)
      "현 대인의 제안은 감사합니다.
       하지만 아미파의 일은 아미파가 처리합니다."

  → 의(0.9): 외부 세력에 의존하지 않는다.
  → 성실성(0.9): 장문인의 원칙.
  → 그러나 이것은 동시에:
     "당신에게 빚지고 싶지 않다"
     → 왜 빚지기 싫은가? 빚지면 관계가 복잡해지니까.
     → 왜 복잡해지면 안 되는가?
     → (이 질문에 명경은 답하지 못한다)
```

## 6. 제4막 — "사태." "...그 호칭은."

### 균열의 순간

```
정치적 대화가 끝나고, 잠시 침묵.
밖에서 바람 소리.
차가 식어간다.

남궁현이 찻잔을 내려놓는다.
평소의 미소가 사라진다.
처음으로 "남궁현" 자신의 얼굴이 드러난다.

남궁현: "사태."

명경: "네."

남궁현: "...아니."

  (1초의 침묵.)

남궁현: "경아."
```

### 플레이어 개입 분기

```
[플레이어가 함께 있을 경우 — 3가지 선택]

이 시점에서 플레이어는 개입할 수 있다:

A. 침묵을 지킨다 (관찰)
   → 가장 자연스러운 선택.
   → 두 사람의 대화가 계속된다 (제5막으로).
   → 보상: 명경 호감도 +5, 남궁현 호감도 +5
     ("이 아이가 눈치가 있구나")

B. "두 분 사이에 무슨 일이 있었습니까?" (직접 질문)
   → 대화가 끊긴다.
   → 명경: "...오래된 이야기다." (회피)
   → 남궁현: "전장에서 같이 싸운 동료요." (가면을 다시 쓴다)
   → 균열이 닫힌다. 이 씬에서는 더 이상 진전 없음.
   → 그러나 다음 기회에 명경이 먼저 이야기할 수 있음.
   → 보상 없음. 관계 변화 없음.

C. "금낭화... 약장에 있던 그 꽃 말씀이시죠?" (연결)
   → ★ 가장 위험하고 가장 깊은 선택.
   → 명경의 비밀(금낭화)과 남궁현의 기억을 연결한다.
   → 명경: (얼굴이 하얘진다) "...너 그것을 봤느냐."
   → 남궁현: (놀람) "사태가... 그것을 아직 갖고 계시오?"
   → 명경: (5초 침묵) "...약재 표본이라고 했을 텐데."
   → 남궁현: (목소리 떨림) "약효가 없는 꽃인데요."
   → 명경: (일어선다) "...오늘은 여기까지 하지요."
   
   이 선택의 결과:
   · 씬이 일찍 끝난다 (제5막 생략).
   · 그러나 다음 날, 명경이 플레이어를 불러
     "네가 본 것은 아무에게도 말하지 마라"고 한다.
     (이것이 명경이 자기 감정을 인정한 최초의 순간)
   · 남궁현은 그 밤 잠을 이루지 못한다.
     (사강의 로제: "재떨이에 담배꽁초를 눌러 끄면서")
   · 보상: 명경 호감도 +15, 4단계 관계 확정 진입.
          남궁현의 감정 락 해제 → 이후 대화에서 진심 빈도 증가.
```

## 10. LLM 구현 노트

```
이 씬의 대사 생성에서 LLM이 지켜야 할 원칙:

  1. 두 NPC 모두 감정을 직접 말하지 않는다.
     명경: 의술의 언어로 번역 (§11 감정 표현 패턴)
     남궁현: 미소와 공손한 말투로 위장 (§11 말투 규칙)
     → 감정은 오직 "행동 묘사"로만 전달.
        (손 떨림, 침묵, 찻잔 기울기, 시선 변화)

  2. 침묵을 두려워하지 않는다.
     이 씬에서 가장 중요한 것은 "대사"가 아니라 "침묵".
     (1초), (3초), (5초) — 침묵의 길이가 감정의 크기.
     LLM은 침묵 지시를 정확히 따른다.

  3. 호칭이 감정의 바로미터다.
     남궁현: "사태" → 공식. "경아" → 진심.
     명경: "현 대인" → 거리. "현 공자" → 과거.
     호칭 전환 시 반드시 상대의 반응을 생성.

  4. 플레이어는 "관객"이면서 "촉매"다.
     두 NPC의 대화에 플레이어가 개입하면
     대화의 방향이 바뀐다.
     개입하지 않으면 두 NPC의 고유 패턴대로 진행.
     → 플레이어의 "선택하지 않는 선택"도 의미가 있다.

  5. 이 씬은 전투가 없다.
     검도, 내공도, 무공도 없다.
     차와 말과 침묵만 있다.
     그것이 이 씬을 칠국춘추에서 가장 강렬한 씬으로 만든다.
     "가장 조용한 씬이 가장 격렬하다."
```
