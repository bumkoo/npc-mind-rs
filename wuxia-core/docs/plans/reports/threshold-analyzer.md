## 1. 벤치마크 목적

Step 3.1의 GAP 분석은 **그룹 평균** 기반이었다. 평균은 내부 분포를 숨긴다. Threshold Analyzer는 **개별 쌍(pair)** 수준까지 파고들어, 실전에서 "엉뚱한 기억"이 검색 결과에 섞이는 경우가 정확히 몇 건인지 측정한다.

### 1.1 핵심 질문

```
  "혈교에 대해 물어봤는데, 소연의 시장 기억이 상위에 올라오는 일이 있는가?"
  "무협과 전혀 무관한 날씨/음식 기억이 threshold를 뚫는 일이 있는가?"
```

### 1.2 분석 대상 모델 (5개)

| 후보 | 모델 | 비고 |
|:----:|:-----|:----:|
| B | bge-m3-q8_0 | Step 3.1 상위권 |
| C | bge-m3-Q4_K_M | Step 3.1 이전 선정 모델 |
| F' | embeddinggemma-300m-qat-Q8_0 + task prompt | **최종 선정** |
| G' | embeddinggemma-300m-qat-Q4_0 + task prompt | 경량 대안 |
| H' | embeddinggemma-300m-Q8_0 + task prompt | 비QAT 대조군 |

## 2. 분석 프레임워크

### 2.1 측정 지표

```
  L2_min  = 같은 주제 의역 쌍 중 가장 낮은 유사도 (최약 관련 기억)
  L3_max  = 다른 주제 교차 쌍 중 가장 높은 유사도 (최강 무관 기억)
  L4_max  = 완전 무관 쌍 중 가장 높은 유사도   (최강 쓰레기 기억)
  
  GAP     = L2_min - L3_max  (양수면 분리 성공, 음수면 겹침)
  margin  = threshold - L4_max (양수면 L4 방어 성공)
```

### 2.2 위험 시나리오

```
  시나리오 A: L2/L3 겹침 (GAP < 0)
  → "소연의 시장 기억"이 "혈교" 검색에 상위 노출
  → 몰입 파괴, NPC 대화 맥락 혼란

  시나리오 B: L4 역전 (L4_max > threshold)
  → "오늘 날씨가 좋다"가 "검술 수련" 검색에 노출
  → NPC가 엉뚱한 말을 하는 치명적 버그
```

### 2.3 Threshold 산출 공식

```
  threshold = L2_min  (보수적 설정)
  
  근거: L2_min보다 낮은 유사도는 "관련 기억"이 아닐 가능성이 높다.
  L2_min 자체를 threshold로 사용하면 관련 기억 0% 손실 + 최대 방어.
```

## 4. 관찰 및 분석

### 4.1 bge-m3의 L4 역전 문제

bge-m3 계열(B, C)은 L2/L3 분리는 완벽하지만(GAP 양수), L4 역전이 심각하다. "매일 새벽에 검술을 수련한다"와 "오늘 날씨가 좋다" 쌍의 유사도가 threshold를 돌파하여 4~5건이 통과한다. 이는 bge-m3가 무협 도메인과 일상 도메인을 구분하지 못한다는 것을 의미한다.

### 4.2 공통 문제 쌍: "무공/수련" 그룹

모든 모델, 모든 언어에서 L2 최하위를 기록하는 동일한 쌍이 존재한다.

```
  "무공 연마를 게을리하면 실력이 떨어진다"
  ↔ "그는 십 년째 한 가지 검초만 반복하고 있다"
  
  두 문장 모두 "무공/수련" 주제지만:
  문장1: 게을리 → 실력 하락 (경고/교훈)
  문장2: 십 년째 반복 (인내/노력)
  → 톤이 정반대라 모델이 헷갈림
```

이 쌍이 L2_min을 결정하므로, threshold가 이 쌍을 통과시킬 정도로 낮아야 한다.

### 4.3 ZH 1쌍 겹침의 실전 영향

ZH에서 L3_max(0.4681)가 L2_min(0.4668)을 0.0013 차이로 역전한다. 그러나 게임이 한국어 단일 언어이므로 실전 영향은 없다. 나중에 중국어 지원 시 2-stage search의 keyword overlap(Stage 2)이 이 경계 사례를 방어한다.

### 4.4 H' vs F' — 절대 점수 vs 안전 마진

H'는 L2_min(0.5263)이 전체 최고지만, L4_max(0.5134)도 같이 높아 margin이 0.0080에 불과하다. F'는 L2_min(0.4656)이 낮지만 L4_max(0.4264)를 확실히 밀어내어 margin 0.0310을 확보한다. 실전에서는 절대 점수보다 안전 마진이 중요하므로 F'가 우세하다.

### 5.1 선정: F' (embeddinggemma-300m-qat-Q8_0 + task prompt)

| 기준 | 결과 |
|------|------|
| KO L4 역전 | 0/24 ✅ |

| ZH L4 역전 | 0/24 ✅ |
| KO GAP | +0.0660 (전체 1위) |
| KO margin | +0.0310 (전체 1위) |
| 벡터 차원 | 768 (bge-m3 대비 25% 절약) |
| CPU 속도 | 28ms/건 |

### 5.2 설정 파일 반영 (assets/ai/embedding.toml)

```toml
[threshold]
KO = 0.4656    # L2_min 기준
EN = 0.4580
ZH = 0.4668
default = 0.4656

[search]
boost_ratio = 1.1           # keyword 보너스 시 threshold × 1.1
candidate_multiplier = 3    # top_k × 3 후보 확보
```

### 5.3 2-stage search 연계

```
  Stage 1: similarity >= config.threshold_for(lang)  → L3, L4 필터링
  Stage 2: keyword overlap 검증                       → ZH 1쌍 경계 방어
  
  두 단계 합산으로 3개 언어 모두 완전 방어 달성.
```
