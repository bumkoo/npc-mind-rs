## 0. 왜 약전인가

```
진영은 게임 시작 15년 전에 사망한 인물이다.
플레이어가 직접 만날 수 없다.

그러나:
  · 진야림의 효(0.7) — 아버지에 대한 기억이 모든 선택의 기저
  · 조고의 기억 #4 — "진영은 바른 말을 했다. 그래서 죽었다."
  · 자유도시의 전사 — 이 도시가 "자유"인 이유의 기원
  · 플레이어의 거울 — "가족을 잃고 살아남은 자"의 원형

진영은 게임 내에서 다음으로 등장:
  ① 진야림의 회상 (밤 모닥불, 호감도 이벤트)
  ② 영주성 폐허의 비석/유물
  ③ 낙양 문서고의 칙서
  ④ 개방 소풍자의 증언
  ⑤ 조고의 반응 ("영주... 오래된 이름이군.")
```

| 생존 후손 | 막내 아들 진야림(陳野林) — 당시 10세, 호위무사가 탈출시킴 |

### 이름의 뜻

```
陳 (진) = 대진 황실 방계 성씨. 영주 왕가의 성.
寧 (녕/영) = 편안할 녕.

"편안한 진씨" — 이름 그대로 평화를 추구한 사람.

아이러니:
  · 寧 = 편안함. 그러나 그의 죽음은 가장 불안한 사건이 되었다.
  · 아들 진야림(陳野林)은 아버지의 성(陳)만 남기고
    이름(寧)은 버렸다.
    "편안함은 거짓이었으니까."
  · 영주(寧州)의 寧도 같은 글자.
    → 진영의 이름이 곧 나라의 이름. 왕과 땅이 하나인 번왕국.
    → 왕이 죽자 나라도 죽었다.
```

| 신경증 | 0.4 | 불안보다 원칙에 기반한 판단. 그러나 마지막에는 공포를 느꼈을 것 |

### 가치관 — WuxiaValues (추정)

| 가치 | 수치 | 설명 |
|------|------|------|
| 의(義) | 0.8 | **핵심 가치**. "옳은 것을 말해야 한다" |
| 인(仁) | 0.7 | 백성을 보살피는 번왕. 세금 착취 거부 |
| 효(孝) | 0.6 | 대진 황실에 대한 충성 — 그러나 맹목적이지 않음 |
| 충(忠) | 0.5 | "황실에 충성하되, 황실이 백성을 해치면 말해야 한다" |
| 야망 | 0.2 | 영토 확장이나 권력에 관심 없음. 영주를 잘 지키면 족함 |
| 복수 | 0.1 | 원한을 품는 성격이 아님 |

```

  의(0.8) ────── 진영의 중심축
    │
    ├── "옳은 것을 말해야 한다"
    │    → 태무제 앞에서 공개 반대
    │    → "폐하, 백성의 피로 왕좌를 칠하시면
    │       그 왕좌는 미끄러워 앉을 수 없습니다."
    │
    ├── 인(0.7) + 충(0.5) = 갈등
    │    "백성을 보살피는 것이 충성인가,
    │     황제의 명을 따르는 것이 충성인가?"

         → "나는 왕좌를 노리는 게 아니다.
            그저 옳은 말을 한 것뿐이다."

  │ "옳은 것을 말한다"    │ "아버지를 기억한다"    │
  │ 충(0.5) 갈등         │ 충(0.2) 거의 없음     │
  │ "황실에 말한다"       │ "나라가 나를 버렸다"   │
  │ 야망(0.2) 낮음       │ 야망(0.1) 극히 낮음   │
  │ 말하는 사람           │ 침묵하는 사람          │
  │ 글과 논리의 사람      │ 밀림과 본능의 사람     │
  │ 죽음: 말해서 죽었다   │ 생존: 도망쳐서 살았다  │

    "아버지가 말해서 죽었으니, 나는 침묵한다"
    → 역설: 침묵이 효의 표현
```

```
  배후 — 조고의 기억 #4에서:
  "영주 번왕 진영은 조정 회의에서 나를 '비천한 자'라 불렀다."
  → 진영이 조고를 직접 겨냥한 것인가?
  → 가능한 해석:
     A. 진영이 조고의 정책을 "비천한 방법"이라 비판
        → 조고가 개인적 모욕으로 받아들임
     B. 진영이 조고의 출신을 실제로 알았을 가능성
        → 영주 왕가의 정보력 + 개방과의 우호 관계
        → 만약 그렇다면: 진영은 "반대"만 한 것이 아니라
           "조고의 약점"을 건드린 것
        → 조고의 기억에서 "비천한 자"가 특별히 아픈 이유
     C. 조고의 기억이 왜곡
        → 진영이 실제로 한 말과 조고가 기억하는 말이 다름
        → 천민 콤플렉스가 진영의 말을 뒤틀어 기억
  → 게임 내에서 진실은 확정하지 않음. 플레이어가 해석.
```

```
  └─────────────────────────────────────────────┘

  10세 진야림이 본 것:
  · 아버지가 검을 뽑는 것 (떨리는 손)
  · 성벽 너머의 불꽃
  · 형과 누나의 비명
  · 점점 작아지는 영주성
  → 15년간 하루도 잊지 않은 기억
```

## 4. 유물과 흔적 — 게임 내 등장 방식

### 유물 ① — 영주성 폐허의 비석

```
  위치: 자유도시 서쪽 외곽, 무너진 성벽 근처
  상태: 반쯤 묻혀 있음. 풀과 이끼에 덮여 읽기 어려움

  비석 내용 (플레이어가 풀을 걷으면):
  "寧州藩王陳寧  在此"
  (영주 번왕 진영이 여기에 있었다)

  → 누가 세웠는가?
    · 개방 소풍자가 비밀리에 세운 것으로 추정
    · "기록이 지워져도, 돌은 남는다"
  → 진야림 동행 시: 무언 반응. 비석 앞에 오래 서 있음.
    (플레이어 선택: 말을 건다 / 기다린다)
```

### 유물 ② — 옥패 (진야림 소지)

```
  진영이 막내에게 남긴 유일한 물건.
  · 앞면: 영주 왕가 문장 (寧 + 용봉 문양)
  · 뒷면: "寧州地契 — 御覽" (영주 지계 — 어람)
  · 의미: 낙양 황실 문서고 열람 열쇠 + 자유도시 법적 소유권 증명
  · 진야림은 앞면의 의미만 알고 있음 (뒷면은 v1.1에서 공개)
```

### 유물 ③ — 낙양 문서고의 칙서

```
  위치: 대진 낙양 황궁 지하 문서고
  접근 조건: 대진 잠입 퀘스트 + 옥패 or 십상시 해체
  
  문서 내용:
  · "태무제 칙서 — 영주 번왕국 폐지. 역병에 의한 왕가 단절."
  · 그러나 같은 서랍에:
    "십상시 작전 기록 — 영주 번왕 진영 처리 완료. 왕족 17명."
  · 두 문서의 날짜가 같음 → "역병"이 "학살"이었다는 물증
  · → 조고 비밀 ④ 의 물리적 증거
```

### 등장 ④ — 개방 소풍자의 증언

```
  트리거: 소연 호감도 50+ AND 자유도시 영주성 폐허 방문 후

  소풍자: "아이야, 이 도시에 왕이 있었던 거 알고 있나?"
          (지팡이를 짚으며)
          "진영이라고... 별로 유명하진 않았지.
           작은 나라의 학자 왕. 돈은 좀 있었고.
           개방한테 잘해줬어. 정보도 나누고, 밥도 줬고."
          (뜸을 들이며)
          "역병으로 죽었다고? ....하."
          "15년 전에 역병이 칼을 들고
           성벽을 넘었다는 말은 처음 듣는군."
```

### 등장 ⑤ — 진야림의 회상 (호감도 70+)

```
  트리거: 밤 모닥불 옆. 진야림 호감도 70+.
  
  진야림: (불을 바라보며, 오래 침묵)
          "...아버지는 검을 잡을 줄 몰랐어."
          "학자였거든. 글만 읽었어. 검은 장식이었지."
          (또 침묵)
          "근데 그날 밤에... 뽑더라고."
          "떨리는 손으로."
          (불을 쏘아봄)
          "뽑아서 뭐가 달라졌겠어. 못 싸우는데.
           근데... 뽑긴 했으니까."
          (진야림이 처음으로 웃는다. 
           슬픈 웃음.)
          "그게 우리 아버지야."
```

## 5. 서사적 기능 — 세 캐릭터를 관통하는 유령

```
진영이 세 캐릭터에게 미치는 영향:

┌─────────────────────────────────────────────┐
│                                              │
│  진야림에게:                                  │
│  · "아버지" — 효(0.7)의 대상                  │
│  · "말해서 죽은 사람" — 침묵하는 이유          │
│  · "왕이 될 필요 없다. 살기만 하면 된다"       │
│    → 야망(0.1)의 기원                         │
│  · "검을 뽑은 사람" — 무력한 용기의 기억       │
│    → 진야림이 숲에서 칼을 든 것도               │
│       어딘가에서 아버지의 메아리                │
│                                              │
│  조고에게:                                    │
│  · "비천한 자라 불렀던 번왕" — 개인적 원한     │
│  · "첫 번째 성공적인 숙청" — 방법론의 기원     │
│  · "완료 처리한 건" — 진야림 생존 = 실수의 증거 │
│  · 기억 #4: "바른 말을 하면 죽는다"            │
│    → 조고가 "바른 말"에 대해 가진 양가감정      │
│    → 어머니도 "바른 세상"에서 죽었으니까        │
│                                              │
│  플레이어에게:                                │
│  · "나와 같은 유형의 피해자" — 가족을 잃은 자   │
│  · "진야림을 이해하는 열쇠" — 아버지를 알아야   │
│    아들을 이해할 수 있다                       │
│  · "조고의 악행 연쇄의 첫 고리" — 영주→개방→화산│
│    → 조고 타도 퀘스트의 증거 축적               │
│  · "바른 말의 대가" — 게임의 도덕적 질문        │
│    → "옳은 말을 하면 죽는 세상에서,             │
│       그래도 옳은 말을 해야 하는가?"            │
│                                              │
└─────────────────────────────────────────────┘

한 문장 요약:
  "검을 잡을 줄 모르는 학자가 마지막에 검을 뽑았다.
   그것이 무력함의 끝이었고, 동시에 의(義)의 시작이었다."
```

## 6. LLM 활용 — NPC 대사에서 진영이 언급될 때

### 진야림이 아버지를 말할 때

```
규칙:
1. 주어 생략. "아버지가"를 잘 안 쓴다. "그 사람이" 또는 생략.
   ✗ "아버지는 학자였어"
   ✓ "학자였어. 글만 읽었어."
2. 감정보다 사실만 말한다. 눈물이나 분노 표현 없음.
3. 유일한 예외: "검을 뽑았다" 에피소드. 이때만 조금 길어진다.
4. 진영을 "아버지" 대신 "우리 아버지"라고 부를 때가 있음 (효의 발현).
```

### 조고가 영주를 말할 때

```
규칙:
1. "영주" 또는 "그 번왕"이라 부른다. 절대 "진영"이라 이름 부르지 않음.
   → 이름을 부르면 인간으로 인정하는 것. 조고는 그러지 않는다.
2. 감정 없이 말한다. "정리한 건"이라는 표현.
3. 유일한 감정 누출: "비천한"이라는 단어에 미세한 반응.
   → 동작 묘사로 표현: (차잔을 내려놓는다.) "...오래된 일이지."
```

### 소풍자가 영주를 말할 때

```
규칙:
1. 구어체. 회상하듯 느리게 말한다.
2. 감정은 있으나 절제. 개방 장로의 품격.
3. "역병이 칼을 들고" 같은 비유 사용.
4. 직접적으로 "조고가 죽였다"라고 말하지 않음 (증거 없으므로).
   → 대신 암시. "역병이 어디서 왔는지는... 글쎄."
```
