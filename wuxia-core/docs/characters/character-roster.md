## 0. 범례

```
열전 상태:
  ✅ 완성  = 개별 열전 문서 있음 (능/성/신 수치, 대사, 퀘스트 포함)
  📝 배치  = 세계사 연표에 이름·역할 배치됨 (열전 미작성)
  🔲 필요  = 아직 설정 없음. 향후 추가 필요

인물 유형:
  🎮 = 플레이어 캐릭터
  🗡️ = 현역 NPC (게임 시작 시 생존, 직접 만남)
  📜 = 역사 인물 (이미 사망, NPC 대사·서적으로 등장)
  👻 = 생사 불명 (퀘스트 대상)
  ⚔️ = 십상시 (조고의 사병)
```
