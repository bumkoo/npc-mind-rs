## 1. 무협 세계관 생성 관점

### 1.1 협(俠, hsia)의 정의와 사회적 기원

**어원:** 遊俠(yu-hsia) = 遊(방랑) + 俠(강제하다/바로잡다)  
→ "나라를 돌아다니며 무력으로 불의를 바로잡는 자"

**사회적 기원에 대한 3가지 학설:**

| 학설 | 주장자 | 핵심 내용 |
|------|--------|-----------|
| 전문직업인설 | 도희성, 노간 | 실업 농민·장인이 직업 무사가 됨 |
| 몰락귀족설 | 양련승 | 봉건 질서 해체 후 지위 잃은 무사 계급 + 하층민 합류 |
| **기질론(저자 채택)** | 마스부치 타츠오 | 특정 계급이 아닌 **기질과 행동 양식**의 문제 |

**저자의 근거:**
- 사마천이 "포의(布衣)의 협객", "마을의 협객" 등 출신을 특정하는 표현을 썼다 → 모든 협객이 평민이었다면 굳이 구분할 필요 없음
- 주가(朱家)는 노예를 사서 농사 짓는 지주였고, 영성(寧成)은 부유해진 후 협객 행세 → 협으로 생계를 유지한 것이 아님
- 결론: **협객은 사회 계급이 아니라, 강한 개인주의적 기질을 가진 자들의 행동 양식**

> **🎮 게임 설계 시사점:** NPC의 "협객 여부"는 출신 계급이 아닌 성격 특성(Big Five)과 가치관 조합으로 결정해야 함

### 1.2 협객의 8대 이상 (캐릭터 가치 체계)

| # | 이상 | 설명 | 게임 수치화 가능성 |
|---|------|------|--------------------|
| 1 | **이타(利他)** | 가난한 자·곤경의 자를 도움. 낯선 이에게도 적용. 義(yi)="초도덕적 행위" | 공감(empathy) + 의리(loyalty) |
| 2 | **정의(正義)** | 가족 충성보다 상위. 곽해는 조카 살해범을 풀어줌(조카가 잘못) | 의리 vs 혈연 충돌 이벤트 |
| 3 | **개인자유** | 법·관습 무시, 보헤미안적 삶. 형가는 개백정·악사와 시장에서 음주가무 | 반체제 성향, 사회적 평판 |
| 4 | **개인적 충성** | 군주가 아닌 "나를 알아주는 자(知己)"에 대한 충성 | 관계 시스템의 핵심 동력 |
| 5 | **용기** | 물리적·도덕적 용기. 죽음 앞에서도 태연 | 담력(willpower) 스탯 |
| 6 | **신의(信義)** | "말하면 반드시 행하고, 행하면 반드시 이룬다" - 사마천 | 약속 시스템, 평판 시스템 |
| 7 | **명예** | 행동을 단속하고 명예를 소중히 여겨 천하에 이름을 떨침 | 명성(fame) 수치 |
| 8 | **관대/재물 경시** | 돈을 받되 집착 없음. 호화롭게 쓰되 친구와 나눔, 혹은 검소히 살며 가난한 이에게 줌 | 경제 시스템과 연동 |

**협객의 결함 (균형잡힌 캐릭터 설계용):**
- 싸움에 너무 열성적이고 쉽게 분노
- 복수가 과도할 때 있음 (연 날리다 죽은 쥐 맞자 부자 집안 몰살)
- 정의 개념이 개인 수준에 한정 → 사회 전체 이익 고려 부족
- 법 무시 → 사회 질서 추가 교란

> **🎮 게임 설계 시사점:** 협객 NPC에게 미덕과 결함을 동시 부여. "과도한 복수" "좁은 시야의 정의"는 플레이어와의 갈등 씨앗이 됨

### 1.3 사상적 관계 (4대 학파와의 비교)

#### 협객 vs 유가(儒家)

| 항목 | 유가 | 협객 |
|------|------|------|
| 사랑의 범위 | 차등적 사랑 (부모→가족→타인) | 보편적 의리 (낯선 이에게도 동일) |
| 행동 원칙 | 중용(中庸), 절제 | 극단으로 치닫는 경향 |
| 복수 | 용서(恕)와 양보(讓) | 복수를 미덕으로 삼음 |
| 진실성 | 상대적 (상황 따라 거짓 가능) | 절대적 (반드시 말과 행동 일치) |

**공통점:** 인의(仁義)를 중시하나 해석이 다름

#### 협객 vs 법가(法家)

- 한비자: "유자는 글로 법을 어지럽히고, 협자는 무력으로 금령을 범한다"
- 법가는 국가 통제 강조 → 협객은 개인 자유 강조
- **한무제의 협객 탄압:** 법가적 통치와 협객의 본질적 충돌
- 공통점 거의 없음 → **천적 관계**

#### 협객 vs 묵가(墨家)

| 항목 | 묵가 | 협객 |
|------|------|------|
| 조직 | 엄격한 조직, 지도자에 생사여탈권 | 자발적, 느슨한 결합 |
| 전투 | 원칙적으로 반전, 약국 방어만 참여 | 항상 싸움 준비 |
| 관심 | 정치·사회적 형평 | 개인적 정의만 |
| 생활 | 금욕적, 규율적 | 자유분방 |

**공통점:** 겸애(兼愛), 이타주의, 자기희생, 절대적 신의

#### 협객 vs 도가(道家)

| 항목 | 도가 | 협객 |
|------|------|------|
| 행동 | 무위(無爲) 권장 | 적극적 행동 |
| 자유 | 절대적·정신적 자유 | 사회적 자유 |
| 형이상학 | 심오한 철학 체계 | 관심 없음 |

**공통점:** 개인주의, 관습 거부, 반(反)권위, 자연스러운 본성 추구  
**역사적 연결:** 진평, 전숙, 급암, 정당시 등 한대 협객들이 도가를 공부했다는 기록

> **🎮 게임 설계 시사점:** NPC 가치관 시스템에서 4학파 성향을 축(axis)으로 활용 가능. 협객은 "묵가적 이타 + 도가적 자유 + 반유가·반법가" 조합. 정파(유가·법가 경향) vs 사파(도가·묵가 경향)의 이념적 기반으로 활용

### 1.4 역사적 변천 (세계관 시대 설정용)

| 시기 | 특징 | 세계관 활용 |
|------|------|-------------|
| 전국~전한 (BC 300~120) | 협객의 전성기. 제후들이 식객(門客) 3천명 보유. 평민 협객 병존 | 7국 구도의 원형 |
| 한무제 탄압 (BC 180~20) | 법가적 중앙집권으로 협객 조직적 탄압. 거창(劇昌) 등 체포·처형 | 국가 vs 무림 갈등 |
| 후한~삼국 (25~265) | 여수(呂遂): 기부형 협객. 전위(典韋): 무사형 협객. 혜강(嵆康): 문인형 협객 | 다양한 협객 아키타입 |
| 수당 (589~907) | 두건덕: 반란형. 곽원진: 관료형. 이백: 시인형 | 협객의 다양한 진로 |
| 명청 (1368~1911) | 쇠퇴기. 표국(鏢局, 호송업) 등장 → 협객이 법의 수호자로 변신 | 무림의 제도화·상업화 |

**표국(鏢局) 시스템 - 세계관 경제 요소:**
- 보표(保鏢): 물품 운송 보험·호위 시스템
- 표객(鏢客): 무술 고수이자 상업적 호위무사
- 협객 → 표객 전환 = 무법자에서 법의 수호자로 변화
- 청렴한 표객은 부패 관료 호위 거부, 빈민 착취 거부

**지리적 분포:**
- 대부분 화북 출신 (하북·하남 2/3 이상)
- 북방 유목민 근접 → 이동의 자유, 무예 중시 문화 영향

> **🎮 게임 설계 시사점:** 7국 중 북방 국가에 협객 문화 강세, 남방은 상대적 약세 설정 가능. 표국은 경제·퀘스트 시스템의 핵심 요소

## 2. 캐릭터 생성 관점

### 2.1 역사적 협객 아키타입 (NPC 원형)

#### 유형 A: 귀족 후원자형
**신릉군(信陵君) 위무기** (卒 BC 243)
- 위(魏)나라 왕자. 식객 3천명 보유
- 핵심 특성: 겸손, 신분 차별 없음, 전략적 사고
- 서사 패턴: 문지기 후영(侯嬴)을 스승처럼 대우 → 후영의 계책으로 조(趙)나라 구원 → 참언으로 실각 → 주색에 빠져 알코올 중독사
- **비극적 결말:** 공을 세워도 참소에 의해 파멸

> 🎮 **NPC 원형:** 높은 지위 + 겸손 + 전략가 + 비극적 몰락. 식객 시스템의 모델

#### 유형 B: 자객/의사형
**형가(荊軻)** (卒 BC 227)
- 위(衛)나라 출신, 독서와 검술 애호
- 핵심 특성: 심오한 내면, 음주벽, 예술적 감성
- 서사 패턴: 개백정·악사와 시장에서 음주가무 → 연태자 단(丹)의 복수 의뢰 수락 → 진시황 암살 실패 → 죽음
- 동반자 전광(田光): 비밀 지키기 위해 자결 (신의의 극단)
- 동반자 고점리(高漸離): 형가 사후 축(筑) 연주로 접근해 진시황 암살 시도 → 실패·처형

> 🎮 **NPC 원형:** 예술가적 기질의 자객. 지기(知己) 관계의 극단적 충성. 연쇄 복수 이벤트 체인

#### 유형 C: 은둔 의협형
**주가(朱家)** (BC 3세기)
- 수백 명의 범법자 은닉, 구해준 뒤 다시 만나지 않음
- 의복은 검소, 식사는 소박, 자기 마차 타지 않고 급한 사람에게 양보
- "남을 구한 후 보답 거절" = 초도덕적 행위

> 🎮 **NPC 원형:** 숨겨진 고수. 도움 후 사라짐. 명성 거부형. 플레이어가 찾아야 하는 퀘스트 대상

#### 유형 D: 민간 협객 지도자형
**곽해(郭解)**
- 키 작고 몸 왜소하지만 "남을 괴롭히지 않음"이 특징
- 사람들이 자발적으로 따름 → 조카 살해범을 풀어줌 (조카가 잘못이므로)
- 한무제의 호족 이주 정책에 걸려 처형
- 부하 계소공(季少公): 곽해 소재 발설 않기 위해 자결

> 🎮 **NPC 원형:** 카리스마 리더. 정의를 가족보다 우선. 국가 권력과 충돌하는 서사

#### 유형 E: 문인 협객형
**이백(李白)** (701~762)
- 시인이자 청년기 협객. 검술 애호. 1년 만에 거금을 곤경의 사람들에게 씀
- 친구 위호(韋皓)에 따르면 직접 수명을 죽임
- 혜강(嵇康, 223~262): 시인·철학자·음악가·대장장이이자 도가적 협객. 처형 전 거문고 연주

> 🎮 **NPC 원형:** 무예+문예 겸비형. 낮에는 시인, 밤에는 검객

#### 유형 F: 여성 협객형
**섭은낭(聶隱娘)** (당대 전기)
- 10세에 비구니에게 납치되어 5년간 암살 훈련
- 초자연적 능력: 칼을 뇌 속에 숨김, 낮에는 원앙이 됨
- 남편을 직접 선택 (거울 닦는 남자)

**홍선(紅線)** (당대 전기)
- 절도사의 시녀이자 비밀 자객
- 적 장군의 침소에 침투, 금합(金盒)을 훔쳐와 무력 대결 없이 항복 유도
- 임무 완료 후 "신선의 길을 따르겠다"며 사라짐

> 🎮 **NPC 원형:** 초능력적 여성 자객. 자유의지로 행동. 임무 후 은둔

#### 유형 G: 전환형 (도적→영웅)
**대약사(戴若思)** (3세기 진대)
- 청년기 도적단 두목. 시인 육기(陸機)의 짐을 약탈
- 육기가 "자네 능력이면 도적이 아깝다" → 감동하여 눈물, 검 버리고 대화
- 이후 친구가 되어 결국 고위 관직까지 오름

> 🎮 **NPC 원형:** 전직(轉職) 가능한 캐릭터. 플레이어의 선택/대화에 따라 적→동료 전환

### 2.2 캐릭터 외형·복장 묘사 패턴 (픽셀아트 참고)

수호전의 양지(楊志) vs 소초(索超) 비무 장면에서 추출한 무장 묘사 공식:

```
[캐릭터 외형 묘사 템플릿]
머리: {투구 종류} + {장식(술, 깃털 등)}
갑옷: {재질} + {문양} + {색상}
허리: {띠 재질} + {버클 장식}
무기: {주무기} + {보조(활, 화살)}
탈것: {말의 특징 + 색상}
별명: {특성 기반 2~3자 별명}
```

**별명(綽號) 체계 - 캐릭터 명명 참고:**
- 동물 기반: 표두(豹頭) 임충, 흑선풍(黑旋風) 이규
- 능력 기반: 입천서(入天鼠) 노방, 입지서(入地鼠) 한창
- 외모 기반: 금모서(錦毛鼠) 백옥당
- 기상 기반: 급시우(及時雨) 송강

### 2.3 협객 행동 패턴 (AI 행동 트리 참고)

사마천이 정리한 협객 행동의 핵심 규칙:

```
IF 불의를 목격 THEN
    무기를 들고 개입 (길에서 불의를 보면 칼을 뽑아 돕는다)
    
IF 은혜를 입음 THEN  
    반드시 보답 (죽음으로도)
    BUT 은혜를 베풀면 → 보답 거절 (초도덕)

IF 비밀을 위탁받음 THEN
    죽어도 발설하지 않음 (자결로 증명하기도)

IF 약속함 THEN
    반드시 이행 ("말하면 행하고, 행하면 이룬다")

IF 부(富)를 얻음 THEN
    친구와 나눔 OR 가난한 이에게 줌
    
IF 모욕당함 THEN
    즉각 보복 OR 참고 기회를 노림 (과잉 보복 위험)
```

## 3. 이벤트/서사 생성 관점

### 3.1 문학 장르별 서사 패턴 진화

```
역사 기록 (사기) ─→ 시(詩) ─→ 전기(傳奇) ─→ 화본(話本) ─→ 장편소설 ─→ 희곡
 (사실)        (서정)    (단편환상)    (구술)      (수호전)     (경극)
  BC 1C        AD 2~9C   AD 7~9C      AD 10~13C   AD 14~17C   AD 18~20C
```

**사실→허구 변환의 핵심 메커니즘:**
1. **과장(Exaggeration):** 무예 능력의 초자연화 (칼을 뇌 속에 숨김 등)
2. **낭만화(Romanticization):** 암살 → 의협 행위로 미화
3. **유형화(Typification):** 개인 → 보편적 영웅 원형으로
4. **연쇄화(Serialization):** 단일 인물 이야기 → 108호걸 집단 서사로 확장

### 3.2 당대 전기(傳奇) - 핵심 서사 패턴 6가지

#### 패턴 1: 규염객(虬髯客) 이야기 - "영웅삼인방"
- 3명의 운명적 만남: 규염객(호걸) + 이정(관료) + 홍불녀(미녀)
- 규염객은 천하를 노리다 이세민의 관상을 보고 포기 → 해외로 떠남
- **서사 공식:** 만남 → 인물 품평 → 대의를 위한 양보 → 이별

> 🎮 **이벤트 패턴:** 3인 운명적 조우. NPC가 플레이어의 "그릇"을 평가하여 동행/이탈 결정

#### 패턴 2: 곤륜노(崑崙奴) - "노비의 초인적 구출"
- 노비 마늘(磨勒)이 주인을 위해 담을 넘어 미녀 구출
- 탈출 후 "제 할 일은 끝났습니다" → 종적 감춤
- **서사 공식:** 신분 낮은 초인 → 의뢰 수행 → 보상 거부 → 소멸

> 🎮 **이벤트 패턴:** 의외의 조력자. 퀘스트 완료 후 사라지는 NPC

#### 패턴 3: 섭은낭(聶隱娘) - "여자객의 성장과 선택"
- 10세 납치 → 5년 훈련 → 자객으로 귀환 → 스승의 명령 거부 → 자유 선택
- **서사 공식:** 강제 입문 → 수련 → 각성 → 독립 → 자기 길 선택

> 🎮 **이벤트 패턴:** NPC 성장 서사. 과거 트라우마 → 현재의 갈등 → 플레이어 개입으로 분기

#### 패턴 4: 여관의 노인 - "숨겨진 고수의 시험"
- 관리 위생규가 활쏘기 자랑 → 노인이 "검술을 알아야지" 경고
- 밤에 초자연적 현상으로 화살 모두 무력화
- 다음날 노인이 검법 약간 전수 후 사라짐
- **서사 공식:** 자만 → 숨은 고수 조우 → 시험/굴복 → 소량 전수 → 고수 소멸

> 🎮 **이벤트 패턴:** 랜덤 인카운터형 스승. 성장 시스템과 연동

#### 패턴 5: 정의의 검객 - "은혜 보답의 체인"
- 관리가 죄수를 풀어줌 → 수년 후 죄수가 지방관이 되어 은인 재회
- 은인 접대 중 아내가 "저 사람 죽이고 재산 빼앗자" → 검객이 아내 살해
- **서사 공식:** 은혜 → 장기간 경과 → 재회 → 배은망덕 발각 → 응징

> 🎮 **이벤트 패턴:** 장기 서사 아크. 과거 선택이 수년 뒤 결과로 돌아옴

#### 패턴 6: 계포(季布) 포박 이야기 - "추격과 은닉"
- 한고조가 거액 현상금 걸고 추적
- 친구 주(朱)씨 집 이중벽에 숨어 지냄
- 머리 깎고 노비 변장 → 주 씨가 그를 주헌에게 팔아 탈출 성사
- 최종적으로 황제에게 사면받음
- **서사 공식:** 추적 → 은닉 → 변장/위장 → 중간 조력자 연쇄 → 사면/탈출

> 🎮 **이벤트 패턴:** 도주/은닉 퀘스트. 다수 NPC의 연쇄 협력 필요

### 3.3 수호전(水滸傳) - 장편 서사 구조 분석

**형성 과정 (구술→문학):**
```
역사적 송강의 난 (1121) 
  → 민간 전설 확산 
    → 남송 직업 이야기꾼의 공연 (1127~1279)
      → 원대 잡극으로 극화 (1280~1368)
        → 시내암/나관중의 장편화 (14C 말)
          → 120회본 완성 (1614)
            → 금성탄의 70회 절본 (1641)
```

**서사 구조적 특징:**
- 민담 서사시(folk epic)적 접근이 적절: 느슨한 에피소드 연결, 공식구(formulae) 반복
- 공식구 예: "배고프면 먹고, 목마르면 마시고; 아침에 출발, 밤에 쉬었다"
- 108호걸 집결이 클라이맥스 → 이후는 하향

**캐릭터 유형 분류 (수호전 기준):**

| 유형 | 대표 인물 | 핵심 특성 |
|------|-----------|-----------|
| 의적 수령 | 송강(宋江) | 외교적, 관직 미련, 위선적 측면 |
| 의승(義僧) | 노지심(魯智深) | 직설적, 거침없는 정의감 |
| 무식한 영웅 | 이규(李逵) | 순진/잔인 공존, 충성, 무분별 |
| 몰락 엘리트 | 임충(林沖) | 인내형, 억울함 축적 → 폭발 |
| 기예형 | 시천(時遷) | 도술, 잠입, 정찰 특기 |
| 여전사 | 손이랑(孫二娘) | 인육만두, 거침없는 여장부 |

### 3.4 후대 협의소설의 변화 (세계관 진화 참고)

| 시기 | 유형 | 특징 | 대표작 |
|------|------|------|--------|
| 청대 초~중기 | 공안+협의 | 청관(淸官) 보좌형 협객 | 삼협오의, 시공안, 팽공안 |
| 청대 중기 | 무협+연애 | 협객의 사랑 이야기 결합 | 아녀영웅전(兒女英雄傳) |
| 청대 말~현대 | 검선(劍仙)물 | 비행하는 검객, 선도(仙道) 결합 | 촉산검협전(蜀山劍俠傳) |
| 청대 말 | 체력 강조형 | 육체적 무술 위주 | 협의영웅전 |

**아녀영웅전의 서사 혁신 (연애+무협):**
- 13매(十三妹): 부친 복수를 위해 무예 수련한 여성
- 복수 완료 후 → 평범한 결혼 생활 수용
- **서사 공식:** 원한 → 수련 → 복수 → 일상 회귀 (카타르시스+안정)

> 🎮 **게임 설계 시사점:** 무협 + 연애 결합은 플레이어 몰입도 증가. NPC 로맨스 라인은 복수/갈등 서사와 교차시킬 것

### 3.5 동서양 기사 비교 (세계관 독창성 확보용)

| 항목 | 서양 기사 | 중국 협객 |
|------|-----------|-----------|
| 사회적 지위 | 명확한 계급 (기사 계급) | 모든 계급에서 출현 |
| 종교 | 기독교적 의무 | 무종교 (도가 경향 있음) |
| 조직 | 기사단, 엄격한 규율 | 자발적, 느슨한 결합 |
| 충성 대상 | 왕/영주 | 지기(知己) |
| 여성관 | 궁정식 사랑(courtly love) | 무관심 또는 유흥 정도 |
| 예절 | 정교한 의례 | 관습 무시, 자유분방 |
| 법과의 관계 | 봉건 체제의 기둥 | 법 밖의 존재 |
| 복장 | 갑옷, 문장(紋章) | 자유 (검소~화려 스펙트럼) |

**공통점:**
- 이타주의, 정의, 용기, 명예, 관대함, 신의
- 약자·가난한 자 보호
- 명예를 위한 죽음 불사

**로빈 훈드와 수호전의 유사성:**
- 둘 다 의적(義賊) 집단
- 부자에게서 빼앗아 빈민에게 나눔
- 잔인과 관대 공존
- 로빈 = 조개(晁蓋, 지도자) + 화영(花榮, 궁술)의 합성
- 터크 수사 ≒ 노지심(魯智深)
- 리틀 존 ≒ 연청(燕青)

> **🎮 게임 설계 시사점:** 칠국춘추의 세계관은 서양 기사와의 차별점(무계급, 무종교, 반체제)을 살리면서, 공통점(이타, 정의, 명예)으로 보편적 공감을 확보

## 4. 게임 시스템 설계 직접 활용 요소 정리

### 4.1 NPC 가치 체계 파라미터

```
[협객 가치 8축 시스템]
altruism:       0~100  // 이타심 (자기희생 의지)
justice:        0~100  // 정의감 (불의 개입 임계값)  
freedom:        0~100  // 자유 추구 (법·관습 무시 정도)
personal_loyalty: 0~100 // 지기에 대한 충성
courage:        0~100  // 용기 (위험 감수 임계값)
truthfulness:   0~100  // 신의 (약속 이행 강도)
honor:          0~100  // 명예 추구 (명성에 대한 욕구)
generosity:     0~100  // 관대함 (재물 경시 정도)
```

### 4.2 이벤트 트리거 공식

```
[협의 이벤트 발생 조건]
"노상불의" 이벤트:
  IF npc.justice > 70 AND witness(injustice) 
  THEN intervene(probability = npc.courage / 100)

"지기 충성" 이벤트:  
  IF relationship.trust > 80 AND benefactor.in_danger
  THEN sacrifice_self(probability = npc.personal_loyalty / 100)

"비밀 유지" 이벤트:
  IF entrusted_secret AND interrogated
  THEN resist(threshold = npc.truthfulness)
  IF resist_fails THEN suicide(probability = npc.honor / 100)

"과잉 보복" 이벤트:
  IF insulted AND npc.freedom > 80 AND npc.justice < 50
  THEN disproportionate_revenge()
```

### 4.3 서사 패턴 템플릿

| 패턴 ID | 명칭 | 구조 | 필요 NPC 수 |
|---------|------|------|-------------|
| SP-01 | 영웅삼인방 | 운명적 만남 → 품평 → 동행/이별 | 3 |
| SP-02 | 숨은 고수 | 자만 → 시험 → 굴복 → 전수 → 소멸 | 2 |
| SP-03 | 추격과 은닉 | 현상금 → 은닉 → 변장 → 연쇄 조력 → 사면 | 4+ |
| SP-04 | 은혜 보답 | 은혜 → 시간경과 → 재회 → 보답/배신 분기 | 2+ |
| SP-05 | 강제 입문 | 납치/강제 → 수련 → 각성 → 독립 선택 | 2 |
| SP-06 | 전환(도적→영웅) | 적대 조우 → 인물 감화 → 전직 | 2 |
| SP-07 | 공의 vs 참소 | 대공 → 모함 → 실각 → 주색/은둔/재기 분기 | 3+ |
