OCC · Object 분기 對象

"무언가를 접함." 대상의 존재 자체에 대한 호불호 — 사물(명검), 장소(절벽·밀실), 사람의 특성(카리스마) 등. 3개 분기 중 가장 단순하다.

2생성 감정 · 강도

조건생성 감정 (부호)강도 공식
단일ap>0 Love / ap<0 Hate|ap| × appealingness_weight × 1.0
최단 경로 전망도 관계 배율도 없다. 매력도 한 값과 성격 weight만으로 결정된다. modifier는 항상 1.0 — 사물·장소에 대한 감정은 상대와의 관계와 무관하기 때문. weight는 심미안(aesthetic_appreciation) 한 facet만 작용한다(05 문서).

3무협 워크드 예시

weight=1.0 가정.

명검을 손에 든 순간 (매력)

appealingness = +0.9

Love = |+0.9| × 1.0 × 1.0 = 0.90
독약이 든 그릇을 마주함 (혐오)

appealingness = −0.7

Hate = |−0.7| × 1.0 × 1.0 = 0.70
복합과의 차이 같은 "독약" 장면이라도 — 독에 당한 사건은 Event(Distress), 독을 탄 행동은 Action(Reproach), 독약이라는 대상 자체의 혐오가 여기 Object(Hate)다. 세 분기가 한 장면에 동시에 채워질 수 있고, 그때 복합 감정이 자동 생성된다(04 문서).

4실제 코드

▸ appraisal/object.rs — appraise() 전문 domain/emotion/appraisal/object.rs 
pub fn appraise<P: AppraisalWeights>(p: &P, state: &mut EmotionState,
    object: &ObjectFocus) {
    let ap = object.appealingness;
    let w = p.appealingness_weight(ap);
    let ctx = &object.target_description;

    add_valence(state, EmotionType::Love, EmotionType::Hate, ap, w, 1.0, ctx);
}
