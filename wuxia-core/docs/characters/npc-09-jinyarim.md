| 별호 | 임귀 (林鬼, Forest Ghost) — 묘족이 붙인 이름 |

### 이름의 뜻

```
진야림 (陳野林):

  陳 (진) = 성씨. 영주 왕가의 성씨 (대진 황실 방계)
           → 남만에서 "진"은 흔한 음절이라 의심받지 않음
           → 성을 남긴 이유: "아버지를 버릴 수는 없으니까"
  野 (야) = 들, 야생
  林 (림) = 숲

  "야생의 숲" — 밀림에서 자란 사람

  이름의 이중성:
  ① 표면: 남만 밀림에서 자란 사람에게 자연스러운 이름
  ② 진실: 18세에 본인이 직접 지은 이름
     → 왕족 이름을 버리고 새 이름을 취함
     → "나는 영주의 왕자가 아니라, 숲의 사람이다"
     → 이름 자체가 정체성 선택의 결과

  왜 성씨를 남겼는가:
  "이름은 내가 선택한 거야.
   하지만 성은... 아버지와 어머니가 준 거니까.
   버릴 수는 없었어."
  → 효(0.7)의 발현. 과거를 외면하되 완전히 끊지는 못하는 내면.

  별호: 임귀(林鬼) — "숲의 귀신"
  ┌─────────────────────────────────────────────┐
  │  기원:                                       │
  │  묘족 사냥꾼들이 밀림에서                      │
  │  나타났다 사라지는 존재를 보고 붙인 이름.       │
  │  "귀신이 고기를 가져다놓고 갔다"               │
  │  "귀신이 함정을 놓아서 멧돼지가 잡혔다"         │
  │  → 진야림이 묘족 발견 전 2년간 혼자 살 때의 흔적│
  │                                              │
  │  본인 반응:                                   │
  │  "귀신이면 귀신이지. 편하잖아.                  │
  │   귀신한테는 아무도 안 물어보니까.               │
  │   이름도, 출신도, 어디서 왔는지도."              │
  └─────────────────────────────────────────────┘

  아이러니:
  "임귀(林鬼)" = 숲의 귀신 = 죽은 자
  실제로 진야림은 세상에서 "사망 추정" 처리된 사람.
  십상시의 기록: "유모 1명과 막내 왕자 1명 도주.
                  남쪽 방면 추격 실패. 사망 추정 처리."
  → 그는 진짜로 "귀신"이 된 것이다.
     세상에서는 죽은 사람. 밀림에서만 살아있는 사람.
```

## 2. 능력(能) — 성장 도메인 (9개 능력치)

| 범주 | 능력 | 수치 | 특이사항 |
|------|------|------|----------|

| 지적 | 지혜 | 60 | 밀림 생존 지혜 + 10세까지의 왕족 교육 잔재 |
| 지적 | 책략 | 45 | 사냥꾼의 함정 사고 + 왕족 교양의 흔적 |

## 6. 내면 갈등 (Core Conflict)

### ⚔ 진야림의 딜레마

```
  "돌아가야 하는가, 머물러야 하는가"

  ┌──────── 숲의 사람 ─────────┐
  │  15년간 밀림에서 살았다.     │
  │  함정을 놓고, 사냥하고,      │
  │  별을 보며 잤다.             │
  │  아무에게도 고개 숙이지 않았다.│
  │  이것이 자유다.              │
  │  "이게 나야."               │
  └────────────────────────────┘
              vs
  ┌──────── 왕의 아들 ─────────┐
  │  아버지가 죽었다.            │
  │  형이 죽었다. 누나가 죽었다.  │
  │  그 원수가 살아있다.          │
  │  아버지가 지키려 한 땅이      │
  │  폐허가 되어 있다.           │
  │  "도망친 아들로 끝날 건가?"   │
  └────────────────────────────┘

  이 갈등이 다른 NPC와 다른 점:
  ┌─────────────────────────────────────────────┐
  │  소연: "해야 하는데 못 한다" (사부가 막는다)     │
  │  야율설화: "하고 싶은데 누구인지 모르겠다"       │
  │  플레이어: "해야 하는지 모르겠다" (기억 불완전)   │
  │                                              │
  │  진야림: "할 수 있는데 안 한다" (의도적 거부)     │
  │  → 유일하게 "능동적으로 과거를 외면"하는 캐릭터   │
  │  → 외면의 이유가 합리적이기 때문에 더 복잡         │
  │  → "밀림으로 도망친 것"인가 "밀림을 선택한 것"인가 │
  │    이 질문이 진야림 퀘스트라인의 축                │
  └─────────────────────────────────────────────┘
```

### 숨겨진 공포

```
  진야림이 절대로 말하지 않는 것:

  "돌아가면 또 잃는다."

  ┌─────────────────────────────────────────────┐
  │  10세에 모든 것을 잃었다.                       │
  │  아버지, 어머니, 형, 누나, 집, 이름.            │
  │  하룻밤에 전부.                                │
  │                                              │
  │  그 이후로:                                    │
  │  · 집을 짓지 않는다 (나무 위 임시 은신처만)       │
  │  · 사람과 깊이 사귀지 않는다                     │
  │  · 무언가를 소유하지 않는다                      │
  │  · "가진 게 없으면 잃을 것도 없다"               │
  │                                              │
  │  이것은 자유가 아니라 공포의 결과.                │
  │  "자유롭게 사는 것"과 "잃는 것이 두려운 것"은     │
  │  겉으로 같아 보인다.                            │
  │  진야림 자신도 구분하지 못한다.                   │
  │                                              │
  │  → 플레이어와의 관계가 이 갈등을 깨뜨린다.        │
  │  → 동료가 생기면, 잃을 수 있는 것이 생긴다.       │
  │  → "또 잃을까 봐 무섭다"를 인정하는 것이          │
  │    진야림 성장의 핵심 순간.                      │
  └─────────────────────────────────────────────┘
```

## 7. 핵심 관계 (관계 도메인)

| 대상 | 관계 유형 | 감정 | 복잡도 |
|------|----------|------|--------|
| **플레이어** | 안내자 → 동료 → 거울 | 경계 → 신뢰 → "같은 부류" | ★★★★★ |
| **소연** | 정보상과 안내자의 만남 | 경계 + 호기심 → 연대 가능 | ★★★★ |
| **야율설화** | 왕족이길 거부하는 자 끼리 | 거울 관계 | ★★★★ |
| **조고** | 원수 (아버지를 죽인 자) | 분노 + 무력감 | ★★★★★ |
| **남만 대족장** | 묵인자. 말 없는 보호자 | 감사 + 거리감 | ★★★ |
| **묘족** | 이웃. 부족원은 아님 | 빚진 감정 + 소속감 부재 | ★★★ |
| **죽은 아버지 (진영)** | 기억 속의 아버지 | 효 + 죄책감 | ★★★★★ |

```
진야림의 관계 구조 — "귀신의 거리":

  [진영 ☠] ← 죽은 아버지의 기억
      │
      │ (죄책감: "나만 도망쳤다")
      │
  [진 야 림] ──── 원수 ──── [조고]
   │    │    │                │
   │    │    │          (무력감: "할 수 없다")
   │    │    │
   │    │    └── 경계→신뢰 ── [플레이어]
   │    │                      "같은 부류. 같은 밤의 아이."
   │    │
   │    ├── 묵인 ──── [대족장]
   │    │              "말 없이 지켜보는 사람"
   │    │
   │    └── 빚 ──── [묘족]
   │                  "갚아야 할 은혜"
   │
   └── 거울 ──── [야율설화]
                  "너도 도망친 거야? ...나도."

  핵심:
  진야림은 "아무에게도 다가가지 않는 사람"이다.
  소연이 "가면을 쓴 교류"라면,
  진야림은 "교류 자체를 피하는 은둔".
  플레이어가 이 벽을 허무는 것이 관계 퀘스트의 핵심.
```

### 플레이어와의 공명

```
  진야림 (25세)                플레이어 (17세)
  ────────────                ────────────
  10세에 가족 잃음              5세 납치, 7세 멸문 목격
  기억이 완전함                기억이 불완전함
  본인이 출신을 알고 있음       본인이 출신을 모름
  의도적으로 숨김              기억이 없어 모를 뿐

  복수를 유보함                복수 대상을 모름
  밀림에서 혼자 자람            자유도시 빈민가에서 자람
  생존 전문가                  아직 미완성

  공명 포인트:
  "너는 기억이 안 나서 괴롭고,
   나는 기억이 나서 괴로워."
  → 같은 조고의 피해자이지만 반대편에 서 있는 거울
  → 이 대비가 두 캐릭터의 관계에 깊이를 준다.
```

## 8. 비밀 (Secret) — 플레이어가 발견할 것

### 비밀 ① — 영주 왕족 정체 (핵심 비밀)

```

  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  · 자유도시 탐색 중 영주성 폐허에서 왕가 문장(紋章) 발견
  · + 진야림 동행 상태
  · + 플레이어가 옥패의 존재를 감지 (관찰 이벤트)

  진야림: (오래 침묵한 뒤)
          "...눈이 좋네."
          (옥패를 꺼내 보여준다)
          "맞아. 이건 영주 왕가의 것이야."
          (돌아본다)
          "그래서? 어쩔 건데?"

  분위기: 방어적. 인정하되 감정을 보이지 않음.
  → PsychologyEvent::EmotionChanged (진야림: 경계+불안)
  → 이후 호감도에 따라 더 열리거나 완전히 닫힘.

  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  경로 B: 자발적 고백 (호감도 70+)
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  트리거 조건:
  · 플레이어와의 호감도 70 이상
  · 밤, 야영 중 모닥불 옆에서

  진야림: (불을 바라보며)
          "...너한테 하나 말할게."
          (옥패를 꺼낸다)
          "진짜 이름은... 아니, 원래 이름은 따로 있어.
           영주 번왕국 — 지금 자유도시라 부르는 곳.
           거기 왕의 아들이었어."
          (불꽃을 본다)
          "15년 전에 다 타버렸어.

          (플레이어를 본다)
          "너한테 말하는 건...
           네가 나를 다르게 볼 것 같지 않아서야."

  · 진야림이 동료 상태

          "...내가 할 말이 있다."
          (옥패를 높이 든다)

          "왕이 되러 온 게 아니야.
           하지만 이 땅이 불타는 걸
```

```
  → "아버지가 남긴 유물" 정도로만 인식
```

```
  │                                              │
```

## 11. LLM 대사 생성 가이드 (AI 도메인)

### 말투 규칙

```
1. 말이 짧다. 1~2문장이 기본.
   ✗ "이 길은 매우 위험하므로 조심해서 가야 합니다.
      독사가 많고, 독초도 있으니 함부로 만지지 마세요."
   ✓ "위험해. 따라와."

2. 감정 표현이 적다. 사실만 말한다.
   ✗ "정말 슬픈 일이야. 마음이 아프다."
   ✓ "...그래." (침묵.) "밥 먹자."

3. 밀림/자연 관련 말은 길어진다.
   ✓ "이 풀은 독이 있어. 줄기는 괜찮은데 잎을 만지면
      손이 부어. 3시간 후에 빠지긴 하는데, 아파."
   → 유일하게 말이 많아지는 주제 = 자연/생존 지식

4. 거짓말할 때 짧아진다.
   평소: 짧음 (1~2문장)
   거짓말: 더 짧아짐 (단답)
   "어머니가 중원 사람이었어." ← 이게 거짓말 패턴
   → 소연이 이 패턴을 감지함

5. 과거를 말할 때 주어를 생략한다.
   ✗ "내가 10살 때 성이 불탔다."
   ✓ "...타버렸어. 다." (주어 없음)
   → 과거를 말하면서 자기를 지우는 무의식

6. 호칭:
   · 플레이어: "너" → 친해지면 이름
   · 소연: "정보상" → "소연"
   · 야율설화: "공주" (비꼬는 뉘앙스) → "설화"
   · 묘족 사람들: 이름으로 직접 부름
   · 대족장: "어른" (유일한 존칭)
   · 조고: 이름을 부르지 않음. "그놈." 또는 침묵.

7. 남만 억양 혼재:
   · 가끔 남만식 어순이 섞임
   · "밥 먹었어 너?" (남만 어순) vs "너 밥 먹었어?" (중원 어순)
   · 감정이 격해지면 남만어 단어가 튀어나옴
   · → LLM 지시: 10% 확률로 어순 뒤집기
```

### 행동 결정 예시 (Personality × Values)

```
상황: "플레이어가 '영주성 폐허를 같이 가자'고 제안"

     호감도 50 미만: "...혼자 갈게." → 단독 행동
     호감도 50~69: "...가자. 근데 나한테 아무것도 묻지 마."
     호감도 70+: "...가자." (그리고 경로 B 트리거 가능)
```

## 12. 종합 — 진야림이라는 인물

```
한 문장 요약:
  "돌아갈 곳이 있지만 돌아가지 않는 자,
   숲에서 귀신으로 사는 것을 자유라 믿는 잊혀진 왕자."

게임적 가치:
  ① 남만 안내자 — 남만 밀림 탐색의 필수 NPC
  ② 자유도시 역사의 열쇠 — 영주 왕국의 유일한 증인
  ③ 조고 퀘스트 추가 동기 — 세 번째 피해자
  ④ 레인저/생존 전문가 — 독특한 전투 스타일
  ⑤ 약초/독 전문가 — 명경·당무괴 퀘스트 시너지
  ⑥ 동료 캐릭터 — 남만 이후 전국 동행 가능
```
