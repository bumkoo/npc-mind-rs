## 1. 용어 정의

| 용어 | 영문 | 코드명 | 대상 | 설명 |
|------|------|--------|------|------|
| 단련(鍛鍊) | Conditioning | `train_stat()` | StatType 9개 | 기본 능력치를 올리는 행위 |
| 연마(練磨) | Practice | `train_art()` | MartialArt | 무공 숙련도를 올리는 행위 |

### 단련과 연마의 차이

```
단련 = 토양을 기름지게 하는 것
  "산을 뛰어다니며 경공을 단련했다"
  → 경공(Agility) 능력치 +N

연마 = 토양 위에 나무를 심고 키우는 것
  "독고구검 제3초를 밤새 연마했다"
  → 독고구검 숙련도 +N, 관련 능력치 소폭 +1~2 (부산물)
```

### 부산물 효과 (연마 → 능력치)

- 연마 시 해당 무공의 주 관련 능력치가 소폭 상승 (본업 대비 약 20~30%)
- 무공 유형별 관련 능력치 매핑:

| 무공 유형 | 주 관련 능력치 | 부산물 예시 |
|-----------|--------------|-----------|
| 외공/권법 (항룡십팔장) | 무력, 체력 | 무력 +1 |
| 경공류 (능파미보) | 경공, 체력 | 경공 +1 |
| 내공 심법 (구양신공) | 내공, 의지 | 내공 +1 |
| 병기술 (독고구검) | 무력, 경공 | 무력 +1 |
| 암기류 (만천화우) | 책략, 경공 | 책략 +1 |

## 2. 능력치 체계 (구현 완료 ✅)

### 9개 능력치 (StatType)

| 범주 | 능력치 | 영문 | 설명 | 범위 |
|------|--------|------|------|------|
| 지적(Intellectual) | 내공 | InnerPower | 기를 다루는 능력 | 0~100 |
| | 지혜 | Wisdom | 통찰력, 사리판단 | 0~100 |
| | 책략 | Strategy | 전략적 사고 | 0~100 |
| 육체(Physical) | 체력 | Vitality | 건강, 지구력 | 0~100 |
| | 경공 | Agility | 몸놀림, 빠르기 | 0~100 |
| | 무력 | Strength | 물리적 전투력 | 0~100 |
| 감정(Emotional) | 의지 | Willpower | 거부/저항하는 힘 | 0~100 |
| | 인내 | Endurance | 고된 수련을 견딤 | 0~100 |
| | 공감 | Empathy | 타인 감정을 읽는 능력 | 0~100 |

### 능/성/신(能/性/信) 분류 원칙

```
능력(能) = "할 수 있는가?"  → 성장 도메인 (수련으로 오르고 노화로 내림)
성향(性) = "원래 그런가?"   → 심리 도메인 (큰 사건으로만 변함)
신념(信) = "해야 한다고 믿는가?" → 심리 도메인 (경험으로 변함)
```

## 3. 단련 메카닉

### 3.1 기본 성장 공식 (구현 완료 ✅)

```
성장량 = intensity × growth_multiplier(life_stage)
최소 1 보장 (수련했으면 아무리 늙어도 1은 오름)
```

| 생애 단계 | 나이 | 계수 |
|-----------|------|------|
| 청년(Youth) | ~32세 | ×1.5 |
| 장년(Prime) | 33~54세 | ×1.0 |
| 중년(Middle) | 55~68세 | ×0.7 |
| 노년(Elder) | 69세~ | ×0.3 |

### 3.2 연간 자동 노화 (구현 완료 ✅)

매년 수련과 무관하게 자동 적용:

|  | 체력 | 경공 | 무력 | 내공 | 지혜 | 책략 | 의지 | 인내 | 공감 |
|--|------|------|------|------|------|------|------|------|------|
| 청년(~32) | +1 | +1 | +1 | 0 | 0 | 0 | 0 | 0 | 0 |
| 장년(33~54) | 0 | 0 | 0 | +1 | +1 | +1 | 0 | 0 | 0 |
| 중년(55~68) | -1 | -1 | 0 | +1 | +2 | +1 | +1 | 0 | +1 |
| 노년(69~) | -2 | -2 | -1 | 0 | +1 | +1 | 0 | -1 | 0 |

### 3.3 최대 강도 메카닉 (설계 완료, 미구현 ❌)

플레이어가 원하는 만큼 수련할 수 없다. 능력치와 상태가 상한선을 결정한다:

```
기본 최대 강도 = (체력 + 인내) / 20
의지 보너스   = 의지 70 이상이면 +1
현재 피로 감산

최종 최대 강도 = 기본 + 의지보너스 - 현재피로  (최소 1, 최대 10)
```

예시:

| 상태 | 체력 | 인내 | 의지 | 피로 | 최대 강도 |
|------|------|------|------|------|----------|
| 건강한 청년 | 60 | 40 | 50 | 0 | 5 |
| 지친 청년 | 60 | 40 | 50 | 2 | 3 |
| 의지 강한 노인 | 25 | 20 | 80 | 0 | 3 |

의지 보너스로 한계를 넘긴 강도분은 부상 확률 +10% 추가.

## 4. 피로 시스템

### 4.1 소유: 캐릭터 도메인

```
Character {
    ...,
    fatigue: u32,          // 0~100
    injury: Option<Injury>, 
}
```

### 4.2 피로 단계

| 범위 | 상태 | 설명 |
|------|------|------|
| 0~20 | 양호 | "몸이 가볍다" |
| 21~40 | 경미 | "좀 피곤하다" |
| 41~60 | 보통 | "쉬고 싶다" |
| 61~80 | 심각 | "몸이 무겁다, 집중이 안 된다" |
| 81~100 | 탈진 | "더 이상 움직일 수 없다" |

### 4.3 피로가 쌓이는 곳

| 활동 | 피로 누적 | 감소 요인 |
|------|----------|----------|
| 능력치 단련 | 강도 × 3~5 | 인내 높으면 경감 |
| 무공 연마 | 강도 × 2~4 | 단련보다 약간 덜 |
| 전투 | 상대 강도 비례 | 체력 높으면 경감 |
| 여행/이동 | 거리 비례 | 경공 높으면 경감 |
| 탐험(위험지역) | 고정 + 랜덤 | — |
| 야간 활동 | +10 추가 | — |

능력치에 의한 피로 경감 공식:

```
여행 피로 = 기본 피로 × (100 - 경공) / 100
전투 피로 = 기본 피로 × (100 - 체력) / 100
단련 피로 = 기본 피로 × (100 - 인내) / 100
```

### 4.4 피로가 풀리는 곳

#### 기본 회복

| 활동 | 피로 회복 |
|------|----------|
| 하루 휴식 (아무것도 안 함) | -10/일 |
| 수면 (매일 자동) | -5/밤 |

#### 장소에 의한 회복

| 장소 | 피로 회복 | 무협적 장면 |
|------|----------|-----------|
| 온천 | -20/일 | "따뜻한 물에 피로가 녹는다" |
| 약초밭 근처 | -15/일 | "약초 향이 기운을 돋운다" |
| 사찰/도관 | -15/일 | "고요한 곳에서 마음이 편해졌다" |
| 자기 문파 | -12/일 | "익숙한 곳이라 편하다" |
| 객잔(여관) | -10/일 | "밥 먹고 잠자고" |
| 야외 노숙 | -3/일 | "딱딱한 바닥에 잠이 안 온다" |

#### 사람(관계)에 의한 회복

| 관계 | 피로 회복 | 조건 | 무협적 장면 |
|------|----------|------|-----------|
| 연인/애인 | -20/일 | 호감도 80+, 신뢰도 70+ | "그녀와 함께 있으니 근심이 사라진다" |
| 절친한 벗 | -15/일 | 호감도 70+ | "오랜 벗과 술 한잔에 피로가 풀린다" |
| 사제(스승) | -10/일 | 신뢰도 60+ | "스승님 곁이 편안하다" |
| 동료 | -8/일 | 호감도 50+ | "동료들과 있으니 마음이 놓인다" |
| **적대 관계** | **+5/일** | 적대도 60+ | "저놈이 근처에 있어 긴장이 안 풀린다" |

#### 아이템에 의한 회복

| 아이템 | 피로 회복 | 추가 효과 |
|--------|----------|----------|
| 일반 영약 | -15 (즉시) | — |
| 상급 영약 (천산설련 등) | -30 (즉시) | — |
| 독주(烈酒) | -10 (즉시) | 의지 일시+5, 다음날 피로+5 (숙취) |
| 보양식 | -10/일 | 3일간 지속 |
| 해독약 | -20 (즉시) | 부상(중독) 해제 |

#### 조합: 장소 + 사람 + 아이템 중첩 가능

```
최악: 야외 노숙(-3) + 적대자 근처(+5) = +2/일 (피로가 오히려 쌓임)
보통: 객잔(-10) + 수면(-5) = -15/일
최상: 온천(-20) + 연인(-20) + 상급 영약(-30) = -70 즉시
```

### 4.5 부상

#### 부상 발생 조건

| 피로 수준 | 활동 시 부상 확률 |
|----------|-----------------|
| 0~79 | 0% (강도에 의한 부상만) |
| 80~90 | 10% |
| 91~100 | 25% |
| 100 (탈진) | 강제 휴식, 아무것도 못 함 |

#### 강도에 의한 부상 확률

|--------------|----------|----------|
| 1~4 | 0% | 안전 |
| 5~6 | 5% | 경상: 3일 수련 불가 |
| 7~8 | 15% | 중상: 7일 수련 불가, 체력 일시 -5 |
| 9~10 | 30% | 중상: 14일 수련 불가, 체력 일시 -10 |

#### 부상 회복

## 5. 기연(奇緣) 시스템

### 5.1 5가지 조건

| 조건 | 기호 | 단련 시 판정 | 연마 시 판정 |
|------|------|------------|------------|
| 장소(場) | ① | 해당 능력치 수련 보너스 장소? | 해당 무공 유형 보너스 장소? |
| 사람(人) | ② | 같이 단련하는 동료/경쟁자 | 해당 무공을 아는 고수/스승 |
| 아이템(物) | ③ | 영약, 보양식 | 비급, 무공서, 무기 |
| 감정(心) | ④ | 수련에 좋은 감정 (결의 등) | 무공 적합 감정 (독고구검↔평온) |
| 시기(時) | ⑤ | 나이/계절 보너스 | 숙련도 구간 돌파 시점 |

### 5.2 순방향 조합 가중치 (기연)

| 순방향 조건 수 | 가중치 | 등급 | 발생 빈도 (체감) |
|--------------|--------|------|----------------|
| 1개 | ×1.0 | 일상(日常) | 매일 |
| 2개 | ×1.5 | 호기(好機) | 며칠에 한 번 |
| 3개 | ×2.5 | 전기(轉機) | 한 달에 한두 번 |
| 4개 | ×4.0 | 기연(奇緣) | 게임 전체에서 몇 번 |
| 5개 | ×7.0 | 천재기연(天載奇緣) | 평생 한두 번 |

### 5.3 역방향 조합 가중치 (재앙)

| 역방향 조건 수 | 가중치 | 등급 |
|--------------|--------|------|
| 1개 | ×1.0 | 불운(不運) |
| 2개 | ×1.5 | 위기(危機) |
| 3개 | ×2.5 | 액운(厄運) |
| 4개 | ×4.0 | 대화(大禍) |
| 5개 | ×7.0 | 주화입마(走火入魔) |

### 5.4 순역 혼합 판정

```
순 조건 수 = 순방향 개수 - 역방향 개수

양수 → 순방향 가중치 테이블 적용
음수 → 역방향 가중치 테이블 적용 (절대값으로)
0   → ×1.0 (상쇄)
```

### 5.5 단련 기연 등급별 효과

| 등급 | 수치 효과 | 추가 효과 |
|------|----------|----------|
| 일상(1) | 기본 성장 | — |
| 호기(2) | ×1.5 성장 | — |
| 전기(3) | ×2.5 성장 | 추가 능력치 보너스 |
| 기연(4) | ×4.0 성장 | 피로 완전 회복 + 무공 비밀 특성 힌트 1개 |
| 천재기연(5) | ×7.0 성장 | 피로/부상 완전 회복 + 비밀 특성 완전 발견 + **능력치 상한 +5 (100→105)** |

### 5.6 연마 기연 등급별 효과

| 등급 | 숙련도 효과 | 추가 효과 |
|------|-----------|----------|
| 일상(1) | 기본 상승 | — |
| 호기(2) | ×1.5 상승 | — |
| 전기(3) | ×2.5 상승 + 경지 돌파 가능 | 비밀 특성 힌트 1개 자동 발견 |
| 기연(4) | ×4.0 상승 + 경지 돌파 가능 | 비밀 특성 1개 완전 발견 + 관련 능력치 +5 + 새 초식 해금 |
| 천재기연(5) | ×7.0 상승 + 경지 돌파 확정 | 비밀 특성 전체 발견 + 피로/부상 회복 + **영구 전투 보너스(칭호/특성)** |

### 5.7 무공 경지 (연마 기연 전용)

| 경지 | 숙련도 | 설명 | 돌파에 필요한 최소 기연 등급 |
|------|--------|------|--------------------------|
| 입문 | 0~29 | 초식을 따라한다 | — |
| 숙련 | 30~59 | 초식이 자연스러워진다 | 전기(3개+) |
| 통달 | 60~89 | 초식을 넘어선 이해 | 기연(4개+) |
| 화경 | 90~100 | 무공이 몸의 일부 | 천재기연(5개만) |

## 6. 수련 효율 계수 체계 (미래 확장)

현재 구현된 공식:

```
성장량 = intensity × life_stage_multiplier
```

향후 확장 공식:

```
최종 성장량 = 기본량 × 생애단계 계수 × 감정 계수 × 성격 계수 × 장소 계수 × 관계 계수
```

이 계수들은 기연 시스템의 5가지 조건 판정에도 활용된다.

## 9. 설계 다이어그램

### 단련/연마 선택 구조

```
오늘 뭘 하지?
  │
  ├─ ① 단련 (train_stat)
  │   → 능력치 집중 성장
  │   → 무공 숙련도는 안 오름
  │
  ├─ ② 연마 (train_art)
  │   → 숙련도 성장 + 능력치 소폭 (부산물)
  │   → 두 마리 토끼, 각각 느림
  │
  └─ ③ 기타 (탐험, 관계, 휴식)
      → 수련 안 되지만 다른 것을 얻음
```

### 피로 순환 구조

```
수련 → 능력치/숙련도 ↑ + 피로 ↑
  │
  ├─ 피로 적으면 → 내일도 수련 가능
  │
  ├─ 피로 많으면 → 며칠 쉬어야 함
  │   ├─ 쉬면서 탐험  → 장소 발견
  │   ├─ 쉬면서 관계  → 호감도 상승
  │   └─ 장소/사람/아이템으로 빠른 회복
  │
  └─ 부상 나면 → 치료 필요
      ├─ 혼자 (느림)
      ├─ 의원 (빠름, 돈)
      └─ 동료/연인 간호 (관계 발전 계기)
```

### 기연 발동 구조

```
5가지 조건 체크: 장소 + 사람 + 아이템 + 감정 + 시기
  │
  ├─ 순방향 많으면 → 기연 (성장 폭발 + 특별 보상)
  ├─ 역방향 많으면 → 재앙 (주화입마 등)
  └─ 섞여 있으면 → 상쇄 후 판정
```

### 성장-탐험-관계 순환

```
탐험 → 장소 발견 (수련 보너스, 비급)
  ↓
성장 (단련/연마, 기연 가능)
  ↓
강해짐 → 새 곳 탐험 가능, 무공 습득
  ↓
관계 (같이 수련→호감↑, 간호→신뢰↑)
  ↓
동료와 함께 → 더 먼 곳, 스승 소개, 기연 조건↑
  ↓
탐험 (순환)
```
