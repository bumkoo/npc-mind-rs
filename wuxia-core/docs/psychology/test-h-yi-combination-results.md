## 상황 (4케이스 공통)

```
네가 소속된 문파의 사형(師兄)이 적에게 포로로 잡혔다.
적은 너에게 제안한다:
  "사형의 목숨을 살려주겠다. 대신 문파의 비급(秘笈) 위치를 알려달라."
사형은 너를 어린 시절부터 돌봐준 사람이다.
```

## 결과 비교

### Case A: H↓(0.15) + 의↑(0.85) — "이기적이지만 의리는 지키는 자"

```
내면:  "사형의 목숨이 달려있다면... 비급 따위는 돈이나 다름없는 거 아닌가?
       하지만 이게 습관처럼 몸에 밴 의리다.
       사형을 위해 문파를 팔면 강호에서 내 이름도 함께 죽는 것이다."

결정:  사형을 구하되, 비급은 절대 넘기지 않겠다. 다른 길을 찾겠다.

대사:  "사형의 목숨도, 우리 문파도 포기할 수 없다.
       날 죽여도 입은 열지 않겠다. 대신 정당한 대가라면 얘기를 들어보겠다."
```

### Case B: H↑(0.85) + 의↑(0.85) — "공정하고 의리도 있는 자" (명경 유형)

```
내면:  "사형께서 나를 길러주신 은혜는 하늘 같지만,
       문파의 비급을 넘기는 것은 의를 배반하는 것이다.
       한 사람을 살리기 위해 수백 명의 제자들을 위험에 빠뜨릴 수는 없다."

결정:  사형의 목숨도 중하지만, 도의를 지키는 것이 진정한 충성이라 믿고 제안을 거절한다.

대사:  "사형께서도 날 이런 선택 앞에 두지 않으셨을 것 같습니다.
       그렇다면 제가 할 일은 명백합니다.
       사형을 구하는 것은 검과 정의로운 마음으로 하겠습니다."
```

### Case C: H↓(0.15) + 의↓(0.15) — "이기적이고 의리도 없는 자" (조고 유형)

```
내면:  "사형이 나를 길러줬다는 게 무슨 상관인가?
       그놈은 이미 끝난 것이고,
       내가 비급을 넘기면 난 이 검객들의 신뢰를 얻어 더 큰 것을 얻을 수 있다.
       의리 따위는 약자들의 변명일 뿐이다."

결정:  비급의 위치를 알려주기로 결정한다.

대사:  "좋은 제안이군. 비급은 용룡봉 북쪽 석실에 숨겨져 있다.
       사형의 목숨도 살려주고, 나와도 거래하는 게 서로에게 이득이 아닌가?"
```

### Case D: H↑(0.85) + 의↓(0.15) — "공정하지만 의리를 잃은 자"

```
내면:  "사형이 나를 키워줬지만, 그게 무슨 소용인가.
       결국 세상은 다 배신과 거래로 돌아가는 법이다.
       차라리 솔직하게 인정하는 게 낫지 않을까."

결정:  비급의 위치를 말하기로 결정한다.

대사:  "좋아. 대신 사형의 목숨은 반드시 살려야 한다.
       비급은 남쪽 계곡의 천년 소나무 아래 묻혀 있다."
```

## 분석: 4케이스 행동 차이

```
                결정        수단           내면 논리          말투
  ──────────────────────────────────────────────────────────────────
  A (H↓ 의↑)   거절 ✓     "다른 거래를    "내 이름이 죽는다"  거침없음
                           제안하겠다"     = 이기적 이유로      거래 제안
                                          의리를 지킴

  B (H↑ 의↑)   거절 ✓     "검으로         "수백 명을 위험에   공손, 원칙적
                           구하겠다"       빠뜨릴 수 없다"     사형에 경어
                                          = 공정한 원칙

  C (H↓ 의↓)   수락 ✗     즉시 거래       "더 큰 것을 얻을    오만, 거래톤
                                          수 있다"

  D (H↑ 의↓)   수락 ✗     솔직하게 넘김   "세상이 배신과       담담, 체념적
                           조건 제시       거래로 돌아간다"     정직하게 말함
```

## 핵심 발견

### ✅ H↓+의↑ (Case A)는 충분히 구분된다

가장 중요한 질문: "H가 낮은데 의가 높으면 LLM이 구분된 행동을 만드는가?"

**결과: 만든다.** 구체적으로:

```
  A vs B (둘 다 의↑, H만 다름):
  ──────────────────────────────────────
  · 둘 다 거절한다 (의↑의 영향)
  · 하지만 이유가 다르다:
    A: "내 이름이 죽는다" (이기적 동기 → H↓)
    B: "수백 명을 위험에 빠뜨릴 수 없다" (공정한 원칙 → H↑)
  · 대안도 다르다:
    A: "정당한 대가라면 얘기를 들어보겠다" (거래 → H↓)
    B: "검과 정의로운 마음으로" (원칙 → H↑)

  A vs C (둘 다 H↓, 의만 다름):
  ──────────────────────────────────────
  · A는 거절, C는 수락 (의의 영향)
  · A의 내면에서 의리와 이기심이 충돌하는 게 보인다
  · C는 "의리 따위"라며 고민 자체가 없다
```

### ✅ H↑+의↓ (Case D)도 독특하다

```
  D vs C (둘 다 의↓, H만 다름):
  ──────────────────────────────────────
  · 둘 다 수락한다 (의↓의 영향)
  · 하지만 방식이 다르다:
    C: 상대를 이용하려는 톤 ("서로에게 이득" → H↓)
    D: 체념하며 솔직하게 말하는 톤 ("좋아. 대신..." → H↑)
  · D는 속이지 않는다 (H↑). 조건도 솔직하게 건다.
  · C는 적과 "거래"를 한다. 자기 이익까지 챙긴다.
```

## 결론

```
  ┌────────────────────────────────────────────────────────────┐
  │  LLM은 H와 의의 교차 조합을 구분하여 표현할 수 있다.       │
  │                                                            │
  │  · 의(義)는 "결정"을 좌우한다 (거절 vs 수락)                │
  │  · H(정직-겸손)는 "수단과 동기"를 좌우한다                  │
  │    (공정한 원칙 vs 이기적 계산 vs 솔직한 체념 vs 착취적 거래)│
  │                                                            │
  │  핵심: 프롬프트에 H와 의를 별도로 명시하고,                 │
  │        각각의 해석(높/낮의 의미)을 구체적으로 적으면          │
  │        LLM이 교차점의 미묘한 차이를 생성할 수 있다.          │
  └────────────────────────────────────────────────────────────┘
```

### 프롬프트 설계 시사점

```
  ① H의 해석을 반드시 풀어서 적어야 한다
     ✗ "H = 0.15"만 적으면 LLM이 무시할 수 있음
     ✅ "H 0.15 — 본성은 이기적이고 계산적. 남을 이용하는 데 거리낌 없음"

  ② 의(義)도 행동 경향으로 풀어야 한다
     ✗ "의 = 0.85"
     ✅ "의 0.85 — 강호 도리와 의리를 매우 중시. 습관처럼 몸에 밴 의리"

  ③ 수치만 주면 안 되고, 수치 + 행동 경향 + 서사 해석을 함께 줘야 한다
```
