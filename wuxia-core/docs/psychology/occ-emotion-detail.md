## 1. OCC 모델 기초 — 왜 OCC인가

OCC(Ortony, Clore & Collins, 1988)는 감정을 **"상황에 대한 인지적 평가의 결과"**로 본다.
같은 사건이라도 사람마다 다르게 느끼는 이유는, 각자의 목표·기준·태도가 다르기 때문이다.

칠국춘추에서 이 "각자의 목표·기준·태도"가 바로 **③층 5가치(충/의/효/복수/야망)**다.

```
  왜 OCC가 게임에 적합한가:

  ┌──────────────────────────────────────────────────────────┐
  │  ① 수식화 가능 → 코드로 <1ms 계산 (결정적, 재현 가능)  │
  │  ② 개인차 표현 → 5가치가 평가 기준이므로 NPC마다 다름   │
  │  ③ 22종 세분화 → 분노와 경멸, 자부와 감탄을 구분        │
  │  ④ 게임 AI 검증 → 30년간 가상 캐릭터에 가장 많이 사용   │
  └──────────────────────────────────────────────────────────┘
```

## 2. 3가지 평가 대상 — 사건·행위자·대상

OCC는 세상을 바라보는 시선을 3가지로 나눈다.

```
  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │            자극이 들어왔다. 무엇에 초점을 맞추는가?         │
  │                                                             │
  │  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
  │  │   사건의      │  │   행위자의   │  │   대상의     │      │
  │  │   결과        │  │   행동       │  │   속성       │      │
  │  │  (Event)      │  │  (Agent)     │  │  (Object)    │      │
  │  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘      │
  │         │                 │                  │              │
  │    "내 목표에      "내 기준에          "내 취향에            │
  │     어떤 영향?"    맞는 행동?"         맞는 것?"            │
  │         │                 │                  │              │
  │    평가 기준:       평가 기준:         평가 기준:            │
  │    바람직성         칭찬할 만함         호감                 │
  │    (desirability)  (praiseworthiness)  (appealingness)      │
  │         │                 │                  │              │
  │    ┌────┴────┐     ┌─────┴─────┐     ┌─────┴─────┐        │
  │    │ 쾌      │     │ 찬성      │     │ 호감      │        │
  │    │ pleased │     │ approving │     │ liking    │        │
  │    │ 불쾌    │     │ 반대      │     │ 비호감    │        │
  │    │displeased│    │disapproving│    │ disliking │        │
  │    └─────────┘     └───────────┘     └───────────┘        │
  │                                                             │
  │    14종 감정          4종 감정           2종 감정            │
  │    + 복합 4종                            (+ 확장 2종)       │
  └─────────────────────────────────────────────────────────────┘
```

**칠국춘추에서의 매핑**:

```
  평가 대상      칠국춘추 입력           5가치 연결
  ────────────────────────────────────────────────────
  사건 결과      게임 이벤트 발생        충·의·효·복수·야망 전부
                 (납치, 전투, 배신 등)   → "내 가치에 비추어 좋은가?"

  행위자 행동    NPC/플레이어의 행동     의(義) 중심
                 (도움, 배신, 폭력 등)   → "이 행동이 도리에 맞는가?"

  대상 속성      무공, 보물, 장소 등     야망(野) 중심
                 (명검, 비급, 문파 등)   → "이것이 매력적인가?"
```

## 3. 22종 감정 전체 목록

### 3.1 가지 I — 사건의 결과에 대한 감정 (14종)

#### A. 안녕 감정 (Well-being) — 자기 자신의 결과

```
  ┌────────┬──────────┬──────────────────────────────────────────┐
  │ OCC    │ 번역어   │ 유발 조건                                │
  │ 원어   │ (한자)   │                                          │
  ├────────┼──────────┼──────────────────────────────────────────┤
  │ Joy    │ 희열     │ 바람직한 사건의 결과가 실제로 일어남      │
  │        │ (喜悅)   │                                          │
  ├────────┼──────────┼──────────────────────────────────────────┤
  │Distress│ 고뇌     │ 바람직하지 않은 사건의 결과가 실제로      │
  │        │ (苦惱)   │ 일어남                                   │
  └────────┴──────────┴──────────────────────────────────────────┘
```

**무협 예시**:

```
  사건: "사부 명경이 독에서 회복했다"
  
  소연 → 희열(Joy)
    유발: 충(70) × 사건바람직성(90) / 100 = 63
    "사부님이 살아계시다... 다행이다"

  조고 → 고뇌(Distress)
    유발: 야망(100) × 사건불리함(70) / 100 = 70
    "그 늙은이가 또 살아남았단 말인가"
```

#### B. 전망 감정 (Prospect-based) — 미래/불확실한 결과

```
  ┌───────────────┬──────────┬────────────────────────────────────┐
  │ OCC 원어      │ 번역어   │ 유발 조건                          │
  ├───────────────┼──────────┼────────────────────────────────────┤
  │ Hope          │ 기대     │ 바람직한 결과가 일어날 전망         │
  │               │ (期待)   │                                    │
  ├───────────────┼──────────┼────────────────────────────────────┤
  │ Fear          │ 두려움   │ 바람직하지 않은 결과가 일어날 전망  │
  │               │ (懼)     │                                    │
  ├───────────────┼──────────┼────────────────────────────────────┤
  │ Satisfaction  │ 흡족     │ 기대했던 좋은 결과가 실제로 확인됨  │
  │               │ (快)     │ (Hope의 확인)                      │
  ├───────────────┼──────────┼────────────────────────────────────┤
  │Fears-confirmed│ 절망     │ 두려워했던 나쁜 결과가 실제로 확인  │
  │               │ (絕望)   │ (Fear의 확인)                      │
  ├───────────────┼──────────┼────────────────────────────────────┤
  │ Relief        │ 안도     │ 두려워했던 결과가 일어나지 않음     │
  │               │ (安堵)   │ (Fear의 불확인)                    │
  ├───────────────┼──────────┼────────────────────────────────────┤
  │Disappointment │ 실망     │ 기대했던 좋은 결과가 일어나지 않음  │
  │               │ (失望)   │ (Hope의 불확인)                    │
  └───────────────┴──────────┴────────────────────────────────────┘
```

**전망 감정의 시간 흐름**:

```
  시간 ──────────────────────────────────────────→

  [기대(Hope)]──┬──확인──→ [흡족(Satisfaction)]
                │
                └──불확인→ [실망(Disappointment)]

  [두려움(Fear)]──┬──확인──→ [절망(Fears-confirmed)]
                  │
                  └──불확인→ [안도(Relief)]
```

**무협 예시**:

```
  사건: "비무대회 결과 발표를 앞두고"

  남궁현:
  · 야망(90) → 기대(Hope) 강도 80
    "이번엔 반드시 형을 이기겠다"

  [결과: 패배]
  · 기대 → 실망(Disappointment) 강도 70
    "또... 또 형에게 졌다"

  [결과: 승리]
  · 기대 → 흡족(Satisfaction) 강도 90
    "드디어... 나도 할 수 있다는 것을 보여줬다"
```

#### C. 타인운 감정 (Fortunes-of-others) — 타인의 결과에 대한 반응

```
  ┌────────────┬──────────┬──────────────────────────────────────┐
  │ OCC 원어   │ 번역어   │ 유발 조건                            │
  ├────────────┼──────────┼──────────────────────────────────────┤
  │ Happy-for  │ 축하     │ 타인에게 바람직한 결과 +             │
  │            │ (慶)     │ 나도 그것이 바람직하다고 느낌         │
  ├────────────┼──────────┼──────────────────────────────────────┤
  │ Pity       │ 측은     │ 타인에게 바람직하지 않은 결과 +       │
  │            │ (惻隱)   │ 나도 그것이 안타깝다고 느낌           │
  ├────────────┼──────────┼──────────────────────────────────────┤
  │ Gloating   │ 통쾌     │ 타인에게 바람직하지 않은 결과 +       │
  │            │ (痛快)   │ 나는 그것이 바람직하다고 느낌          │
  ├────────────┼──────────┼──────────────────────────────────────┤
  │ Resentment │ 시기     │ 타인에게 바람직한 결과 +              │
  │            │ (忌)     │ 나는 그것이 바람직하지 않다고 느낌     │
  └────────────┴──────────┴──────────────────────────────────────┘
```

**타인운 감정의 2×2 구조**:

```
                    타인에게 좋은 결과    타인에게 나쁜 결과
                  ┌──────────────────┬──────────────────┐
  나에게도 좋다   │  축하(Happy-for)  │       —          │
  (동조)          │  慶               │                  │
                  ├──────────────────┼──────────────────┤
  나에게는 나쁘다 │  시기(Resentment) │       —          │
  (반감)          │  忌               │                  │
                  ├──────────────────┼──────────────────┤
  나에게도 나쁘다 │       —           │ 측은(Pity)       │
  (동정)          │                  │ 惻隱              │
                  ├──────────────────┼──────────────────┤
  나에게는 좋다   │       —           │ 통쾌(Gloating)   │
  (적대)          │                  │ 痛快              │
                  └──────────────────┴──────────────────┘
```

**무협 예시**:

```
  사건: "야율설화가 초원에서 탈출에 성공했다"

  소연 → 축하(Happy-for)
    관계: 동료(+0.3) + 의(80) "같은 처지의 아이"
    "잘 됐다. 그 아이도 자기 길을 찾았구나"

  남궁현 → 시기(Resentment)
    관계: 경쟁(-0.1) + 야망(90) "나는 아직 못 벗어났는데"
    "흥, 야만인 주제에 자유를 얻다니"

  사건: "조고가 중상을 입었다"

  명경 → 측은(Pity)
    정(80) "적이라도 사람의 고통을 외면하지 않는다"
    + 의(90) "무고한 이를 해친 자지만... 고통받을 필요까진"

  소연 → 통쾌(Gloating)
    복수(80) × 원수관계(100) / 100 = 80
    "드디어... 아비의 원수가 피를 흘렸다"
```

### 3.2 가지 II — 행위자의 행동에 대한 감정 (4종)

```
  ┌────────────┬──────────┬──────────────────────────────────────┐
  │ OCC 원어   │ 번역어   │ 유발 조건                            │
  ├────────────┼──────────┼──────────────────────────────────────┤
  │ Pride      │ 자부     │ 자기 자신의 행동이 기준에 부합       │
  │            │ (自負)   │ (칭찬할 만하다)                      │
  ├────────────┼──────────┼──────────────────────────────────────┤
  │ Shame      │ 수치     │ 자기 자신의 행동이 기준에 위배       │
  │            │ (恥)     │ (비난할 만하다)                      │
  ├────────────┼──────────┼──────────────────────────────────────┤
  │ Admiration │ 감탄     │ 타인의 행동이 기준에 부합            │
  │            │ (歎)     │ (칭찬할 만하다)                      │
  ├────────────┼──────────┼──────────────────────────────────────┤
  │ Reproach   │ 비난     │ 타인의 행동이 기준에 위배            │
  │            │ (責)     │ (비난할 만하다)                      │
  └────────────┴──────────┴──────────────────────────────────────┘
```

**"기준"이란 무엇인가 — 5가치가 기준이다**:

```
  행위자 감정의 "기준(standard)"
  = 칠국춘추에서는 5가치(충/의/효/복수/야망)

  NPC가 타인의 행동을 평가할 때:
  · 의(義) 높은 NPC → 도리에 맞지 않는 행동에 강한 비난(Reproach)
  · 충(忠) 높은 NPC → 조직을 배반하는 행동에 강한 비난(Reproach)
  · 야망(野) 높은 NPC → 기회를 놓치는 행동에 비난보다 경멸

  NPC가 자기 행동을 평가할 때:
  · 의(義) 높은데 도리를 어겼다 → 수치(Shame)
  · 충(忠) 높은데 주군을 지켰다 → 자부(Pride)
```

**무협 예시**:

```
  사건: "소연이 적에게 잡힌 동료를 두고 탈출했다"

  명경이 소연의 행동을 봄:
  · 의(90) × 행동위반강도(60) / 100 → 비난(Reproach) 54
    "아무리 상황이 어려워도 동료를 버려선..."

  소연 자신:
  · 의(80) × 행동위반강도(60) / 100 → 수치(Shame) 48
  · 하지만 충(70) × 사부명령이행(80) / 100 → 자부(Pride) 56
    → 수치와 자부가 공존! "사부의 명을 따랐지만... 마음이 편치 않다"
```

### 3.3 가지 II+I — 복합 감정 (4종)

사건의 결과 + 행위자의 행동이 결합되어 발생하는 감정이다.

```
  ┌──────────────┬──────────┬─────────────────────────────────────┐
  │ OCC 원어     │ 번역어   │ 유발 조건                           │
  ├──────────────┼──────────┼─────────────────────────────────────┤
  │Gratification │ 뿌듯함   │ 자부(Pride) + 희열(Joy)             │
  │              │ (得意)   │ 자신의 칭찬할 행동이 좋은 결과 초래 │
  ├──────────────┼──────────┼─────────────────────────────────────┤
  │ Remorse      │ 회한     │ 수치(Shame) + 고뇌(Distress)        │
  │              │ (悔恨)   │ 자신의 비난할 행동이 나쁜 결과 초래 │
  ├──────────────┼──────────┼─────────────────────────────────────┤
  │ Gratitude    │ 감은     │ 감탄(Admiration) + 희열(Joy)        │
  │              │ (感恩)   │ 타인의 칭찬할 행동이 좋은 결과 초래 │
  ├──────────────┼──────────┼─────────────────────────────────────┤
  │ Anger        │ 분노     │ 비난(Reproach) + 고뇌(Distress)     │
  │              │ (憤怒)   │ 타인의 비난할 행동이 나쁜 결과 초래 │
  └──────────────┴──────────┴─────────────────────────────────────┘
```

**복합 감정의 구조**:

```
           자신의 행동             타인의 행동
        ┌──────────────┐     ┌──────────────┐
  좋은  │ 뿌듯함        │     │ 감은          │
  결과  │ = 자부 + 희열 │     │ = 감탄 + 희열 │
        │ (得意)        │     │ (感恩)        │
        ├──────────────┤     ├──────────────┤
  나쁜  │ 회한          │     │ 분노          │
  결과  │ = 수치 + 고뇌 │     │ = 비난 + 고뇌 │
        │ (悔恨)        │     │ (憤怒)        │
        └──────────────┘     └──────────────┘
```

**무협 예시 — 분노(Anger)의 해부**:

```
  사건: "당무괴(조고의 부하)가 마을 사람들을 학살했다"
  NPC: 명경

  ① 행위자 평가 (행동 가지):
     당무괴의 행동이 기준에 위배
     의(90) × 위반강도(95) / 100 → 비난(Reproach) = 85.5

  ② 사건 평가 (사건 가지):
     마을 사람 죽음이 바람직하지 않음
     충(90) × 목표위협(수호 목표)(90) / 100 → 고뇌(Distress) = 81

  ③ 복합:
     비난(85.5) + 고뇌(81) → 분노(Anger)
     최종 강도 = max(85.5, 81) × 1.2 = 100 (상한)

  → 분노는 단순 화가 아니다.
  → "비난할 행동 + 나쁜 결과"가 결합된 복합 감정이다.
  → 그래서 분노는 "책임자"가 있다. 단순 불운에는 분노가 아니라 고뇌가 온다.
```

### 3.4 가지 III — 대상의 속성에 대한 감정 (2종)

```
  ┌────────────┬──────────┬──────────────────────────────────────┐
  │ OCC 원어   │ 번역어   │ 유발 조건                            │
  ├────────────┼──────────┼──────────────────────────────────────┤
  │ Love       │ 애착     │ 익숙한 대상의 속성이 호감             │
  │            │ (愛)     │                                      │
  ├────────────┼──────────┼──────────────────────────────────────┤
  │ Hate       │ 혐오     │ 익숙한 대상의 속성이 비호감           │
  │            │ (厭)     │                                      │
  └────────────┴──────────┴──────────────────────────────────────┘
```

**무협에서의 활용**:

```
  애착(Love):
  · 소연 → 사부에게 받은 단검 (도구 + 관계 기억)
  · 명경 → 화산파 옛 도장 (장소 + 형성 기억)
  · 야율설화 → 초원의 바람 (장소 + 자유의 상징)

  혐오(Hate):
  · 소연 → 조고의 문장이 새겨진 깃발 (원수의 상징)
  · 진야림 → 술 (의존 대상이면서 자기혐오의 매개)
  · 남궁현 → 형이 쓰는 검 (열등감의 대상)
```

### 5.2 증폭 강도 공식

```
  감정_최종강도 = 기본강도 × 가치_가중치 × 기분편향 × 성격필터

  여기서:
  · 기본강도  = 사건의 객관적 중요도 (0~100, 게임 이벤트 시스템이 제공)
  · 가치_가중치 = 해당 NPC의 5가치 수치 (0~100)
  · 기분편향  = PAD 기반 (§5.3 참조)
  · 성격필터  = HEXACO 기반 (§5.4 참조)
```

### 5.3 기분편향 (PAD → 감정 증폭)

```
  긍정 감정 증폭율 = 1.0 + (P × 0.3)
  부정 감정 증폭율 = 1.0 - (P × 0.3)

  예:
  P = +0.5 (좋은 기분):
  · 긍정 감정 × 1.15 (살짝 증폭)
  · 부정 감정 × 0.85 (약간 억제)

  P = -0.8 (나쁜 기분):
  · 긍정 감정 × 0.76 (억제)
  · 부정 감정 × 1.24 (크게 증폭)
```

### 5.4 성격필터 (HEXACO → 감정 필터)

```
  ※ 메인 문서(npc-psychology-architecture.md §6.3)와 동기화
  ※ HEXACO 값 범위: 0~100

  H (정직-겸손) → 도덕적 감정 필터
    죄책감(Shame/Guilt) × (1.0 + H × 0.005)
    통쾌(Gloating)      × (1.0 - H × 0.004)
    도덕비난(Reproach)   × (1.0 + H × 0.003)
    H=90이면: 죄책감 ×1.45, 통쾌 ×0.64, 도덕비난 ×1.27
    H=10이면: 죄책감 ×1.05, 통쾌 ×0.96, 도덕비난 ×1.03

  E (정서성) → 두려움/공감 필터  ← BigFive-N의 불안 분리
    두려움(Fear)    × (1.0 + E × 0.005)
    측은(Pity)      × (1.0 + E × 0.004)
    E=80이면: 두려움 ×1.40, 측은 ×1.32
    E=20이면: 두려움 ×1.10, 측은 ×1.08

  X (외향성) → 감정 표현 강도 (내부 강도와 별개)
    X 높으면: 같은 감정도 행동으로 더 크게 표출
    X 낮으면: 강한 감정도 내면에 담아둠

  A (친화성) → 분노/원한 조절  ← BigFive-A에서 분노조절 합류
    분노(Anger)     × (1.0 - A × 0.004)
    원한(Resentment) × (1.0 - A × 0.003)
    A=80이면: 분노 ×0.68, 원한 ×0.76
    A=20이면: 분노 ×0.92, 원한 ×0.94

  C (성실성) → 감정 억제
    C 높으면: 감정을 느끼되 행동에 덜 반영 (이성적)
    C 낮으면: 감정이 바로 행동으로 연결 (충동적)

  O (개방성) → 새로운 감정 수용
    O 높으면: 복합 감정(감은+수치 동시 등) 경험 가능
    O 낮으면: 단순 감정으로 귀결 (분노 OR 슬픔, 둘 다는 어려움)
```

## 8. 감정 → PAD 변환 매핑

각 감정이 기분(PAD)에 미치는 영향을 정의한다.

```
  ┌──────────────┬────────┬────────┬────────┐
  │ 감정 유형    │ ΔP     │ ΔA     │ ΔD     │
  │              │(쾌/불쾌)│(각성)  │(지배감)│
  ├──────────────┼────────┼────────┼────────┤
  │ Joy 희열     │ +0.4   │ +0.2   │ +0.1   │
  │ Distress 고뇌│ -0.4   │ +0.2   │ -0.2   │
  │ Hope 기대    │ +0.2   │ +0.1   │ +0.1   │
  │ Fear 두려움  │ -0.3   │ +0.4   │ -0.4   │
  │ Satisfaction │ +0.3   │ -0.1   │ +0.2   │
  │ Fears-conf.  │ -0.5   │ +0.3   │ -0.5   │
  │ Relief 안도  │ +0.3   │ -0.3   │ +0.1   │
  │ Disappointment│-0.3   │ -0.1   │ -0.2   │
  │ Happy-for 축하│+0.2   │ +0.1   │ +0.1   │
  │ Pity 측은    │ -0.2   │ +0.1   │ -0.1   │
  │ Gloating 통쾌│ +0.3   │ +0.3   │ +0.3   │
  │ Resentment시기│-0.2   │ +0.2   │ -0.3   │
  │ Pride 자부   │ +0.3   │ +0.2   │ +0.3   │
  │ Shame 수치   │ -0.3   │ +0.1   │ -0.4   │
  │ Admiration감탄│+0.2   │ +0.1   │ -0.1   │
  │ Reproach 비난│ -0.2   │ +0.2   │ +0.1   │
  │Gratification │ +0.4   │ +0.2   │ +0.4   │
  │ Remorse 회한 │ -0.4   │ +0.1   │ -0.4   │
  │ Gratitude감은│ +0.3   │ +0.1   │ -0.1   │
  │ Anger 분노   │ -0.3   │ +0.5   │ +0.2   │
  │ Love 애착    │ +0.3   │ +0.1   │ +0.1   │
  │ Hate 혐오    │ -0.3   │ +0.2   │ +0.1   │
  └──────────────┴────────┴────────┴────────┘
  
  주의: 위 값은 intensity=100 기준 최대값이다.
  실제 적용: ΔP_actual = ΔP_max × (emotion_intensity / 100)
```

**PAD 특징 패턴**:

```
  분노(Anger): P-, A++, D+
  → 불쾌하지만 각성 높고 지배감 있음 = "화가 나서 뭔가 하려 함"

  두려움(Fear): P-, A++, D--
  → 불쾌하고 각성 높지만 무력감 = "위험을 느끼고 도망치려 함"

  절망(Fears-confirmed): P--, A+, D--
  → 매우 불쾌, 각성 있지만 극심한 무력감 = "최악이 현실이 됨"

  안도(Relief): P+, A--, D+
  → 쾌적하고 이완됨 = "긴장이 풀림"
```

## 9. 시간 감쇠 규칙

### 9.1 감쇠 공식

```
  intensity(t) = intensity₀ × e^(-λ × Δt)

  λ (감쇠 상수) = 감정 유형별로 다름
  Δt = 경과 게임 시간 (시간 단위)
```

### 9.2 감정별 감쇠 속도

```
  ┌──────────────────┬────────┬─────────────────────────────────┐
  │ 감정 유형        │ 반감기 │ 설계 근거                       │
  │                  │(게임시간)│                                │
  ├──────────────────┼────────┼─────────────────────────────────┤
  │ 빠르게 사라지는  │        │                                 │
  │  안도(Relief)    │ 2시간  │ 긴장 해소 후 빠르게 정상화      │
  │  흡족(Satisfaction)│3시간 │ 만족감은 금방 당연해짐          │
  │  통쾌(Gloating)  │ 3시간  │ 통쾌함은 오래가지 않음          │
  │  축하(Happy-for) │ 3시간  │ 타인의 일에 대한 반응           │
  ├──────────────────┼────────┼─────────────────────────────────┤
  │ 보통 속도        │        │                                 │
  │  희열(Joy)       │ 6시간  │ 기쁨은 하루 정도 지속           │
  │  고뇌(Distress)  │ 8시간  │ 슬픔은 기쁨보다 오래감          │
  │  기대(Hope)      │ 12시간 │ 기대는 결과 나올 때까지 유지    │
  │  두려움(Fear)    │ 12시간 │ 두려움은 위협 해소까지 유지     │
  │  자부(Pride)     │ 6시간  │                                 │
  │  감탄(Admiration) │ 4시간 │                                 │
  ├──────────────────┼────────┼─────────────────────────────────┤
  │ 느리게 사라지는  │        │                                 │
  │  분노(Anger)     │ 24시간 │ 분노는 쉽게 가라앉지 않음       │
  │  수치(Shame)     │ 24시간 │ 치욕은 오래 남음                │
  │  회한(Remorse)   │ 48시간 │ 후회는 매우 오래 지속           │
  │  절망(Fears-conf.)│36시간 │ 절망에서 빠져나오기 어려움      │
  │  시기(Resentment)│ 24시간 │ 시기심은 은근히 오래감          │
  ├──────────────────┼────────┼─────────────────────────────────┤
  │ 사라지지 않는    │        │                                 │
  │  애착(Love)      │  ∞     │ 기억이 유지하는 한 지속         │
  │  혐오(Hate)      │  ∞     │ 기억이 유지하는 한 지속         │
  └──────────────────┴────────┴─────────────────────────────────┘

  * Love/Hate는 시간 감쇠가 아니라 기억 중요도 감쇠에 의존
  * 감쇠 후 threshold(1.0) 미만이 되면 감정 목록에서 제거
  * Tier 2 성찰(하루 끝)에서 잔존 감정 정리
```

### 9.3 감쇠 중단 조건

```
  감쇠가 멈추거나 재강화되는 경우:

  · 같은 종류의 사건 반복 → 강도 갱신 (더 높은 값으로)
  · 관련 기억 회상 (LanceDB 검색 히트) → 감쇠 속도 ×0.5
  · 성찰(Tier 2~3)에서 재평가 → LLM이 강도 조정
  · 복수(復) 관련 감정은 복수 대상을 만날 때마다 재점화
```

            Self::Pity         => PadDelta { pleasure: -0.2, arousal:  0.1, dominance: -0.1 },

            Self::Remorse      => PadDelta { pleasure: -0.4, arousal:  0.1, dominance: -0.4 },
            Self::Gratitude    => PadDelta { pleasure:  0.3, arousal:  0.1, dominance: -0.1 },
            Self::Anger        => PadDelta { pleasure: -0.3, arousal:  0.5, dominance:  0.2 },
            Self::Love         => PadDelta { pleasure:  0.3, arousal:  0.1, dominance:  0.1 },
            Self::Hate         => PadDelta { pleasure: -0.3, arousal:  0.2, dominance:  0.1 },
        }
    }

    /// 감정별 반감기 (게임 시간, 시간 단위)
    pub fn half_life_hours(&self) -> f32 {
        match self {
            Self::Relief | Self::Satisfaction | Self::Gloating | Self::HappyFor => 3.0,
            Self::Joy | Self::Pride | Self::Admiration => 6.0,
            Self::Distress | Self::Hope | Self::Fear => 10.0,

        }
    }
}
