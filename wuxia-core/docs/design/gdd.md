## 1. 컨셉 (Concept)

### 1.1 엘리베이터 피치

> **"사람을 믿을 수 있는가. 옳은 것을 위해 잃을 수 있는가. 원하는 것을 잡을 수 있는가.  
> 삶이 던지는 질문들 앞에서, 모든 인물이 각자의 답을 찾아간다.  
> 그들의 인생을 들여다보고, 그 인생의 일부가 되는 무협 RPG."**

한 줄 버전:  
> **"삶의 질문에 각자의 답을 찾아가는 사람들의 열전 — 무협 RPG"**

#### 1.1.1 삶의 세 가지 질문

이 게임의 모든 인물은 다음 질문들에 부딪히고, 경험을 통해 자기만의 답을 만들어간다.
플레이어는 그 과정을 스스로 경험하고, 또 목격한다.

```
  믿음(信, Trust) — "사람을 믿을 수 있는가?"
  믿고 배신당한 사람은 닫히고, 믿고 구원받은 사람은 열린다.

  옳음(正, Rightness) — "옳은 것을 위해 손해를 감수할 수 있는가?"
  신념을 위해 싸워본 사람은 단단해지고, 외면한 사람은 흔들린다.

  바람(願, Want) — "나는 무엇을 바라는가?"
  속박당해본 사람은 자유를 갈망하고, 자유 속에서 외로웠던 사람은 소속을 원한다.
  가진 게 없던 사람은 더 원하고, 다 가져봤지만 허무했던 사람은 멈춘다.
```

분류 기준: 관계의 대상 (타인 / 원칙 / 자기 자신) → MECE

#### 1.1.2 변화 패턴 — "경험이 답을 바꾸는 원리"

세 축 모두에서 동일하게 작동하는 변화의 패턴이 있다.

> **"잃어본 사람은 집착하고, 집착으로 더 잃은 사람은 놓는 법을 배운다."**

```
  믿음의 궤적: 믿었다 → 배신 → 불신 → (다시 열리거나 더 닫히거나)
  옳음의 궤적: 신념 → 좌절 → 타협 → (더 깊은 신념이거나 포기거나)
  바람의 궤적: 원했다 → 얻었다 → 허무 → (멈추거나 새 욕망이거나)

  공통 구조: 가졌다 → 잃었다 → 집착 → (놓거나 더 집착하거나)
  → 이것은 축이 아니라, 심리 시스템의 변화 엔진
```

> 📎 세 질문의 심리 시스템 구현: [npc-psychology-architecture.md](npc-psychology-architecture.md) §3~5

#### 1.1.3 보편 3축과 무협 5가치의 관계

```
  보편 3축 = "이 사람이 어떤 존재인가" (서사/LLM용)
  변화 패턴 = "경험이 어떻게 사람을 바꾸는가" (시스템 원리)
  무협 5가치 = "구체적 상황에서 어떻게 판단하는가" (코드용)
            충(忠) / 의(義) / 효(孝) / 복수(復) / 야망(野)
```

> 📎 5가치 상세: [npc-psychology-architecture.md](npc-psychology-architecture.md) §4

### 1.2 피치 요소 분해

| 우선순위 | 요소 | 피치에서의 표현 |
|:--------:|------|----------------|
| 1 | 삶의 보편적 질문 | "사람을 믿을 수 있는가. 옳은 것을 위해 잃을 수 있는가. 나는 무엇을 바라는가." |
| 2 | 모두가 자기 인생의 주인공 | "모든 인물이 각자의 답을 찾아간다" |
| 3 | 상호적 열전 구조 | "그들의 인생을 들여다보고, 그 인생의 일부가 된다" |
| 4 | 무협이라는 렌즈 | "무협 RPG" |

### 1.3 피치 필터 — 기능 추가 판단 기준

이 게임에 기능을 추가할 때, 엘리베이터 피치와의 정합성을 검토한다.

```
✅ 채택 기준:
  · 인물이 삶의 질문에 자율적으로 답을 만들어가는 기능
  · 경험이 가치관을 실제로 변화시키는 기능
  · 플레이어가 인물의 인생을 들여다볼 수 있는 기능 (열전)
  · 플레이어의 행동이 인물의 "답"에 영향을 주는 기능

❌ 보류 기준:
  · 정답이 정해진 퀴스트 (질문에 "정답"은 없다)
  · 인물이 플레이어 중심으로만 존재하는 구조
  · 선택이 수치만 바꾸고 서사적 의미가 없는 기능
```

### 1.4 Player Fantasy — "플레이어는 누가 되고 싶은가"

> **"상처를 안고도 앞으로 나아가며,  
> 사람들과 진심으로 연결되고,  
> 내 선택으로 세상과 나 자신의 이야기를 쓰는 경험"**
>
> 한 단어로: **"연결과 성장" (Connection & Growth)**

#### 3개 층위

| 층위 | 내용 | 칠국춘추에서의 표현 |
|------|------|-------------------|
| 감정 (깊은 층) | 이 게임이 주는 감정 | 소속감, 선택의 무게감, 진심의 연결 |
| 역할 (중간 층) | 플레이어가 되는 존재 | 상처 입은 영웅 / 진실 추구자 / 관계의 달인 |
| 행동 (표면 층) | 실제 하는 행동 | 대화, 탐색, 수련, 선택 |

#### 정렬 검증

```
행동: 인물과 대화하고, 그들의 인생을 들여다보고, 자기 답을 선택한다
      ↓ 이 행동을 통해
역할: 여러 인생의 일부가 되고, 자기 열전을 써 나가는 사람이 된다
      ↓ 그 역할을 통해
감정: "여러 삶을 살아본 기억" "내 답이 그들의 답에도 영향을 줬다"

→ 3겹이 "연결과 성장"으로 정렬됨 ✓
→ 엘리베이터 피치(삶의 질문 + 열전 구조)와 같은 방향 ✓
```

#### Fantasy 위반 방지

| 위반 사례 | 파괴되는 Fantasy | 대책 |
|----------|----------------|------|
| NPC가 과거 대화를 잊음 | 이해받고 싶다 | AI 기억 시스템 |
| 선택해도 결과가 같음 | 선택의 무게감 | 관계값+분기 실작동 |
| 전투만 강요 | 관계의 달인 | 모든 상황에 비전투 선택지 |
| 성장 체감 없음 | 상처 입은 영웅 | NPC가 성장 언급 + 새 선택지 해금 |

### 1.5 레퍼런스 게임

| 게임 | 참고 요소 | 칠국춘추에서의 적용 |
|------|----------|-------------------|
| 디스코 엘리시움 | 내러티브 RPG의 대화 깊이 | 대화가 핵심 게임플레이 |
| 스타듀밸리 | NPC 관계 시스템, 하루 시간 관리 | 시간대별 행동 선택, NPC 호감도 |
| 크루세이더 킹즈 | 캐릭터 성격/관계 시뮬레이션 | NPC 자율 행동, 세대 교체 |
| 와호장룡 (영화) | 내면 갈등, 액션보다 감정 | 게임 톤과 분위기 |

## 2. 핵심 메카닉 — 3겹 코어 루프 (Core Loop)

### 2.1 코어 루프 개요

```
  ┌─────────────────────────────────────────────────────┐
  │  장기 루프 (4막, 40~70시간)                           │
  │  "이 게임을 통해 어떤 이야기를 만들었나?"               │
  │                                                     │
  │  ├── 세션 루프 (하루 = 6시간대, 30분~2시간)            │
  │  │   "오늘 게임하면서 뭘 이뤘나?"                      │
  │  │                                                  │
  │  │   ├── 마이크로 루프 (1~5분)                        │
  │  │   │   "지금 이 순간 뭘 하나?"                      │
  │  │   │                                              │
  └─────────────────────────────────────────────────────┘
```

### 2.2 마이크로 루프 — 5가지 행동 유형

플레이어가 1~5분 안에 반복하는 기본 행동 단위.

```
  ① 대화(Talk)     NPC와 대화, 선택지 or 자유 입력  ← 게임의 심장
  ② 탐색(Explore)  장소 이동, 단서 발견, 환경 관찰
  ③ 수련(Train)    무공 수련, 서적 연구, 사부에게 배움
  ④ 전투(Combat)   턴제 전투, 회피/협상 가능         ← 양념, 주식 아님
  ⑤ 거래(Trade)    물품/정보 거래, 경제 활동
```

#### 행동 간 연결 흐름

```
                  ┌──────────┐
          ┌──────→│ ① 대화   │←──────┐
          │       └────┬─────┘       │
          │            │             │
          │     정보 획득/갈등 발생     │
          │            │             │
          │            ▼             │
     ┌────┴─────┐  ┌──────────┐  ┌──┴───────┐
     │ ⑤ 거래   │  │ ② 탐색   │  │ ③ 수련   │
     └──────────┘  └────┬─────┘  └──┬───────┘
                        │            │
                   위험 조우      도전 필요
                        │            │
                        ▼            ▼
                  ┌──────────┐
                  │ ④ 전투   │
                  └──────────┘
```

#### 대화 루프 상세 — 관계 깊이에 따른 반응 분화

```
예시: 플레이어가 "요즘 조심해"를 선택했을 때

  소연 호감도 30 (초면):
  → "누군지도 모르는 사람한테 그런 말 들으면 좀 무섭거든."
  → 호감 +2

  소연 호감도 60 (친밀):
  → "너도 느꼈어? 같이 알아보지 않을래?"
  → 호감 +5, 퀘스트 해금

  소연 호감도 80 (깊은 신뢰):
  → "사실 나한테도 말 못한 게 있어. 오늘 밤에 시간 돼?"
  → 호감 +3, 소연 과거 고백 이벤트 해금
```

#### 수련 루프 상세 — 사부와의 관계가 성장에 연결

```
명경(사부): "자세가 흐트러졌다. 다시."
  [수련 3회 반복]
명경: "네 검에서 분노가 느껴진다. 무엇이 너를 화나게 하느냐?"

  A. "아무것도 아닙니다." → 수련 효율 보통, 관계 변화 없음
  B. "꿈에서 불타는 산을 봤습니다." → 수련 효율 높음, 관계 +5
  C. [직접 입력] → LLM이 명경의 성격으로 반응

→ 수련이 수치 올리기가 아니라 사부와의 관계를 깊게 하는 시간
```

#### 마이크로 루프 보상 구조

```
  일반 RPG의 보상:              칠국춘추의 보상:
  ─────────────────            ─────────────────
  경험치 +100                  NPC가 나를 기억하는 대사
  레벨업!                      관계가 깊어지며 열리는 이야기
  전설 무기 획득                과거의 기억 조각 발견
  새 스킬 해금                  "이 사람의 진짜 속마음은 뭘까?"

  → 칠국춘추의 진짜 보상 = "이야기의 진전" + "관계의 깊이"
```

### 2.3 세션 루프 — 하루의 흐름 (6시간대)

게임 속 하루는 6개의 시간대(Watch)로 구성된다. (시간 도메인 v1.1 기반)

```
시간대         시진             현대 시간    특징
──────────────────────────────────────────────────
Dawn(여명)    인시~묘시         03~07시    내공 수련 ×1.2, 하루의 시작
Morning(오전) 진시~사시         07~11시    탐색/거래/이동 최적
Midday(정오)  오시~미시         11~15시    외공/무력 ×1.2, 전투 빈발
Afternoon(오후) 신시~유시       15~19시    지적 활동/연마 ×1.2
Evening(황혼) 술시~해시         19~23시    관계 형성 최적, 피로 회복 시작
Night(심야)   자시~축시         23~03시    수면(기본), 사파 무공 ×1.3

1 tick = 1 시간대. 6 tick = 1일. 2160 tick = 1년(360일).
```

#### 시간대별 분위기와 최적 행동

```
시간대       최적 행동          보조 행동            분위기
─────────────────────────────────────────────────────
Dawn       ③수련(내공)       ②탐색(새벽 산책)     고요, 집중
Morning    ②탐색 ⑤거래      ①대화(정보 수집)     활기, 바쁨
Midday     ③수련(외공) ④전투 ②탐색(위험지역)     뜨거움, 긴장
Afternoon  ③수련(지적) ⑤거래 ①대화(전략 상담)    차분, 사색
Evening    ①대화(관계)       ⑤거래(암시장)        따뜻함, 여운
Night      수면(기본)        ③수련(사파) ②탐색    어둠, 비밀
```

#### 하루의 감정 곡선

```
긴장

 │          ⚔              ⚡
 │         전투           플래시백
 │        ╱    ╲         ╱

 │  ╱     획득     ╲╱

 ├──────┬──────┬──────┬──────┬──────┬──→
```

#### 세션 루프 설계 원칙

| 원칙 | 설명 |
|------|------|
| 선택의 기회비용 | 하루 6시간대. 수련하면 탐색 못 한다. 매일 의미 있는 결정. |
| NPC도 하루를 보낸다 | 플레이어가 수련하는 동안 소연은 정보를 모으고, 명경은 약초를 캔다. |
| 밤은 무의식의 시간 | 플래시백, 악몽, 도청, 암습 — 낮의 선택이 밤의 결과를 만든다. |

### 2.4 장기 루프 — 4막 구조

게임 전체는 기승전결 4막으로 구성된다. 총 게임 내 시간 약 3~4년(17세→20~21세), 실제 플레이 약 40~70시간.

#### 제1막: 자유도시 (起) — "나는 누구인가"

```
기간: 게임 내 1~3개월 | 플레이 5~10시간 | 17세

  ⓐ 세상과의 첫 접촉
     · 소연과의 만남 (첫 NPC, 가이드)
     · 자유도시의 규칙 학습
     · 기본 생존: 돈 벌기, 정보 모으기

  ⓑ 과거의 그림자
     · 플래시백 발동 (매화 문양)
     · 혈매화검에 반응하는 사람들
     · 정체 위기: "넌 화산파 생존자야?"

  ⓒ 첫 번째 선택
     · 소연: "같이 과거를 파헤치자"
     · 명경: "내게 배워라"
     · 또는: "나는 여기서 그냥 살겠다"

  1막의 끝: 자유도시 밖으로 나가야 할 이유가 생긴다
```

#### 제2막: 강호 (承) — "세상은 내가 생각한 것보다 넓다"

```
기간: 게임 내 6개월~2년 | 플레이 15~30시간 | 17~19세

  ⓐ 칠국 탐험 — 7개 국가의 문화, 갈등을 체험
  ⓑ 관계망 확장 — 주요 NPC 9인과 관계 형성
  ⓒ 성장과 선택 — 문파 가입 or 독립 or 비전투 경로
  ⓓ 진실의 조각들 — 피의 실종 + 붉은 밤 단서 수집

  2막의 끝: 두 진실이 하나로 연결된다는 발견
  "피의 실종과 화산파 멸문, 그 뒤에 같은 사람이 있다"
```

#### 제3막: 폭풍 (轉) — "모든 것이 뒤집힌다"

```
기간: 게임 내 6개월~1년 | 플레이 10~20시간 | 19~20세

  ⓐ 진실의 충격 — 전모 드러남, 선과 악의 경계 흐려짐
  ⓑ 관계의 시험 — 배신, 화해, 이별, 재회
  ⓒ 세계의 위기 — 칠국 전쟁 위기, 혈교 잔당 활동
  ⓓ 최종 선택의 기로 — 조고 추적? 혈교 저지? 중재? 떠남?

  3막의 끝: "사슴과 말" — 조고와의 최종 대면 설정
```

#### 제4막: 춘추 (結) — "나의 이야기를 쓴다"

```
기간: 게임 내 1~3개월 | 플레이 5~10시간 | 20~21세

  ⓐ 최종 결전 — 조고 처단/설득/방치
  ⓑ 관계의 결실 — 각 NPC 최종 귀결
  ⓒ 플레이어의 정체성 — 能/性/信 최종 수치가 엔딩 결정
```

#### 엔딩 분기 구조

3축 조합으로 결정:

| 축 | 선택지 |
|----|--------|
| 조고 처리 | 처단 / 설득 / 방치 / 동맹 |
| 칠국 판도 | 통일 / 평화 공존 / 전쟁 지속 / 새 질서 |
| 개인 관계 | 연인과 함께 / 혼자 / 사제 계승 / 강호 방랑 |

핵심 엔딩 후보:

| 엔딩 | 조건 개요 | 한 줄 |
|------|----------|-------|
| 🌅 협객의 길 | 조고 처단 + 평화 + 방랑 | "검 하나 들고 강호를 떠도는 협객이 되었다" |
| 🏯 왕좌의 그림자 | 조고 제거 + 새 질서 + 지도자 | "아이들이 부순 세상을, 아이들이 다시 세웠다" |
| 💔 비극 | 진실의 대가가 너무 큼 | "알지 말았어야 할 진실이었을까?" |
| 🌸 일상으로 | 강호 떠남 + 평범한 삶 | "검을 내려놓고, 작은 차관을 열었다" |
| 🔥 계승 | 사부 계승 + 문파 재건 | "화산파는 멸문당했지만, 그 정신은 살아있다" |
| 🌑 어둠 | 조고 동맹 or 혈교 수용 | "이 세상이 준 상처를, 세상에 돌려주겠다" |
| 📖 미완 | 메인 퀘스트 포기 | "이야기는 아직 끝나지 않았다" |

#### 장기 루프 설계 원칙

| 원칙 | 설명 |
|------|------|
| 기다려주지 않는 세계 | NPC에게 시간 제한이 있다. 명경의 수명, 소연의 위험, 조고의 계획. |
| 돌아올 수 없는 선택 | 각 막의 끝에 되돌릴 수 없는 선택. 리플레이 가치 창출. |
| 성장의 실감 | 1막의 겁먹은 소년이 4막에서 강호를 바꾸는 인물이 되는 과정 체감. |
| 나의 이야기 | "맞는 엔딩" "틀린 엔딩"이 아니라 "나의 선택이 만든 이야기". |
