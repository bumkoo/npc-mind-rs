OCC · Action 분기 行爲

"누군가가 무엇을 했음." 행위자가 자기 자신인지 타인인지에 따라 귀인(Attribution) 감정이 갈린다. 타인 행동에만 관계 배율이 곱해진다.

1입력 설정값 — ActionFocus

domain/emotion/situation.rs · struct ActionFocus

필드타입의미작가 입력?
praiseworthinessf32−1.0 비난 ~ +1.0 칭찬✅ 작가
agent_idOption<String>None = 자기 자신, Some = 타인✅ 작가
modifiersOption<RelationshipModifiers>행위자와의 관계 배율. 자기 행동·대화 상대=행위자면 None(→ dialogue_modifiers fallback), 제3자 행위자면 Some❌ 호출 측
modifiers는 작가 입력이 아니다 작가가 쓰는 ActionInput에는 modifiers 필드가 없다(description·agent_id·praiseworthiness 3개뿐). ActionInput::into_domain이 받는 agent_modifiers 인자가 그대로 ActionFocus.modifiers로 들어간다. 자기 행동이면 None(관계 무의미), 타인 행동이면 호출 측(MindService)이 그 행위자 관계 배율을 채운다.

※ Event의 modifiers는 EventFocus 최상위가 아니라 desirability_for_other 안에 중첩되며, 그쪽은 Option이 아니라 필수(없으면 에러 거부)다 — Action과 정반대.
agent_id 정규화 (DTO 경계) 시나리오 JSON은 자연스럽게 agent_id: npc_id로 쓴다. 그러나 OCC 엔진에서 자기 행동은 agent_id == None 규약이다. 그래서 ActionInput::into_domain에서 agent_id == npc_id이면 None으로 자동 정규화한다. 이 처리가 없으면 Pride/Shame이 Admiration/Reproach로 잘못 분류된다.

2생성 감정 · 강도

agent_id생성 감정 (부호)강도 공식
None · 자기 행동pw>0 Pride / pw<0 Shame|pw| × pw_weight(self) × 1.0
Some · 타인 행동pw>0 Admiration / pw<0 Reproach|pw| × pw_weight(other) × (intensity_mult × trust_mod)
관계 배율 타인 행동에만 modifier = intensity_multiplier × trust_modifier가 곱해진다. 같은 비난받을 행동이라도 신뢰하던 자가 했을 때 Reproach가 더 크다. 자기 행동(Pride/Shame)은 상대 관계와 무관하므로 modifier=1.0 고정. 제3자 행동이면 action.modifiers(Some)를, 대화 상대 행동이면 dialogue_modifiers를 쓴다.

3무협 워크드 예시

weight=1.0 가정.

신뢰하던 사형제가 나를 밀고했다 (타인 · 비난)

agent_id=Some, pw=−0.8, trust_modifier=1.3, intensity_multiplier=1.0

Reproach = |−0.8| × 1.0 × (1.0 × 1.3) = 1.04 → clamp 시 1.0
곽정이 스스로 비겁한 짓을 했다 자책 (자기 · 비난)

agent_id=None, pw=−0.6

Shame = |−0.6| × pw_weight(self) × 1.0 // 관계 무관

4실제 코드

▸ appraisal/action.rs — appraise() domain/emotion/appraisal/action.rs 
pub fn appraise<P: AppraisalWeights>(p: &P, state: &mut EmotionState,
    dialogue_modifiers: &RelationshipModifiers, action: &ActionFocus) {
    let pw = action.praiseworthiness;
    let ctx = &action.description;

    match (&action.agent_id, &action.modifiers) {
        (None, _) => {
            // 자기 행동 (Pride, Shame)
            let w = p.praiseworthiness_weight(true, pw);
            add_valence(state, EmotionType::Pride, EmotionType::Shame,
                        pw, w, 1.0, ctx);
        }
        (Some(_), mods) => {
            // 타인 행동 (Admiration, Reproach)
            let mods = mods.as_ref().unwrap_or(dialogue_modifiers);
            let w = p.praiseworthiness_weight(false, pw);
            let modifier = mods.intensity_multiplier * mods.trust_modifier;
            add_valence(state, EmotionType::Admiration, EmotionType::Reproach,
                        pw, w, modifier, ctx);
        }
    }
}
