관계 반영

"관계"는 감정에 두 번 관여한다 — ① 감정 발생 시 modifier로 증폭/억제하고, ② 발생한 감정이 다시 관계 4축을 갱신한다. 둘은 완전히 다른 메커니즘이라 분리해 본다.

두 개념을 혼동하지 말 것 (A) modifier 산출 = Relationship::modifiers() — affinity·trust → 4 배율 (1단계로 투입)
(B) 4축 갱신 = update_axes_from_emotion — 감정 → 관계 변동 (6단계 산출)

1(A) modifier 산출

domain/relationship/mod.rs · Relationship::modifiers()

1단계 공식의 modifier는 여기서 나온다. affinity와 trust 두 축만 쓴다(respect·wariness 미사용). ±100 raw 값에 1/100 스케일 튜닝 가중치를 직접 곱한다.

필드산식튜닝 상수 (default)곱해지는 분기
intensity_multipliermax(0, 1 + affinity × w)0.005타인 행동(Admir./Reproach)
trust_modifier1 + trust × w0.003〃 (intensity와 곱)
empathy_modifiermax(0, 1 + affinity × w)0.003HappyFor / Pity
hostility_modifiermax(0, 1 − affinity × w)0.003Resentment / Gloating
부호의 묘 hostility만 1 − affinity×w다. 그래서 적대 관계(affinity 음수)면 −(−affinity)가 양수가 되어 hostility_modifier > 1 → 시기·고소함이 증폭된다. 반대로 친밀(affinity 양수)이면 hostility < 1로 억제. 중립(0)이면 4필드 전부 1.0.
affinity=+80(친밀), trust=+50 · affinity=−80(원수)
친밀: intensity = 1+80×0.005 = 1.40 · empathy = 1+80×0.003 = 1.24 · hostility = 1−80×0.003 = 0.76 원수: intensity = 1−80×0.005 = 0.60 · empathy = 0.76 · hostility = 1+80×0.003 = 1.24 trust_mod = 1 + 50×0.003 = 1.15
Phase 2.5 검토 예정 · 개선 계획 현 modifiers()는 affinity·trust 2축만 사용 — respect·wariness는 (B) 4축 갱신엔 쓰이나 modifier 산출엔 미반영(설계 근거 문서 부재, 코드 구조에서 역추론). 로드맵 §5 Phase 2.5 RelationshipModifiers 정밀화에서 검토 예정:
  • ① trust_modifier .max(0.0) 보정 — 4필드 중 유일하게 하한 클램프 없음(부호 반전 가능). 동작 불변·저위험 → 우선
  • ② 상한 clamp 도입 — personality weight [0.5,1.5]와 대칭. 폭주 방어 → 우선
  • ③ respect_modifier 신설 — Admiration/Reproach가 존경과 직결되나 미반영(서사 정합) → spec 확정 후
  • ④ wariness 되먹임 — 경계 누적→Reproach 증폭. 단 양의 피드백 루프라 안정화 장치(감쇠·히스테리시스) 동반 필수 → spec 확정 후
①②는 로드맵 사각지대의 신규 부채(Phase 2.3 종결 후 발견), ③④는 로드맵이 이미 가리키는 Phase 2.5 예정 작업.

2(B) 감정 → 4축 갱신

domain/relationship/mapping.rs · update_axes_from_emotion()

mapping.rs 4축 변동 = base_delta(감정) × 강도 × hexaco_modifier(감정, HEXACO)

흐름: ① BondStatus 차단(사망/해소/휴면이면 즉시 종료) → ② base_delta 48셀 lookup → ③ 강도·HEXACO 곱 → ④ apply_delta (4축 자동 clamp).

base_delta — 12 OCC 명시 + 10 default

4축 = trust / affinity / respect / wariness. Well-being·Prospect·Remorse·Gratification 10종은 의도적으로 0(B-D14).

"부정 감정" 분류의 비대칭 A− Forgiveness 룰의 "부정 감정"은 OCC valence가 아니라 base_delta의 affinity 부호 기준이다. 그래서 Pity는 OCC상 부정 반응이지만 affinity +10이라 제외된다 — "인색한 사람의 동정심 증폭"이라는 서사 모순을 피하기 위함(회고 §W2).

3무협 워크드 예시 — 임충 산신묘

임충이 육겸의 음모를 듣고 Anger 0.95 (단위 테스트 실제값)

입력 관계: trust 50 · affinity 40 · respect 30 · wariness 5
임충 HEXACO: Sincerity 0.7 / Forgiveness −0.7 / Prudence 0.8 → modifier 3단 적용: ×1.2(trust) → ×1.5(전역, Anger 부정) → ×0.8(전역)

modifier = { trust 1.44, affinity 1.2, respect 1.2, wariness 1.2 } trust : −25 × 0.95 × 1.44 = −34.2 → 50−34.2 = 15.8 affinity : −10 × 0.95 × 1.2 = −11.4 → 40−11.4 = 28.6 respect : 0 × … = 0 → 30.0 wariness : +25 × 0.95 × 1.2 = +28.5 → 5+28.5 = 33.5

한 번의 분노가 신뢰를 절반으로 깎고 경계심을 6배로 끌어올린다. 이 값이 다시 modifiers()로 들어가 다음 대화의 감정 강도를 바꾼다 — 루프가 닫힌다.

BondStatus 게이트 상대가 사망(Deceased)·관계 해소(Resolved)·휴면(Dormant)이면 accepts_live_input()가 false → 감정이 아무리 커도 4축은 변동하지 않는다. Active·Reactivating만 통과. 또한 Pride/Shame는 자기 감정이라 호출 측에서 별도 가드(B-D12).

▸ mod.rs — Relationship::modifiers() domain/relationship/mod.rs 
pub fn modifiers(&self) -> RelationshipModifiers {
    let affinity = self.affinity.value();  // ±100 raw
    let trust = self.trust.value();
    let p = profile();
    RelationshipModifiers {
        intensity_multiplier: (1.0 + affinity * p.rel_affinity_intensity_weight).max(0.0),
        trust_modifier:        1.0 + trust * p.rel_trust_emotion_weight,
        empathy_modifier:     (1.0 + affinity * p.rel_affinity_empathy_weight).max(0.0),
        hostility_modifier:   (1.0 - affinity * p.rel_affinity_hostility_weight).max(0.0),
    }
}
▸ mapping.rs — update_axes_from_emotion() + hexaco_modifier domain/relationship/mapping.rs 
pub fn update_axes_from_emotion(rel: &mut Relationship,
    emotion: EmotionType, intensity: f32, hexaco: &HexacoProfile) {
    if !rel.bond_status().accepts_live_input() { return; }   // 게이트

    let base = base_delta(emotion);
    let m = hexaco_modifier(emotion, hexaco);
    let delta = AxisDelta {
        trust:    base.trust    * intensity * m.trust,
        affinity: base.affinity * intensity * m.affinity,
        respect:  base.respect  * intensity * m.respect,
        wariness: base.wariness * intensity * m.wariness,
    };
    rel.apply_delta(&delta);   // 4축 자동 clamp
}

// hexaco_modifier 핵심 룰 (임계 0.5)
if hexaco.honesty_humility.sincerity.value() > 0.5 {
    m = m.scale_axis(AxisKind::Trust, 1.2); }
if hexaco.agreeableness.forgiveness.value() < -0.5
   && is_negative_emotion(emotion) {
    m = m.combine_uniform(1.5); }
if hexaco.conscientiousness.prudence.value() > 0.5 {
    m = m.combine_uniform(0.8); }
