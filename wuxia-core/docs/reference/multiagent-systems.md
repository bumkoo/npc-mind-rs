# 멀티에이전트 시스템 설계 핵심 요약 (칠국춘추 참조)

> 원본: Michael Albada "Building Applications with AI Agents"
> 목적: 칠국춘추 NPC 오케스트레이션, 통신 프로토콜, 도구 선택 참조

---

## 1. 에이전트 아키타입 비교

| 유형 | 강점 | 약점 | 칠국춘추 적용 |
|---|---|---|---|
| Reflex | 밀리초 응답 | 다단계 추론 불가 | NPC 즉각 반응 (공격 회피) |
| ReAct | 유연한 적응 | 높은 지연/비용 | NPC 탐색적 행동 |
| Plan-Execute | 명확한 분해 | 계획 오버헤드 | NPC 일과 계획 |
| Query-Decomposition | 검색 정확도 | 다중 도구 호출 | NPC 정보 수집 |
| Reflection | 오류 조기 감지 | 추가 컴퓨팅 | NPC 성찰 시스템 |
| Deep Research | 복잡한 조사 | 매우 높은 비용 | 사용 안함 |

## 2. 도구 선택 전략 (Tool Selection)

### 2.1 표준 도구 선택
- LLM에 모든 도구 정의를 제공 → 모델이 적절한 도구 선택
- 단순하지만 도구 수 증가 시 확장성 저하

### 2.2 시맨틱 도구 선택
- 도구 설명을 임베딩 → 쿼리와 유사도로 후보 선정
- 확장성 좋지만 시맨틱 충돌 가능

### 2.3 계층적 도구 선택
- 도구를 카테고리로 그룹화 → 단계적 선택
- 대규모 도구셋에 적합하지만 다단계 LLM 호출 필요

### 칠국춘추 적용
```
NPC 도구 카테고리:
├── 전투 도구: 공격, 방어, 무공 사용, 도주
├── 사회 도구: 대화, 거래, 정보 수집, 동맹 제안
├── 이동 도구: 장소 이동, 탐색, 추적
└── 성장 도구: 수련, 독서, 명상, 사사
```

## 3. 통신 아키텍처

### 3.1 로컬 vs 분산 통신
- **로컬**: 인메모리 메시지 패싱 (단일 프로세스)
- **분산**: 비동기, 장애 허용 필수

### 3.2 A2A (Agent-to-Agent) 프로토콜
```
Agent Card (에이전트 카드):
{
  "identity": "남궁혁",
  "capabilities": ["검술대련", "제자훈련", "정보수집"],
  "schemas": { ... },
  "endpoint": "local://npc/namgunghyuk",
  "version": "1.0"
}
```
- 에이전트가 자신의 능력을 선언 → 다른 에이전트가 발견/협상

### 3.3 MCP (Model Context Protocol)
- JSON-RPC 2.0 기반
- 서버가 사용 가능한 메서드 목록 공개 → 클라이언트(LLM)가 적절한 메서드 선택
- 도구 재사용: 한 번 MCP로 노출하면 모든 에이전트가 사용 가능

### 칠국춘추 NPC 간 통신 모델
```
┌─────────┐     메시지 큐      ┌─────────┐
│ NPC A   │ ──────────────►  │ NPC B   │
│ (남궁혁) │                   │ (소연)   │
└─────────┘     ◄──────────── └─────────┘
                 응답

통신 유형:
1. 직접 대화 (근접 시)
2. 전서구/서신 (원거리)
3. 소문/평판 (간접 전파)
```

## 4. 오케스트레이션 패턴

### 4.1 도구 실행 체인
```
도구A 결과 → 도구B 입력 → 도구B 결과 → 도구C 입력
```
예: NPC가 적 탐색 → 위치 확인 → 이동 → 대화 시도

### 4.2 병렬 도구 실행
```
      ┌─ 도구A ─┐
입력 ─┤         ├─ 결과 통합
      └─ 도구B ─┘
```
예: NPC가 동시에 주변 감시 + 대화 진행

### 4.3 그래프 기반 실행
- 조건부 분기, 루프, 병합이 가능한 DAG 구조
- 복잡한 NPC 행동 시나리오에 적합

## 5. 에이전트 그룹화 전략

### 전문 에이전트로 분리하는 기준:
1. 도구가 5~10개 이상일 때
2. 도구가 서로 다른 도메인에 속할 때
3. 특정 도구 조합이 자주 함께 사용될 때

### 칠국춘추 NPC 에이전트 그룹화
```
무인(武人) 에이전트: 전투 + 무공수련 도구
상인(商人) 에이전트: 거래 + 정보 + 이동 도구
관원(官員) 에이전트: 정치 + 조사 + 명령 도구
협객(俠客) 에이전트: 전투 + 사회 + 탐색 도구 (가장 복잡)
```

## 6. 안전성과 신뢰성

### 에이전트 내부 실패 방어
- 입력 검증 → 실행 모니터링 → 출력 검증 → 폴백 처리
- 에이전트 행동 제약(guardrails) 설정

### 칠국춘추 적용
- NPC 행동 범위 제한: 성격/신념에 반하는 행동 차단
- 게임 규칙 위반 방지: 무공 레벨 초과 행동 차단
- 대화 안전 필터: 게임 세계관에 맞지 않는 발언 차단
