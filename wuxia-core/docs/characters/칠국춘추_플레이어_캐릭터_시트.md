## 2. 연표 대입 (열전)

### ▸ 12년 전 (5세) — 피의 실종 사건

낙양 지하에서 혈교에 의해 납치됨. 황제(태무제)의 수명 연장 실험 대상. 혈교의 약물에 짧은 기간 노출되었으나, 5세의 어린 나이였기에 효과가 다른 방식으로 발현됨 (혈맥 공명의 기반).

개방 거지들의 구출 작전으로 탈출. 구출 직후, 아이를 보호하던 개방 거지가 화산파 제자 임서운(林書雲)에게 아이를 맡김. "이 아이를 부탁한다. 우리는 여기서 막겠다." 직후 십상시가 개방을 학살.

### ▸ 12~10년 전 (5~7세) — 화산파에서의 2년

화산파 말단 제자 임서운이 아이를 데리고 화산(華山)으로 돌아감. 비공식적으로 양육. 이 시기에 혈매화검을 처음 접함 — 화산파 보물이 아닌, 임서운 개인의 검. 아이는 화산파 생활을 희미하게 기억하나, 정식 제자가 아니었으므로 무공 수련 경험은 거의 없음.

> ⚠ **설정 의도 (플레이어 오인식)**: 플레이어는 임서운을 "말단 제자"로 기억한다. 실제로는 추양진인의 수제자. 7세 아이의 시점에서 직위를 알 수 없었기 때문. 게임 진행 중 화산파 진상 조사 퀘스트에서 "그 사람이 사실은..."이라는 반전으로 드러남. → `history-characters` §12 참조.

### ▸ 10년 전 (7세) — 붉은 밤의 변

화산파 멸문. 임서운이 아이를 혈매화검과 함께 화산 뒤편으로 도망시킴. "살아야 한다. 이 검을 가지고 가라." 이후 행방불명. (⚠ 플레이어는 사망으로 인식. 실제 생사 불명 — `history-characters` 참조) 아이 혼자 산을 내려옴.

### ▸ 10~5년 전 (7~12세) — 떠돌이 생활

혼자 떠돌며 생존. 최종적으로 자유도시 근처에 정착. 빈민가에서 자라남. 검술이 아닌 생존술을 배움. 혈매화검은 유일한 소지품이자 유일한 연결고리.

### ▸ 5년 전 (12세) — 칠국 독립, 자유도시 탄생

무법지대에서 나름의 질서가 생김. 플레이어는 자유도시 하층민으로 안착.

### ▸ 현재 (17세) — 게임 시작

자유도시 뒷골목에서 아침을 맞음. 소연(23)과 첫 만남. 새벽(Dawn) 시간대. 피로 20, 부상 없음.

## 3. 기억의 구조 (기억상실이 아님)

플레이어는 기억상실이 아니다. 5세와 7세 아이의 불완전한 기억이 감각 조각으로 남아있는 것이다.

### ▸ 5세 기억 (피의 실종)

| 구분 | 내용 |
|------|------|
| 기억되는 것 | 어두운 지하, 축축한 냄새 |
| 기억되는 것 | 다른 아이들의 울음소리 |
| 기억되는 것 | 누군가의 손이 나를 끌어냄 |
| 기억되는 것 | "도망쳐!" 하는 외침 |
| 모르는 것 | 그곳이 낙양이었다는 것 |
| 모르는 것 | 혈교의 실험이었다는 것 |
| 모르는 것 | 개방이 구해줬다는 것 |
| 모르는 것 | 소연도 거기 있었다는 것 |

### ▸ 7세 기억 (붉은 밤의 변)

| 구분 | 내용 |
|------|------|
| 기억되는 것 | 산 위의 집이 불탔다 |
| 기억되는 것 | 검을 쥐어주며 "살아야 한다" |
| 기억되는 것 | 그 사람(임서운)의 얼굴 |
| 기억되는 것 | 혼자 산을 내려온 것 |
| 모르는 것 | 그곳이 화산파였다는 것 |
| 모르는 것 | 왜 멸문당했는지 |
| 모르는 것 | 임서운이 왜 자기를 돌봐줬는지 |
| 모르는 것 | 혈매화검의 의미 |

### ▸ 플래시백 메카닉 (서사 + 심리 도메인 연동)

특정 장소/인물/아이템을 만날 때 플래시백 발동:

| 트리거 | 플래시백 내용 | 도메인 이벤트 |
|--------|-------------|--------------|
| 낙양 지하 방문 | 5세 기억 조각 되살아남 | NarrativeEvent::FlashbackTriggered |
| 화산 방문 | 7세 기억 되살아남 | NarrativeEvent::FlashbackTriggered |
| 소연의 납치 이야기 청취 | "... 나도 비슷한 기억이..." | PsychologyEvent::EmotionChanged |
| 혈교 관련 아이템 발견 | 몸이 반응 (혈맥 공명 전조) | GrowthEvent::BloodResonanceHint |
| 명경의 비약 접촉 | 5세 납치 시 투약된 약물 기억 | PsychologyEvent::EmotionChanged |

## 4. 내면 갈등 (Core Conflict)

### ⚔ 플레이어의 딜레마

| 과거를 파헤쳐야 하는가 | vs | 지금의 삶을 살면 되지 않는가 |
|:---:|:---:|:---:|

**과거를 파헤쳐야 하는가:**
- 5세의 지하, 7세의 불꽃
- 알면 알수록 위험해진다
- 혈교가 나를 다시 찾을 수 있다
- 진실을 알면 복수해야 하는가?

**지금의 삶을 살면 되지 않는가:**
- 자유도시에서 그냥 살 수도 있다
- 검을 팔고 장사를 시작할 수도
- 과거를 모르는 게 더 안전하다
- 하지만 플래시백이 멈추지 않는다

> ➤ "기억을 되찾는 것이 자유인가, 족쇄인가?" — 플레이어의 선택이 답을 만든다

### ▸ 4인의 청년 캐릭터 공명 구조

| 캐릭터 | 나이 | 과거 | 핵심 질문 |
|--------|------|------|----------|
| 플레이어 | 17 | 5세 납치, 7세 멸문 목격 | 과거를 파헤칠 것인가, 묻을 것인가 |
| 소연 | 23 | 11세 납치, 구출자 사망 목격 | 복수할 것인가, 놓을 것인가 |
| 야율설화 | 17 | 12세 볼모로 보내짐 | 아버지의 딸일 것인가, 나일 것인가 |
| 명경 | 49 | 19세 황제를 살림 | 행동할 것인가, 지킬 것인가 |

**공통 테마: "어른들의 전쟁에서 살아남은 아이들이, 이제 자기 이야기를 쓰기 시작한다"**

## 5. 혈맥 공명 (血脈共鳴) — 숨겨진 메카닉

혈교의 실험 흔적으로 인해 플레이어의 몸에 잠재된 특수 능력. 위험하지만 강력한 양날의 검.

| 항목 | 내용 |
|------|------|
| 발동 조건 | 극단적 감정 상태 + 전투 또는 수련 중 |
| 효과 | 일시적 육체 능력치 ×1.5 (1시간대) |
| 대가 | 발동 후 피로 +30, 부상 위험 |
| 위험성 | 사용할수록 혈교의 흔적 활성화 → 당무괴/혈교가 감지 → 추적당함 |
| 플레이어 선택 | "이 힘을 쓸 것인가, 봉인할 것인가" |
| 봉인 도움 | 명경(아미파)이 의술로 봉인/제어 가능 |
| 성장 도메인 연동 | 기연 시스템의 감정(④) 조건과 연결 |

### ▸ 소연과의 차이

- **소연 (11세, 6년 노출):** 피에 특수 성분. 타인이 원하는 자원. → 위협의 대상
- **플레이어 (5세, 짧은 노출):** 몸 자체에 발현. 자기 자신이 위험. → 선택의 대상

## 6. 能/性/信 초기값 (17세, 수련 경험 없음)

### ▸ 能(능) — 성장 도메인

| 범주 | 능력 | 수치 | 특이사항 |
|------|------|:----:|----------|
| 지적 | 내공 | 5 | 수련한 적 없음 |
| 지적 | 지혜 | 25 | 10년 생존으로 체득한 세상물정 |
| 지적 | 책략 | 30 | 빈민가 생활에서 배운 눈치 |
| 육체 | 체력 | 45 | 절대 값은 낮으나 나이 대비 양호 |
| 육체 | 경공 | 40 | 도망/회피 경험 |
| 육체 | 무력 | 35 | 정식 무공 없이 체득한 싸움 |
| 감정 | 의지 | 50 | 상대적으로 높음 — 10년 혼자 살아남은 생존력 |

**특징:** 전체적으로 낮으나, 의지가 상대적으로 높음. 정식 수련 없이 빈민가에서 체득한 육체 능력. 내공은 거의 없음.

### ▸ 性(성) — 심리/성격 Aggregate

| 성격 축 | 수치 | 해석 |
|---------|:----:|------|
| 개방성 | 0.6 | 낯선 것에 경계하면서도 호기심 |
| 성실성 | 0.5 | 생존에 필요한 만큼만 |
| 외향성 | 0.4 | 혼자 지내는 데 익숙하나 외롭 |
| 친화성 | 0.5 | 사람을 믿고 싶지만 쉽게 못 믿음 |
| 신경증 | 0.6 | 과거 트라우마, 밤에 악몽 |

### ▸ 信(신) — 심리/가치관 Aggregate (빈 캔버스)

| 가치관 | 수치 | 해석 |
|--------|:----:|------|
| 충 (忠) | 0.3 | 충성할 대상이 아직 없음 |
| 의 (義) | 0.5 | 의리의 개념은 있으나 시험받은 적 없음 |

## 8. 대화 시스템 — 선택지 + 자유 입력

NPC와의 대화에서 플레이어는 선택지(A/B/C/D)를 고를 수도 있고, 직접 텍스트를 입력할 수도 있다.

### ▸ 예시: 소연과의 첫 만남

```
소연: "그 검, 꽤 값나가겠네. 팔 생각 없어?"

  A. "팔 수 없다."
  B. "얼마 줄 건데?"
  C. "넌 누구야?"
  D. (검에 손을 올린다)
  E. [직접 입력: ________________]
```

- 선택지는 가이드라인
- 자유 입력은 LLM NPC의 강점을 살리는 통로
- NPC의 LLM이 플레이어 입력에 성격/가치관/관계 수치에 맞춰 실시간 반응 생성

## 9. 메인 퀘스트 구조 — 두 개의 진실

플레이어의 과거가 두 사건에 걸쳐있으므로, 메인 퀘스트도 두 가닥으로 진행된다.

|  | 진실 1: 피의 실종 사건 | 진실 2: 붉은 밤의 변 |
|--|----------------------|---------------------|
| **핵심 질문** | 황제의 수명 연장 실험의 진짜 목적은? | 화산파는 왜 멸문당했는가? |
| **관련 NPC** | 소연, 조고, 당무괴, 혈교 | 명경, 남궁혁, 조고 |
| **플레이어 관계** | 직접 피해자 | 보호받은 자 |
| **탐색 방법** | 소연과 공동 조사, 낙양 지하 탐색 | 화산 방문, 명경의 증언 |
| **반전** | 두 사건이 하나의 음모로 연결되어 있음 | ← 동일 |

플레이어는 메인 퀘스트를 추적할 수도, 무시하고 상인/무인/탐험가 등 다른 삶을 선택할 수도 있다. 하지만 플래시백은 멈추지 않는다.
