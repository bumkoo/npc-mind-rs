## 개요
동해 진씨 상방 당주. character-roster N9 우선순위 ★★★. H20 진해(陳海)의 직계 고손자
로 진씨 270년 상업 가문의 현세대 수장. 자본·정보·외교의 삼각 능력자이며 동해 연방
경제 축. 8년 전 개방 장로 소풍자(npc-11)로부터 소연(npc-05, 당시 15세)을 정보원으로
고용한 점이 게임 서사의 직접 단서. 본 .md는 character-roster + npc-05-soyeon.md의 깊은
묘사(8년 전 파견·표면/실체 이중 구조·진대인 시각의 소연 평가) 다중 출처에서 추론한
정밀 등급 매핑.

## 배경
약 217년차 출생. 진해(고조부)가 200년 전 동해 자치 조례 작성으로 동해 상방 기반을
다진 뒤 진씨 가문이 4대에 걸쳐 동해 경제를 장악. 진대인은 30대 중반에 가문 당주
즉위 + 동해 진씨 상방 확장. 5년 전 칠국 독립 흐름에 편승해 동해 연방 핵심 자본가
지위 확립. 8년 전(15세 시점의 소연) 개방 장로 소풍자(npc-11)로부터 소연을 정보원
으로 고용 — 본인 시점에선 "쓸 만한 도구를 키우는 것" + 사부의 부탁이라 거절 어려움.
실제 소연은 개방의 침투 요원으로 진씨 상방 정보망을 학습 중. 게임 시작 시점 53세,
동해 연방·자유도시·개방 세 축의 거래자.

## 동기
표층은 **상방 확장 + 칠국 경제 패권** — 자본가의 본분. 심층은 **진씨 가문 270년
명예 보존**. 효(0.7)가 가장 높은 가치이며 야망(0.7)과 동률 — 가문 명예 + 자기 야망이
같은 방향. 두려워하는 것은 (1) 진씨 가문이 평민화되는 것 (2) 정보망 통제 상실 — 특히
소연이 개방 침투 요원으로 발각될 경우 (3) 혈교 잔당 거래 의혹이 공식화되는 것.
직접 두려워하지 않는 것은 무공·전투 — 호위·자객 운용으로 대체.

## 비밀
1. **소연이 개방 침투 요원임**: 본인은 인지 단계 미상. 명시적으로 모르거나 의심
   상태. 발각 시 8년 거래 관계 파탄 + 개방-진씨 갈등 격화. 메인 퀘스트 분기.
2. **혈교 잔당 거래 의혹**: character-roster N24 "혈교 연구자" + N23 "혈교 잔당"
   라인과 연결. 당무괴(npc-04)의 혈교 비술 연구에 자본 제공 가능성. 본인 명확한
   기록 부재 — 거래 흔적 추적이 메인 퀘스트 단서.
3. **진씨 가문 270년 비밀**: 진해(고조부)가 200년 전 동해 자치 조례 작성 시 대진

   퀘스트의 후반 분기 변수.

## 게임에서의 역할
동해 연방 경제 축의 중심 NPC + 소연 분기의 한 축. 메인 퀘스트 단계:

1. **초반** — 자유도시 정보 거래 시 본 인물의 천이방(소연 운영) 통해 간접 등장.
   player는 진대인을 "동해 큰 손"으로 인지.
2. **중반** — 소연이 개방 침투 요원임이 본 인물에게 발각될 위기 시 분기 — (a) 폭로
   (b) 모르는 척 + 거래 유지 (c) 역이용 + 개방 통제. 셋 중 분기.
3. **후반** — 혈교 잔당 거래 의혹 추적 시 본 인물의 자본 흐름이 결정적 단서.
   당무괴 (npc-04) 비술 연구와의 연결고리 노출 가능.
