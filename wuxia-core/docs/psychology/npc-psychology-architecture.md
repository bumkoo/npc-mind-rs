## 1. 개요 — 7층 아키텍처

NPC의 내면은 7개 층으로 구성된다. 위로 갈수록 안정적이고, 아래로 갈수록 빠르게 변한다. 성찰(⑦)이 모든 층을 재평가하는 메타 층이다.

```
  ┌─────────────────────────────────────────────────────────┐
  │              NPC 심리 아키텍처 v3 (HEXACO 통합)          │
  │                                                          │
  │  ━━━ 거의 변하지 않는 층 ━━━━━━━━━━━━━━━━━━━━━━━━━━━   │
  │                                                          │
  │  ① 성격 (HEXACO)                                        │
  │     H/E/X/A/C/O = 행동 패턴의 기질적 토대               │
  │     변화: Tier4에서만, ±5 제한, 최대 2요인               │
  │     나이 drift: 없음 (성격은 경험으로만 변한다)          │
  │                                                          │
  │  ━━━ 천천히 변하는 층 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   │
  │                                                          │
  │  ② 3축 가치관 (믿음/옳음/바람)                           │
  │     각 축 = { 강도, 신조, 형성기억, 대안후보[] }          │
  │     = "이 사람이 어떤 존재인가" (LLM용 서사)             │
  │     변화:                                                │
  │       강도 — Tier1~2에서 ±5~10                           │
  │       신조 — Tier3~4에서만 전환 가능                     │
  │                                                          │
  │  ③ 5가치 (충/의/효/복수/야망)                            │
  │     = "구체적 상황에서 어떻게 판단하는가" (OCC용 수식)    │
  │     변화: Tier1~3에서 ±5~20                              │
  │                                                          │
  │  ━━━ 빠르게 변하는 층 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   │
  │                                                          │
  │  ④ 감정 (OCC 인지평가)                                   │
  │     사건 → 5가치 기준 평가 → 22종 감정 유발              │
  │     = "지금 무엇을 느끼는가"                             │
  │                                                          │
  │  ⑤ 기분 (PAD)                                           │
  │     감정 누적 → P/A/D 3차원 상태                         │
  │     = "전반적으로 어떤 상태인가" (렌즈 역할)             │
  │                                                          │
  │  ⑥ 행동 (Utility AI → LLM)                              │
  │     PAD + 성격 + 가치관 → 행동 범주 (코드)               │
  │     행동 범주 → 구체적 행동/대사 (LLM)                   │
  │                                                          │
  │  ━━━ 메타 층 (위 모든 것을 재평가) ━━━━━━━━━━━━━━━━━━   │
  │                                                          │
  │  ⑦ 성찰·계획 (Tier 1~4)                                 │
  │     = "돌아보고, 의미를 찾고, 다음을 계획한다"           │
  │     → ①~⑥ 모든 층에 역방향 영향                        │
  │                                                          │
  │  ━━━ 저장 층 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   │
  │                                                          │
  │  기억 스트림 (Memory Stream + LanceDB)                   │
  │     관찰/감정/성찰/계획 모두 기록                        │
  │     recency × importance × relevance로 검색              │
  │                                                          │
  │  관계 (Relationship) — 관계 도메인 소유                  │
  │     NPC↔NPC, NPC↔Player 감정/신뢰/적대                  │
  │                                                          │
  └─────────────────────────────────────────────────────────┘
```

**핵심 설계 원칙**:
- 코드는 ④⑤⑥을 담당한다 (수식 계산, <1ms, 결정적)
- LLM은 ⑥의 구체적 행동/대사 + ⑦성찰을 담당한다 (창의적, 가끔 호출)
- ②와 ③은 "같은 내면의 다른 표현"이다 (§5 참조)

## 2. ①층 성격 (HEXACO)

> "이 사람은 원래 어떤 사람인가" (性)

성격은 NPC의 가장 안정적인 층이다. 모든 하위 층에 필터 역할을 한다.

### 2.1 왜 BigFive에서 HEXACO로 변경했는가

> 📎 상세 내용: [bigfive-to-hexaco-migration.md](bigfive-to-hexaco-migration.md) §2~§3
>
> 핵심 요약: ① H(정직-겸손) 요인이 무협 서사의 의리/배신 갈등을 직접 표현, ② E/A 재편으로 두려움과 분노 분리 조절 가능, ③ ①층↔③층 연결이 자연스러워짐

### 2.2 HEXACO 6요인 정의

```
  요인                    범위       핵심 질문
  ──────────────────────────────────────────────────────────────
  H (정직-겸손,           0~100     "남을 이용하지 않고 공정한가?"
     Honesty-Humility)              높음: 공정, 겸손, 법규 준수
                                    낮음: 조작, 착취, 특권의식, 물욕

  E (정서성,              0~100     "자신과 가족의 안전에 민감한가?"
     Emotionality)                  높음: 두려움, 걱정, 공감, 애착
                                    낮음: 대담, 냉담, 독립적

  X (외향성,              0~100     "사회적으로 자신감 있고 활발한가?"
     eXtraversion)                  높음: 사교적, 자신감, 활력
                                    낮음: 내성적, 조용, 수줍음

  A (친화성,              0~100     "도발에 참을 수 있고 용서하는가?"
     Agreeableness)                 높음: 관용, 인내, 유연
                                    낮음: 분노, 원한, 고집, 비판적

  C (성실성,              0~100     "규율 있고 계획적인가?"
     Conscientiousness)             높음: 근면, 체계적, 신중
                                    낮음: 충동적, 무계획, 태만

  O (개방성,              0~100     "새로운 경험과 사고에 열린가?"
     Openness)                      높음: 창의적, 지적 호기심, 유연
                                    낮음: 관습적, 실용적, 보수적
```

### 2.3 BigFive와의 차이 — 무엇이 어떻게 이동했나

> 📎 상세 매핑 다이어그램: [bigfive-to-hexaco-migration.md](bigfive-to-hexaco-migration.md) §3~§4
>
> 핵심 요약: BigFive-N(신경증)이 불안→HEXACO-E, 분노→HEXACO-A로 분리. BigFive-A의 동정심→HEXACO-E로 이동. H(정직-겸손) 신규 추가. 글자 주의: BigFive-E(외향성) ≠ HEXACO-E(정서성).

### 2.4 H 요인과 무협 — ①층↔③층 연결

H(정직-겸손)는 무협 서사의 중심축인 "의리와 배신"의 기질적 토대다.

```
  H와 ③층 5가치의 관계:
  ──────────────────────────────────────────────
  H = 기질 ("이 사람은 원래 공정한 사람인가")
  충/의 = 경험 ("살면서 충성과 의리를 얼마나 내면화했나")

  둘은 독립적으로 움직인다:
  · H 높음 + 의 높음 = 명경 (본성도 공정, 경험도 의리)
  · H 높음 + 의 낮음 = "본성은 공정하나 배신당해 의리를 잃음"
  · H 낮음 + 의 높음 = "본성은 이기적이나 습관으로 의리를 지킴"
  · H 낮음 + 의 낮음 = 조고 (본성도 착취적, 경험도 비도덕)

  H가 높다고 선인은 아니다:
  · H 90 + 바람 90 "정의를 세우겠다" → 독선적 광신자도 가능
  · H 10 + 옳음 90 "힘이 정의다" → 조고처럼 확고한 악역
  → 방향(신조)은 ②층이 결정. H는 수단(공정/착취)의 성향만 표현.
```

**Low-H 인물 유형 가이드** (Lee & Ashton, Chapter 4):

```
  H↓ + E↓ = "탐욕+대담" → 조고 유형
             겁 없이 남을 착취, 냉혈, 권력 추구
  H↓ + E↑ = "비겁한 간신" → 위험은 피하면서 뒤에서 조작
  H↓ + X↑ = "나르시시스트" → 카리스마 있지만 자기과시
  H↓ + A↓ = "잔인한 폭군" → 착취적이고 분노도 격함
  H↑ + A↓ = "원칙적+불같은" → 공정하지만 도발에 참지 못함
  H↑ + E↑ = "의로운 걱정쟁이" → 공정하고 공감 강하지만 소심
```

### 2.5 하위 층에 대한 영향 (6요인 → OCC/행동 필터)

```
  H (정직-겸손) → 도덕적 감정 필터
    H 높음: 죄책감(Shame/Guilt) 증폭, 통쾌(Gloating) 억제
    H 낮음: 죄책감 억제, 남의 불행에 쾌감(Gloating) 증폭
    H 낮음: 배신을 목격해도 "나도 그랬을 것" → 도덕적 비난(Reproach) 약화

  E (정서성) → 두려움/공감 필터
    E 높음: Fear(두려움) 증폭, Pity(측은) 증폭, 애착 감정 강화
    E 낮음: 위험에도 두려움 약함, 타인 고통에 무감각
    Utility AI: E 높으면 flee 점수 증가, E 낮으면 fight 점수 증가

  X (외향성) → 감정 표현 강도
    X 높음: 같은 감정도 행동으로 더 크게 표출, 대화 개시 확률 증가
    X 낮음: 강한 감정도 내면에 담아둠
    Utility AI: X 높으면 negotiate/seek_ally 점수 증가

  A (친화성) → 분노/원한 조절
    A 높음: Anger(분노) 억제, 용서 점수 증가, 협상 선호
    A 낮음: 사소한 도발에도 즉각 분노, 원한 장기 유지
    Utility AI: A 높으면 negotiate 점수 증가, A 낮으면 fight 점수 증가

  C (성실성) → 감정 억제 + 계획 이행
    C 높음: 감정을 느끼되 행동에 덜 반영 (이성적), 계획 이행률 증가
    C 낮음: 감정이 바로 행동으로 연결 (충동적)

  O (개방성) → 복합 감정 + 신조 수용
    O 높음: 복합 감정(감은+수치 동시 등) 경험 가능, 새로운 신조 수용 확률 증가
    O 낮음: 단순 감정으로 귀결, 기존 신조 고수
```

### 2.6 변화 규칙

**핵심 원칙: 사람은 나이로 변하지 않는다. 겪은 일과 내린 선택으로만 변한다.**

```
  나이의 역할:
  · 나이 → 육체적 능력 변화 (성장 도메인: 체력, 경공, 무력 등)
  · 나이 → 성격 변화 없음 (심리 도메인: H/E/X/A/C/O)
  · 나이 drift: 6요인 전부 없음

  근거:
  · 성격 변화 연구(Roberts et al. 2006, Bleidorn et al. 2022)에서
    나이에 따른 변화의 원인은 "나이 자체"가 아니라
    "사회적 역할 변화"와 "감정 조절 전략 학습"
  · 무협 세계는 현대 사회와 환경이 근본적으로 다름
  · 자동 drift는 NPC 개성을 오히려 깎아먹음
    (나이든 NPC가 전부 비슷한 방향으로 이동하는 문제)
```

**성격이 변하는 유일한 경로: Tier 4 (인생 성찰)**

```
  조건:
  · Tier 4 (인생 성찰)이 트리거된 경우만
  · 코드가 ±5로 범위 제한 (clamp)
  · 한 번에 최대 2개 요인만 변경 가능
  · LLM이 "어떤 요인이, 어떤 방향으로, 왜" 결정

  제한 규칙:
  ┌──────────────────────────────────────────────────────┐
  │  1. Tier 1~3에서: 성격 변화 불가 (delta = 0)         │
  │  2. Tier 4에서: ±5 제한, 6요인 중 최대 2개만         │
  │  3. 나이 drift: 없음 (6요인 전부)                    │
  │  4. 어떤 경우에도 0~100 범위 clamp                   │
  └──────────────────────────────────────────────────────┘
```

**예시 — 서사적 의미**:

```
  진야림의 X(외향성) 변화:
  ┌──────────────────────────────────────────────┐
  │ 게임 시작:  X = 30  (과거 트라우마로 은둔)     │
  │                                              │
  │ 플레이어와 함께 여행하며                      │
  │ Tier 3급 사건 3회 누적 → Tier 4 트리거        │
  │                                              │
  │ LLM 성찰: "사람과 함께하는 게 나쁘지 않았다"  │
  │ → X += 5 → X = 35                            │
  │                                              │
  │ 이것이 10년간 3번 더 일어나면                  │
  │ → X = 35 → 40 → 45 → 50                      │
  │ = 은둔자가 조금씩 세상에 나오는 서사           │
  └──────────────────────────────────────────────┘

  조고의 H(정직-겸손)는 변하는가?
  ┌──────────────────────────────────────────────┐
  │ 게임 시작:  H = 10  (본질적으로 착취적)        │
  │                                              │
  │ 30년간 권력을 유지 → H는 변하지 않음           │
  │ (drift가 없으므로 나이 들어도 자동 상승 없음)  │
  │                                              │
  │ 플레이어가 조고에게 신뢰를 보이는 루트:        │
  │ Tier 4 성찰 → "이것이 신뢰라는 것인가"        │
  │ → H += 5 → H = 15 (극히 미미한 변화)          │
  │ = 극악인도 완전히 변하지는 않는다              │
  └──────────────────────────────────────────────┘
```

## 3. ②층 3축 가치관 (믿음/옳음/바람) + 신조

> "이 사람은 어떤 존재인가" — 서사적 정체성의 핵심

3축은 NPC의 근본적 존재 방식을 정의한다. 각 축은 강도(intensity) + 신조(creed) + 형성기억(formation memories) + 대안후보(candidates)로 구성된다.

### 3.1 축 정의

```
  축         핵심 질문                   범위
  ──────────────────────────────────────────────────
  믿음(信, Trust)       "사람을 믿을 수 있는가?"           0 (불신) ~ 100 (깊은 신뢰)
  옳음(正, Rightness)  "옳은 것을 위해 잃을 수 있는가?" 0 (무원칙) ~ 100 (확고한 신념)
  바람(願, Want)        "나는 무엇을 바라는가?"           0 (무욕) ~ 100 (강한 바람)
```

**설계 원칙**:
- 강도(0~100)에 도덕적 위계가 없다. 높다고 좋은 게 아니다.
- 같은 수치라도 신조(방향)가 다르면 완전히 다른 인물이다.
- 형성기억이 "왜 이 사람이 이런 신조를 갖게 되었는가"를 설명한다.

### 3.2 구조

```
  축 수치 (0~100) = 강도 ("얼마나 강하게")
  신조 (텍스트) = 방향 ("어떤 내용으로")
  형성기억 (기억ID 목록) = 원인 ("왜 이렇게 되었나")
  대안후보 (목록) = 변화 가능성 ("다른 방향의 씨앗")
```

### 3.3 같은 수치, 다른 인물 — 신조의 역할

```
  옳음 90 × 2명:
  ┌─────────────────────────────────────────────┐
  │ 명경: "도의를 지켜야 한다"                    │
  │ → 충↑ 의↑ → 제자 보호, 정파 수호             │
  │                                              │
  │ 조고: "힘이 곧 정의다"                        │
  │ → 충↓ 의↓ 야망↑ → 권력 장악, 방해물 제거     │
  │                                              │
  │ 수치는 같다. 방향이 정반대다.                 │
  │ 둘 다 30년간 흔들리지 않았다.                 │
  │ → 이것이 두 사람이 거울인 진짜 이유           │
  └─────────────────────────────────────────────┘

  바람 70 × 3명:
  ┌─────────────────────────────────────────────┐
  │ 소연: "원수를 갚고 정보망을 세우겠다"          │
  │ 야율설화: "누구의 도구도 아닌 나가 되겠다"     │
  │ 남궁현: "인정받고 싶다. 왕좌를 원한다"         │
  │                                              │
  │ 셋 다 70인데 원하는 것이 완전히 다르다.        │
  │ → 수치만으로 구분 불가. 신조가 결정적 차이.    │
  └─────────────────────────────────────────────┘
```

### 3.4 사용처

3축+신조는 **LLM 전용**이다. OCC 수식에 직접 투입되지 않는다.

```
  ✅ LLM 대사 생성 프롬프트에 포함
  ✅ LLM 성찰 프롬프트에 포함
  ✅ 내면 독백/내레이션 생성
  ✅ 캐릭터 시트 (플레이어에게 보여주는 것)
  ❌ OCC 감정 평가 수식 (→ 5가치가 담당)
  ❌ Utility AI 행동 점수 계산 (→ 5가치+PAD가 담당)
```

## 4. ③층 5가치 (충/의/효/복수/야망)

> "구체적 상황에서 어떻게 판단하는가" — OCC 감정 평가의 직접 입력

5가치는 코드에서 수식으로 직접 사용되는 실전값이다.

### 4.1 정의

```
  가치     핵심 질문                     OCC 트리거
  ──────────────────────────────────────────────────────
  충(忠)   조직/주군에 헌신하는가?        조직 위협 → 분노/두려움
  의(義)   강호 도리를 지키는가?          도리 위반 → 분노/경멸
  효(孝)   가족/스승에 도리를 다하는가?   가족 위험 → 걱정/공포
  복수(復) 원한을 갚으려 하는가?          원수 출현 → 증오/결의
  야망(野) 높은 곳을 원하는가?            기회 → 흥분 / 좌절 → 분노
```

### 4.2 OCC 감정 평가에서의 사용

```
  사건: "당무괴가 제자 소양을 납치"
  NPC: 명경

  의(90) × 위반강도(90) / 100 = 분노(81)
  충(90) × 제자보호목표위협(80) / 100 = 두려움(72)
  효: 관련 없음 → 0
  
  → 코드가 <1ms에 계산 완료
  → 5가치가 "이 사건이 이 NPC에게 얼마나 중요한가"의 가중치
```

### 4.3 5가치를 줄일 수 없는 이유

```
  충 ≠ 효:
  남궁현 — 형에 대한 의무(효 60)는 있지만 가문을 뒤집으려 함(충 50)
  → 가족 도리와 조직 충성은 독립적으로 움직임

  복수 ≠ 야망:
  소연 — "원수를 갚겠다"(복수 80)와 "정보망을 세우겠다"(야망 70)
  → 원수 관련 사건에서 복수가 야망과 질적으로 다른 감정을 유발함
  → "원수를 찾았다" = 증오+결의 (복수) ≠ "기회가 왔다" = 흥분 (야망)
```

### 4.4 사용처

5가치는 **코드 전용**이다.

```
  ✅ OCC 감정 평가 수식의 직접 입력
  ✅ Utility AI 행동 점수 계산
  ✅ 관계 변화 계산
  ❌ LLM 프롬프트에 필수 아님 (넣어도 되지만 3축이 우선)
```

## 5. 3축 ↔ 5가치 관계 규칙

> "소설의 언어(3축)와 게임 엔진의 언어(5가치)"

### 5.1 관계 유형: 해석 관계

3축과 5가치는 자동계산도 아니고 완전 독립도 아닌 **해석 관계**다.

```
  ❌ 자동계산 (파생):
     "옳음 90이면 충 = 옳음×0.8 = 72" → 조고의 충이 72? 말이 안 됨
  
  ❌ 완전 독립:
     "둘 다 따로 변함" → 3축의 존재 이유가 없음
  
  ✅ 해석 관계:
     3축+신조가 5가치의 "왜?"를 설명한다.
     5가치는 그 범위 안에서 경험에 의해 독자적으로 변한다.
```

### 5.2 해석 경로 예시

```
  명경:
  옳음 90 "도의를 지킨다"
  ├→ 충 90: 도의를 지키는 방법 = 맡은 바에 충실
  ├→ 의 90: 도의 자체가 의리의 상위 개념
  └→ 복수 10, 야망 10: 바람 30 "개인 욕심 없다"이므로

  조고:
  옳음 90 "힘이 정의다"
  ├→ 충 10: 힘의 논리에서 충성은 약점
  ├→ 의 10: 강호 도리는 강자의 속임수
  └→ 야망 100: 바람 90 "모든 것을 원한다"이므로

  → 같은 옳음 90인데 5가치 분포가 정반대
  → 신조 방향이 이 차이를 설명
```

### 5.3 불일치는 자연스럽다

```
  진야림: 옳음 40인데 의 60
  → 원칙에 대한 확신은 부서졌지만 습관으로 몸에 밴 의리는 남아있다
  → 이것은 "관성"이다. 자동계산으로는 절대 표현할 수 없다.

  소연: 믿음 50인데 충 70
  → 사부 한 사람에게 집중된 믿음(信)이 높은 충성으로 발현
  → "반은 믿고 반은 안 믿는다"가 아니라 "한 사람만 믿는다"

  야율설화: 바람 80인데 야망 50
  → 바람의 신조가 "자유"이지 "권력"이 아니므로 야망으로 전부 전환되지 않음
```

### 5.4 상호 영향 규칙

```
  ⬇ 하향 압력 (3축 → 5가치):
  ──────────────────────────────────
  3축이 크게 변하면 5가치에 "압력"이 생긴다.
  즉시 변화가 아니라, 다음 성찰(Tier2/3)에서 LLM이 조정한다.
  
  예: 명경의 옳음이 90→50으로 떨어지고
      신조가 "도의를 지킨다"→"생존이 먼저"로 바뀌면
      → 다음 성찰에서 LLM이 충/의에 하락 압력 반영

  ⬆ 상향 신호 (5가치 → 3축):
  ──────────────────────────────────
  5가치의 누적 변화가 쌓이면 Tier3/4 성찰에서 3축에 영향.
  
  예: 소연이 의리를 배반당하는 경험 반복
      의 80→70→60→50
      → Tier3/4 성찰에서 옳음의 신조 자체에 균열
```

### 5.5 역할 분담 요약

```
  ┌────────────────────────────────────────────────────────┐
  │          3축 (믿음/옳음/바람)    5가치 (충/의/효/복수/야망)│
  ├────────────────────────────────────────────────────────┤
  │ 본질     "이 사람은 누구인가"  "구체적으로 어떻게 판단" │
  │ 수준     근본적/철학적         실전적/상황적            │
  │ 사용처   LLM 프롬프트          OCC 감정 평가 수식      │
  │ 변화속도 느림 (Tier 2~4)       중간 (Tier 1~3)        │
  │ 변화범위 큼 (인생이 바뀜)      작음 (반응이 달라짐)    │
  │ 구성     강도+신조+형성기억    수치만                  │
  │ 개수     3개                   5개                     │
  │ 상호관계 하향 압력 발생         상향 신호 발생          │
  │ 불일치   가능하고 자연스러움    ← 이게 캐릭터의 깊이   │
  └────────────────────────────────────────────────────────┘
```

## 6. ④층 감정 (OCC)
> 📎 상세 설계: [occ-emotion-detail.md](occ-emotion-detail.md)

> "지금 무엇을 느끼는가" — 사건에 대한 즉각적 반응

### 6.1 OCC 인지 평가 흐름

```
  자극(사건) → 분류(사건/행위자/객체) → 평가 → 감정 유형 결정 → 강도 계산

  평가 시 사용되는 것:
  · 5가치 → "이 사건이 내 가치와 충돌하는가?"
  · 목표 → "이 사건이 내 목표를 위협하는가?"
  · 관계 → "이 행위자와 나의 관계는?"
  · 기분(PAD) → 편향 (좋은 기분이면 긍정 감정 증폭)
  · 성격(HEXACO) → 필터 (6요인별 감정 조절)
```

### 6.2 핵심 공식

```
  감정_최종강도 = 기본강도 × 가치_가중치 × 기분편향 × 성격필터

  분노 = 가치위반강도 × 해당_가치_수치 × 기분편향 × A필터
  두려움 = 목표위협강도 × 목표중요도 × (1 - D값) × E필터
  죄책감 = 자기행동도덕위반 × H(정직-겸손) × 해당_가치_수치
  통쾌 = 상대불행강도 × (1 - H) × 관계적대도
```

### 6.3 HEXACO 성격필터 (BigFive에서 변경) [v2.0]

```
  H (정직-겸손) → 도덕적 감정 필터
    죄책감(Guilt/Shame) × (1.0 + H × 0.005)
    통쾌(Gloating) × (1.0 - H × 0.004)
    도덕비난(Reproach) × (1.0 + H × 0.003)
    H=90이면 죄책감 ×1.45, 통쾌 ×0.64
    H=10이면 죄책감 ×1.05, 통쾌 ×0.96

  E (정서성) → 두려움/공감 필터
    두려움(Fear) × (1.0 + E × 0.005)
    측은(Pity) × (1.0 + E × 0.004)
    E=80이면 두려움 ×1.4, 측은 ×1.32
    E=20이면 두려움 ×1.1, 측은 ×1.08

  X (외향성) → 감정 표현 강도
    X 높으면: 같은 감정도 행동으로 더 크게 표출
    X 낮으면: 강한 감정도 내면에 담아둠
    (내부 강도와 별개, 행동 표출 계수에 영향)

  A (친화성) → 분노/원한 조절
    분노(Anger) × (1.0 - A × 0.004)
    원한(Resentment) × (1.0 - A × 0.003)
    A=80이면 분노 ×0.68 (억제)
    A=10이면 분노 ×0.96 (거의 억제 안 됨)

  C (성실성) → 감정→행동 억제
    C 높으면: 감정을 느끼되 행동에 덜 반영 (이성적)
    C 낮으면: 감정이 바로 행동으로 연결 (충동적)

  O (개방성) → 복합 감정 수용
    O 높으면: 복합 감정(감사+수치 동시 등) 경험 가능
    O 낮으면: 단순 감정으로 귀결 (분노 OR 슬픔, 둘 다는 어려움)
```

### 6.4 특징

- **코드로 처리** (<1ms, 결정적)
- 매 사건마다 발생
- 시간에 따라 자연 감쇠 (중립으로 회복)
- 기분(PAD)에 누적되어 흔적을 남김

## 7. ⑤층 기분 (PAD)

> "전반적으로 어떤 상태인가" — 감정의 렌즈

### 7.1 PAD 3차원

```
  P (Pleasure)  -1.0 ~ +1.0  쾌/불쾌
  A (Arousal)   -1.0 ~ +1.0  각성/이완
  D (Dominance) -1.0 ~ +1.0  지배감/무력감
```

### 7.2 기분이 감정에 미치는 편향 (렌즈 효과)

```
  기분 적대적 (P=-0.9):
  · 같은 사건이라도 부정 감정 증폭, 긍정 감정 억제
  · "평소 같으면 감사할 상황인데 짜증이 난다"

  기분 좋음 (P=+0.5):
  · 부정 사건에도 감정 반응이 약함
  · "보통 화날 상황인데 그냥 넘어간다"
```

### 7.3 변화 규칙

- 감정이 발생할 때마다 PAD에 누적
- OCC 감정 → PAD 매핑 테이블로 변환
- Tier 2(일상 성찰)에서 리셋/조정
- 시간에 따른 자연 감쇠 (중립으로)

## 8. ⑥층 행동 (Utility AI → LLM)

> "무엇을 하는가" — 코드가 범주, LLM이 구체화

### 8.1 코드: 행동 범주 결정 (Utility AI)

```
  입력: PAD 기분 + 성격(HEXACO) + 감정(OCC) + 5가치
  출력: ActionCategory (fight / flee / negotiate / grieve / seek_ally / ...)

  예:
  fight_score     = f(arousal, dominance, anger, -A, -E)
  negotiate_score = f(-arousal, A, X)
  flee_score      = f(arousal, -dominance, fear, E)
  exploit_score   = f(-H, ambition, dominance)

  → 최고 점수 범주가 선택됨
```

### 8.2 LLM: 구체적 행동/대사 생성

```
  프롬프트에 담기는 것:
  ┌──────────────────────────────────────────────┐
  │ 너는 [NPC이름]이다.                           │
  │ 성격 (HEXACO):                                │
  │ · H(정직-겸손) [수치] — [높/낮 해석]            │
  │ · E(정서성)    [수치] — [높/낮 해석]            │
  │ · X(외향성)    [수치] — [높/낮 해석]            │
  │ · A(친화성)    [수치] — [높/낮 해석]            │
  │ 핵심 가치관:                                  │
  │ · 믿음(信) [수치] — [신조]                      │
  │ · 옳음(正) [수치] — [신조]                    │
  │ · 바람(願) [수치] — [신조]                    │
  │ 현재 감정: [OCC 결과]                         │
  │ 현재 기분: [PAD 상태]                         │
  │ 결정된 행동 범주: [Utility AI 결과]           │
  │ 관련 기억: [LanceDB 검색 결과]                │
  │ 상대: [관계 정보]                             │
  │                                              │
  │ 이 상황에서 너는 어떻게 행동하겠는가?          │
  │ JSON 형식으로: { action, dialogue, inner_thought } │
  └──────────────────────────────────────────────┘

  참고: HEXACO 6요인 중 C, O는 프롬프트에 생략 가능.
  H, E, X, A가 대사/행동에 가장 직접적 영향.
  C, O는 코드 필터에서 주로 작용.
```

### 8.3 호출 타이밍

```
  평상시 (일상):     코드만 (Utility AI) → LLM 호출 ✗
  중요 사건:         코드(1~4층) + LLM(5층) → 비동기 호출
  대화:              코드(상태 취합) + LLM(응답 생성)
  하루 끝:           LLM(성찰 + 계획)
```

## 9. ⑦층 성찰·계획 (Tier 1~4)

> 📎 상세 설계: [reflection-tier-system.md](reflection-tier-system.md)
>
> "돌아보고, 의미를 찾고, 다음을 계획한다"
> Stanford Generative Agents의 Reflection + Planning을 무협 맥락으로 확장

```
  Tier 1 ─ 순간 반응      🔧 코드      매 이벤트
```

## 11. 코드/LLM 역할 분담

```
  🔧 코드가 결정하는 것 (확정적, 빠름, 매번 같음)
  ─────────────────────────────────────────
  · OCC 감정 수치 계산 (5가치 입력, HEXACO 성격필터)
  · PAD 기분 갱신
  · 행동 범주 (Utility AI 점수)
  · 성찰 트리거 여부 (importance 합산, 극단값 감지)
  · 변화 범위 제한 (clamp)
  · Memory Stream 저장/검색 (LanceDB)
  · 게임 물리/이동/전투 실행

  🧠 LLM이 결정하는 것 (창의적, 상황적, 매번 다름)
  ─────────────────────────────────────────
  · 구체적 대사와 행동 묘사
  · 하루 계획 내용
  · 관계 재평가의 "이유"와 "라벨"
  · 기억 중요도 재평가 (과거 사건의 의미 변화)
  · 목표 추가/변경/포기의 "내용"
  · 가치관 충돌의 구체적 내용
  · 신조 뉘앙스 변화, 전환 판단
  · 성격 변화의 "방향"과 "이유"

  🔧+🧠 협업 (코드가 범위 설정, LLM이 내용 결정)
  ─────────────────────────────────────────
  · 3축 강도: 코드가 Tier별 ±범위 제한, LLM이 수치 제안
  · 5가치: 코드가 ±범위 제한, LLM이 어떤 가치가 변하는지 제안
  · 성격: 코드가 ±5 제한 + 최대 2요인 제한, LLM이 어떤 축 변하는지 제안
  · 신조 전환: 코드가 대안후보 존재 확인, LLM이 전환 여부 판단
  · 목표: 코드가 최대 목표 수 제한, LLM이 내용 생성
```

**안전장치** — LLM 출력 검증 (설계 의사코드, 실제 구현 시 동일 패턴 적용):

```rust
fn apply_reflection_result(
    psyche: &mut NpcPsyche,
    result: &ReflectionResult,
    tier: ReflectionTier,
) {
    let max_axis_delta = match tier {
        Tier1 => 5.0,
        Tier2 => 10.0,
        Tier3 => 20.0,
        Tier4 => 30.0,
    };
    let max_value_delta = match tier {
        Tier1 => 5.0,
        Tier2 => 10.0,
        Tier3 => 20.0,
        Tier4 => 20.0,
    };
    let max_personality_delta = match tier {
        Tier4 => 5.0,
        _ => 0.0,  // Tier 1~3에서 성격 변화 불가
    };

    // ── ② 3축 강도 변화 clamp (3개 모두 동일 패턴) ──
    let axes = [
        (&mut psyche.values_core.trust.intensity,      result.trust_delta),
        (&mut psyche.values_core.rightness.intensity,   result.rightness_delta),
        (&mut psyche.values_core.want.intensity,        result.want_delta),
    ];
    for (intensity, delta) in axes {
        *intensity += delta.clamp(-max_axis_delta, max_axis_delta);
        *intensity = intensity.clamp(0.0, 100.0);
    }

    // ── ③ 5가치 변화 clamp (5개 모두 동일 패턴) ──
    let values = [
        (&mut psyche.values_practical.loyalty,        result.loyalty_delta),
        (&mut psyche.values_practical.righteousness,   result.righteousness_delta),
        (&mut psyche.values_practical.filial_piety,    result.filial_piety_delta),
        (&mut psyche.values_practical.vengeance,       result.vengeance_delta),
        (&mut psyche.values_practical.ambition,        result.ambition_delta),
    ];
    for (value, delta) in values {
        *value += delta.clamp(-max_value_delta, max_value_delta);
        *value = value.clamp(0.0, 100.0);
    }

    // ── ① 성격 변화 clamp (Tier4에서만, 최대 2요인) ──
    if max_personality_delta > 0.0 {
        let traits = [
            (&mut psyche.personality.honesty_humility,    result.honesty_humility_delta),
            (&mut psyche.personality.emotionality,        result.emotionality_delta),
            (&mut psyche.personality.extraversion,        result.extraversion_delta),
            (&mut psyche.personality.agreeableness,       result.agreeableness_delta),
            (&mut psyche.personality.conscientiousness,   result.conscientiousness_delta),
            (&mut psyche.personality.openness,            result.openness_delta),
        ];
        let mut changed_count = 0;
        for (t, delta) in traits {
            if delta.abs() > 0.1 && changed_count < 2 {
                *t += delta.clamp(-max_personality_delta, max_personality_delta);
                *t = t.clamp(0.0, 100.0);
                changed_count += 1;
            }
        }
    }

    // ── ② 신조 전환 (Tier3~4, 대안후보 존재 시만) ──
    if let Some(ref transition) = result.creed_transition {
        let axis = match transition.target_axis {
            Axis::Trust     => &mut psyche.values_core.trust,
            Axis::Rightness => &mut psyche.values_core.rightness,
            Axis::Want      => &mut psyche.values_core.want,
        };
        let has_candidate = axis.creed_candidates
            .iter()
            .any(|c| c.text == transition.new_creed);
        let tier_allowed = matches!(tier, Tier3 | Tier4);

        if has_candidate && tier_allowed {
            axis.creed = transition.new_creed.clone();
            // 전환 자체를 형성기억에 기록
            axis.formation_memories.push(transition.trigger_memory_id);
        }
        // 조건 불충족 시 전환 무시 (강도 변화는 위에서 이미 적용됨)
    }
}
```

```rust
/// NPC 심리 전체 구조
pub struct NpcPsyche {
    // ① 거의 변하지 않는 층
    pub personality: HexacoPersonality,

    // ② 천천히 변하는 층 — LLM용 서사

    // ③ 천천히 변하는 층 — OCC용 수식
    pub values_practical: PracticalValues,

    // ④⑤ 빠르게 변하는 층
    pub emotions: Vec<OccEmotion>,
    pub mood: PadState,

    // ⑥⑦ 메타
    pub current_goals: Vec<Goal>,
    pub daily_plan: Option<DailyPlan>,

    // 저장 — LanceDB 연동
    pub memory_stream: MemoryStream,
}

/// ① 성격 (HEXACO) [v2.0 변경: BigFive → HEXACO]
pub struct HexacoPersonality {
    pub honesty_humility: f32,  // H 정직-겸손 0~100
    pub emotionality: f32,      // E 정서성   0~100
    pub extraversion: f32,      // X 외향성   0~100
    pub agreeableness: f32,     // A 친화성   0~100
    pub conscientiousness: f32, // C 성실성   0~100
    pub openness: f32,          // O 개방성   0~100
}

/// ② 3축 가치관 (LLM용)
pub struct WuxiaValues {
    pub trust: ValueAxis,       // 믿음(信)
    pub rightness: ValueAxis,   // 옳음(正)
    pub want: ValueAxis,        // 바람(願)
}

pub struct ValueAxis {
    pub intensity: f32,                         // 강도 0~100
    pub creed: String,                          // 현재 신조
    pub creed_candidates: Vec<CreedCandidate>,  // 대안 후보
    pub formation_memories: Vec<MemoryId>,      // 형성 기억 참조
}

pub struct CreedCandidate {
    pub text: String,           // 대안 신조 텍스트
    pub source: String,         // 어디서 접촉했나
    pub exposure_count: u32,    // 접촉 횟수
    pub resonance: f32,         // 공명도 0~100
}

/// ③ 5가치 (OCC용)
pub struct PracticalValues {
    pub loyalty: f32,           // 충(忠)
    pub righteousness: f32,     // 의(義)
    pub filial_piety: f32,      // 효(孝)
    pub vengeance: f32,         // 복수(復)
    pub ambition: f32,          // 야망(野)
}

/// ④ 감정
pub struct OccEmotion {
    pub emotion_type: EmotionType,
    pub intensity: f32,
    pub source_event: EventId,
    pub timestamp: GameTime,
}

/// ⑤ 기분
pub struct PadState {
    pub pleasure: f32,          // -1.0 ~ +1.0
    pub arousal: f32,
    pub dominance: f32,
}
```
