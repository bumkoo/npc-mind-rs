## 0. 칠국 총론

### 0.1 왜 "칠국"인가

```
270년 전:  하나의 제국 (대진)
    ↓
10년 전:   붉은 밤의 변 → 대진 와해
    ↓
5~7년 전:  6개 지역 독립/자치 선언
    ↓
현재:      7개 정치체 공존 → "칠국춘추"

"칠국"이라 부르지만, 실제로는:
  · 왕조 4개 (황제/왕이 통치)
  · 부족연합 1개 (합의체)
  · 공화국 1개 (의회)
  · 자치령 1개 (무정부)
  → NPC 대사: "칠국이라지만, 나라다운 나라가 몇 개나 되나?"
```

## 1. 대진(大辰) — 축소 제국

### 1.1 기본 정보

| 항목 | 내용 |
|------|------|
| 정체 | 왕조 — 270년 역사의 원래 제국. 현재 중원만 보유 |
| 수도 | 낙양(洛陽) — 한때 대륙의 중심. 이제는 쇠락한 옛 수도 |
| 원수 | 천순제 (꼭두각시 황제) |
| 실권자 | 조고 (권신, 십상시 수장) |
| 면적 | 중원 일부만 보유. 왕조 중 가장 많이 축소됨 |
| 인구 | 여전히 가장 많음 (중원 인구 밀집) |

### 1.2 통치 구조

```
대진 권력 구조:

  [천순제] ←── 꼭두각시 ──→ [조고]
  (황제)      "옥좌에 앉되   (권신)
              말은 하지 마라"
      │                        │
      │ 형식적 칙령             │ 실질 명령
      │                        │
      ▼                        ▼
  [황실 관료]              [십상시]
  (무력화됨)              조고의 사설 첩보/암살 조직
                               │
                    ┌──────────┼──────────┐
                    │          │          │
                  간첩        암살자      행정관
                 (타국 침투)  (위협 제거)  (세금/물류)

  소림/무당의 위치:
  · 대진 영토 내에 위치하지만 황실 직속 아님
  · "황실을 지지하나 불만 증가"
  · 소림 방장: 명목상 무림맹주이나 실권 약화
  · 무당: 중재자 전통 유지하려 하나 고립
```

### 1.3 소속 문파

| 문파 | 위치 | 상태 | 갈등 |
|------|------|------|------|
| 소림(少林) | 숭산(嵩山) | 명목상 무림맹주 파 | "대진을 지켜야 하나? 이미 끝난 제국인데?" |
| 무당(武當) | 무당산(武當山) | 중재자 전통 유지 | "어느 편도 들지 않으면 모두의 적이 된다" |

### 1.4 경제

```
· 한때 대륙 경제의 중심이었으나, 교역로 단절로 쇠락
· 상방이 여전히 낙양에 거점을 두고 있어 완전 붕괴는 아님
· 조고가 세금 착취 → 민심 이반 가속
· 화폐: 여전히 "대진 냥(兩)"이 기축 통화
  → 다른 국가들이 독자 화폐를 만들기 시작했으나 아직 불완전
```

### 1.5 핵심 갈등

```
외부 갈등:
  · "잃어버린 영토를 되찾겠다" — 수복 야심
  · 6국 모두와 잠재적 적대
  · 그러나 군사력 부족으로 실행 불가

내부 갈등:
  · 천순제 vs 조고: 꼭두각시가 깨어날 것인가?
  · 소림/무당 vs 조정: 문파가 독자 행동할 것인가?
  · 민중 불만: 세금 착취 + 옛 영광에 대한 회한
  · 혈교 잔당: 낙양 지하에 여전히 거점? (메인 퀘스트 연동)
```

### 1.6 플레이어 방문 이유

```
① 메인 퀘스트: 피의 실종 사건의 현장이 낙양 지하
② 조고 대면: 메인 적대자의 근거지
③ 소림/무당 방문: 정파 핵심 문파 접촉
④ 혈교 단서: 낙양 지하 탐색
⑤ 야율설화 관련: 설화의 볼모 거처가 낙양
```

## 2. 남궁(南宮) — 가문 왕국

### 2.1 기본 정보

| 항목 | 내용 |
|------|------|
| 정체 | 왕조 — 남궁세가가 세운 무인 왕국 |
| 수도 | 검성(劍城) — 남궁세가 본거지를 확장한 성채 도시 |
| 원수 | 남궁혁 (검왕, 42세) |
| 면적 | 서남부 내륙. 산악 + 평야 혼합 |
| 인구 | 중간. 무인 비율이 칠국 중 가장 높음 |

### 2.2 통치 구조

```
남궁 왕국 권력 구조:

  [남궁혁] ←── 검으로 세운 나라
  (검왕)
      │
      ├─── [남궁현] (숙부, 행정 총괄)
      │     "나라 경영의 실무는 내가"
      │     └── [장로단] (남궁현이 포섭 중)
      │
      ├─── [남궁린] (동생, 비공식 무력)
      │     "공식 직위 없음. 연무장의 그림자"
      │
      └─── [청성파] (보호/통제 아래)
            "보호인가 새 주인인가?"

  특징:
  · 1인 카리스마에 의존하는 체제
  · 남궁혁이 없으면 왕국이 유지될 수 있는가? → 핵심 불안
  · 남궁현의 야심이 이 구조적 약점을 노리는 중
```

### 2.3 소속 문파

| 문파 | 위치 | 상태 | 갈등 |
|------|------|------|------|
| 남궁세가 | 검성 | 왕실 그 자체 | 가문 내부 분열 (혁 vs 현) |
| 청성(靑城) | 청성산 (남궁 영토 내) | 보호받으나 자유 없음 | "무림 문파가 왕국의 신하가 되는 건가?" |

### 2.4 경제

```
· 군사 강국이나 경제 기반 취약
· 남궁현이 동해 연방(진대인)과 비밀 교역로 개설 중
· 검성 자체가 거래 중심이 아님 → 세금 수입 부족
· 남궁혁의 정책: "백성이 배불러야 검도 쓴다"
  → 의도는 좋으나 경제 감각 부족
  → 남궁현이 경제를 실질 운영
```

### 2.5 핵심 갈등

```
외부 갈등:
  · 대진과 국경 분쟁 (옛 영토 주장)
  · 북원과 간헐적 충돌 (바투의 확장)

내부 갈등:
  · 남궁혁 vs 남궁현: 왕 vs 숙부의 권력 투쟁
  · 남궁린의 위치: 진실을 알게 되면 누구 편?
  · 청성파의 자유 욕구: "보호"에서 "독립"으로
  · 화산파 멸문의 진실: 남궁혁이 관여했는가?
```

### 2.6 플레이어 방문 이유

```
① 남궁혁 대면: 화산파 멸문 의혹 추궁
② 남궁현 접촉: 화산파 증거 보유자
③ 남궁린: 동세대 동료, 내부 정보원
④ 청성파 접촉: 정파 문파 탐방
⑤ 붉은 밤의 변 단서: 화산 폐허가 남궁 영토 근처
```

### 3.1 기본 정보

| 항목 | 내용 |
|------|------|
| 정체 | 왕조 — 독공(毒功) 대가가 지배하는 이색 왕국 |
| 수도 | 독관성(毒關城) — 옛 변경 요새. 당무괴가 장악 후 개명 |
| 원수 | 당무괴(唐無怪) — 별호: 독왕(毒王) |
| 면적 | 서부 변경. 산악 + 사막 + 관문 지형 |
| 인구 | 적음. 변경민 + 당가 일족 + 군사 주둔 |

### 3.2 통치 구조

```
서량 권력 구조 — "왕이 나라에 관심이 없는 나라":

  [당무괴] ←── 서량 왕 (독왕)
  (53세)      "나라? 그런 건 알아서 해. 연구를 방해하지만 마라."
      │
      ├─── [당가 일족] (왕실 겸 연구 집단)
      │     · 사천 당가 본가의 후예
      │     · 독약/해독약/비약 제조 = 서량의 핵심 산업
      │     · 당무괴의 연구를 보좌하는 가문
      │     · "연구 성과가 곧 국력"
      │
      ├─── [곽천웅] (수석 장군, 군사 총괄)
      │     · 변경 수비대 출신. 30년 서쪽 관문 방어
      │     · 당무괴가 왕이 된 후 군사를 위임받음
      │     · "독왕 폐하는 연구실에 계신다. 군사는 내가 한다."
      │     · 사실상 서량 군사의 실질 지휘관
      │     · 당무괴에 대한 감정: 충성이 아닌 체념
      │       "미친놈이지만 독을 이길 수는 없으니까"
      │
      ├─── [점창파] (군사 편입)
      │     · 곽천웅 휘하에서 군사적 협력
      │     · 점창파 무인이 서량 군에 반쯤 편입
      │     · "무인이 군인이 되는 건가?"
      │
      └─── [아미파] (사실상 감금)

            · 독립 당시 서량에 포위됨

            · 명경: 제자 200명이 인질. 떠날 수 없음
            · "한 국가의 왕이 정파 문파를 국가 차원에서 억류"
              → 무림 전체의 도덕적 문제

  당무괴가 서량 왕이 된 경위:
  ──────────────────────────────────
  · 6년 전, 대진 붕괴 직후 서량 변경 혼란
  · 기존 군벌 장군들이 독립을 선언하려 했으나
  · 당무괴가 독안개로 서량 수도를 하루 만에 제압
  · "항복하면 살려준다. 연구만 하게 해주면 된다."
  · 군벌 장군들: 저항 → 독에 쓰러짐 → 항복
  · 곽천웅만 "독에 저항하는 내공"으로 버텨냄
    → 당무괴: "재미있군. 넌 살려둘 가치가 있다."
    → 곽천웅이 수석 장군으로 임명된 배경

  독왕의 통치 스타일:
  · 세금: "약재로 내. 돈은 필요 없다."
  · 법률: "내 연구를 방해하면 죽는다. 그 외에는 자유."
  · 외교: "나한테 묻지 마. 곽 장군이 알아서 해."
  · 결과: 서량은 "왕이 있으되 통치하지 않는" 기형 국가
         군사는 곽천웅, 경제는 당가, 왕은 연구실

  나이: 50대 중반

            · 상방과 결합하여 해군화
            · 정파 문파이나 "돈을 위해 검을 쓰는" 비판 받음
            · "정파인가, 상인인가?"

  공화국의 의사결정:
  · 상방 대표들의 다수결
  · 1 상방 = 1 표 (자본 규모와 무관하게)
  · 그러나 실질적으로 3대 상방이 좌우
  · 소규모 상방의 불만 잠재
```

### 6.3 소속 문파

|------|------|------|------|
| 해남(海南) | 해문 및 연안 | 상방과 결합, 해군화 | "돈은 많지만 정파의 명예를 잃고 있다" |

### 6.4 경제

```
· 칠국 중 가장 부유
· 해상 무역의 독점 → 다른 국가 모두와 거래
· 화폐: "대진 냥" + 동해 독자 "해(海) 은표" 발행
· 상방 네트워크가 국경을 초월 → 전쟁 중에도 교역
· 진씨 상방 200년 역사 (시조 진승)
· "전쟁은 나쁘다. 전쟁은 교역을 멈춘다. 교역이 멈추면 다 죽는다."
```

### 6.5 핵심 갈등

```
외부 갈등:
  · 대진의 수복 야심 (과거 동해는 대진 영토)
  · 해적 문제: 자유도시 출신 해적과 충돌

내부 갈등:
  · 3대 상방 vs 소규모 상방: "부자만의 공화국"
  · 해남파 정체성: 무인인가 상인인가
  · 진대인 vs 장씨/왕씨: 의회 내 주도권
  · 남궁현과의 비밀 거래: 발각되면 외교 문제
```

### 6.6 플레이어 방문 이유

② 진대인 접촉: 경제 도메인 핵심 NPC
③ 해남파 방문: 정파 문파
④ 해상 탐험: 섬, 해적, 해상 교역

### 7.5 핵심 갈등

```
내부 갈등:
  · 무정부의 대가: 약한 자가 착취당함
  · 개방의 역할 확대: "비공식 정부"가 되어가는 것에 대한 부담
  · 피난민 증가: 전쟁 난민이 몰려들어 자원 부족
  · 각국 첩자들의 암투: 자유도시가 정보전의 전장

[v1.1 추가] 영주의 유산 — 잠재적 갈등:
  · 진야림의 정체가 공개되면 자유도시의 근본이 흔들림
  · "왕이 없어서 자유"인 도시에 "왕의 후계자"가 나타남
  · 개방/상방 입장: "왕이 돌아오면 우리의 권한은?"
  · 시민 입장: "왕이 있으면 더 안전하나?" vs "자유가 없어지나?"
  · 조고 입장: "살아있었나. 처리해야 한다."
  · → 진야림 퀘스트라인이 자유도시 전체의 정치 구조를 뒤흔듦

플레이어 시작 지점으로서의 의미:
  · "어디에도 속하지 않는 곳"에서 시작
  · → 어디든 갈 수 있다 = 자유
  · → 아무도 보호해주지 않는다 = 위험
  · → "이곳에서 나는 누구인가?"
  · [v1.1] + "이 자유는 학살 위에 세워진 것이다"
    → 자유도시의 자유에 대한 이중적 시선
```

  중립: 큰 이해관계 없음
  교역: 경제적 협력 관계
  비밀: 공개되지 않은 비밀 연결 (남궁현-진대인)

  활용: 전략적으로 이용 (남궁이 자유도시를 완충으로)
