## 1. 도메인 개요

### 1.1 도메인 정의

심리 도메인은 NPC의 **내면 세계**를 담당한다. 성격, 가치관, 감정, 기분, 행동 판단, 성찰 — 이 모든 것이 심리 도메인의 소유다.

```
  핵심 질문: "이 사람은 어떤 마음을 가졌나?"
  소유 데이터: 성격(HEXACO), 3축 가치관, 5가치, 감정(OCC), 기분(PAD), 기억 스트림

  비유:
    캐릭터 도메인 = 호적부 (누구인가)
    성장 도메인   = 수련일지 (얼마나 강한가)
    심리 도메인   = 내면 독백 (무엇을 느끼고 생각하는가)
```

### 1.2 能/性/敍/判 프레임워크

심리 도메인과 성장 도메인의 경계를 명확히 하기 위해 **네 가지 질문**으로 분류한다:

```
  질문                      답의 종류     소유 도메인       예시
  ──────────────────────────────────────────────────────────────
  "할 수 있는가?"           능력(能)      성장 도메인        의지, 공감, 내공
  "원래 그런 사람인가?"     성향(性)      심리/성격 (①층)    H(정직-겸손), X(외향성)
  "어떤 존재인가?"          서사(敍)      심리/3축 (②층)     믿음, 옳음, 바람
  "상황에서 어떻게          판단(判)      심리/5가치 (③층)    충, 의, 효, 복수, 야망
   판단하는가?"
```

**핵심 구분 원칙**:
- 같은 감정 관련 단어라도 **"할 수 있는가"**이면 성장 도메인, **"원래 그런가"**이면 심리 도메인이다.
- 예: 공감(empathy) 능력 = 80 → "타인 감정을 잘 읽을 수 있다" (성장 도메인)
- 예: A(친화성) = 0.9 → "원래 도발에도 참고 용서하는 성격이다" (심리 도메인)
- 츤데레 = 공감(능력) 높음 + A(친화성, 성향) 낮음 → 두 도메인이 독립적으로 작동하는 증거
- H(정직-겸손) 추가로 "본질적으로 남을 이용하는 사람인가?"를 ①층에서 직접 표현 가능
- **敍와 判의 분리**: 같은 옳음 0.9라도 명경("도의를 지킨다")과 조고("힘이 정의다")는 정반대 인물이다. 수치(判)만으로는 구분 불가, 신조 텍스트(敍)가 결정적 차이를 만든다.

### 1.3 소유 데이터 요약

| 층 | 데이터 | 변화 속도 | 처리 주체 |
|----|--------|-----------|-----------|
| ① 성격 (HEXACO) | H/E/X/A/C/O (각 0~100) | 거의 불변 (Tier4에서만 ±5) | 🔧 코드 + 🧠 LLM |
| ② 3축 가치관 | 믿음/옳음/바람 (강도+신조+형성기억+대안후보) | 느림 (Tier 2~4) | 🧠 LLM 전용 |
| ③ 5가치 | 충/의/효/복수/야망 (각 0~100) | 중간 (Tier 1~3) | 🔧 코드 전용 |
| ④ 감정 (OCC) | 22종 인지평가 결과 | 빠름 (매 사건) | 🔧 코드 |
| ⑤ 기분 (PAD) | P/A/D 3차원 (-1.0~+1.0) | 빠름 (감정 누적) | 🔧 코드 |
| ⑥ 행동 | ActionCategory | 빠름 (매 판단) | 🔧 코드 → 🧠 LLM |
| ⑦ 성찰 | Tier 1~4 성찰 결과 | 가변 (Tier에 따라) | 🔧+🧠 협업 |
| 기억 스트림 | 관찰/감정/성찰/계획 기록 | 지속 누적 | 🔧 코드 (LanceDB) |

## 2. 7층 아키텍처

NPC의 내면은 7개 층으로 구성된다. 위로 갈수록 안정적이고, 아래로 갈수록 빠르게 변한다. 성찰(⑦)이 모든 층을 재평가하는 메타 층이다.

```
  ┌─────────────────────────────────────────────────────────┐
  │              NPC 심리 아키텍처 v3 (HEXACO 통합)          │
  │                                                          │
  │  ━━━ 거의 변하지 않는 층 ━━━━━━━━━━━━━━━━━━━━━━━━━━━   │
  │                                                          │
  │  ① 성격 (HEXACO)                                        │
  │     H/E/X/A/C/O = 행동 패턴의 기질적 토대               │
  │     변화: Tier4에서만, ±5 제한, 최대 2요인               │
  │     나이 drift: 없음 (성격은 경험으로만 변한다)          │
  │                                                          │
  │  ━━━ 천천히 변하는 층 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   │
  │                                                          │
  │  ② 3축 가치관 (믿음/옳음/바람)                           │
  │     각 축 = { 강도, 신조, 형성기억, 대안후보[] }          │
  │     = "이 사람이 어떤 존재인가" (LLM용 서사)             │
  │     변화:                                                │
  │       강도 — Tier1~2에서 ±5~10                           │
  │       신조 — Tier3~4에서만 전환 가능                     │
  │                                                          │
  │  ③ 5가치 (충/의/효/복수/야망)                            │
  │     = "구체적 상황에서 어떻게 판단하는가" (OCC용 수식)    │
  │     변화: Tier1~3에서 ±5~20                              │
  │                                                          │
  │  ━━━ 빠르게 변하는 층 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   │
  │                                                          │
  │  ④ 감정 (OCC 인지평가)                                   │
  │     사건 → 5가치 기준 평가 → 22종 감정 유발              │
  │     = "지금 무엇을 느끼는가"                             │
  │                                                          │
  │  ⑤ 기분 (PAD)                                           │
  │     감정 누적 → P/A/D 3차원 상태                         │
  │     = "전반적으로 어떤 상태인가" (렌즈 역할)             │
  │                                                          │
  │  ⑥ 행동 (Utility AI → LLM)                              │
  │     PAD + 성격 + 가치관 → 행동 범주 (코드)               │
  │     행동 범주 → 구체적 행동/대사 (LLM)                   │
  │                                                          │
  │  ━━━ 메타 층 (위 모든 것을 재평가) ━━━━━━━━━━━━━━━━━━   │
  │                                                          │
  │  ⑦ 성찰·계획 (Tier 1~4)                                 │
  │     = "돌아보고, 의미를 찾고, 다음을 계획한다"           │
  │     → ①~⑥ 모든 층에 역방향 영향                        │
  │                                                          │
  │  ━━━ 저장 층 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   │
  │                                                          │
  │  기억 스트림 (Memory Stream + LanceDB)                   │
  │     관찰/감정/성찰/계획 모두 기록                        │
  │     recency × importance × relevance로 검색              │
  │                                                          │
  │  관계 (Relationship) — 관계 도메인 소유                  │
  │     NPC↔NPC, NPC↔Player 감정/신뢰/적대                  │
  │                                                          │
  └─────────────────────────────────────────────────────────┘
```

**핵심 설계 원칙**:
- 코드는 ④⑤⑥을 담당한다 (수식 계산, <1ms, 결정적)
- LLM은 ⑥의 구체적 행동/대사 + ⑦성찰을 담당한다 (창의적, 가끔 호출)
- ②와 ③은 "같은 내면의 다른 표현"이다 (§5 참조)

## 3. ①층 성격 (HEXACO)

> "이 사람은 원래 어떤 사람인가" (性)
> 📎 상세: [npc-psychology-architecture.md](npc-psychology-architecture.md) §2
> 📎 BigFive→HEXACO 전환: [bigfive-to-hexaco-migration.md](bigfive-to-hexaco-migration.md)
> 📎 기질·가치관 상세: [npc-temperament-values-detail.md](npc-temperament-values-detail.md)

성격은 NPC의 가장 안정적인 층이다. 모든 하위 층에 필터 역할을 한다.

### 3.1 BigFive에서 HEXACO로 변경한 이유

```
  ① H(정직-겸손) 요인이 무협 서사의 의리/배신 갈등을 직접 표현
     · BigFive에는 이것을 ①층에서 표현할 수단이 없었음
     · H 요인 = "이 사람이 본질적으로 남을 이용하는 사람인가"

  ② E(정서성)와 A(친화성)의 재편으로 감정 필터 정밀도 향상
     · BigFive-N(신경증)에 "불안"과 "분노"가 뒤섞여 있었음
     · HEXACO는 불안→E, 분노→A로 분리
     · 조고: "겁은 없는데(E↓) 화는 불같다(A↓)" 표현 가능

  ③ ①층(기질) ↔ ③층(5가치) 연결이 자연스러워짐
     · H = 충/의의 기질적 토대
     · "왜 이 사람은 의리를 중시하는가?" → 기질적으로 H가 높아서
```

### 3.2 HEXACO 6요인 정의

```
  요인                    범위       핵심 질문
  ──────────────────────────────────────────────────────────────
  H (정직-겸손,           0~100     "남을 이용하지 않고 공정한가?"
     Honesty-Humility)              높음: 공정, 겸손, 법규 준수
                                    낮음: 조작, 착취, 특권의식, 물욕

  E (정서성,              0~100     "자신과 가족의 안전에 민감한가?"
     Emotionality)                  높음: 두려움, 걱정, 공감, 애착
                                    낮음: 대담, 냉담, 독립적

  X (외향성,              0~100     "사회적으로 자신감 있고 활발한가?"
     eXtraversion)                  높음: 사교적, 자신감, 활력
                                    낮음: 내성적, 조용, 수줍음

  A (친화성,              0~100     "도발에 참을 수 있고 용서하는가?"
     Agreeableness)                 높음: 관용, 인내, 유연
                                    낮음: 분노, 원한, 고집, 비판적

  C (성실성,              0~100     "규율 있고 계획적인가?"
     Conscientiousness)             높음: 근면, 체계적, 신중
                                    낮음: 충동적, 무계획, 태만

  O (개방성,              0~100     "새로운 경험과 사고에 열린가?"
     Openness)                      높음: 창의적, 지적 호기심, 유연
                                    낮음: 관습적, 실용적, 보수적
```

> ⚠️ **H 요인 표기 규칙**: 학술 원본 명칭 `Honesty-Humility(정직-겸손)`을 유지하되, 게임 시스템 해석으로 `(원칙↔실리)` 주석을 병기한다. "높다=좋다"는 도덕적 편향을 방지하기 위함이다.

### 3.3 H 요인과 무협 — ①층↔③층 연결

```
  H와 ③층 5가치의 관계:
  ──────────────────────────────────────────────
  H = 기질 ("이 사람은 원래 공정한 사람인가")
  충/의 = 경험 ("살면서 충성과 의리를 얼마나 내면화했나")

  둘은 독립적으로 움직인다:
  · H 높음 + 의 높음 = 명경 (본성도 공정, 경험도 의리)
  · H 높음 + 의 낮음 = "본성은 공정하나 배신당해 의리를 잃음"
  · H 낮음 + 의 높음 = "본성은 이기적이나 습관으로 의리를 지킴"
  · H 낮음 + 의 낮음 = 조고 (본성도 착취적, 경험도 비도덕)
```

> 📎 H×의 조합의 LLM 행동 생성 검증: [test-h-yi-combination-results.md](test-h-yi-combination-results.md)

**Low-H 인물 유형 가이드** (Lee & Ashton, Chapter 4):

```
  H↓ + E↓ = "탐욕+대담" → 조고 유형
  H↓ + E↑ = "비겁한 간신" → 위험은 피하면서 뒤에서 조작
  H↓ + X↑ = "나르시시스트" → 카리스마 있지만 자기과시
  H↓ + A↓ = "잔인한 폭군" → 착취적이고 분노도 격함
  H↑ + A↓ = "원칙적+불같은" → 공정하지만 도발에 참지 못함
  H↑ + E↑ = "의로운 걱정쟁이" → 공정하고 공감 강하지만 소심
```

### 3.4 하위 층에 대한 영향 (6요인 → OCC/행동 필터)

```
  H (정직-겸손) → 도덕적 감정 필터
    H 높음: 죄책감(Shame/Guilt) 증폭, 통쾌(Gloating) 억제
    H 낮음: 죄책감 억제, 남의 불행에 쾌감(Gloating) 증폭
    H 낮음: 배신을 목격해도 "나도 그랬을 것" → 도덕적 비난(Reproach) 약화

  E (정서성) → 두려움/공감 필터
    E 높음: Fear(두려움) 증폭, Pity(측은) 증폭, 애착 감정 강화
    E 낮음: 위험에도 두려움 약함, 타인 고통에 무감각
    Utility AI: E 높으면 flee 점수 증가, E 낮으면 fight 점수 증가

  X (외향성) → 감정 표현 강도
    X 높음: 같은 감정도 행동으로 더 크게 표출, 대화 개시 확률 증가
    X 낮음: 강한 감정도 내면에 담아둠
    Utility AI: X 높으면 negotiate/seek_ally 점수 증가

  A (친화성) → 분노/원한 조절
    A 높음: Anger(분노) 억제, 용서 점수 증가, 협상 선호
    A 낮음: 사소한 도발에도 즉각 분노, 원한 장기 유지
    Utility AI: A 높으면 negotiate 점수 증가, A 낮으면 fight 점수 증가

  C (성실성) → 감정 억제 + 계획 이행
    C 높음: 감정을 느끼되 행동에 덜 반영 (이성적), 계획 이행률 증가
    C 낮음: 감정이 바로 행동으로 연결 (충동적)

  O (개방성) → 복합 감정 + 신조 수용
    O 높음: 복합 감정(감은+수치 동시 등) 경험 가능, 새로운 신조 수용 확률 증가
    O 낮음: 단순 감정으로 귀결, 기존 신조 고수
```

### 3.5 변화 규칙

**핵심 원칙: 사람은 나이로 변하지 않는다. 겪은 일과 내린 선택으로만 변한다.**

```
  나이의 역할:
  · 나이 → 육체적 능력 변화 (성장 도메인: 체력, 경공, 무력 등)
  · 나이 → 성격 변화 없음 (심리 도메인: H/E/X/A/C/O)
  · 나이 drift: 6요인 전부 없음

  성격이 변하는 유일한 경로: Tier 4 (인생 성찰)
  ┌──────────────────────────────────────────────────────┐
  │  1. Tier 1~3에서: 성격 변화 불가 (delta = 0)         │
  │  2. Tier 4에서: ±5 제한, 6요인 중 최대 2개만         │
  │  3. 나이 drift: 없음 (6요인 전부)                    │
  │  4. 어떤 경우에도 0~100 범위 clamp                   │
  └──────────────────────────────────────────────────────┘
```

## 4. ②층 3축 가치관 (믿음/옳음/바람) + 신조

> "이 사람은 어떤 존재인가" — 서사적 정체성의 핵심
> 📎 상세: [npc-psychology-architecture.md](npc-psychology-architecture.md) §3
> 📎 신조 변화: [creed-change-mechanic.md](creed-change-mechanic.md)

### 4.1 축 정의

```
  축         핵심 질문                   범위
  ──────────────────────────────────────────────────
  믿음(信)   "사람을 믿을 수 있는가?"       0 (불신) ~ 100 (깊은 신뢰)
  옳음(正)   "옳은 것을 위해 잃을 수 있는가?" 0 (무원칙) ~ 100 (확고한 신념)
  바람(願)   "나는 무엇을 바라는가?"         0 (무욕) ~ 100 (강한 바람)
```

**설계 원칙**:
- 강도(0~100)에 도덕적 위계가 없다. 높다고 좋은 게 아니다.
- 같은 수치라도 신조(방향)가 다르면 완전히 다른 인물이다.
- 형성기억이 "왜 이 사람이 이런 신조를 갖게 되었는가"를 설명한다.

### 4.2 구조

```
  축 수치 (0~100) = 강도 ("얼마나 강하게")
  신조 (텍스트) = 방향 ("어떤 내용으로")
  형성기억 (기억ID 목록) = 원인 ("왜 이렇게 되었나")
  대안후보 (목록) = 변화 가능성 ("다른 방향의 씨앗")
```

### 4.3 같은 수치, 다른 인물 — 신조의 역할

```
  옳음 90 × 2명:
  ┌─────────────────────────────────────────────┐
  │ 명경: "도의를 지켜야 한다"                    │
  │ → 충↑ 의↑ → 제자 보호, 정파 수호             │
  │                                              │
  │ 조고: "힘이 곧 정의다"                        │
  │ → 충↓ 의↓ 야망↑ → 권력 장악, 방해물 제거     │
  │                                              │
  │ 수치는 같다. 방향이 정반대다.                 │
  └─────────────────────────────────────────────┘
```

### 4.4 사용처

3축+신조는 **LLM 전용**이다. OCC 수식에 직접 투입되지 않는다.

```
  ✅ LLM 대사 생성 프롬프트에 포함
  ✅ LLM 성찰 프롬프트에 포함
  ✅ 내면 독백/내레이션 생성
  ✅ 캐릭터 시트 (플레이어에게 보여주는 것)
  ❌ OCC 감정 평가 수식 (→ 5가치가 담당)
  ❌ Utility AI 행동 점수 계산 (→ 5가치+PAD가 담당)
```

### 4.5 신조 변화 메카닉

> 📎 상세: [creed-change-mechanic.md](creed-change-mechanic.md)

```
  변화의 세 겹:
  ① 강도 변화 = 흔들림 (자주, Tier 1~2) — 같은 방향, 약해진 힘
  ② 뉘앙스 변화 = 색채 변화 (가끔, Tier 2) — 핵심 유지, 톤 변화
  ③ 신조 전환 = 방향 변경 (드묾, Tier 3~4) — 인생이 달라짐

  전환 조건 (세 가지 동시 충족):
  ① 기존 신조의 실패 경험 + ② 대안 신조와의 접촉 + ③ 선택의 순간
```

## 5. ③층 5가치 (충/의/효/복수/야망)

> "구체적 상황에서 어떻게 판단하는가" — OCC 감정 평가의 직접 입력
> 📎 상세: [npc-psychology-architecture.md](npc-psychology-architecture.md) §4

### 5.1 정의

```
  가치     핵심 질문                     OCC 트리거
  ──────────────────────────────────────────────────────
  충(忠)   조직/주군에 헌신하는가?        조직 위협 → 분노/두려움
  의(義)   강호 도리를 지키는가?          도리 위반 → 분노/경멸
  효(孝)   가족/스승에 도리를 다하는가?   가족 위험 → 걱정/공포
  복수(復) 원한을 갚으려 하는가?          원수 출현 → 증오/결의
  야망(野) 높은 곳을 원하는가?            기회 → 흥분 / 좌절 → 분노
```

### 5.2 OCC 감정 평가에서의 사용

```
  사건: "당무괴가 제자 소양을 납치"
  NPC: 명경

  의(90) × 위반강도(90) / 100 = 분노(81)
  충(90) × 제자보호목표위협(80) / 100 = 두려움(72)
  효: 관련 없음 → 0

  → 코드가 <1ms에 계산 완료
  → 5가치가 "이 사건이 이 NPC에게 얼마나 중요한가"의 가중치
```

### 5.3 사용처

5가치는 **코드 전용**이다.

```
  ✅ OCC 감정 평가 수식의 직접 입력
  ✅ Utility AI 행동 점수 계산
  ✅ 관계 변화 계산
  ❌ LLM 프롬프트에 필수 아님 (넣어도 되지만 3축이 우선)
```

## 6. 3축 ↔ 5가치: 해석 관계

> 📎 상세: [layer1-layer2-relationship.md](layer1-layer2-relationship.md)
> 📎 상세: [npc-psychology-architecture.md](npc-psychology-architecture.md) §5

3축과 5가치는 자동계산도, 완전 독립도 아닌 **해석 관계**다. 성찰(⑦층)이 양자를 번역하는 역할을 한다:

```
  ②층 3축 (믿음/옳음/바람 + 신조)
     │                              ▲
     │  ⬇ 하향 압력                  │  ⬆ 상향 신호
     │  3축이 크게 변하면             │  5가치의 누적 변화가
     │  → 다음 성찰에서               │  쌓이면 Tier 3~4 성찰에서
     │    5가치에 압력 반영            │  3축 신조에 균열 발생
     ▼                              │
  ③층 5가치 (충/의/효/복수/야망)     │
     │                              │
     │ 수식 입력 (코드, <1ms)         │
     ▼                              │
  ④층 OCC → ⑤층 PAD → 감정 누적 ───┘
                           │
                    ⑦층 성찰 (LLM)
                    코드: 범위 제한 (clamp)
                    LLM: 내용 결정
```

**불일치는 자연스럽다** — 이것이 인물의 깊이를 만든다:
- 진야림: 옳음 0.4(부서진 상태)인데 의 0.6 → 원칙은 무너졌지만 몸에 밴 의리는 남아있다 (관성)
- 소연: 믿음 0.5인데 충 0.7 → 사부 한 사람에게 집중된 믿음(信)이 높은 충성으로 발현

### 6.1 역할 분담 요약

```
  ┌────────────────────────────────────────────────────────┐
  │          3축 (믿음/옳음/바람)    5가치 (충/의/효/복수/야망)│
  ├────────────────────────────────────────────────────────┤
  │ 본질     "이 사람은 누구인가"  "구체적으로 어떻게 판단" │
  │ 수준     근본적/철학적         실전적/상황적            │
  │ 사용처   LLM 프롬프트          OCC 감정 평가 수식      │
  │ 변화속도 느림 (Tier 2~4)       중간 (Tier 1~3)        │
  │ 변화범위 큼 (인생이 바뀜)      작음 (반응이 달라짐)    │
  │ 구성     강도+신조+형성기억    수치만                  │
  │ 개수     3개                   5개                     │
  │ 상호관계 하향 압력 발생         상향 신호 발생          │
  │ 불일치   가능하고 자연스러움    ← 이게 캐릭터의 깊이   │
  └────────────────────────────────────────────────────────┘
```

## 7. 1층(성격) ↔ 2층(가치관) 관계

> 📎 상세: [layer1-layer2-relationship.md](layer1-layer2-relationship.md)
> 📎 유형 정리: [character-typology.md](character-typology.md)

```
  ① 1층 → 2층: "기질적 토양"
     성격은 특정 가치관이 형성되기 쉬운 토양을 제공한다.
     그러나 토양이 작물을 결정하지는 않는다.

  ② 2층 → 1층: "극히 드문 역류"
     가치관이 성격을 바꾸는 경우는 Tier4 인생 성찰에서만 가능.

  ③ 1층 ↔ 2층 불일치: "캐릭터의 깊이"
     성격과 가치관이 어긋나는 것은 버그가 아니라 인간다움이다.
     불일치가 내면 갈등을 만들고, 갈등이 서사를 만든다.
```

**핵심 구분**: 기질(①)은 **"수단의 성향"** (어떻게 행동하는가), 가치관(②)은 **"방향의 선택"** (무엇을 위해, 무엇이 옳은가). 같은 성격이라도 가치관에 따라 전혀 다른 인물이 된다.

## 8. ④층 감정 (OCC 인지평가)

> "지금 무엇을 느끼는가" — 사건에 대한 즉각적 반응
> 📎 상세: [occ-emotion-detail.md](occ-emotion-detail.md)

### 8.1 왜 OCC인가

OCC(Ortony, Clore & Collins, 1988)는 감정을 **"상황에 대한 인지적 평가의 결과"**로 본다. 같은 사건이라도 사람마다 다르게 느끼는 이유는, 각자의 목표·기준·태도가 다르기 때문이다. 칠국춘추에서 이 "각자의 목표·기준·태도"가 바로 **③층 5가치**다.

```
  왜 OCC가 게임에 적합한가:
  ┌──────────────────────────────────────────────────────────┐
  │  ① 수식화 가능 → 코드로 <1ms 계산 (결정적, 재현 가능)  │
  │  ② 개인차 표현 → 5가치가 평가 기준이므로 NPC마다 다름   │
  │  ③ 22종 세분화 → 분노와 경멸, 자부와 감탄을 구분        │
  │  ④ 게임 AI 검증 → 30년간 가상 캐릭터에 가장 많이 사용   │
  └──────────────────────────────────────────────────────────┘
```

### 8.2 3가지 평가 대상

```
  평가 대상      칠국춘추 입력           5가치 연결
  ────────────────────────────────────────────────────
  사건 결과      게임 이벤트 발생        충·의·효·복수·야망 전부
                 (납치, 전투, 배신 등)   → "내 가치에 비추어 좋은가?"

  행위자 행동    NPC/플레이어의 행동     의(義) 중심
                 (도움, 배신, 폭력 등)   → "이 행동이 도리에 맞는가?"

  대상 속성      무공, 보물, 장소 등     야망(野) 중심
                 (명검, 비급, 문파 등)   → "이것이 매력적인가?"
```

### 8.3 OCC 인지 평가 흐름

```
  자극(사건) → 분류(사건/행위자/객체) → 평가 → 감정 유형 결정 → 강도 계산

  평가 시 사용되는 것:
  · 5가치 → "이 사건이 내 가치와 충돌하는가?"
  · 목표 → "이 사건이 내 목표를 위협하는가?"
  · 관계 → "이 행위자와 나의 관계는?"
  · 기분(PAD) → 편향 (좋은 기분이면 긍정 감정 증폭)
  · 성격(HEXACO) → 필터 (6요인별 감정 조절)
```

### 8.4 핵심 공식

```
  감정_최종강도 = 기본강도 × 가치_가중치 × 기분편향 × 성격필터

  분노 = 가치위반강도 × 해당_가치_수치 × 기분편향 × A필터
  두려움 = 목표위협강도 × 목표중요도 × (1 - D값) × E필터
  죄책감 = 자기행동도덕위반 × H(정직-겸손) × 해당_가치_수치
  통쾌 = 상대불행강도 × (1 - H) × 관계적대도
```

### 8.5 HEXACO 성격필터 공식

```
  H → 죄책감(Guilt/Shame) × (1.0 + H × 0.005)
     통쾌(Gloating) × (1.0 - H × 0.004)
     도덕비난(Reproach) × (1.0 + H × 0.003)

  E → 두려움(Fear) × (1.0 + E × 0.005)
     측은(Pity) × (1.0 + E × 0.004)

  A → 분노(Anger) × (1.0 - A × 0.004)
     원한(Resentment) × (1.0 - A × 0.003)

  C → 감정→행동 억제 계수
  O → 복합 감정 수용 여부
```

### 8.6 MVP 12종 우선 구현

Joy, Distress, Hope, Fear, Anger, Gratitude, Pride, Shame, Admiration, Reproach, Love, Hate

### 8.7 특징

- **코드로 처리** (<1ms, 결정적)
- 매 사건마다 발생
- 시간에 따라 자연 감쇠 (중립으로 회복)
- 감정은 유형별 반감기에 따라 자연 감쇠 (분노 24시간, 안도 2시간, 애착/혐오 ∞)
- 기분(PAD)에 누적되어 흔적을 남김

## 9. ⑤층 기분 (PAD)

> "전반적으로 어떤 상태인가" — 감정의 렌즈

### 9.1 PAD 3차원

```
  P (Pleasure)  -1.0 ~ +1.0  쾌/불쾌
  A (Arousal)   -1.0 ~ +1.0  각성/이완
  D (Dominance) -1.0 ~ +1.0  지배감/무력감
```

### 9.2 렌즈 효과

```
  기분 적대적 (P=-0.9):
  · 같은 사건이라도 부정 감정 증폭, 긍정 감정 억제
  · "평소 같으면 감사할 상황인데 짜증이 난다"

  기분 좋음 (P=+0.5):
  · 부정 사건에도 감정 반응이 약함
  · "보통 화날 상황인데 그냥 넘어간다"
```

### 9.3 변화 규칙

- 감정이 발생할 때마다 PAD에 누적
- OCC 감정 → PAD 매핑 테이블로 변환
- Tier 2(일상 성찰)에서 리셋/조정
- 시간에 따른 자연 감쇠 (중립으로)

## 10. ⑥층 행동 (Utility AI → LLM)

> "무엇을 하는가" — 코드가 범주, LLM이 구체화

### 10.1 코드: 행동 범주 결정 (Utility AI)

```
  입력: PAD 기분 + 성격(HEXACO) + 감정(OCC) + 5가치
  출력: ActionCategory (fight / flee / negotiate / grieve / seek_ally / ...)

  예:
  fight_score     = f(arousal, dominance, anger, -A, -E)
  negotiate_score = f(-arousal, A, X)
  flee_score      = f(arousal, -dominance, fear, E)
  exploit_score   = f(-H, ambition, dominance)

  → 최고 점수 범주가 선택됨
```

### 10.2 LLM: 구체적 행동/대사 생성

```
  프롬프트에 담기는 것:
  ┌──────────────────────────────────────────────┐
  │ 너는 [NPC이름]이다.                           │
  │ 성격 (HEXACO): H/E/X/A [수치 + 해석]          │
  │ 핵심 가치관: 믿음/옳음/바람 [수치 + 신조]       │
  │ 현재 감정: [OCC 결과]                         │
  │ 현재 기분: [PAD 상태]                         │
  │ 결정된 행동 범주: [Utility AI 결과]           │
```

## 12. 코드/LLM 역할 분담

```
  🔧 코드가 결정하는 것 (확정적, 빠름, 매번 같음)
  ─────────────────────────────────────────
  · OCC 감정 수치 계산 (5가치 입력, HEXACO 성격필터)
  · PAD 기분 갱신
  · 행동 범주 (Utility AI 점수)
  · 성찰 트리거 여부 (importance 합산, 극단값 감지)
  · 변화 범위 제한 (clamp)
  · Memory Stream 저장/검색 (LanceDB)

  🧠 LLM이 결정하는 것 (창의적, 상황적, 매번 다름)
  ─────────────────────────────────────────
  · 구체적 대사와 행동 묘사
  · 하루 계획 내용
  · 관계 재평가의 "이유"와 "라벨"
  · 기억 중요도 재평가
  · 신조 뉘앙스 변화, 전환 판단
  · 성격 변화의 "방향"과 "이유"

  🔧+🧠 협업 (코드가 범위 설정, LLM이 내용 결정)
  ─────────────────────────────────────────
  · 3축 강도: 코드가 Tier별 ±범위 제한, LLM이 수치 제안
  · 5가치: 코드가 ±범위 제한, LLM이 어떤 가치가 변하는지 제안
  · 성격: 코드가 ±5 제한 + 최대 2요인 제한, LLM이 방향 결정
  · 신조 전환: 코드가 대안후보 존재 확인, LLM이 전환 여부 판단
```

### 12.1 안전장치 — LLM 출력 검증 (설계 의사코드)

```rust
fn apply_reflection_result(
    psyche: &mut NpcPsyche,
    result: &ReflectionResult,
    tier: ReflectionTier,
) {
    let max_axis_delta = match tier {
        Tier1 => 5.0, Tier2 => 10.0, Tier3 => 20.0, Tier4 => 30.0,
    };
    let max_value_delta = match tier {
        Tier1 => 5.0, Tier2 => 10.0, Tier3 => 20.0, Tier4 => 20.0,
    };
    let max_personality_delta = match tier {
        Tier4 => 5.0, _ => 0.0,  // Tier 1~3에서 성격 변화 불가
    };

    // ② 3축 강도 변화 clamp
    for (intensity, delta) in axes {
        *intensity += delta.clamp(-max_axis_delta, max_axis_delta);
        *intensity = intensity.clamp(0.0, 100.0);
    }

    // ③ 5가치 변화 clamp
    for (value, delta) in values {
        *value += delta.clamp(-max_value_delta, max_value_delta);
        *value = value.clamp(0.0, 100.0);
    }

    // ① 성격 변화 clamp (Tier4에서만, 최대 2요인)
    if max_personality_delta > 0.0 {
        let changed = traits.iter()
            .filter(|(_, d)| d.abs() > 0.0)
            .count();
        assert!(changed <= 2, "최대 2개 요인만 변경 가능");
    }
}
```

## 13. Aggregate 구조

심리 도메인은 **세 개의 독립 Aggregate**를 가진다.

```
psychology/
├── personality.rs    ← Aggregate 1: HexacoPersonality (①층, 性)
├── three_axis.rs     ← Aggregate 2: ThreeAxisValues (②층, 敍)
├── values.rs         ← Aggregate 3: WuxiaValues (③층, 判)
├── emotion.rs        ← OccEmotion + PADState (④⑤층)
├── behavior.rs       ← UtilityAI 행동 범주 (⑥층)
├── reflection.rs     ← 성찰 Tier 1~4 (⑦층)
└── memory.rs         ← MemoryStream (LanceDB 연동)
```

**분리 근거**:
- 성격(①)과 가치관(②③)은 **독립적으로 변한다** (배신 → 가치관만 변함, 은둔 → 성격만 변함)
- 3축(②)과 5가치(③)는 **사용처와 변화 속도가 다르다** (3축=LLM 서사, 5가치=OCC 수식)
- Aggregate는 "같이 변하는 것"을 묶는 단위 → 따로 변하면 분리

**Aggregate 1 — 성격 (HexacoPersonality, ①층)**:
- H/E/X/A/C/O (각 f32, 0.0~1.0)
- 거의 변하지 않음. Tier 4에서만 ±0.05 제한, 최대 2요인.

**Aggregate 2 — 3축 가치관 (ThreeAxisValues, ②층)**:
- 믿음/옳음/바람 (각 축 = 강도 f32 + 신조 String + 형성기억 + 대안후보[])
- LLM 프롬프트 전용.

**Aggregate 3 — 5가치 (WuxiaValues, ③층)**:
- 충/의/효/복수/야망 (각 f32, 0.0~1.0)
- OCC 감정 평가 수식의 직접 입력.

## 14. 타 도메인 연결

### 14.1 심리 → 성장 (수련 효율)

```
OCC 감정 → 수련 효율 계수:
  Joy(희열)      → 전반적 ×1.1
  Anger(분노)    → 무력 ×1.5, 내공 ×0.7
  Distress(고뇌) → 공감 ×1.4, 무력 ×0.6
  Fear(두려움)   → 경공 ×1.3, 의지 ×0.5

OCC 감정 → 무공 적합도 (기연 조건④):
  독고구검 ↔ Joy/Relief    (마음이 편해야 깨달음)
  항룡십팔장 ↔ Pride        (강한 자부심이 필요)
  구음백골조 ↔ Anger/Hate   (어두운 감정이 맞음)
```

### 14.2 심리 → 관계

- 심리 도메인의 가치관 + 관계 도메인의 적대도를 조합하여 배반 감지
- 야망(높음) + 충성(낮음) + 적대도(높음) = 배반 위험

### 14.3 심리 → 전투

- 감정 상태가 전투 판정에 영향 (분노 → 공격력↑ 방어력↓)

### 14.4 심리 → LLM Adapter

- 심리 도메인은 데이터와 규칙의 주인
- LLM Adapter는 성찰/대사 생성 시 호출되는 도구 (인프라)
- 심리 도메인이 "성찰이 필요하다"고 판단 → LLM Adapter에 요청 → 결과를 기억에 저장
- 프롬프트에는 3축+신조가 포함되고, OCC/PAD 상태가 컨텍스트로 제공됨

### 14.5 시간 → 심리

- YearPassed 이벤트 수신 → 성격 미세 변화 (Tier 4 기반)
