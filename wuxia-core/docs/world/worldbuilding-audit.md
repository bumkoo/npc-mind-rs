## 1. 총평

칠국춘추의 세계관은 **솔로 개발 프로젝트로서 놀라운 깊이**를 갖추고 있습니다. 270년 역사 연표, 7개 국가의 정치체제, 구파일방의 분산 배치, 사파 3파벌 체계, 상방 경제 네트워크까지 다층적으로 설계되어 있습니다.

핵심 강점은 **갈등 씨앗의 역추적 방법론**입니다. 현재 갈등 → 역사적 근원을 추적하는 방식이 일관되게 적용되어, "왜 화산파가 멸문당했는가?"라는 질문에 240년치 역사적 축적으로 답할 수 있습니다.

## 2. 구조 점검 — 초기 설정과의 일치 확인

### 2.1 국가 구조 (요구사항 vs 현재)

| 요구사항 | 현재 설정 | 상태 | 비고 |
|----------|----------|------|------|
| 7개 국가 | 7개 확인 | ✅ | 대진, 남궁, 서량, 북원, 남만, 동해, 자유도시 |
| 4개 왕조 | 4개 확인 | ✅ | 대진(축소 제국), 남궁(가문 왕국), 서량(독왕), 북원(유목 왕국) |
| 3개 공화국 | **1개 공화국 + 1개 부족연합 + 1개 자치령** | ⚠️ 변경됨 | 초기 설계(공화국 3)에서 진화함 |

**⚠️ 변경 사항 확인 필요**:

초기 요구사항은 "3 국가는 공화국"이었으나, 현재 세계관에서는:
- 동해: 공화국 (상방의회) → 유일한 공화국
- 남만: 부족연합 (합의체)
- 자유도시: 강호자치령 (무정부)

이 변경은 세계관의 다양성 측면에서 **더 좋은 선택**이지만, 초기 의도와 달라졌으므로 확인이 필요합니다.

### 3.2 🟡 문파 배치 불일치 (중간)

**history-characters-v1.0** (이전 문서):
```
남궁: 남궁세가, 아미(!), 청성
서촉/서량: 아미(본거지), 점창
남만: 점창(!), 공동(?)
```

**seven-nations-v1.0** (최신 문서):
```
남궁: 남궁세가, 청성
서량: 점창, 아미(당무괴 억류)
남만: 공동(?)
```

**차이점**:
- 아미파: 이전 문서에선 남궁에도 배치, 최신에선 서량에만 → **최신이 맞음** (명경이 서량에서 감금 중)
- 점창파: 이전 문서에선 남만에도 느낌표, 최신에선 서량에만 → **최신이 맞음**
- → `history-characters-v1.0` 12절 문파 배치표 수정 필요

### 3.3 🟡 당무괴 소재지 표기 (중간)

### 3.4 🟢 플레이어 캐릭터 시트 vs NPC 열전 (경미)

플레이어 시트에서 임모(任某)를 "임모"로, 이후 세계사 인물 배치에서 임서운(林書雲)으로 확정.

- 다만 "任某"는 "이름 미상"의 뜻이므로 게임 내에서 "처음엔 이름을 모르고 나중에 알게 되는" 구조로 활용 가능

## 5. 갈등 구조 점검 — 층위별 분석

### 5.1 국가 간 갈등 (매크로)

```
갈등 매트릭스 건강도 확인:

  대진 ←→ 남궁     적대   ✅ 영토 분쟁. 역사적 근거 있음
  대진 ←→ 북원     적대   ✅ 볼모 조약. 설화가 연결고리
  대진 ←→ 동해     경계   ✅ 7년 전 독립 전쟁. 경제적 긴장
  서량 ←→ 북원     충돌   ✅ 서쪽 국경. 곽천웅이 방어
  남궁 ←→ 남만     마찰   ⚠️ 구체적 분쟁 내용 미설정
  
  미약한 축:
  동해 ←→ 남만     교역   ⚠️ 갈등이 없음. 너무 평화로움?
  서량 ←→ 남만     중립   ⚠️ 당무괴의 남만 약재 관심 외에 연결 약함
```

**권장**: 남만-동해, 남만-서량 축에 잠재적 갈등 요소 추가 (약재 독점권 분쟁 등)

### 5.2 인물 간 갈등 (마이크로)
