PAD 자극 경로

v1.1.0 · 수정 2026-06-05T03:53:11+09:00

OCC를 우회하는 두 번째 계보. 상황을 재평가하지 않고, Player 발화의 PAD 3축으로 기존 감정 강도만 직접 증폭·약화한다. 새 감정은 생성하지 않는다.

OCC 경로와의 근본 차이 01~07(OCC)은 "상황 → 성격이 감정을 계산". 08(PAD)은 "발화 → 감정을 직접 민다". HEXACO weight·기준값·prospect 전부 거치지 않는다. 실시간 대화 매 턴의 경로.

1입력 — Pad 3축

domain/pad.rs · struct Pad

필드타입의미
pleasuref32쾌·불쾌
arousalf32각성·이완
dominancef32지배·복종

OCC 경로의 desirability_for_self 같은 입력 필드가 존재하지 않는다. Player 발화를 PAD로 분석한 값이 곧 자극이 된다. MCP StimulusApplyRequested로 진입.

2핵심 공식 — apply_stimulus

stimulus.rs · 감정별 루프 Δ = alignment × absorb × impact_rate × inertia
새 강도 = clamp( 기존 강도 + Δ , 0 , 1 )
항출처의미
alignmentpad_dot(emotion_pad, stimulus)그 감정의 PAD 좌표와 자극의 내적 — 같은 방향이면 +, 반대면 −
absorbpersonality.stimulus_absorb_rate(stimulus)성격이 캡슐화한 "자극 수용도" (HEXACO)
impact_rateprofile().stimulus_impact_rate (0.5)한 턴 변동 제한 계수 (튜닝)
inertia(1−i).max(stimulus_min_inertia) (0.30)이미 강한 감정일수록 덜 흔들림. 단 최소 관성 보장
방향 동역학 자극과 같은 방향 감정 → 증폭. 반대 방향 → 감소. stimulus_fade_threshold(0.05) 이하로 떨어진 감정은 자연 소멸(remove). iter_active만 순회 — 새 감정은 절대 생성 안 함(OCC와 결정적 차이).

pad_dot 두 인자의 출처

alignment = pad_dot(emotion_pad, stimulus) — 이 내적의 두 입력은 출처가 다르다.

인자출처성격
emotion_pademotion_to_pad(감정타입) — pad.rs 룩업감정별 상수 좌표 (NPC·상황 무관)
stimulusStimulusApplyRequested.pad (이벤트 입력)대사 분석 산출 변수 (임베딩→PAD→청자변환)
내적의 의미 "이 감정의 고정 방향"(emotion_pad)과 "들어온 자극 방향"(stimulus)이 얼마나 정렬됐는지. 양수면 그 감정 증폭, 음수면 약화. stimulus 출처 파이프라인은 09(대사→PAD) 참조.

4무협 워크드 예시

임충이 분노(0.4) 중, Player가 도발 대사

자극 PAD = 분노 방향과 정렬(alignment>0). absorb=0.8, impact=0.5 가정, inertia=(1−0.4)=0.6

Δ = alignment(+0.7) × 0.8 × 0.5 × 0.6 = +0.168 새 분노 = clamp(0.4 + 0.168, 0, 1) = 0.568 // 같은 방향 자극 → 기존 분노 증폭. 새 감정 생성 없음
위로 대사 (분노와 반대 방향)
Δ = alignment(−0.6) × 0.8 × 0.5 × 0.6 = −0.144 새 분노 = 0.4 − 0.144 = 0.256 // 약화

▸ stimulus.rs — apply_stimulus 전문 domain/emotion/stimulus.rs 
fn apply_stimulus<P: StimulusWeights>(&self,
    personality: &P, current_state: &EmotionState, stimulus: &Pad) -> EmotionState {
    let absorb = personality.stimulus_absorb_rate(stimulus);
    let p = profile();
    let mut new_state = current_state.clone();

    for (t, i, _) in current_state.iter_active() {
        let emotion_pad = emotion_to_pad(t);
        let alignment = pad_dot(emotion_pad, *stimulus);
        let inertia = (1.0 - i).max(p.stimulus_min_inertia);
        let delta = alignment * absorb * p.stimulus_impact_rate * inertia;
        let new_intensity = (i + delta).clamp(0.0, 1.0);

        if new_intensity < p.stimulus_fade_threshold {
            new_state.remove(t);          // 자연 소멸
        } else {
            new_state.set_intensity(t, new_intensity);
        }
    }
    new_state
}
