## 0. 왜 본기(本紀)인가

```
태무제는 게임 시작 15년 전에 사망했거나 행방불명된 인물이다.
그러나 칠국춘추의 모든 현역 인물은 태무제의 그림자 안에 있다.

  열전(列傳) = 한 인물의 이야기
  본기(本紀) = 한 시대의 이야기 — 인물을 통해 쓴

  태무제 열전이 아니라 본기인 이유:
  · 명경이 살린 것은 "단운"이다
  · 조고가 배신한 것은 "황제"이다
  · 바투가 믿은 것은 "형"이다
  · 남궁혁이 동경한 것은 "영웅"이다
  · 진영이 반대한 것은 "폭군"이다
  → 이 모든 사람이 만난 것은 같은 사람이다.
  → 그러므로 이것은 한 사람의 전기가 아니라,
     한 시대의 기록이다.

  게임 내 등장 방식:
  ① 명경의 회상 — "30년 전, 내가 살린 사람"
  ② 조고의 기억 — "나를 높여준 자, 내가 무너뜨린 자"
  ③ 바투의 분노 — "형이라 불렀던 자, 약속을 저버린 자"
  ④ 남궁혁의 동경 — "12세 소년이 올려다본 영웅"
  ⑤ 진영의 유서 — "폐하, 백성의 피로 왕좌를 칠하시면..."
  ⑥ 낙양 황궁의 밀실 — 단운의 유서와 혈교 거래 증거
  ⑦ 풍만리의 전설 — 전장에서 함께 싸운 자의 행방
  → 플레이어는 파편을 모아 하나의 그림을 완성한다.
     그러나 그림은 보는 각도에 따라 다르다.
```

### 이름의 뜻

```
端 = 바를 단, 시작
雲 = 구름 운

"바른 구름" 또는 "시작의 구름"

  황실 방계 왕족의 이름답게 "端(바름)"으로 시작.
  즉위 전에는 "바른 뜻을 품은 구름 같은 청년"이었다.
  → 구름은 비를 내려 만물을 적시지만
    폭풍이 되면 만물을 쓸어버린다.
  → 이름 자체가 비극의 예고:
    "바름(端)"에서 시작했으나 "바름"을 잃은 자.

  묘호 "태무(太武)":
  太 = 클 태
  武 = 무예 무, 전쟁 무
  → "위대한 전쟁의 황제"
  → 서역 연합을 격퇴한 공으로 추존
  → 아이러니: "무(武)"로 나라를 구했으나
    "무(武)"로 나라를 부쉈다.
```

## 5. 열전 — 제1막: 빛 (207~240년차 / 0~33세)

### 5.1 방계의 야망

```
단운의 출신 — "왕좌에서 가장 먼 왕족":

  207년차 출생.
  대진 황실 진씨(辰氏) 방계 중의 방계.
  황위 계승 서열: 17위 이하 (사실상 없음).

  대진 황실의 상황 (200~230년차):
  · 중앙 권력 약화. 지방 자치 요구 증가.
  · 황위 계승 분쟁 반복 — 5대에 걸쳐 8번 교체.
  · 직계 왕족들이 서로 죽이며 소진.
  · 방계 왕족은 낙양에서 이름만 유지.

  단운의 아버지: 방계 왕족. 관직 없음.
  단운의 어머니: 서량 변경 군인의 딸.
  → "왕족이되 왕족 대접을 받지 못한 아이"
  → 야망(0.9)의 씨앗.

  어린 단운:
  "언젠가 내가 왕좌에 앉으면,
   다시는 아버지가 고개를 숙이지 않아도
   되게 하겠습니다."
  → 진심이었다. 그래서 비극이다.
```

### 5.2 즉위 — 237년차 (30세)

```
  236년차:
  · 제16대 황제, 후사 없이 급사.
  · 직계 왕족 대부분 이미 사망 또는 추방.
  · 방계를 뒤지다 단운을 발견.

  단운이 선택된 이유:
  ① 살아있는 왕족 중 가장 젊고 건강
  ② 군사적 배경 (어머니 쪽 서량 군인 혈통)
  ③ 조정 파벌에 연루되지 않음 (너무 방계라서)
  ④ 원로들의 계산: "꼭두각시로 쓰자"

  즉위 후:
  · 1년 안에 원로 3인을 교체.
  · 2년 안에 조정을 장악.
  · "꼭두각시"를 기대한 원로들의 착각.

  이 시기 조고(20세)의 입궁:
  · 단운이 즉위할 때 하급 관리로 입궁
  · 원로들의 혼란 속에서 단운에게 밀서 전달:
    "폐하, 좌승상의 재산 목록입니다."
  · 단운: "...자네 이름이?"
  · 조고: "조고라 합니다. 폐하."
```

### 전장의 에피소드 — 아름다운 순간들

## 7. 열전 — 제2막: 그림자 (240~250년차 / 33~43세)

### 7.1 전후 — 약속의 시대

```
전쟁 승리 후 단운에게 쏟아진 약속들:

  무림에게: "전쟁이 끝나면 원래대로 돌아간다"
  바투에게: "북원의 독립을 인정하겠다"
  명경에게: "은혜를 갚겠다"
  백성에게: "태평성세를 이루겠다"

  → 단운은 이 중 하나도 지키지 않았다.

  왜?
  "전쟁을 이겼으니 이제 진짜 일을 해야 한다."
  태무제의 3대 목표:
  ① 병권 회수 — 무림을 통제
  ② 지방 자치 진압 — 중앙집권
  ③ 수명 연장 — 내가 영원히 이 일을 해야 한다
  → ③이 ①②를 망치는 비극 구조
```

### 7.2 바투와의 약속 파기

```
  전쟁 직후: 바투: "독립을 선언해 달라."
            단운: "시기가 아니다. 조정이 안정되면."
  1년 후:   바투: "1년이 지났다."
            단운: "조금만 더."
  3년 후:   바투: "단운. 더 이상은 못 참는다."
            단운: "참아라. 형이 부탁한다."
            바투: "...형? 황제가 형이라 부르면
                  형제의 나라를 속국으로 두어도 되는가?"
  5년 후:   단운: (조고 영향 하) "볼모를 보내라."
            바투: "...볼모? 초원에서는 형제의 자식을
                  볼모로 잡지 않는다. 네가 처음이다."

  → 바투는 전후 소진 + 부족 통합 미완 → 거부할 힘 없음
  → 태무제 시기: 이름만 보내고 버팀
  → 태무제 사후: 조고가 "진짜 볼모" 재요구
  → 5년 전(265년차): 결국 막내 딸 야율설화(12세)를 보냄
    · 바투 41세에 얻은 아이 — 초원의 모든 꽃을 닮은 딸
    · "아들을 보내면 전쟁이 된다. 딸을 보내면 평화가 된다."
    → 사랑하는 딸이기에 보낼 수 있었다
    → "이 아이는 검을 들지 않으니 적어도 죽지는 않겠지"
    → 그런데 야율설화가 천마기공을 배우게 된다 — 바투는 모름
```

### 7.3 무림-관의 유착 (4단계)

```
  1단계 (전후 직후): 명예로운 협력
    "함께 피를 흘린 전우"

  2단계 (5~10년 후): 관성적 협력
    관에서 무림에 "작은 부탁" → 점점 커짐
    대가: 영토 보호, 세금 면제, 관직 제공

  3단계 (10~15년 후): 하수인화
    조고가 태무제 사후 권력 장악
    일부 문파가 조고의 어두운 일을 수행

  4단계 (현재): 분열과 비판
    젊은 협객: "구파일방은 기득권이다"
    무진대사(66세): "사조의 문을 열어야 했는가,
                   닫았어야 했는가."
```

### 7.4 조고의 성장

```
  25세: "충성스러운 관리" — 단운이 위
  30세: "유능한 참모" — 점점 대등
  35세: "필수적인 존재" — 단운이 의존
  40세: "제거할 수 없는 존재" — 단운이 아래

  십상시 결성 — 245년차 (조고 30세):
  · 무림 고수 10인을 사병으로 편입
  · 단운: "경호 조직이 필요하다면 만들어라."
  → 단운은 "경호 조직"을 허가했다.
    조고는 "암살 조직"을 만들었다.
```

### 7.5 혈교 비밀 거래

### 8.1 추양진인과의 대립

```
  조고: (옆에서 기록한다)

  조고: "예, 폐하."

  조고: "깨끗이 처리했습니다."
  단운: (창밖을 본다. 아무 말 없다.)
```

### 8.3 단운의 유서

```
사망/행방불명 직전 — 명경에게 보낸 편지:

  "경아(鏡兒),
   30년 전의 약속을 지키지 못했다.
   내가 만든 이 세상이 무너지고 있다.
   화산파를 막을 수 없었다. 용서해 다오."

  → 이 유서의 해석이 게임의 핵심 미스터리 중 하나:
  ① "화산파를 막을 수 없었다" = 화산파 멸문 명령이 아닌?
     → 누가 화산파 멸문을 결정했는가?
  ② "이 세상이 무너지고 있다" = 조고를 통제 불가?
  ③ "용서해 다오" = 참회? 자기 연민?
  → 명경은 이 편지를 아무에게도 보여주지 않았다.
     호감도 90+ 특정 퀘스트 완료 시에만 공개.
```

### 8.4 사망/행방불명 — 255년차

```
태무제의 최후 — 세 가지 이론:

  공식 기록:
  "태무제 단운은 혈교 잔당과의 전투 중 부상으로 사망."

  이론 A: 조고의 독살
  · 더 이상 단운이 필요 없다고 판단.
  · 십상시를 통해 독살.
  · 근거: 단운 사후 조고가 즉시 권력 장악.

  이론 B: 혈교 비술의 부작용으로 심신 약화
  · 전투에 나갈 체력이 아니었으나 출진.
  · 일종의 자살적 출진.
  · 근거: 단운의 유서 어조 = 체념.

  이론 C: 자발적 실종
  · 모든 것에 지쳐 스스로 사라짐.
  · "황제 단운은 죽었다. 단운은 살았다."
  · 근거: 시신이 확인되지 않음.

  → 게임은 어떤 이론이 맞는지 확정하지 않는다.
  → 플레이어가 증거를 모아 자기 결론을 내리는 구조.
  → 셋 다 맞을 수도, 셋 다 틀릴 수도 있다.
```

### 9.2 단운이 각 인물에게 남긴 것

```
각 NPC가 기억하는 단운 — 같은 사람, 다른 기억:

  명경(49세):
  "30년 전 내가 살린 사람.
   그 사람이 세상을 망쳤다.
   ...그런데 마지막 편지는 '미안하다'였다."
  → 태무제에 대한 감정: 원망 + 미련 + 죄책감
  → "내가 살리지 않았다면 세상이 달랐을까?"

  조고(55세):
  "나를 높여준 자. 그리고 내가 넘어선 자."
  → 태무제에 대한 감정: 경멸 + 부채의식
  → 조고는 단운을 얕보지 않는다.
     "단운은 약했던 것이 아니다. 방향이 틀렸을 뿐."

  바투(58세):
  "형이라 불렀다. 진심이었다.
   형도 진심이었을까. 모르겠다."
  → 태무제에 대한 감정: 분노 + 그리움
  → "단운이 살아있었다면 이런 일은 없었을까.
     아니, 단운이 시작한 일이다."

  남궁혁(42세):
  "12세 때 언덕에서 봤다. 깃발이 펄럭였다.
   저런 사람이 되겠다고 생각했다."
  → 태무제에 대한 감정: 동경 + 초월
  → "나는 단운이 하려던 것을 더 잘하겠다."
  → 그러나 남궁혁의 방법도 단운과 닮아가고 있다.

  남궁현(51세):
  "전장에서 만났다. 위엄 있는 분이었다.
   그런데 그 위엄이 마지막에는..."
  → 태무제에 대한 감정: 실망 + 교훈
  → "야망은 좋다. 다만 방향을 잃으면 안 된다."

  진야림(25세):
  "아버지를 죽이라 명한 황제."
  → 태무제에 대한 감정: 무(無)
  → 진야림은 태무제를 증오하지 않는다. 이미 죽었으니.
     진야림이 증오하는 것은 "실행한 자" = 조고.

  무진대사(66세):
  "전장에서 함께 싸웠다. 용감한 분이었다.
   전쟁이 끝나고 약속을 어겼다.
   그러나 나도 약속을 어겼다."
  → 태무제에 대한 감정: 복잡한 동지의식 + 자기 비판
  → "단운을 탓하기 전에, 나 자신부터 돌아봐야 한다."

  추양진인(사망):
  (붉은 밤의 변, 화산파 멸문 직전)
  "폐하, 이것이 당신의 답입니까?"
  → 마지막까지 "폐하"라 불렀다. 존경이 아니라 분노.
```

### 9.3 태무제 이후의 연쇄

```
단운 사후 조고의 15년:

  255년차: 태무제 사망/행방불명
           → 조고가 즉시 실권 장악
           → 영주 번왕국 폐지 → 대진 직할 편입
  
  258년차: 피의 실종 사건
           → 조고가 위험 인물 제거
           → "알고 있는 자를 없애면, 진실이 바뀐다"
  
  260년차: 붉은 밤의 변. 화산파 멸문.
           → 추양진인 전사. 임서운 도주.
           → 플레이어(7세) 혈매화검과 함께 구출.
           → "화산파는 너무 많이 알고 있었다."
  
  261~265년차: 칠국 분열
           → 동해 독립 → 서량 독립 → 남궁 독립
           → 남만 독립 → 자유도시 선포
  
  265년차: 천순제 옹립. 꼭두각시 황제.
           → 조고의 완전한 권력.
  
  270년차 (현재): 게임 시작.
           → 단운이 심은 씨앗이 모두 열매를 맺음.
              모든 열매가 독이다.

  조고의 악행 연쇄 — 단운이 연 문:
  ┌─────────────────────────────────────────────┐
  │  ① 영주 숙청(255) → "태무제 명(命)" → 조고 실행│
  │  ② 피의 실종(258) → 조고 단독 판단              │
  │  ③ 화산파 멸문(260) → 조고 단독(?) 판단         │
  │                                              │
  │  ①은 단운의 명령이 있었다.                     │
  │  ②③에 단운의 명령이 있었는지는 불명.            │
  │  → 단운이 살아있었다면 ②③을 막았을까?           │
  │  → 아니면 단운의 침묵이 허가였을까?             │
  │  → 이것이 게임의 핵심 미스터리.                 │
  │                                              │
  │  공통 패턴:                                    │
  │  · 실행: 십상시 (무력)                          │
  │  · 은폐: 기록 조작 (붓)                         │
  │  · 결과: 공식적으로 "사고" 또는 "정당한 조치"    │
  │  · 생존자: 아이 (조고가 간과한 변수)             │
  │                                              │
  │  "어른들의 전쟁에서 살아남은 아이들이            │
  │   자기 이야기를 쓰기 시작한다."                  │
  └─────────────────────────────────────────────┘
```

## 11. 비밀 (Secret) — 플레이어가 발견할 것

### 비밀 ① — 혈교와의 거래 전모

```
단운은 수명 연장만 원한 것이 아니다.
혈교 비술을 통해 내공을 비약적으로 끌어올리려 했다.

  조고가 이 거래를 관리한 이유:
  "폐하, 쓸모가 있을 것입니다."
  → 조고는 처음부터 이 거래를 자기 카드로 활용할 계획이었다.
  → 단운이 혈교와 거래한 사실 = 조고의 약점 장악 수단.
  → "폐하, 이 사실이 알려지면..."
     단운: "...알겠다."
  → 이 한마디로 조고에 대한 의존이 완성.

  낙양 지하 혈교 시설:
  · 조고가 관리한 비밀 연구소.
  · 12년 전 소연과 다른 아이들이 납치된 곳이 바로 여기.
  · 현재도 존재 — 피의 실종의 최종 답.

  → 메인 퀘스트 "피의 실종의 진실"의 핵심.
```

### 비밀 ② — 화산파 멸문의 진짜 명령자

```
공식 기록: "화산파가 반역을 도모하여 진압."
조고 주장: "태무제의 유지(遺志)를 따른 것."

  실제:
  · 태무제의 유서에는 "화산파를 막을 수 없었다"고 기록.
  · "막을 수 없었다" = 화산파 멸문을 자기가 명령한 것이 아닌?
  · 아니면 "막을 수 없었다" = 조고를 막을 수 없었다?

  가설 A: 조고의 독단
  · 태무제 사후 조고가 "유지"를 사칭하여 멸문 실행.
  · 화산파의 혈교 지식 = 조고의 혈교 거래를 폭로할 위험.

  가설 B: 태무제의 암묵적 허가
  · 살아있을 때 "화산이 문제다"라고 말한 적 있음.
  · 조고가 이를 "명령"으로 확대 해석.
  · 단운 자신도 이 확대 해석을 예상했을 수 있음.

  가설 C: 남궁혁의 공모
  · 남궁 독립에 화산파가 걸림돌.
  · 남궁혁이 조고와 "교환" — 화산파 멸문 협력 ↔ 남궁 독립 묵인.
  · 근거: 남궁혁이 "붉은 밤" 언급 시 신경증 0.6 상승.

  → 게임은 확정하지 않는다.
  → 플레이어가 증거를 모아 자기 결론을 내린다.
```

### 비밀 ③ — 태무제 생존 가능성

```
시신 미확인.
유서의 존재.
혈교 수명 연장 비술.

  만약 살아있다면:
  · 63세 (현재 기준).
  · 혈교 비술의 부작용으로 심신 변질 가능.
  · 서역 어딘가, 또는 대진 변경에 은거?
  · 풍만리의 행방불명과 관련?
    (풍만리도 혈교 비술로 수명 연장 → 둘 다 서역?)

  게임적 의미:
  · 플레이어가 태무제 생존 단서를 추적할 수 있는 숨겨진 퀘스트.
  · 만약 만난다면 — 48세에 멈춘 외모의 노인?
  · "경아(명경)는 잘 있느냐?"가 첫마디일 수도.
  · 또는 혈교 비술에 완전히 잠식되어
    본인 인격이 남아있지 않을 수도.

  → 이것은 v1.0에서 확정하지 않는다.
  → "가능성"으로만 남겨둔다.
  → 게임 확장이나 후속작의 카드.
```

## 13. LLM 대사 생성 가이드 (AI 도메인)

### NPC별 태무제 언급 규칙

```
태무제는 직접 등장하지 않으므로,
다른 NPC의 대사를 통해서만 존재한다.
각 NPC가 태무제를 언급할 때의 규칙:

  명경:
  · 호칭: "폐하" 또는 "단운" (감정 상태에 따라)
  · 평상시: 언급 회피. "오래된 일이다."
  · 호감도 80+: "30년 전에 한 사람을 살렸다. 그 사람이..."
  · 유서 공개 시: 목소리 떨림. 긴 침묵.
  · 금지: 태무제를 직접 비난하지 않는다. 비난 대신 침묵.

  조고:
  · 호칭: "선제(先帝)" (공식석상) / "단운" (독백 또는 비밀 대화)
  · 태도: 존경하는 척하지만 본심은 초월감.
  · "선제께서 시작하신 일을 마무리할 뿐입니다."
  · 플레이어가 추궁 시: "단운은 약한 사람이 아니었네.
    다만... 방향이 틀렸을 뿐이야."
  · 금지: 태무제를 공개적으로 폄하하지 않는다 (정당성 유지 위해).

  바투:
  · 호칭: "단운" 또는 "형" (감정 폭발 시)
  · 태도: 분노와 그리움이 뒤섞인.
  · "형이라 불렀다. 한때는 진심이었다."
  · 야율설화 언급 시: "네 형이 시작한 일 때문에 내 딸이..."
  · 금지: 태무제를 "황제"라 부르지 않는다. 끝까지 "단운" 또는 "형".

  남궁혁:
  · 호칭: "태무제" (공식적 거리)
  · 태도: 동경하되 비판적.
  · "위대한 황제였다. 다만 너무 많은 것을 원했다."
  · 화산파 언급 시: 미묘한 반응 (신경증 ↑).
  · 금지: 감정적이 되지 않는다. 항상 분석적.

  무진대사:
  · 호칭: "태무 폐하" (존경의 잔재)
  · 태도: 자기 비판과 엮여 있음.
  · "폐하와 함께 싸웠다. 그것이 자랑이었다.
    그런데 그 자랑이 사슬이 될 줄은..."
  · 금지: 태무제를 비난하면 자기도 비난해야 하므로, 비난 대신 탄식.
```

### 태무제 회상 장면 생성 지침

```
LLM이 태무제 회상 장면을 생성할 때:

  원칙 ①: 같은 장면, 다른 기억
  · 전쟁 장면을 명경이 회상하면: 의료 중심. 피와 약초 냄새.
  · 같은 장면을 바투가 회상하면: 기마전 중심. 바람과 활 소리.
  · 같은 장면을 조고가 회상하면: 보급 중심. 숫자와 목록.
  → 하나의 사건, NPC 수만큼의 기억.

  원칙 ②: 미화하지 말 것
  · 태무제는 영웅이 아니다. 폭군도 아니다.
  · "한때 영웅이었고, 나중에 폭군이 된 자"도 아니다.
  · 정확히: "처음부터 끝까지 야망의 사람.
    야망이 옳은 방향일 때는 영웅, 틀린 방향일 때는 폭군."
  · → NPC가 태무제를 회상할 때 "좋은 시절"만 말하지 않는다.
       좋은 시절 안에도 이미 그림자가 있었다는 것을 보여준다.

  원칙 ③: 유서는 최고의 카드
  · 단운의 유서("경아, 미안하다")는 게임 전체에서
    가장 감정적 무게가 큰 대사 중 하나.
  · LLM이 유서를 함부로 생성하지 않는다.
  · 유서 공개 조건이 충족되었을 때만.
  · 공개 시 명경의 반응은 최소 5초 침묵 후 한마디.
```

## 14. 사기(史記) 태사공曰 — 열전의 결어

```
태사공이 말한다 (太史公曰):

  단운은 구름이었다.
  
  비를 내려 만물을 적시기도 했고,
  폭풍이 되어 만물을 쓸기도 했다.
  
  30년 전, 중원의 모든 영웅이 한 사람 아래 모였다.
  그 한 사람이 사라진 뒤,
  영웅들은 서로의 적이 되었다.
  
  혹자는 말한다:
  "단운이 없었다면 칠국은 없었을 것이다."
  
  그러나 또한 이렇게도 말할 수 있다:
  "단운이 없었다면 서역 연합에 중원이 짓밟혔을 것이다."
  
  영웅과 폭군 사이에 선 하나가 있다.
  그 선은 눈에 보이지 않는다.
  넘었는지조차 모르는 사이에 넘어간다.
  
  단운은 그 선을 넘었는가?
  아니면 선 자체가 처음부터 없었는가?
  
  이것을 판단하는 것은 역사가의 일이 아니다.
  이것을 판단하는 것은
  — 지금 이 이야기를 살아가는 자의 일이다.
  
  즉, 플레이어의 일이다.
```

## 15. 부록: 소림 항렬 체계

```
칠국춘추 소림사 항렬표 (270년, 7세대):

  세대   돌림자   시기              대표 인물
  ────────────────────────────────────────────
  1대    元(원)   건국기 (270년 전)   원혜대사 — 혈교 봉인
  2대    慧(혜)   240년 전           혜안대사 — 병권 회수 시 황실 협력
  3대    淨(정)   170~140년 전       정심대사 — 사파 파문 결정
  4대    覺(각)   80년 전            각원대사 — 혈교 경고 무시
  5대    智(지)   50~30년 전        ★ 지해대사(智海) — 전쟁 시 설득자
  6대    武(무)   30년 전~현재       ★ 무진대사(武眞) — 현 방장. 금강권
  7대    空(공)   현재 젊은 세대      수련 중인 제자들

  항렬 의미:
  元 = 근원   → 시작하는 자
  慧 = 지혜   → 밝히는 자
  淨 = 정결   → 가르는 자 (파문의 아이러니)
  覺 = 깨달음 → 보아야 할 자 (못 본 아이러니)
  智 = 지혜   → 아는 자
  武 = 무(武) → 행하는 자
  空 = 공(空) → 비우는 자 (미래 세대)

  ★ 5대 "智"와 6대 "武"의 대비:
  · 지해대사 = 지혜로 설득한 자 (전쟁 불참, 전후 입적)
  · 무진대사 = 주먹으로 증명한 자 (금강권, 현 방장)
  → 이름만 봐도 사부(지혜)와 제자(무력)의 대비가 드러남.

  게임 내 항렬 작동:
  智해(5대) ← 사부
    └→ 武진(6대) ← 현 방장
         └→ 空현(7대) ← 젊은 제자
  이름만 보면 서로 몇 세대인지 즉시 파악 가능.
```
