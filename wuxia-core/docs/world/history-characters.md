# 칠국춘추 세계사 연표 — 인물·문파 배치 v1.2

> **문서 버전**: v1.0  
> **작성일**: 2026-02-12  
> **상태**: 초안 → v1.1 (미정 인물 작명 완료. 각 인물 열전은 별도 문서로 확장 예정)  
> **관련 문서**: `history.md` (연표 골격), `character-naming.md` (작명 근거)  
> **설계 원칙**: 각 분기점에 "누가 관여했는가"를 배치하여, NPC 대사·퀘스트의 역사적 근거 확보  

---

## 0. 배치 원칙

### 0.1 왜 인물·문파를 배치하는가

```
연표만 있으면:  "240년 전 병권 회수 시도가 있었다"  ← 교과서
인물이 있으면:  "240년 전 3대 황제 태광제가 소림 방장 혜안에게
                무기 등록을 요구했고, 화산 장문인 청풍검 진무양이
                이를 거부하여 무림 독립이 관행화되었다"  ← 이야기
```

NPC가 "우리 문파의 조사(祖師)인 진무양 선배님이..."라고 말할 수 있으려면, 각 분기점에 구체적 인물이 필요합니다.

### 0.2 인물 유형

| 유형 | 설명 | 게임 내 기능 |
|------|------|-------------|
| 역사 인물 | 이미 죽은 사람 | NPC 대사, 서적, 비문에 등장 |
| 현역 인물 | 게임 시작 시 생존 | NPC로 직접 만남 |
| 전설 인물 | 실존 여부 불확실 | 퀘스트 단서, 비급 저자 |

### 0.3 문파 위치 추적 원칙

270년간 구파일방의 **정치적 입장**이 변합니다. 각 분기점에서 "이 문파는 어느 편이었는가"를 추적하면, 현재의 동맹/적대 관계에 역사적 깊이가 생깁니다.

## 1. 건국기 — 원년 (270년 전): 창세 전쟁

### 1.1 핵심 인물

| 인물 | 소속 | 역할 | 사후 평가 |
|------|------|------|-----------|
| **대진 태조 (진천명/辰天命)** | 황실 | 무림 연합의 지원을 받아 황제 즉위 | "건국의 영웅. 무림과의 약속을 지킨 유일한 황제" |
| **초대 무림맹주 (현무진인/玄武眞人)** | 무당파 | 구파일방 결성을 주도, 초대 맹주 | "무당이 한때 맹주 파였다는 증거" |
| **소림 방장 (달마원/達摩院) 원혜대사** | 소림 | 혈교의 마공을 봉인하는 불법(佛法)을 주도 | "소림의 혈교 마공 봉인술이 여기서 시작" |
| **화산 개조 (자양진인/紫陽眞人)** | 화산파 | 혈교 토벌 선봉, 혈교 본거지에 최초 진입 | "화산파가 혈교에 집착하는 이유의 근원" |
| **혈교 교주 (적마존/赤魔尊)** | 혈교 | 270년 전 패퇴, "멸망"한 것으로 기록 | "정말 죽었는가? 잔존 세력은?" |
| **개방 초대 방주 (천리안/千里眼)** | 개방 | 혈교 정보 수집을 담당, 첩보전 승리의 핵심 | "개방의 정보력 전통이 여기서 시작" |

### 1.2 문파 입장

```
구파일방 건국기 입장표:

문파        입장              근거
───────────────────────────────────────────
소림        황실 협력          불교 + 안정 추구
무당        맹주 파            초대 맹주 배출
화산        선봉 독립파        "우리가 싸워서 이겼다" 자부심
곤륜        황실 협력          서역 방어 담당
아미        중립 치유          전장 의료 담당
청성        화산과 동맹        독립 노선
해남        황실 협력 (해상)   해상 수송 담당
점창        소림 추종          안정 추구
공동        독립              산중 은거 성향
개방        초월적 중립        정보 조직의 특성
```

### 1.3 "약속"의 구체적 내용

```
【무림-조정 상호존중 맹약 (武林-朝廷 相互尊重盟約)】

  장소: 혈교 격퇴 직후, 중원 평야 전장
  방식: 구두 + 맹세 (문서 없음 → 270년 분쟁의 씨앗)

  태조의 약속:        무림맹주의 약속:
  ─────────────      ──────────────
  "문파의 무력을     "황실의 정당성을
   침범하지          훼손하지
   않겠다"           않겠다"

  "무림인을          "국가 위기 시
   강제 징집하지      자발적으로
   않겠다"           협력하겠다"

  해석 분쟁 포인트:
  ① "침범하지 않겠다"의 범위는? → 세금은? 등록은?
  ② "자발적 협력"의 한계는? → 거부할 수 있는가?
  ③ 구두 맹약이므로 증인이 죽으면? → 해석권은 누구에게?
```

```
상방 구조 (200년 전 형성):

```

```
  곤륜  → 서역 교역 관문 → 지역 패권

  소림/무당 → 자급자족 (수련 위주)
  화산/청성 → 내륙 산중, 교역과 거리

→ 200년 전부터 "돈 있는 문파"와 "무공만 있는 문파"의 격차 시작
```

| **녹림왕 (산적왕/山賊王)** | 녹림/흑도 | 상방 호위 거부한 무인들의 결집. "약탈이 아닌 통행세" | "흑도의 시작은 생존이었다" |
| **독고선 (獨孤仙)** | 독립 세력 | 어디에도 속하지 않은 방랑 검객의 상징적 인물 | "후대 독립 무인들의 정신적 시조" |

### 5.2 사파 3파벌의 기원 상세

```
파문의 3가지 유형 → 사파 3파벌의 기원:

  ① "금기된 지식 추구" 파문
     └─→ 천마신교 (마교 계열)
         핵심 인물: 초대 천마 (소림 출신)
         동기: "혈교 무공을 이해해야 막을 수 있다"
         정파 해석: "사도(邪道)에 물들었다"
         사파 해석: "진리를 추구했을 뿐"
         → 3대 천마 (현재 게임 내 인물)로 계승

  ② "돈을 위해 검을 쓴다" 파문
     └─→ 흑도 (녹림)
         핵심 인물: 초대 녹림왕
         동기: 문파 규율에 맞지 않는 거친 무인들
         상방과의 관계: 적대 → 공생 (통행세 ↔ 보호)
         → 현재 상방 내 무력 집행 조직으로 변질

  ③ "나는 내 검만 따른다" 자진 이탈
     └─→ 독립 세력
         핵심 인물: 독고선
         동기: 조직에 대한 회의. "문파는 감옥이다"
         특징: 느슨한 연대, 공식 조직 없음
         → 자유도시에 독립 무인이 특히 많은 이유
```

### 6.1 핵심 인물

### 6.2 자치 요구와 구파일방의 반응

```
자치 운동에 대한 문파별 반응 (110년 전):

  문파        반응             이유
  ──────────────────────────────────────────
  소림       반대 (황실 지지)   안정 우선, 통일 유지
  무당       우려하나 중립      "시비를 판단할 때가 아니다"
  화산       은밀히 동조        "황실이 약속을 안 지키니 당연"
  곤륜       서역 자치 요구     곤륜 자체가 변경 → 사실상 자치 희망
```
