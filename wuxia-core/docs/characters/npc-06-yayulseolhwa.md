### 이름의 뜻

```
耶律 (야율) = 북원 왕족 성씨.
  · 역사 참조: 요(遼)나라 야율씨에서 음감 차용
  · 유목 민족 왕족의 표지 — 이름만 들어도 "초원의 사람"
  · 대진식 이름이 아닌 것 자체가 정체성의 선언

雪 (설) = 눈.
花 (화) = 꽃.

"눈 속에 피는 꽃"

  雪(설)의 의미:
  ① 북원의 겨울 — 고향의 풍경
  ② 차갑고 날카로운 외면 — 볼모 생활이 만든 방어기제
  ③ 하얗고 깨끗함 — 아직 피로 물들지 않은 손

  花(화)의 의미:
  ① 초원에 피는 야생화 — 정원이 아닌 들판에서 자라는 생명력
  ② 아름답지만 짧다 — 볼모의 운명. 언제든 꺾일 수 있다
  ③ 아버지 바투가 직접 지은 이름
     → "네가 눈밭에서도 피어나길 바란다"
     → 그런데 그 아버지가 5년 전 딸을 볼모로 보냈다
     → 이름과 행동의 모순이 아이러니

  별호가 없는 이유:
  · 17세. 아직 강호에 발을 들이지 않았다.
  · 별호는 "남이 붙여주는 것"
  · "나는 아직 나를 정의할 말을 찾지 못했다"
  · 게임 진행 중 플레이어의 선택에 따라 별호가 결정되는 시스템
    → "빙원의 칼날 (氷原刃)" or "설중매 (雪中梅)" or "혈화 (血花)" 등
    → 어떤 인간이 되는가에 따라 세상이 다른 이름을 붙인다
```

### 인내 35의 의미 — 설화의 위험성

```
소연 인내 55: "12년을 참았다. 더 참을 수 있다. 하지만 원하지 않는다."
  → 통제된 분노. 언제 터뜨릴지를 계산한다.

명경 인내 88: "30년을 참았다. 더 참을 수 있다. 하지만 한계가 온다."
  → 의무에 의한 인내. 몸이 먼저 무너질 수 있다.

야율설화 인내 35: "5년을 참았다. 더 이상 못 참겠다."
  → 통제되지 않는 분노. 언제 터질지 본인도 모른다.

  위험한 조합:
  의지 65 (높음) + 인내 35 (낮음) = 
  "하고 싶은 것은 반드시 하는데, 
   참아야 할 때 참지 못한다"
  → 이것이 천마신교의 무공과 맞물리면 더 위험해진다.
     천마심법은 "분노를 힘으로 바꾸는" 무공.
     분노가 많을수록 강해진다.
     강해질수록 분노를 놓지 못한다.
     → 성장의 축복이자 저주.
```

## 3. 성향(性) — Big Five 성격 (심리/성격 Aggregate)

| 성격 축 | 수치 | 해석 |
|---------|------|------|
| 개방성 (Openness) | 0.7 | 높음. 초원에서 자란 넓은 시야 + 볼모 생활의 다양한 문화 접촉 |
| 성실성 (Conscientiousness) | 0.5 | 보통. 수련에는 열심이나 규율에는 반항적 |
| 외향성 (Extraversion) | 0.6 | 보통~높음. 말이 많진 않으나 숨기지도 않음. 직접적 |

| 신경증 (Neuroticism) | 0.7 | **높음**. 정체성 혼란 + 억눌린 분노 + 버림받았다는 감각 |

```

      '강한 자가 옳다'고 말하니까."

  "규칙은 싫지만 목표는 있다"
  → 천마신교 수련을 빼먹지 않는 이유:
     "강해져야 한다. 볼모가 아닌 내가 되려면."

  소연과의 성격 대비:
  ┌───────────┬──────────┬──────────┐

## 4. 신념(信) — WuxiaValues 가치관 (심리/가치관 Aggregate)

| 가치관 | 수치 | 해석 |
|--------|------|------|
| 충 (忠) | 0.2 | **극저**. 충성할 대상에 대한 회의. "아버지? 대진? 천마?" |
| 의 (義) | 0.5 | 중간. 의리의 개념은 있으나, 받아본 적이 없어서 미지수 |
| 효 (孝) | 0.4 | 복잡. 아버지를 원망하면서도 버리지 못함 |
| 복수 (復) | 0.6 | 높음. "나를 볼모로 보낸 세상"에 대한 분노 |
| 야망 (望) | 0.7 | **높음**. "누구의 딸도, 누구의 볼모도 아닌 내가 되겠다" |

```
가치관 구조 — "왜 설화는 천마신교에 끌렸는가":

  충(0.2)이 기반이다:
  "아버지는 나를 대진에 볼모로 보냈다.
   북원을 위해서. 평화를 위해서.
   ...나를 위해서는 아무것도 하지 않았다.
   충성? 누구에게? 나를 버린 아버지에게?
   나를 가둔 대진에게?"
  → 충성의 대상이 없다 = 자유이자 공허

  야망(0.7)이 방향이다:
  "내가 원하는 것은 왕좌가 아니다.
   아버지의 왕좌도, 대진의 왕좌도.
   나는 그냥... 나이고 싶다.
   아무도 나를 도구로 쓸 수 없는 '나'."
  → 남궁혁의 야망(0.8)이 "왕국"이라면,
     설화의 야망(0.7)은 "자아"
  → 더 작지만, 더 절실하다.

  효(0.4)가 만드는 균열:
  "아버지를 미워한다. 미워해야 한다.
   그런데... '눈 속에 피는 꽃'이라는 이름을
   지어준 사람도 아버지다.
   초원에서 말 타는 법을 가르쳐준 사람도.
   볼모로 보내기 전날 밤,
   아버지의 눈이 빨갛게 충혈되어 있었다.
   ...그게 미워하기 어렵게 만든다."

  복수(0.6)의 대상이 모호하다:
  "나를 볼모로 보낸 것은 아버지지만,
   볼모 제도를 만든 것은 대진이고,
   이 세상의 규칙을 만든 것은 강자들이다.
   누구에게 분노해야 하지?
   ...전부에게?"
  → 천마신교의 사상: "강한 자가 규칙을 만든다"
  → 설화의 해석: "그렇다면 내가 강해지면 규칙을 바꿀 수 있다"
  → 위험하지만 논리적인 귀결

  의(0.5)가 미래를 결정한다:
  "의리를 받아본 적이 없는 사람이
   의리를 처음 받으면 어떻게 변하는가?"
  → 플레이어가 설화에게 진심으로 의리를 보여주면
     이 수치가 급변할 가능성이 가장 높은 캐릭터
  → 반대로, 배신당하면 의(0.5→0.1)로 추락
  → 가장 극적으로 변할 수 있는 가치관
```

## 6. 배경 서사

### 3줄 요약

> 북원 늑대왕 바투의 외동딸. 12세에 대진과의 평화 담보로 볼모가 되었다.  
> 대진 낙양에서 5년을 갇혀 지내던 중, 3대 천마에게 발견되어 비밀리에 무공을 배운다.  
> 아버지의 딸인가, 대진의 볼모인가, 천마의 제자인가 — 아직 "나"를 찾지 못한 17세.

### 상세 연표

| 시기 | 나이 | 사건 | 심리 변화 |
|------|------|------|-----------|
| 17년 전 | 0세 | 북원 왕궁 출생. 바투의 외동딸 | "초원의 공주" |
| 12~7년 전 | 5~10세 | 초원에서 자유롭게 성장. 말 타기, 활쏘기, 매사냥 | "세상에서 가장 넓은 곳" |
| 6년 전 | 11세 | 대진과 북원의 국경 충돌. 전쟁 위기 | 아버지가 매일 전쟁 준비하는 모습 |
| 5년 전 | 12세 | **대진-북원 평화 조약. 볼모로 대진 낙양에 보내짐** | "아버지가 나를 버렸다" |
| 5~3년 전 | 12~14세 | 낙양 볼모 거처에서 감시 속 생활. 궁정 교육 강제 | 분노 → 체념 → 분노의 반복 |
| 3년 전 | 14세 | **3대 천마가 비밀리에 접촉. "강해지고 싶은가?"** | "예." — 인생의 전환점 |
| 3~현재 | 14~17세 | 천마기공 비밀 수련. 낮에는 볼모, 밤에는 수련 | "강해지면 자유로워진다" |
| 현재 | 17세 | 게임 시작. 자유도시에 천마신교 임무로 파견 | "처음으로 바깥 세상에 나왔다" |

```
야율설화의 인생 — 세 개의 선:

  아버지의 딸 (북원):
  ──────────────────────────────────────
  0~12세: 초원의 자유 ──→ 12세: 버림받음
  ──→ 17세: 아버지의 기억이 점점 흐려진다
  = 끊어진 선. 다시 이을 것인가?

  대진의 볼모 (대진):
  ──────────────────────────────────────
  12세: 낙양 도착 ──→ 14세: 체념
  ──→ 17세: 볼모 생활 5년차. 자유도시 파견
  = 감옥의 선. 끊어버릴 것인가?

  천마의 제자 (천마신교):
  ──────────────────────────────────────
  14세: 천마기공 입문 ──→ 15세: 3층 돌파
  ──→ 17세: "자유를 위한 힘"이 "힘을 위한 힘"이 되기 직전
  = 올라가는 선. 어디까지 올라갈 것인가?

  세 선의 교차점이 "자유도시" (게임 시작).
  처음으로 세 정체성이 동시에 시험받는 장소.
  → 아버지의 적(대진)도 있고,
     천마의 임무도 있고,
     그리고 자기와 같은 나이의 누군가(플레이어)도 있다.
```

## 7. 핵심 관계 (관계 도메인)

| 대상 | 관계 유형 | 감정 | 복잡도 |
|------|----------|------|--------|
| **플레이어** | 동갑 + "이용당한 아이들" | 경계 → 호기심 → 동지/연인? | ★★★★★ |
| **바투 (아버지)** | 혈육 + 버린 자 | 원망 + 그리움 + 이해할 수 없는 사랑 | ★★★★★ |
| **3대 천마 (사상적 스승)** | 사제(師弟) + 이용? | 존경 + 의심 ("나를 키우는 이유가 뭐지?") | ★★★★★ |
| **조고 (대진 권신)** | 감시자/볼모 관리자 | 혐오. "나를 새장에 가둔 자" | ★★★★ |
| **소연** | 미대면. 동세대 | 만나면? "같은 나이대인데 완전히 다른 삶" | ★★★ |
| **명경** | 간접. 정파 대표 | "정파가 말하는 정의란 것도 볼모 제도를 막지 못했다" | ★★ |
| **남궁혁** | 적대 (국경 충돌) | "아버지의 적. 그리고 화산파를 멸한 자" | ★★★ |
| **당무괴** | 잠재적 위협 | 모름. 하지만 천마기공의 마기를 감지할 수 있는 자 | ★★ |

```
야율설화의 관계 구조 — "세 개의 줄에 매달린 인형":

  [바투] ──── 피의 줄 ──── [설화] ──── 사제의 줄 ──── [3대 천마]
   (아버지)                   │                        (스승)
   "돌아오너라"               │                    "더 강해져라"
                              │
                     볼모의 줄 (끊고 싶은 줄)
                              │
                           [대진/조고]
                        "넌 담보물이다"

  핵심: 세 개의 줄 중 어느 것을 끊느냐에 따라
        설화의 미래가 완전히 달라진다.

  ① 피의 줄을 끊으면 → 아버지를 부정. 고향을 잃음.
     → 천마신교 완전 합류 루트
  ② 볼모의 줄을 끊으면 → 대진과 적대. 전쟁 재발 가능.
     → 북원 귀환 루트 or 자유도시 독립 루트
  ③ 사제의 줄을 끊으면 → 힘을 잃음. 하지만 자유.
     → 정파 합류 루트 or 새로운 길

  그리고 플레이어는...
  [플레이어] ──── ???? ──── [설화]
  "세 개의 줄 말고 네 번째 줄.
   이 줄은 누가 매단 것이 아니라
   스스로 잡은 것."
```

```
바투에게 설화는:

     딸을 보내는 자기 자신.

  북원 장수: "왕이시여, 공주님께서 낙양에서 편지를..."

  "영웅" + "배신자" + "유일한 가족"
  → 12세 이전: 세상에서 가장 강한 아버지
  → 12세 이후: 나를 버린 아버지
  → 17세: "...미워해야 하는데, 미워하려면 잊어야 하고,
           잊으려면 초원의 바람 냄새를 잊어야 하는데,

  대화 예시 (게임 후반, 재회 시):
  바투: "...컸구나."
  설화: (아무 말도 하지 못한다.)
  바투: "강해졌느냐?"
  설화: "...네."
  바투: "그래야지."
        (등을 보인다. 어깨가 떨리는 것을 숨긴다.)
  설화: "...아버지."
  바투: (멈춘다. 돌아보지 않는다.)

  바투: "...눈밭에서도 피어나라고."
  설화: "피었어요."

```

  3대 천마: "네가 정하는 것이다.

  → 이 "내가 정해줄 수도 있지만"이 함정인지 배려인지

## 8. 비밀 (Secret) — 플레이어가 발견할 것

### 비밀 ① — 볼모 조약의 진짜 중개자

```
공식 기록: "대진과 북원이 평화 조약을 맺었다"
설화가 아는 것: "아버지가 나를 보냈다"

진실:
  볼모 조약을 중개한 것은 조고(십상시).
  조고가 양쪽을 조종하여 전쟁 위기를 만들고,
  "볼모 교환"이라는 해법을 제시했다.

  조고의 의도:
  ① 북원 왕녀를 볼모로 확보 → 바투를 견제하는 패
  ② 볼모를 통해 북원 내부 정보 수집
  ③ 필요시 설화를 "사고"로 처리하여 북원과 전쟁 명분 확보

  → 바투는 "조고에게 속은 것"일 가능성
  → 전쟁 위기 자체가 조작이었다면?
  → 설화가 이 사실을 알면?
     "아버지가 나를 버린 것이 아니라,
      아버지도 속았다면...?"
     → 분노의 방향이 완전히 바뀐다.
     → 효(0.4 → 0.6+) 상승, 복수(0.6) 대상이 조고로 확정
```

### 비밀 ② — 3대 천마의 진짜 목적

```
3대 천마가 설화를 키우는 이유:

  표면: "재능있는 제자를 키운다"
  
  진짜 이유 (3가설):

  가설 A: "바투 견제" (정치적)
    → 설화를 천마신교 무인으로 성장시키면
       북원 내부에 친(親)천마 세력 구축 가능
    → 설화가 북원 왕위를 이으면 천마신교의 동맹
    → 이 경우 3대 천마는 "설화를 이용하는 자"

  가설 B: "계승자 양성" (진심)
    → 3대 천마 자신이 늙어가고 있다
    → 천마신교의 다음 세대가 필요
    → 설화의 분노와 재능이 천마의 자질과 맞음
    → "이 아이가 4대 천마가 될 수 있다"
    → 이 경우 3대 천마는 "진심으로 키우는 자"

  가설 C: "구원" (개인적)
    → 3대 천마 자신도 볼모/파문 출신
    → 자신의 과거를 설화에게서 보았다
    → "나는 구해주는 사람이 없었다.
       이 아이에게는 내가 있다."
    → 이 경우 3대 천마는 "불완전한 구원자"

  → 조고 열전·남궁혁 열전과 마찬가지로
    플레이어의 탐색 루트에 따라 진실이 달라진다.
```

### 비밀 ③ — 천마기공의 대가

```
천마기공 5층 이상의 부작용:

  3층까지: 분노를 내력으로 전환. 부작용 경미.
  5층부터: 마기(魔氣) 각성. 
    → 분노뿐 아니라 모든 부정적 감정이 힘이 됨
    → 슬픔, 증오, 절망, 질투... 
    → 강해지지만 감정의 균형이 무너진다
    → "행복하면 약해지는" 역설

  설화의 위기:
  · 현재 3층. 곧 5층에 도달할 시점
  · 5층에 들어서면 감정 제어가 극도로 어려워짐
  · 인내(35)가 낮은 설화에게 치명적
  · → 제어 실패 시: 인격 변질 ("마화(魔化)")
  · → 마화된 설화는 NPC가 아니라 "보스"가 된다

  플레이어의 선택:
  ① 설화를 도와 천마기공을 제어한다 → 동반자 루트
     (방법: 명경의 의술 + 플레이어의 감정적 지지)
  ② 천마기공을 봉인한다 → 설화의 힘이 크게 약화
     → 설화의 분노: "내 힘마저 빼앗으려고?"
  ③ 방치한다 → 마화 루트 → 설화 보스전
  ④ 다른 무공으로 대체한다 → 극난이도 루트
     (정파 심법 전수? 플레이어가 직접 가르침?)

  서사적 의미:
  "분노로 강해지는 것은 쉽다.
   분노를 놓고도 강할 수 있는가?"
  → 이것이 설화의 중심 질문이자
     천마신교 전체의 철학적 한계
```

                  (호감도 +3)
      ② "천마신교?"
         → 설화: (경계심 급상승.)
                  "그래서? 정파 편이야?"
                  (도에 손을 올린다.)
                  (호감도 -5, 긴장 상승)
      ③ "싸움 잘하네."
         → 설화: "..."
                  (처음으로 제대로 플레이어를 본다.)
                  "...너도 뭔가 들고 있네."
                  (혈매화검을 힐끗.)
                  (호감도 +5)
      ④ (말없이 지나간다)
         → 설화: (등 뒤에서)
                  "...흥."
                  (하지만 기억한다.)
                  (호감도 ±0, 다음 만남 시 인식)
      ⑤ [직접 입력: ________________]
         → LLM NPC가 설화의 성격에 맞춰 응답
```

## 10. LLM 대사 생성 가이드 (AI 도메인)

### 말투 규칙

```
1. 짧고 직접적. 돌려 말하지 않는다.
   ✗ "그것에 대해서 생각해 볼 필요가 있을 것 같아."
   ✓ "싫어." / "좋아." / "몰라."
   
   → 소연이 "웃으면서 돌려 말하는" 유형이라면,
     설화는 "안 웃고 직선으로 말하는" 유형.

2. 질문을 많이 한다. (공격적 질문)
   "왜?" "그래서?" "그게 뭐?" "네가 뭔데?"
   → 볼모 생활에서 체득: 질문하는 자가 주도권을 잡는다.
   → 동시에 진짜 알고 싶기도 하다. 세상에 대한 호기심.

3. 자연물로 비유한다. (초원의 아이)
   ✗ "위험한 상황이다"
   ✓ "바람 방향이 바뀌었어." / "늑대 냄새가 나."
   → 중원 사람들의 비유(문학적)와 다름
   → 자연 현상, 동물, 계절로 감정을 표현

4. 감정이 격해지면 북원어 단어가 섞인다.
   평소: "됐어. 가자."
   분노: "됐어. ...(북원어 욕). 가자."
   슬픔: "...(북원어 감탄사). ...아무것도 아냐."
   → LLM에게 [북원어]로 태그 지시, 실제 생성은 안 함
   → 플레이어가 "지금 뭐라고 한 거야?"라고 물으면
     "...가르쳐줄까? 가르쳐주면 써먹을 거잖아."

5. 금기어: "볼모", "인질", "담보" — 타인이 쓰면 즉시 적대
   대신 자기가 쓸 때는: "잡혀 있다", "갇혀 있다"
   → 자기 입으로는 말할 수 있지만, 남이 규정하면 안 된다.
   → 이것이 정체성 문제의 핵심:
      "나를 정의하는 것은 나여야 한다"
```

### 기억 스트림 시드 (초기 반성 3개)

```
기억 #1 (중요도: 10/10):
  관찰: "12살 때, 아버지가 나를 대진 사신에게 넘겼다.
         아버지의 눈이 빨갛게 충혈되어 있었다.
         마차가 출발할 때 뒤를 돌아보지 말라고 했다."
  반성: "뒤를 돌아봤다.
         아버지가 서 있었다. 움직이지 않았다.
         작아지는 아버지를 마지막까지 봤다.
         ...그때 아버지가 울었을까?
         5년이 지나도 답을 모르겠다."

기억 #2 (중요도: 9/10):
  관찰: "14살 때, 밤에 누군가가 방으로 왔다.
         '강해지고 싶은가?' 물었다.
         '예'라고 대답했다. 한 번도 망설이지 않았다."
  반성: "천마(天魔)라고 했다.
         사파의 수장. 무림의 적.
         그래서 뭐? 나에게는 처음으로
         '너는 어떻게 하고 싶으냐'고 물어본 사람이다.
         아버지도, 대진도, 아무도 물어보지 않았던 걸."

기억 #3 (중요도: 8/10):
  관찰: "자유도시에 처음 왔다.
         하늘이 넓다. 벽이 없다.
         (정확히는 벽이 있지만, 낙양의 벽보다는 낮다.)"
  반성: "이것이 '자유'인가?
         아직 모르겠다. 
         다만 숨은 좀 쉬어진다.
         ...그런데 천마님의 임무가 있다.
         자유라는 게 원래 이렇게 복잡한 건가?"
```

### 행동 결정 예시 (Personality × Values)

```
상황: "혈매화검을 든 동갑내기(플레이어)가 자유도시에서 눈에 띈다"

  ① 가치관 확인:
     야망(0.7) → "저 검... 뭔가 특별하다"
     복수(0.6) → (이 경우 해당 없음)
     효(0.4)  → (이 경우 해당 없음)
     충(0.2)  → (해당 없음. 충성할 대상 없음)
     의(0.5)  → "적인지 아군인지 아직 모름"

  ② 성격 확인:
     개방성(0.7)  → "호기심. 접근해보자."
     친화성(0.3)  → "그러나 마음을 열지는 않는다."
     외향성(0.6)  → "직접 가서 말을 걸겠다."
     신경증(0.7)  → "경계. 상대의 의도를 먼저 파악."

  ③ 최종 결정:
     "나이가 비슷하네. 그 검은 뭐야."
     (직접적 접근 + 질문으로 시작 + 방어적 자세)
     → 개방성(0.7) + 외향성(0.6)이 접근을 결정
     → 친화성(0.3) + 신경증(0.7)이 방식을 결정
     → "다가가되, 열지는 않는다"
```

## 11. 퀘스트 연결

### 설화 관련 퀘스트 라인

```
┌───────────────────────────────────────────────────────┐
│  메인 퀘스트: "자유의 대가"                            │
│                                                       │
│  Phase 1: 자유도시에서의 만남                          │
│  · 설화와 반복 접촉. 신뢰 or 적대 루트 분기            │
│  · 천마신교 임무와 설화의 개인적 갈등 발견              │
│                                                       │
│  Phase 2: 볼모의 진실                                  │
│  · 비밀 ① 발견: 조고가 볼모 조약을 조작했다            │
│  · 설화에게 알린다 or 숨긴다                           │
│  · → 알리면: 설화의 분노 방향 전환 (아버지→조고)       │
│  · → 숨기면: 나중에 발각 시 관계 파탄                  │
│                                                       │
│  Phase 3: 천마기공의 한계                              │
│  · 설화의 마기 각성 위기                               │
│  · 비밀 ③: 5층 이상의 부작용                          │
│  · 명경의 의술로 제어 가능 (명경 퀘스트와 교차)        │
│  · or 봉인 (설화 약화) or 방치 (마화)                  │
│                                                       │
│  Phase 4: 세 개의 줄                                   │
│  · 최종 분기: 설화의 정체성 선택                       │
│  · 루트 A: 북원 귀환 — 바투와 화해, 공주로서의 삶      │
│  · 루트 B: 천마 계승 — 4대 천마, 사파의 길             │
│  · 루트 C: 자유인 — 어디에도 속하지 않는 새로운 길    │
│  · 루트 D: 마화 — 제어 실패, 보스전                    │
│  · 루트 E: 동반자 — 플레이어와 함께 (연애 루트)       │
└───────────────────────────────────────────────────────┘

다른 NPC 퀘스트와의 교차점:

  설화 × 명경:
  "천마기공의 부작용을 치료할 수 있는 유일한 사람"
  → 사파 제자(설화)를 정파 장문인(명경)이 치료하는 아이러니
  → 명경의 의(0.9): "사파든 정파든, 아픈 아이를 놔둘 수 없다"
  → 이 만남이 명경의 서량 고립 퀘스트에도 영향

  설화 × 소연:
  "동세대 여성. 정반대의 대처법"
  → 소연: 참고, 숨기고, 웃으면서 정보를 모은다
  → 설화: 참지 못하고, 드러내고, 도를 뽑는다
  → 만나면? "너 왜 항상 웃고 있어?" "너 왜 항상 화나 있어?"
  → 서로의 약점을 보완하는 관계 가능

  설화 × 남궁혁:
  "아버지의 적이자, 화산파를 멸한 자"
  → 설화가 남궁 왕국에 들어가면 국경 분쟁 퀘스트
  → 남궁혁은 설화를 "바투의 패"로 경계
  → 플레이어가 중재할 수 있는가?

  설화 × 조고:
  "볼모 제도의 기획자"
  → 비밀 ① 발견 후, 설화의 복수 대상이 조고로 확정
  → 조고에게 설화는 "폐기할 수도 있는 패"
  → 플레이어의 조고 대항 퀘스트에 설화가 합류 가능
```

## 12. 종합 — 야율설화라는 인물

```
한 문장 요약:
  "아버지가 보낸 눈밭에서,
   스승이 준 불꽃으로,
   자기만의 꽃을 피우려는 열일곱 살."

와호장룡 대응:
  옥교룡(玉嬌龍) — 규범에 갇힌 소녀가 자유를 향해 뛰어드는 이야기.
  다만 설화는 옥교룡보다 더 거칠고, 더 분노하고, 더 외롭다.
  옥교룡에게는 적어도 "돌아갈 집"이 있었다.
  설화에게는 그마저도 빼앗겼다.
  → 설화에게 "돌아갈 곳"을 만들어주는 것이 플레이어의 역할일 수 있다.

4인 적대자와의 대비:
  조고 (50대)  — "세상을 바꾸려는 자" — 수단: 책략
  남궁혁 (42)  — "세상을 세우려는 자" — 수단: 검
  당무괴 (53)  — "세상을 이해하려는 자" — 수단: 독
  바투 (40대)  — "세상에서 살아남으려는 자" — 수단: 전쟁
  
  이 네 명의 "어른"이 만든 세상에서
  설화는 "이용당한 아이"다.
  플레이어도, 소연도 마찬가지다.
  
  → "어른들의 전쟁에서 살아남은 아이들이,
     이제 자기 이야기를 쓰기 시작한다"
  → 이것이 칠국춘추의 핵심 테마이고,
     설화는 그 테마의 가장 격렬한 체현이다.

4인 청년 구조에서의 위치:
  ┌─────────────────────────────────────────────────┐
  │  플레이어 (17) — 빈 캔버스. 모든 방향 가능.      │
  │  소연 (23)     — 복수와 계승 사이.               │
  │  야율설화 (17) — 정체성에 갇힌 자.               │
  │  명경 (49)     — 의무에 갇힌 자.                 │
  │                                                  │
  │  설화의 고유 구조:                                │
  │  세 개의 줄: 아버지 / 볼모 / 스승                │
  │  → 소연은 "끊어진 것을 이으려 한다" (개방 재건)   │
  │  → 설화는 "묶인 것을 끊으려 한다" (자유)          │
  │  → 방향이 정반대, 그래서 서로에게 강렬한 거울     │
  │                                                  │
  │  플레이어와의 고유 연결:                          │
  │  "동갑. 이용당한 아이들. 그리고..."               │
  │  플레이어: 과거를 잃은 자 (기억이 없다)           │
  │  설화: 미래를 잃은 자 (자유가 없다)               │
  │  → "너는 어제를 모르고, 나는 내일을 모른다"       │
  │  → 이 두 사람이 함께하면 현재를 살 수 있다        │
  └─────────────────────────────────────────────────┘

게임적 가치:
  ① 전투 파트너 — 육체 능력 최강의 청년 NPC
  ② 연애 루트 — 감정적 깊이가 가장 강렬한 관계
  ③ 분기 허브 — 천마신교/북원/자유 3갈래 선택
  ④ 동반 성장 — 플레이어와 함께 성장하는 유일한 동갑 NPC
  ⑤ 마화 보스 — 관계 실패 시 가장 비극적인 보스전
  ⑥ 테마 체현 — "자유란 무엇인가"의 가장 절실한 질문자
  ⑦ 다중 퀘스트 교차 — 명경/소연/남궁혁/조고 모두와 연결
  ⑧ 별호 시스템 — 플레이어 선택에 따라 이름이 달라지는 유일한 NPC
```
