OCC · 복합 Case 複合

Action과 Event가 동시에 채워질 때, 엔진이 둘을 합쳐 Gratitude/Anger/Gratification/Remorse를 자동 생성한다. 게임이 "이건 분노야"라 지정하지 않는다.

1발동 조건

domain/emotion/appraisal/mod.rs · process()

situation.action과 situation.event가 둘 다 Some일 때만 compound::appraise가 호출된다. 행위자 구분은 action.agent_id.is_none()으로 판정 — is_self.

situation.action.is_some() && situation.event.is_some() └─ compound::appraise(state, is_self = action.agent_id.is_none(), desc)

24개 복합 감정

행위자복합 감정= 평균( 구성1 , 구성2 )의미
자기
is_self=true		Gratificationavg(Pride, Joy)내 좋은 행동이 좋은 결과를 낳음
Remorseavg(Shame, Distress)내 나쁜 행동이 나쁜 결과를 낳음
타인
is_self=false		Gratitudeavg(Admiration, Joy)타인의 좋은 행동이 나에게 좋은 결과
Angeravg(Reproach, Distress)타인의 나쁜 행동이 나에게 나쁜 결과
helpers.rs add_compound 복합 강도 = ( 구성1 강도 + 구성2 강도 ) / 2   (둘 다 > 0 일 때만)
구성 감정은 먼저 존재해야 한다 복합 감정은 이미 계산된 구성 감정의 강도를 읽어 평균한다(state.intensity_of). 그래서 process()에서 event·action을 먼저 appraise한 뒤 compound가 호출된다. 구성 감정 중 하나라도 0이면 복합 감정은 생성되지 않는다.
누적 주의 · EmotionState.add 같은 감정이 여러 경로로 더해지면 EmotionState.add가 강도를 합산 후 0~1 클램프한다. 예: Distress가 Well-being에서 한 번, 다른 맥락에서 또 더해지면 누적된다. 복합의 입력이 되는 Reproach·Distress도 이 누적된 최종값을 본다. context는 최초 1회만 기록(first-write-wins).

3무협 워크드 예시

와호장룡 — 신뢰하던 사형제가 밀고했고(action) 그 결과 독에 당했다(event)

action: agent_id=Some, pw=−0.8, trust_mod=1.3 · event: d=−0.7 · weight=1.0 가정

Reproach = 0.8 × 1.0 × (1.0×1.3) = 1.04 → clamp 1.00 Distress = 0.7 × 1.0 × 1.0 = 0.70 is_self=false → Anger = (1.00 + 0.70) / 2 = 0.85

한 장면에서 Reproach·Distress·Anger가 각각 다른 강도로 동시에 깔린다. Reproach·Distress도 그대로 남고, Anger가 추가된다(별개 OCC 감정).

곽정이 스스로 의로운 결단을 내려 양양을 지켰다 (자기 · 선행+호결과)

action: agent_id=None, pw=+0.9 → Pride · event: d=+0.8 → Joy

Pride = 0.9 × w · Joy = 0.8 × w is_self=true → Gratification = avg(Pride, Joy)

pub fn process<P: AppraisalWeights>(personality: &P, situation: &Situation,
    dialogue_modifiers: &RelationshipModifiers) -> EmotionState {
    let mut state = EmotionState::new();

    if let Some(event) = &situation.event {
        event::appraise(personality, &mut state, event);
    }
    if let Some(action) = &situation.action {
        action::appraise(personality, &mut state, dialogue_modifiers, action);
    }
    if let Some(object) = &situation.object {
        object::appraise(personality, &mut state, object);
    }
    if let (Some(action), Some(_)) = (&situation.action, &situation.event) {
        compound::appraise(&mut state,
            action.agent_id.is_none(), &situation.description);
    }
    state
}

pub fn appraise(state: &mut EmotionState, is_self: bool, desc: &str) {
    if is_self {
        add_compound(state, EmotionType::Gratification,
                     EmotionType::Pride, EmotionType::Joy, desc);
        add_compound(state, EmotionType::Remorse,
                     EmotionType::Shame, EmotionType::Distress, desc);
    } else {
        add_compound(state, EmotionType::Gratitude,
                     EmotionType::Admiration, EmotionType::Joy, desc);
        add_compound(state, EmotionType::Anger,
                     EmotionType::Reproach, EmotionType::Distress, desc);
    }
}

// helpers.rs
pub fn add_compound(state: &mut EmotionState, target: EmotionType,
    c1: EmotionType, c2: EmotionType, ctx: &str) {
    let v1 = state.intensity_of(c1);
    let v2 = state.intensity_of(c2);
    if v1 > 0.0 && v2 > 0.0 {
        let val = (v1 + v2) / 2.0;
        state.add(Emotion::with_context(target, val, ctx));
    }
}
