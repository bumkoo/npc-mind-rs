# Generative Agents 핵심 요약 (칠국춘추 NPC AI 참조)

> 원본: Park et al. "Generative Agents: Interactive Simulacra of Human Behavior" (UIST '23)
> 목적: 칠국춘추 NPC AI 아키텍처 설계의 핵심 참조 자료

---

## 1. 핵심 아키텍처: 3대 구성요소

```
                              ┌─────────┐
                              │  Plan   │
                              └────┬────┘
                                   │
              ┌────────────────────┼────────────────────┐
              │         Generative Agent Memory         │
              │                                         │
 Perceive ───►│  Memory Stream ──► Retrieve ──► Retrieved Memories ──► Act
              │                                         │
              │                    ▲                     │
              │                    │                     │
              │              ┌─────┴─────┐              │
              │              │  Reflect  │              │
              └──────────────┴───────────┴──────────────┘
```

### 1.1 Memory Stream (기억 흐름)
- 에이전트의 모든 경험을 자연어로 기록하는 장기 기억 데이터베이스
- 각 기억 객체 구성: `자연어 설명` + `생성 타임스탬프` + `최근 접근 타임스탬프`
- 기본 단위: **관찰(Observation)** - 에이전트가 직접 인지한 사건

### 1.2 Reflection (성찰)
- 관찰을 바탕으로 더 높은 수준의 추상적 추론 생성
- 트리거 조건: 최근 사건의 중요도 합계가 임계값(150) 초과 시
- 실행 빈도: 하루 2~3회
- 성찰 트리 구조: 리프 노드(관찰) → 중간 노드(1차 성찰) → 상위 노드(고차 성찰)

### 1.3 Planning (계획)
- 일일 계획 → 시간별 분해 → 구체적 행동으로 재귀적 분해
- 환경 변화나 새로운 정보에 따라 **재계획(replan)** 수행

## 2. Memory Retrieval (기억 검색) 공식

```
score = α_recency × recency + α_importance × importance + α_relevance × relevance
```

세 가지 점수를 [0, 1] 범위로 min-max 정규화 후 가중 합산 (논문에서 모든 α = 1)

### 2.1 Recency (최신성)
- 지수 감쇠 함수: 마지막 접근 이후 경과 시간 기반
- 감쇠 계수: 0.995 (게임 내 시간 기준)

### 2.2 Importance (중요도)
- LLM에게 직접 1~10 점수를 요청
- 프롬프트 예시:
```
1(일상적: 양치, 침대 정리)부터 10(극적: 이별, 합격 통보)까지,
다음 기억의 중요도를 평가하시오.
기억: 시장에서 식료품 구매
점수: <fill in>
```
- "방 청소" → 2점, "좋아하는 사람에게 고백" → 8점

### 2.3 Relevance (관련성)
- 기억의 임베딩 벡터와 현재 상황 쿼리 벡터 간 코사인 유사도
- 벡터 DB로 구현 가능

## 3. 칠국춘추 적용 매핑

| Generative Agents 개념 | 칠국춘추 적용 |
|---|---|
| Memory Stream | 벡터DB에 NPC 경험 기록 저장 |
| Observation | NPC의 인지 이벤트 (DomainEvent) |
| Reflection | NPC 성찰 시스템 (성격/신념 변화 트리거) |
| Planning | NPC 일일 행동 계획 (무공 수련, 임무 등) |
| Retrieval Score | recency + importance + relevance 가중 합산 |
| Importance Scoring | Local LLM으로 중요도 1~10 평가 |
| Relevance | 벡터DB 유사도 검색 |
| 25 Agents in Smallville | 50~200 NPC in 칠국춘추 |

---

## 4. 에이전트 초기화 (Seed Memory)

각 에이전트는 한 문단 분량의 자연어 설명으로 초기화:
- 이름, 직업, 성격
- 관계 (가족, 친구, 적)
- 현재 상태와 목표

→ 칠국춘추: NPC 전기(biography) 12섹션 템플릿이 이 역할 수행

---

## 5. 대화 시스템

- 에이전트가 다른 에이전트의 근처에 있으면 대화 가능성 판단
- 대화 시작 조건: 기억 검색 → 관련 기억 존재 + 대화 의향
- 대화 내용은 Memory Stream에 저장 → 이후 Reflection 재료

## 6. 실험 결과 (Ablation Study)

| 조건 | 신뢰도 점수 (μ) |
|---|---|
| **전체 아키텍처** | **29.89** |
| 성찰 제거 | 26.88 |
| 성찰+계획 제거 | 25.64 |
| 인간 작성 | 22.95 |
| 기억+계획+성찰 모두 제거 | 21.21 |

핵심 교훈: Memory + Reflection + Planning 세 요소가 모두 있어야 가장 신뢰할 수 있는 행동 생성

## 7. 핵심 프롬프트 패턴

### 7.1 성찰 생성 프롬프트
```
[NPC이름]에 대한 진술들:
1. [관찰/기억 1]
2. [관찰/기억 2]
...
위 진술에서 추론할 수 있는 5개의 고수준 통찰은?
(형식: 통찰 (근거: 1, 5, 3))
```

### 7.2 성찰 주제 선정 프롬프트
```
위 정보만으로, 진술의 주제에 대해 답할 수 있는
가장 중요한 3가지 고수준 질문은?
```

### 7.3 일일 계획 프롬프트
```
[NPC이름]의 특성과 최근 경험을 바탕으로,
오늘의 대략적인 일과를 계획하시오.
(시간별로 나누어 작성)
```

## 8. 주요 발견: 창발적 사회 행동

논문에서 관찰된 창발적 행동 (프로그래밍하지 않았지만 자연 발생):
- **정보 확산**: 한 에이전트가 알게 된 정보가 대화를 통해 마을 전체로 퍼짐
- **관계 형성**: 공통 관심사를 가진 에이전트끼리 자연스럽게 가까워짐
- **협력 조직**: 발렌타인 파티 기획이 여러 에이전트의 자발적 참여로 실현
- **의견 형성**: 선거 후보에 대한 토론이 에이전트 간 자연 발생

→ 칠국춘추에서 기대: 문파 내 파벌 형성, 무림 소문 확산, NPC 간 자발적 동맹/갈등

## 9. 성능 및 비용 고려사항

- 원본 구현: GPT-3.5-turbo 사용, 25명 에이전트
- 2일 시뮬레이션 → 수천 건의 LLM 호출
- 칠국춘추 적용 시:
  - Local LLM 사용으로 API 비용 제거
  - 50~200 NPC → 추론 최적화 필수 (배치 처리, 캐싱)
  - LLM 추론 500~3000ms → 코드 최적화보다 아키텍처 설계가 중요
